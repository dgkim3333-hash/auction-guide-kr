# auction-guide-kr

경매·공매 전용 — Claude 로 **나만의 경매 에이전트**를 만드는 입문 교재입니다.

경매 지식을 가르치는 교재가 아닙니다. Claude 데스크탑 앱에 **눈과 손(크롬 연결)** 을 달고,
**매주 스스로 물건 목록을 모아 다중선택 엑셀로 정리해 카톡으로 알려 주는 에이전트**를 코딩 없이 만듭니다.

**유료 경매정보 사이트 회원이 아니어도 됩니다.** 대법원 법원경매정보(무료)로 같은 실습을 하는 길을 [09단원](09_법원경매정보_무료경로.md)에 두었습니다.

## 확신도 라벨 — 이 저장소 공통

교재와 스킬 전체가 아래 **네 가지만** 씁니다. 답변에 라벨이 없으면 근거를 물어보세요.

| 라벨 | 뜻 |
|---|---|
| `[확정]` | 그 답변에서 원문·공식 출처로 직접 확인함. 출처와 조회일을 댈 수 있음 |
| `[검증필요]` | 아직 원문으로 확인 못 함. 기억·간접 검색에 기대 값 |
| `[추정]` | 통계·계수·가정으로 만든 예측. 사실이 아님 |
| `[정보부족]` | 확인하려 했으나 공개되지 않아 얻을 수 없음. 사유를 함께 적음 |

> [!NOTE]
> `[정보부족]` 은 「확인할 수 없었다」는 뜻이지 「안 했다」는 뜻이 아닙니다.
> 조회하면 되는 것에 이 라벨이 붙어 있으면 「그건 조회하면 되잖아」라고 되물으세요.
