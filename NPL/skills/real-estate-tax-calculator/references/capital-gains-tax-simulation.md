## 0. 가장 먼저 — 개인인가 법인인가

```
매입 주체 = 법인?
  YES → 3. 법인 분기 (계산 구조가 근본적으로 다르다)
  NO  → 1. 개인 분기
```

**개인과 법인은 「양도차익」의 정의부터 다르다.**

| | 개인 | 법인 |
|---|---|---|
| 과세 대상 | 양도소득 (양도가 − 취득가 − 필요경비 − 공제) | **토지등 양도소득 = 양도금액 − 양도 당시 장부가액** (§55의2⑥) |
| 세금 성격 | 양도소득세 (분류과세) | **법인세 본세 + 추가과세** (§55의2① 본문) |
| 장기보유특별공제 | 있음 | **없음** |
| 기본공제 | 있음 | **없음** |

법인에 개인 양도세 로직을 쓰면 크게 틀린다. 반대도 마찬가지다.

## 1. 개인 — 분기 순서

### 1-1. 자산 종류와 보유기간을 먼저 확정한다

```
보유기간 = 취득일 ~ 양도일          (소득세법 §104②)
  · 상속받은 자산      → 피상속인이 취득한 날을 취득일로 본다
  · 이월과세 대상(§97의2) → 증여자가 취득한 날

경매 낙찰의 취득일 = 매각대금 완납일 (잔금납부일). 낙찰일도 등기일도 아니다
```

**「1년 미만」인지 「1년 이상 2년 미만」인지가 세율을 가른다.** 잔금일을 하루 단위로 확인한다.

### 1-2. 미등기 양도인지 본다 — 여기서 끝날 수 있다

```
취득 등기를 하지 않고 양도했나?   (소득세법 §104①10 · §104③)
  YES → 미등기양도자산 세율 적용. 장기보유특별공제·기본공제 배제
        아래 분기를 더 볼 필요가 없다
  NO  → 1-3 으로
```

NPL·경매 맥락에서 **미등기 전매는 실무상 드물지만, 잔금만 내고 등기 없이 넘기는 구조**를
검토 중이라면 반드시 여기서 걸러야 한다.

### 1-3. 세율 후보를 「전부」 계산한다 — 하나만 고르지 마라

소득세법 §104① 본문 후단:

> 하나의 자산이 둘 이상의 세율에 해당할 때에는 **각각 계산한 산출세액 중 큰 것**을 세액으로 한다

```
후보 A — 단기보유 세율            (§104①2·3)
         자산이 주택·조합원입주권·분양권인지, 그 밖인지로 갈린다
후보 B — 기본세율                 (§55①, §104①1)
후보 C — 조정대상지역 다주택 중과  (§104⑦) — 해당할 때만
후보 D — 비사업용 토지 세율        (§104①8) — 해당할 때만
후보 E — 지정지역 비사업용 토지 가산 (§104④3) — 해당할 때만

세액 = MAX(해당하는 후보들)
```

**§104⑦ 후단이 특히 헷갈린다.** 조정대상지역 다주택 주택을 **2년 미만** 보유하고 양도하면:

```
세액 = MAX( 기본세율+중과율로 계산한 세액 , 단기보유 세율로 계산한 세액 )
```

「중과니까 중과율」도 「단기니까 단기율」도 아니고 **둘 다 계산해서 큰 쪽**이다.

### 1-4. 조정대상지역 다주택 중과의 적용 여부

§104⑦ 은 조문에 **살아 있다.** 다만 시행령으로 적용을 유예해 온 이력이 있다.

```
1. 물건 소재지가 조정대상지역인가?     → adjustment-areas.md 조회
2. 1세대 2주택인가 3주택 이상인가?     → 주택 수 판정 (분양권·입주권 포함 여부 주의)
3. 양도일 기준 유예가 살아 있는가?     → ★ 반드시 현재 시점 확인
```

**3번을 문서로 판단하지 마라.** 유예 종료일은 정책으로 바뀌어 왔다.
`korean-law` 로 소득세법 시행령을 조회하거나 web_search 로 확인하고, 못 하면 `[검증필요]` 로 둔다.
**유예 여부에 따라 세액이 20~30%p 달라진다** — 이 물건의 손익이 뒤집힐 수 있는 크기다.

### 1-5. 과세표준까지 내려가는 순서

```
① 양도가액
② − 취득가액                    ← 경매는 낙찰가(매각대금)
③ − 필요경비                    ← 취득세·등기비용·법무사·중개수수료·명도비·자본적지출
④ = 양도차익
⑤ − 장기보유특별공제            ← 보유 3년 미만이면 0. 중과 적용 시 배제
⑥ = 양도소득금액
⑦ − 기본공제 (연 단위, 인별)
⑧ = 양도소득 과세표준
⑨ × 세율 (1-3 의 MAX)
⑩ = 산출세액
⑪ + 지방소득세 = 산출세액 × 10%
⑫ + 농어촌특별세 = 감면세액 × 20%   ← 감면이 없으면 0
```

**③ 필요경비에 취득세를 반드시 넣는다.** NPL·경매는 취득세가 크므로 빠뜨리면 세금이 과대 계상된다.
**⑤ 는 보유 3년 미만이면 아예 0**이다. 단기 매각 시나리오에서 이 줄을 넣어 계산하면 틀린다.

### 1-6. 같은 해에 둘 이상 양도했으면

§104⑤ — 자산별로 따로 계산한 합계와, 과세표준을 합산해 기본세율로 계산한 금액 중 **큰 쪽**이다.
한 해에 여러 건을 정리하는 계획이면 이 조항을 반드시 적용한다. 물건 하나만 보면 놓친다.

## 2. 개인 — 자산 유형별 진입점 요약

```
주택 (부속토지 포함)
  └ 1년 미만 / 1~2년 / 2년 이상 → 각각 세율 후보 다름
  └ 조정대상지역 다주택이면 §104⑦ 후보 추가

상가·오피스·공장 (비주택 건물)
  └ 주택보다 단기 세율이 낮다. 주택 세율을 쓰지 마라

토지
  └ 비사업용 토지인가 먼저 판정 (§104의3)
  └ 비사업용이면 별도 세율표(§104①8) — 기본세율표가 아니다
  └ 지정지역이면 §104④3 가산까지

조합원입주권 · 분양권
  └ 분양권은 2년 이상 보유해도 별도 세율이 있다 (§104①1 괄호)
  └ 주택 수 판정에 포함될 수 있다 — 다주택 중과 판정 시 주의
```

## 3. 법인 — 분기 순서

### 3-1. 본세와 추가과세는 따로 계산해서 더한다

```
법인세 본세 = 과세표준(제13조) × 세율(제55조)      ← 법인 전체 소득 기준
추가과세    = 토지등 양도소득 × 아래 세율          ← 이 물건만 별도
최종        = 본세 + 추가과세
지방소득세  = (본세 + 추가과세) × 10%
```

**추가과세는 「이 물건 하나」에 붙는다.** 법인의 다른 소득과 통산하지 않는다.

### 3-2. 토지등 양도소득의 정의 (§55의2⑥)

```
토지등 양도소득 = 양도금액 − 양도 당시 장부가액
```

**개인의 「양도가 − 취득가 − 필요경비」와 다르다.** 장부가액은 감가상각 후 금액이므로
건물이 있으면 개인 계산보다 양도소득이 **커진다.** 개인 산식을 그대로 쓰면 과소 계상된다.

### 3-3. 추가과세 세율 판정 (§55의2①)

```
자산이 무엇인가?
  · 주택(부수토지 포함) · 별장   → §55의2①2
  · 비사업용 토지                → §55의2①3
  · 조합원입주권 · 분양권        → §55의2①4
  · 그 밖의 비주택(상가·공장 등) → 추가과세 없음. 본세만

미등기로 양도했나?                → §55의2①2·3 의 미등기 세율 적용 (훨씬 높다)

둘 이상에 해당하면?               → ① 후단: 가장 높은 세액
```

세율 수치는 `tax-rates-2026.md` §4-2·4-3 참조.

### 3-4. 추가과세를 아예 안 하는 경우 (§55의2④)

```
· 파산선고에 의한 처분
· 법인이 직접 경작하던 농지의 교환·분할·통합
· 도시정비법 등에 따른 환지처분
  → 단, 미등기 토지등은 위 제외를 적용받지 못한다 (④ 단서)
```

**NPL 맥락에서 파산 관련 처분은 실제로 걸릴 수 있다.** 채무자 파산 사건과 얽힌 물건이면 확인한다.

### 3-5. 농어촌주택 제외 (§55의2①2 단서)

읍·면에 있으면서 시행령이 정한 기준에 맞는 농어촌주택은 주택 추가과세에서 빠진다.
지방 소재 주택이면 이 예외를 먼저 본다.

## 4. 개인 · 법인 비교표를 낼 때

단기 매각 시나리오에서는 대체로 법인이 유리하지만 **취득세는 법인이 훨씬 비싸다.**
비교표에는 반드시 **취득 + 보유 + 양도 3단계 합계**를 넣는다. 양도세만 비교하면 결론이 뒤집힌다.

```
| 구분        | 개인          | 법인          |
|-------------|--------------|--------------|
| 취득 단계   |              |              |  ← 법인 주택 취득세 중과가 여기서 반영된다
| 보유 단계   |              |              |  ← 법인은 종부세 기본공제 0원
| 양도 단계   |              |              |
| 합계        |              |              |
| 세후 순회수 |              |              |
```

**보유 기간이 길어지면 결론이 뒤집힌다.** 취득세 격차는 한 번이지만 보유세 격차는 매년 반복된다.
몇 년이면 역전되는지 계산해 함께 보여준다.

## 5. 자가 점검 — 숫자를 내보내기 전

```
□ 취득일을 잔금납부일로 잡았는가? (낙찰일·등기일이 아니다)
□ 세율 후보를 전부 계산하고 MAX 를 취했는가? 하나만 골라 쓰지 않았는가
□ 조정대상지역 중과 유예 여부를 이 답변에서 확인했는가? 못 했으면 [검증필요] 를 달았는가
□ 필요경비에 취득세를 넣었는가
□ 보유 3년 미만인데 장기보유특별공제를 넣지 않았는가
□ 법인인데 개인 양도차익 산식(취득가 기준)을 쓰지 않았는가 — 장부가액이다
□ 법인 추가과세를 본세와 따로 계산해 더했는가
□ 지방소득세 10% 를 빠뜨리지 않았는가
□ 모든 금액을 원 단위 풀 콤마로 적었는가
□ 「예상 세액」임을 명시했는가
```
