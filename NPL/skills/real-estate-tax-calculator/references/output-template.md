# 출력 양식 — 5개 섹션 + 한계 고지

이 파일은 **양식**만 담는다. 세율·금액은 `tax-rates-2026.md` 와 조문 조회 결과를 쓴다.

## 공통 규칙

- 원화는 **원 단위 풀 콤마**. `1,137,392,385원`. 억·만 축약 금지
  (법령 조문의 세율 구간·공제액을 그대로 인용할 때만 예외)
- 모든 세액 앞에 **「예상」**을 붙인다. 확정 세액은 관할 세무서·위택스 신고 기준이다
- 확신도 라벨을 단다 — `[확정]` 은 그 답변에서 조문을 직접 조회했을 때만
- 계산 못 한 항목은 빈칸으로 두고 **왜 못 했는지** 적는다. 0원으로 채우지 마라

## 섹션 1 — 기본 정보

```
## 1. 세금 계산 기본 정보

| 항목 | 값 | 근거 |
|---|---|---|
| 소재지 |  | 등기부 |
| 부동산 유형 | 주택 / 오피스텔 / 상가 / 토지 / 공장 | 건축물대장 |
| 조정대상지역 | 해당 / 비해당 | adjustment-areas.md (조회일 ____-__-__) |
| 낙찰가(취득가액) | ____________원 | 매각허가결정 |
| **공시가격** | ____________원 | ★ 아래 출처 표기 필수 |
| 매입 주체 | 개인 1주택 / 개인 다주택 / 법인 |  |
| 전용면적 | ____.__㎡ | 건축물대장 (85㎡ 초과 여부가 농특세를 가른다) |
| 예상 보유기간 | __개월 | |
| 예상 매각가 | ____________원 | |
| 6월 1일 경과 | 예 / 아니오 | 보유세 발생 여부를 가른다 |
```

**공시가격은 조회가 원칙이다. ①을 시도하지 않고 ②로 가지 않는다.**

```
① 실측  — 공시가격 열람 결과 (기준연도 ____년 · 조회처 ____ · 조회일 ____-__-__)
           공동주택            → duckdb 주택공시가격 테이블
           단독·다가구·근린주택 → realtyprice.kr 개별단독주택가격 열람
② 가정  — 감정평가액 ____________원 × 60%   ※ ①에 실패했을 때만
③ 미확정 — 감정평가액도 없어 산출 불가. 보유세는 [정보부족] 으로 둔다
```

②를 쓸 때는 섹션 1 바로 아래에 이 박스를 넣는다. **실패 사유를 비워 두지 않는다.**

```
> ★ 공시가격 가정 — 감정평가액 × 60%   [추정]
> 부동산공시가격 알리미에서 ____-__-__ 조회를 시도했으나 (사유)로 확인하지 못했습니다.
> 실제 값이 확인되면 즉시 다시 계산합니다.
> 공시가격이 달라지면 재산세·종부세가 함께 달라집니다 — 실측 사례에서 이 가정치가
> 실측의 1.55배로 나와 재산세 1세대1주택 특례가 빠지고 종부세 결론이 뒤집힌 적이 있습니다.
```

| 근생분 (건물+부속토지) | ___.__㎡ | __._% | ____________원 | | |
```

> **토지를 따로 떼어 전부 비주택 세율을 적용하지 않는다.** 주택은 건물 + 부속토지 일체다.

## 섹션 3 — 보유 단계

6월 1일을 넘기지 않으면 이 섹션은 **「해당 없음」 한 줄**로 끝낸다. 표를 0원으로 채우지 마라.

```
## 3. 보유 단계 세금 (과세기준일 6월 1일)

취득 시점: ____년 __월 __일 (잔금납부)
→ ____년 6월 1일 시점 소유자: 예 / 아니오
→ 첫 과세연도: ____년

### 재산세
| 항목 | 값 |
|---|---|
| 공시가격 | ____________원 |
| 공정시장가액비율 | __% |
| 과세표준 | ____________원 |
| 재산세 본세 | ____________원 |
| 도시지역분 | ____________원 |
| 지방교육세 | ____________원 |
| **합계** | **____________원** |

### 종합부동산세 — 첫 과세연도 ____년 기준
| 항목 | 값 |
|---|---|
| 공시가격 | ____________원 |
| − 기본공제 | ____________원 |
| × 공정시장가액비율 | __% |
| = 과세표준 | ____________원 |
| × 세율 | __._% |
| = 산출세액 | ____________원 |
| **− 재산세 공제** | **△____________원** |
| = 종부세 | ____________원 |
| + 농어촌특별세 | ____________원 |
| **합계** | **____________원** |
```

> **재산세 공제를 빠뜨리면 종부세가 과대 산출된다.** 산출세액 − 공제액이 음수가 되면 계산이 틀린 것이다.
> 주택·근생 복합이면 **안분된 주택분 과세표준**으로 공제액을 계산한다.

리포트·PPTX 맨 아래에 **반드시** 넣는다. 생략하지 않는다.

```
> **한계 고지**
>
> · 이 산정은 **가정 기반 시뮬레이션**이며 실제 신고 세액과 다를 수 있습니다.
> · 공시가격: ①실측(조회처·기준연도·조회일 병기) / ②조회 실패 후 감정평가액 × 60% 가정 / ③미확정
> · 적용 세율 기준일: ____-__-__ (조회일)
> · 조정대상지역 다주택 중과의 유예 여부는 정책으로 바뀝니다. 양도 시점에 다시 확인하십시오.
> · 2026 세제개편안 항목은 **국회를 통과하지 않은 정부안**입니다.
> · 확정 세액은 관할 세무서·위택스 신고 기준이며, 실제 신고 전 세무사 확인을 권합니다.

**PPTX 에는 분석일·회사명·AI 표기를 넣지 않는다.**

## 자가 점검

```
□ 모든 금액이 원 단위 풀 콤마인가
□ 공시가격 출처를 ①②③ 중 하나로 명시했는가
□ 6월 1일 미경과인데 보유세 표를 0원으로 채우지 않았는가
□ 종부세에서 재산세 공제를 뺐는가
□ 개인·법인을 나란히 냈는가
□ 세율 후보를 전부 계산하고 MAX 를 표로 보여줬는가
□ 한계 고지 박스를 넣었는가
□ 「예상」 표기를 했는가
```
