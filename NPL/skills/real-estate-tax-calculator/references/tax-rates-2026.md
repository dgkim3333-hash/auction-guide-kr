## 1. 취득세 (지방세법)

### 1-1. 주택 유상취득 — 개인

| 구분 | 취득가 6억 이하 | 6억~9억 | 9억 초과 |
|------|---------------|---------|---------|
| 1주택 | 1.0% | 1.0~3.0% 누진 | 3.0% |
| 2주택 (조정) | 8.0% | 8.0% | 8.0% |
| 2주택 (비조정) | 1.0% | 1.0~3.0% | 3.0% |
| 3주택 (조정) | 12.0% | 12.0% | 12.0% |
| 3주택 (비조정) | 8.0% | 8.0% | 8.0% |
| 4주택 이상 | 12.0% | 12.0% | 12.0% |

**6억~9억 누진식 (1주택):**
세율(%) = (취득가액 × 2/3억 - 3) × 1/100
예: 7억 → (7 × 2/3 - 3) × 1/100 ≈ 1.67%

**일시적 2주택 특례:** 종전 주택 3년 이내 처분 조건 시 1~3% 일반세율 적용

### 1-2. 주택 유상취득 — 법인 (NPL 매입 실무 핵심)

**법인:** 주택 수·소재지 무관 **12.0% 일괄 적용**
(지방세법 제13조의2 제1항 제1호)

### 1-3. 주택 중과 제외 예외

- 시가표준액 수도권 1억 이하, 비수도권 2억 이하 → 중과 제외 (1~3% 적용)
- 미분양 주택 (일정 요건) → 중과 제외
- 임대사업자 등록 임대주택 (요건 충족) → 중과 제외

## 5. 세금 민감도 — NPL 단기 매각 시나리오 비교

### 사례: 서울 소재 10억 주택 NPL 낙찰 후 12억 매각 (9개월 보유)

#### 개인 다주택자 (2주택자) 기준
```
[취득]
취득세 8% × 10억 = 8,000만원
농특세 0.6% = 600만원
지방교육세 0.4% = 400만원
─────────────────────
취득 부담 합계 = 9,000만원 (9.0%)

[양도 — 9개월 보유, 1년 미만]
양도차익 = 12억 - 10억 - 필요경비(9,000만원) = 1억 1,000만원
(세율 경합: 단기 70% vs 중과 유예 중이므로 기본세율만 비교)
양도세 = 1.1억 × 70% = 7,700만원
지방소득세 = 770만원
─────────────────────
양도 부담 합계 = 8,470만원

세후 순이익 = 2억 - 9,000만원 - 8,470만원 = 2,530만원
실효 세율 = (9,000 + 8,470) / 20,000 = 87.4% (양도차익 대비)
```

#### 법인 (대부업체) 기준
```
[취득]
취득세 12% × 10억 = 1.2억
농특세 1.0% = 1,000만원
지방교육세 0.4% = 400만원
─────────────────────
취득 부담 합계 = 1.34억 (13.4%)

[양도 — 주택 법인 양도]
양도차익 = 12억 - 10억 - 필요경비(1.34억) = 6,600만원
법인세 기본 = 6,600만원 × 9% = 594만원 (2억 이하)
법인세 추가 (주택 20%) = 6,600만원 × 20% = 1,320만원
지방소득세 = (594 + 1,320) × 10% = 191만원
─────────────────────
양도 부담 합계 = 2,105만원

세후 순이익 = 2억 - 1.34억 - 2,105만원 = 4,495만원
실효 세율 = (1.34억 + 2,105만원) / 2억 = 77.5% (양도차익 대비)
```

**결론:** 1년 미만 단기 매각에서 법인 명의가 개인 다주택자 대비 유리
(개인 다주택 차익의 77% 세금 vs 법인 77.5% 세금이지만 취득세 회피분 감안)

**단, 취득세 초기 부담이 법인이 크므로 매각가가 낮을수록 법인이 불리해지는 역전 포인트 존재**
