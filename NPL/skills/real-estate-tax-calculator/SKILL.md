# 부동산 세금 계산 스킬 (Real Estate Tax Calculator)

## 역할 및 목표

당신은 **NPL 분석 맥락의 부동산 세금 산정 전문가**이다.
NPL 낙찰·회수 시나리오에서 세전(Gross) 회수액과 세후(Net) 회수액의 차이를 명시적으로 계산하여
IRR·적정 매입가 산정의 정확도를 높이는 역할을 수행한다.

**핵심 원칙:**
1. 세율은 분석 시점의 법령 기준으로 적용하되, 변동 가능성이 큰 경우 "확인 필요" 표시
2. 세금은 "가정 기반 시뮬레이션"이며 실제 신고 세액과 다를 수 있음을 항상 명시
3. 단정적 표현 금지 — "예상 세액", "참고용 산정" 등 표현 사용
4. **2026년 5월 9일 양도세 중과 유예 종료는 단기 매각 시나리오의 핵심 변곡점으로 반드시 체크**
5. 법인 NPL 매입자(대부업체 등)의 경우 법인세율 별도 적용
6. **공시가격은 가정하지 않고 조회한다** — 아래 「공시가격 확보」 절이 이 스킬에서 가장 중요하다

확신도 라벨, MOLIT 사용 규칙 등 공통 규칙은 user preferences §1 (사실 검증 원칙) 및 §2 (부동산 시세·매물 조회 규칙)를 따른다.

## ★★ 공시가격 확보 — 가정하기 전에 반드시 조회한다 (2026-08-27 전면 개정 · 2026-09-27 조회 순서 개정)

> **2026-09-27 개정**: 단독·다가구·다중·근린주택의 개별주택가격은 **`vworld-landuse` MCP `get_house_price` 가 1순위**다(API 자동 조회, 대지·연면적 산정값 포함). 응답에 **`stale_warning`** 이 붙거나 조회에 실패했을 때만 알리미 수동 조회로 간다. 상세·주의점은 `property-tax-apportionment` 1-B 가 정본이다.

> **종전 규칙 「공시가격이 없으면 감정평가액 × 60%」는 폐기됐다.**
> 「개별주택가격은 전국 통합 자료가 없다」는 전제가 틀렸다. 통합 다운로드 자료가 없을 뿐,
> **개별 물건 조회는 누구나 로그인·캡차 없이 할 수 있다.**

### 조회 경로

```
공동주택(아파트·연립·다세대)  →  duckdb  주택공시가격  테이블
단독·다가구·다중·근린주택      →  ① vworld-landuse  get_house_price(address= 또는 pnu=)
                                  ② stale_warning·실패 시  https://www.realtyprice.kr/notice/hpindividual/search.htm
토지(개별공시지가)             →  vworld-landuse  get_parcel_info
```

**② realtyprice.kr 절차** (①이 실패했거나 `stale_warning` 일 때만) — 「개별단독주택가격 열람」 → 텍스트검색 → 지번검색
→ 시/도 → 시/군/구 → 읍/면/동 → 일반번지 · 본번 - 부번 → 검색연도 범위(2개 연도 이상) → 검색.
시/군/구 콤보는 시/도를 고른 뒤 비동기로 채워지므로 **선택 사이에 대기를 넣지 않으면 「옵션 없음」 오류가 난다.**

### 결과 표에서 네 값을 전부 가져온다

개별주택가격만 보고 나머지를 버리면 **안분 근거를 통째로 놓친다.**

| 열 | 무엇인가 | 어디에 쓰나 |
|---|---|---|
| **개별주택가격** | 주택 건물 + 부속토지 **일체**의 시가표준액 | 재산세 주택분 · 종부세 과세표준 |
| **대지면적 (전체 / 산정)** | 산정 = 지자체가 정한 **주택 부속토지 면적** | 취득세 §19② 안분 · 근생 부속토지 역산 |
| **건물연면적 (전체 / 산정)** | 산정 = 지자체가 본 **주택분 건물면적** | 안분 검산 |
| **가격기준연도** | 공시기준일 | 산출물에 반드시 병기. 연도 없는 공시가격은 쓰지 않은 것과 같다 |

### 부속토지 면적을 역산해 검산한다

```
주택 부속토지 ÷ 대지 전체 = 비율  →  건물 전체 × 비율 = 주택분 건물면적
그 값이 건축물대장 항목 조합으로 딱 떨어지는지 확인한다
```

딱 떨어지면 **지자체와 똑같은 안분 비율을 쓸 수 있다.** 반드시 한다.
떨어지지 않으면 `[추정]` 으로 적고 구청 확인 항목에 올린다.

**실측 사례 (C사건 · 서울 중랑구 면목동 673-42 · 2026-08-27 조회)**

| 기준일 | 대지 전체/산정 | 건물연면적 전체/산정 | 개별주택가격 |
|---|---|---|---|
| 2026.01.01 | 162.7 / **96.24㎡** | 317.49 / 213.61㎡ | **588,000,000원** |
| 2025.01.01 | 162.7 / 96.24㎡ | 361.11 / 213.61㎡ | 560,000,000원 |

```
96.24 ÷ 162.70 = 59.155%  →  317.49 × 59.155% = 187.81㎡
187.81 = 159.85(3~5층) + 18.44(옥탑 다락) + 9.52(옥탑 계단실)
→ 지자체는 옥탑 다락과 계단실을 전부 주택분으로 보았다
```

**「감정평가액 × 60%」 가정치는 910,768,601원이었다 — 실측의 1.55배로 과대했다.**
그 탓에 시가표준액 900,000,000원 이하 요건에 걸리지 않아 재산세 1세대1주택 특례세율(지방세법 §111의2)이
빠졌고, 개인 종부세도 「과세」로 나왔다. **실측으로 둘 다 뒤집혔다.**

### 그 밖의 조회 규칙

- 여러 필지 위 1동이면 **대표 지번 하나에만** 등재된다. 나머지 지번 0건은 정상이다.
  0건이 나왔다고 「자료 없음」으로 넘기지 마라 — 다른 지번으로 다시 조회한다
- 연도별 「건물연면적 전체」가 다르면 **건축물대장 변동사항**부터 본다. 신규작성(신축) 1건뿐이면
  건물이 바뀐 것이 아니라 지자체 기재 정정이다. 「산정 ÷ 전체」 비율이 연도별로 같으면 결론에 영향 없다
- **`datagokr building_housing_price` 는 쓰지 않는다** — 2024.07.21에서 적재가 멈췄고 단독·다가구는 0건이다

**★ `stale_warning` 을 무시하지 마라.** 마지막 공시연도가 올해분보다 오래됐다는 뜻이다(멸실·용도변경·다세대 전환 의심). 실측 2026-09-27: 강북구 수유동 190-1 은 마지막 값이 2019년분 192,000,000원이었다 — 그대로 넣으면 7년 전 값으로 보유세를 계산한다.

### ①·② 조회에 모두 실패했을 때만 → 감정평가액 × 60%

**조회를 시도하지 않고 바로 여기로 오지 마라.** 시도한 사실과 실패 사유를 함께 적고 `[추정]` 라벨을 단다.

> ★ 공시가격 가정 — 감정평가액 × 60%
> vworld 개별주택가격(get_house_price)과 부동산공시가격 알리미 조회를 모두 시도했으나 (사유)로 확인하지 못했습니다.
> 실제 값이 확인되면 즉시 다시 계산합니다.

**공시가격의 분모는 언제나 감정평가액이다. 낙찰가가 아니다.**
분모가 낙찰가면 유찰 회차마다 공시가격이 달라져 보유세가 낙찰가를 따라 움직이는 오류가 난다.
**낙찰가 시나리오를 여러 개 비교할 때 보유세 행은 전부 같은 값이어야 한다.**
감정평가액이 없는 건(공매 일부 등)에 한해서만 낙찰가를 분모로 쓰되 그 사실을 산출물에 명시한다.

### 교부청구서 역산은 조회 실패 시에만 쓰는 보조 검산이다

**실측 개별주택가격을 얻었으면 역산은 하지 않는다.** 교부청구서는 채무자 단위 체납이라
다른 물건의 세금이 섞여 물건 단위로 분리되지 않는다. 공정시장가액비율·특례세율 분기도 갈려
유일해로 수렴하지 않는다. 역산값은 언제나 `[추정]` 이고 `[확정]` 을 붙이지 마라.

### 호출 전 4단계

```
1. 공시가격을 먼저 확정한다
     ① vworld get_house_price / realtyprice.kr / duckdb 로 조회했나?  → 그 실측값을 쓴다
        (stale_warning 이 붙은 값은 실측값으로 치지 않는다 — 알리미로 확인)
     ② 조회에 실패했나?                      → 감정평가액 × 0.6 을 직접 계산하고 [추정] 을 단다.
                                              시도 사실과 실패 사유를 기록한다
     ③ 감정평가액도 없나?                    → 스크립트를 호출하지 마라.
                                              [정보부족] 으로 두고 무엇을 구하면 되는지 적는다
2. ★ ①을 건너뛰고 ②로 가지 않았는지 스스로 확인한다   ← 이번 개정의 핵심이다
3. public_price= 를 명시적으로 넘긴다        ← 생략 금지. 기본값을 믿지 마라
4. 산출물에 공시가격의 출처와 근거를 적는다    (실측인지, 조회 실패 후 가정인지)
```

### 넘기면 안 되는 인자

**`appraisal_price=` 를 넘기지 마라.**

인자 자체는 시그니처에 **존재한다**(`calculate_total_tax` 439행).

- **신판** — 넘기면 `ValueError` 로 즉시 중단된다. 안전하다
- **구판** — 오류 없이 받아들이고 452행에서 `public_price = appraisal_price * 0.6` 으로
  **조용히 가정을 만들어 쓴다.** 조회를 건너뛴 사실이 결과 어디에도 남지 않는다.
  **가장 위험한 호출 형태다**

(2026-08-27 이전 판 SKILL.md 는 「그 인자가 없어 TypeError 가 난다」고 적었으나 **틀렸다.**
동봉 스크립트가 그 사이 갱신됐고 문서가 따라가지 못했다. 2026-08-27 실측으로 정정.)

가정을 쓸 수밖에 없는 경우에도 `public_price = 감정평가액 * 0.6` 으로 **호출부에서 미리
계산해서** 넘긴다. 그래야 가정을 썼다는 사실이 코드에 남는다.

### ★ 차단 래퍼 — 스크립트를 직접 부르지 말고 이것을 거친다

**신판이 깔려 있으면 이 래퍼는 필요 없다** — 스크립트가 스스로 중단한다.
**구판이면 반드시 거친다.** 문서 경고는 읽고 지나칠 수 있지만 래퍼는 예외를 던진다.
`/tmp/tax_gate.py` 로 저장하고 스크립트 경로를 넘겨 쓴다. 스킬 폴더에는 쓰지 않는다(읽기 전용).

```python
# /tmp/tax_gate.py — 공시가격 미조회 차단 래퍼
import importlib.util, pathlib, sys

SRC = pathlib.Path(sys.argv[1])          # scripts/tax_calculator.py 절대경로
_spec = importlib.util.spec_from_file_location("_tc", SRC)
_tc = importlib.util.module_from_spec(_spec); _spec.loader.exec_module(_tc)

def calculate_total_tax(**kw):
    pp = kw.get("public_price")
    if not isinstance(pp, (int, float)) or isinstance(pp, bool) or not pp > 0:
        raise SystemExit(
            "[차단] public_price 미확정 — 공시가격을 조회하지 않고 세금을 계산할 수 없다.\n"
            "  공동주택            → duckdb 주택공시가격 테이블\n"
            "  단독·다가구·근린주택 → vworld-landuse get_house_price (경고·실패 시 https://www.realtyprice.kr/notice/hpindividual/search.htm)\n"
            "  조회에 실패했으면 실패 사유를 산출물에 적고 "
            "public_price = 감정평가액 * 0.6 을 호출부에서 직접 계산해 명시적으로 넘겨라."
        )
    kw.pop("appraisal_price", None)      # 452행 0.6 폴백 경로를 원천 차단
    return _tc.calculate_total_tax(**kw)

format_kor  = _tc.format_kor
print_report = _tc.print_report
```

**변이 검증 4종 통과 확인(2026-08-27 실측).** 방어를 되돌리면 전부 통과해 버리므로,
래퍼를 고쳤으면 아래를 다시 돌려 실패하는지 본다.

| 호출 | 기대 |
|---|---|
| `public_price` 없이 호출 | `SystemExit` 로 **중단** ✓ |
| `appraisal_price` 만 넘김 | `SystemExit` 로 **중단** ✓ |
| `public_price=0` 으로 넘김 | `SystemExit` 로 **중단** ✓ |
| 실측 `public_price=588000000` | 정상 통과 ✓ |

`calculate_total_tax` 의 기간 인자는 `holding_years` 가 아니라 **`holding_months`** 다(435행).

## 세금 적용 결정 트리

### A. 취득세 결정 트리

```
1. 매입 주체 = 법인?
   YES → 주택이면 12% 일괄 / 비주택이면 4% (시가표준액 수도권 1억 이하 등 예외 시 중과 제외)
   NO (개인) → 2단계로

2. 부동산 유형?
   주택 → 3단계 (다주택·조정 판정)
   비주택(상가·오피스·공장) → 4.0%
   농지(자경) → 1.5% / 농지(비자경) → 3.0%
   원시취득(신축) → 2.8%

3. 보유 주택 수 + 조정대상지역 여부 → tax-rates-2026.md §1-1 표 적용
   - 1주택: 1~3% 누진 (취득가액 구간)
   - 2주택 조정: 8% / 비조정: 1~3%
   - 3주택 조정: 12% / 비조정: 8%
   - 4주택+ : 12%
```

★ **주택 취득세의 「주택」은 주거용 건축물과 그 부속토지를 함께 말한다** (지방세법 §11①8).
**토지를 따로 떼어 전부 4%를 적용하면 크게 과소 계상된다.**

### A-1. ★★ 주택·근생 복합의 안분 — 세목마다 기준이 다르다 (2026-08-27 개정)

> **「연면적 비율로 안분한다」는 틀렸다.** 종전 판이 취득세까지 연면적으로 나누게 하고 있었다.

| 세목 | 근거 조문 | 안분 기준 |
|---|---|---|
| **취득세 (경매·매매 등 승계취득)** | **지방세법 시행령 §19②** | **시가표준액 비율** |
| 취득세 (신축·증축) | 같은 조 **§19③** | 연면적 비율 — 승계취득에는 쓰지 않는다 |
| **재산세 · 종합부동산세** | **지방세법 §106②1호** | **건물 면적비율** |

**두 값이 다른 것이 정상이다.** 같게 나오면 한쪽을 잘못 계산한 것이다.

```
                  (건축물 중 주택 부분 시가표준액[법 §4②])
주택 부분   =  전체  ×  + (부속토지 중 주택 부분 시가표준액[법 §4①])
취득당시가액   취득가액   ───────────────────────────────
                      건축물과 부속토지 전체의 시가표준액
```

**§19② 분자에 개별주택가격을 넣지 마라.** 조문이 「건축물 중 주택 부분은 §4②」라고 못박았다.
§4② 는 건물신축가격기준액 방식이고, 개별주택가격(§4①)은 재산세·종부세용이다.

**안분 비율만 필요하면 기준액·위치지수·잔가율을 몰라도 된다** — 같은 건물의 주택분과 근생분은
구조지수·위치지수·잔가율이 같고, 건물신축가격기준액은 주거용·상업용이 같아 분자·분모에서 상쇄된다.
남는 변수는 **용도지수와 가감산율**뿐이다(다가구 91 / 상점·사무소 112 / 5~10층 건물 1층 상가 +17%).

**상세 절차·지수표·K 민감도는 `property-tax-apportionment` 스킬이 정본이다.** 반드시 그것을 따른다.

**재산세·종부세는 지자체가 이미 나눠 놓아 직접 안분할 일이 거의 없다** — 개별주택가격이
주택 건물 + 부속토지를 일체로 담고, 「대지면적(산정)」의 나머지가 근생 부속토지다.

### B. 보유세 결정 트리 (재산세·종부세)

```
1. 과세기준일 6월 1일 통과?
   NO → 보유세 0 (당해 연도 매도자 부담)
   YES → 2단계로

2. 재산세: 공시가격 × 공정시장가액비율(주택 60%·토지 70%·1세대1주택 특례 43~45%) → 누진세율 적용

3. 종부세 (인별 전국 합산):
   - 법인: 공제 0원, 주택 2주택 이하 2.7% / 3주택+ 5.0% 단일세율
   - 개인 일반: 공제 9억원 후 누진 (2주택↓ 0.5~2.7% / 3주택↑ 0.5~5.0%)
   - 개인 1세대1주택: 공제 12억원 후 누진
```

★ **재산세 1세대1주택 특례세율(지방세법 §111의2)은 시가표준액 900,000,000원 이하 한정이다.**
공시가격을 가정으로 부풀리면 이 특례가 조용히 빠진다 — 실측이 중요한 이유 중 하나다.

★ **종부세는 낙찰 다음 해가 첫 과세연도다.** 과세기준일이 6월 1일이므로 6월 1일 이후 잔금을 내면
그 해 종부세는 0원이고 첫 부담은 다음 해다. **그 해에 적용될 세율로 계산해야 한다** —
현행 세율로 계산하면 틀린다. 2026 세제개편안 로드맵은 `auction-property-card` 8-B 참조.

★ **종부세에서 재산세 공제를 빠뜨리지 마라** (종부세법 §9③ + 시행령 §4의3①).
주택이 1채면 분모·분자가 상쇄되어 `공제액 = (종부세 과세표준 × 재산세 공정시장가액비율 60%)에
재산세 주택분 표준세율을 적용한 금액` 이 된다. **안분 전 금액으로 계산하지 마라** —
주택·근생 복합이면 안분된 주택분 과세표준을 기준으로 공제액을 산출한다.

### C. 양도세 결정 트리 (핵심)

```
1. 매입 주체 = 법인?
   YES → 법인세 결정 트리로 (D 참조)
   NO (개인) → 2단계로

2. 보유기간 분기:
   - 1년 미만:
     주택 → 70% 단일 / 비주택 → 50% 단일
   - 1년~2년 미만:
     주택 → 60% 단일 / 비주택 → 40% 단일
   - 2년 이상 → 누진세율 + (3단계 중과 판정)

3. 다주택+조정지역+양도일?
   - 양도일 ≤ 2026.5.9: 유예 적용 (중과 배제, 기본세율)
   - 양도일 ≥ 2026.5.10: 2주택 +20%p / 3주택+ +30%p, 장기보유특별공제 배제
   - 경합 시: max(단기세율, 누진세율+중과율)

4. 부가세 가산:
   - 지방소득세 = 양도세 × 10% (필수)
   - 농어촌특별세 = 양도세 감면분 × 20% (감면 없으면 0)
```

### D. 법인세 결정 트리 (법인 매입자 양도)

```
1. 법인세 기본 = 누진 (2억↓ 9% / 2억~200억 19% / 200억~3,000억 21% / 3,000억↑ 24%)

2. 추가과세:
   - 주택 양도 → 양도차익 × 20% (법인세법 §55의2)
   - 비사업용 토지 양도 → 양도차익 × 10%
   - 일반 비주택 → 추가 없음

3. 지방소득세 = (법인세 기본 + 추가) × 10%
```

## 부가세 자동 가산 규칙 (누락 금지)

모든 본세에 대해 다음 부가세를 자동 산정한다:

### 취득세 부가세
- **농어촌특별세**: 주택 1~3% 구간 → 0.2% (전용면적 85㎡ 초과 시만, 85㎡ 이하 면제)
  / 주택 중과 8% → 0.6% / 주택 중과 12% → 1.0% / 비주택 → 0.2%
  ※ **다가구주택은 가구당 전용면적으로 85㎡ 를 판정한다** (농특세법 시행령 §4⑤ 괄호)
- **지방교육세**: 주택 일반 = 취득세율 × 50% × 20% / 주택 중과(8·12%) = 0.4%
  / 비주택·토지 = (취득세율-2%) × 20%

### 보유세 부가세
- **재산세 도시지역분**: 재산세 과표 × 0.14%
- **지방교육세**: 재산세 × 20%
- **종부세 농특세**: 종부세 × 20%

### 양도세 부가세
- **지방소득세**: 양도세(또는 법인세+추가) × 10% — 항상 부과
- **농어촌특별세**: 양도세 감면분 × 20% — 감면 없으면 0

4. **섹션 4** — 양도 단계 세금 (매각 시점: 개인/법인 케이스별 양도세/법인세)
5. **섹션 5** — 세후 순회수액 및 IRR 반영 + 민감도 분석

**필수 출력 양식(표·박스 구조)은 `references/output-template.md` 참조.** 단 그 파일의
「공시가격 가정 — 감정평가액 × 60%」 문구는 폐기됐으므로 **조회 결과와 기준연도를 적는 형태로 바꿔 쓴다.**

**섹션 1에는 공시가격의 출처를 반드시 적는다:**

```
[공시가격]
개별주택가격 __________원  (____.__.__ 기준 · vworld get_house_price 또는 알리미 ____-__-__ 조회)   [확정]
개별공시지가 __________원/㎡ (____.__ 기준 · vworld)                                  [확정]
주택 부속토지 ______㎡ / 근생 부속토지 ______㎡  (대지 전체 ______㎡)                   [확정]
```

## 계산 절차 (5단계 개요)

### Step 1 — 기본 정보 확정
매입가, **공시가격(가정하지 말고 조회 — 위 「공시가격 확보」 절)**, 부동산 유형, 소재지, 매입 주체,
전용면적(85㎡ 판정 · 다가구는 가구당).

### Step 2 — 취득 단계 세금 산정

```python
# 예시: 법인이 서울 소재 10억 주택 낙찰
취득세 = 낙찰가 × 0.12          # 법인 12% 중과
농특세 = 낙찰가 × 0.01          # 12% 중과 시 1.0%
지방교육세 = 낙찰가 × (0.12 × 0.5 × 0.2) = 낙찰가 × 0.012

취득단계_총세금 = 낙찰가 × (0.12 + 0.01 + 0.012) = 낙찰가 × 0.142  # 약 14.2%
```

**주택·근생 복합이면 낙찰가를 먼저 §19② 시가표준액 비율로 안분한 뒤** 각 부분에 세율을 적용한다.

**실무 팁:** 법인의 주택 낙찰 시 취득세 부담이 매입가의 약 14%에 달하므로 IRR에 미치는 영향이 매우 크다.

### Step 3 — 보유 단계 세금 산정 (단기 매각 시 생략 가능)

1년 이내 단기 매각의 기본 가정:
- 낙찰 후 6월 1일을 넘기지 않고 매각하면 보유세 회피 가능
- 6월 1일을 경과하면 재산세·종부세 1회분 부담

```python
# 6.1 경과 시 (법인 단일세율 예시)
재산세_과표 = 공시가격 × 0.6       # 주택 공정시장가액비율 60%
재산세 = 적용세율 × 재산세_과표 - 누진공제
도시지역분 = 재산세_과표 × 0.0014
지방교육세_보유 = 재산세 × 0.2

종부세_과표 = 공시가격 × 0.6        # 법인은 공제 없음
종부세 = 종부세_과표 × 0.027       # 법인 2주택 이하 단일세율
농특세_종부 = 종부세 × 0.2
```

위 의사코드의 `공시가격` 자리에는 **조회한 실측 개별주택가격**을 넣는다. 낙찰가를 넣지 마라.
그리고 **보유세는 낙찰가가 달라져도 변하지 않는다** — 시나리오별로 낙찰가만 바꿔 가며
비교표를 만들 때 보유세 행이 함께 움직이면 계산이 틀린 것이다.

### Step 4 — 양도 단계 세금 산정

매입 주체·보유기간·부동산 유형·조정지역 조합별로 분기. 의사코드는 `references/capital-gains-tax-simulation.md` §3 참조.

### Step 5 — 세후 순회수액 및 IRR 반영

```python
세전_순회수액 = 매각가 - 낙찰가 - 취득단계_총세금 - 보유단계_총세금
세후_순회수액 = 세전_순회수액 - 양도단계_총세금

IRR_세전 = IRR([-매입가, 세전_순회수액], 기간)
IRR_세후 = IRR([-매입가, 세후_순회수액], 기간)
```

세후 IRR을 trust-npl-analysis·npl-analysis의 G4 IRR 산정에 그대로 반영.

## 주요 절세 전략 체크 (NPL 단기 매각 특화)

### 전략 1 — 6월 1일 회피
6월 1일을 기준일로 한 재산세·종부세는 "그 날짜의 소유자"가 부담한다.
- **6월 2일 이후 낙찰** → 당해 연도 보유세 회피
- **5월 31일 이전 매각** → 당해 연도 보유세 회피
- **5월 31일 이전 낙찰 + 6월 2일 이후 매각** → 당해 연도 보유세 전액 부담

### 전략 2 — 양도세 중과 유예 활용 (2026.5.9까지)
- 2026년 5월 9일까지 양도하면 다주택 중과세율(20~30%p 추가) 적용 배제
- 개인 다주택자의 NPL 단기 매각은 이 시점 이전 완결이 절세상 유리
- **법인은 해당 유예와 무관** — 법인 주택 양도는 항상 기본 20% 추가과세 적용

### 전략 3 — 필요경비 입증 철저
- 명도비·소송비·리모델링비 등 양도차익 산정 시 공제 가능한 비용을 증빙 확보
- 중개수수료, 등기비용, 법무사 수수료는 세금계산서·현금영수증 필수

### 전략 4 — 법인 vs 개인 명의 선택
단기 매각(1년 미만) 기준 비교:
- 개인 주택: 양도차익의 70% + 지방소득세 → 실효 77%
- 법인 주택: 법인세 9~19% + 주택 추가 20% + 지방소득세 → 실효 약 31~43%
- **법인 명의가 압도적으로 유리** (단기 매각 시나리오 기준)
- 단, 법인 취득세 12% vs 개인 취득세 1~3%의 초기 부담은 고려 필요

★ **장기 보유 시나리오에서는 결론이 뒤집힌다.** 취득세 격차는 한 번이지만
**보유세 격차는 매년 반복된다** — 법인은 종부세 기본공제가 0원이라 지역·금액과 무관하게 과세된다.
몇 년이면 보유세 누적 격차가 취득세 격차를 넘는지 계산해 함께 보여준다.
**공시가격을 가정으로 부풀리면 이 역전 시점이 통째로 틀린다.**

- 매입 적정가 산정 시 세후 순회수 기준 IRR 역산

## 하지 않는 것

- **공시가격을 조회하지 않고 가정하기** — 공동주택은 duckdb, 단독·다가구는 vworld `get_house_price`(1순위)·realtyprice.kr(2순위)에서 개별 조회된다 (2026-08-27 · 2026-09-27 개정)
- **`stale_warning` 이 붙은 개별주택가격을 public_price 로 넘기기** — 몇 년 전 값일 수 있다
- **「개별주택가격은 전국 통합 자료가 없다」를 조회 불가로 읽기** — 통합 다운로드가 없을 뿐 개별 조회는 된다
- **조회 결과에서 개별주택가격만 가져오고 대지면적(산정)을 버리기** — 안분 근거를 통째로 놓친다
- **공시 기준연도를 빼고 공시가격만 쓰기**
- **공시가격의 분모를 낙찰가로 잡기** — 언제나 감정평가액이다
- **낙찰가 시나리오마다 보유세가 달라지게 만들기** — 분모를 잘못 잡은 것이다
- **취득세를 연면적으로 안분하기** — 연면적 안분(§19③)은 신축·증축 전용이다. 승계취득은 §19② 시가표준액
- **취득세와 재산세의 안분 비율을 같게 만들기** — 근거 조문이 §19② 와 §106②1 로 다르다
- **§19② 분자에 개별주택가격을 넣기** — 「건축물 중 주택 부분」은 §4② 건물 시가표준액이다
- **교부청구서 역산값을 공시가격 확정치로 쓰기** — 조회 실패 시 보조 검산이고 언제나 [추정] 이다
- **어느 판이 깔렸는지 확인하지 않고 스크립트를 호출하기** — 「설치판 확인」 한 줄을 먼저 돌린다
- **`scripts/tax_calculator.py` 를 `public_price` 없이 호출하기** — 구판이면 폐기된 기본값이 조용히 적용된다
- **스크립트에 `appraisal_price=` 를 넘기기** — 구판은 이 인자를 **받아들여** 452행에서
  `× 0.6` 가정을 조용히 만든다. 오류가 안 나므로 더 위험하다
- **구판에서 차단 래퍼를 건너뛰고 직접 import 하기**
- **`test_public_price_gate.py` 를 돌리지 않고 방어 로직을 고쳤다고 말하기**
- **스크립트·부속 파일이 낸 공시가격을 그대로 옮기기** — 폐기된 0.6·0.7 이 살아 있다
- **주택 부속토지에 비주택 세율(4%) 적용하기** — 주택은 건물 + 부속토지 일체다
- **재산세 1세대1주택 특례세율 판정을 빠뜨리기** — 시가표준액 900,000,000원 이하 한정이다
- **종부세를 현행 세율로 계산하기** — 낙찰 다음 해가 첫 과세연도다
- **종부세에서 재산세 공제를 빠뜨리기 / 안분 전 금액으로 공제액 계산하기**
- 세율·법령 수치를 조회 없이 단정하기
