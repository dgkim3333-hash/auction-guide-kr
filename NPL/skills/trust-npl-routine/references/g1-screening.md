## Gate 1 — 즉시반려 스크리닝 (2시간)

### 5대 치명 리스크 (1개라도 해당 → 자동 반려)

| # | 항목 | 기준 | 확인 방법 |
|---|-----|------|---------|
| 1 | 담보가치 역전 | 채권최고액 > 시세 × 80% | 감정가·인근 실거래가 1차 확인 |
| 2 | 수익채권 시효 임박 | 소멸시효 완성 6개월 이내 | 최종 연체일·독촉 내역 |
| 3 | 당해세 과다 추정 | 등기부 갑구 압류 합계 > 감정가 × 10% | 갑구 압류 항목 합산 (천원 단위 해석) |
| 4 | 수탁자 블랙리스트 | 내부 블랙리스트 등재 | 내부 신탁사 DB |
| 5 | 신탁사 공매 실적 전무 | 과거 3년 공매 0건 | 온비드 조회 |

### 서울시 물건 필수 추가 체크 — 정비사업 인접 여부

물건 소재지가 **서울시**인 경우 아래 절차를 필수 수행:

1. `__서울시_정비사업_추진현황.xlsx` (456개 구역) 참조
2. 물건의 지번주소·도로명주소를 `위치1(지번주소)`·`위치2(도로명주소)` 컬럼과 대조
3. 동일 동(洞) 또는 인접 동 정비사업 존재 여부 확인
4. 판정: 🔴 구역 내 / 🟡 50m 이내 인접 / ✅ 해당없음

인접 판정 시 추가 분석:
- 구역명·자치구·사업방법(공공/민간)·사업유형·사업추진단계·구역지정일(최초/변경)
- 권리산정 기준일 이전/이후 물건 여부 → 조합원 자격 취득 가능성
- **보상금이 우선수익자에게 귀속되는지** 신탁계약서에서 확인 (신탁 특유 이슈)
- 정비사업 지연·무산 시 회수 시나리오
