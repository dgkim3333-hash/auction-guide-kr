## Gate 3.5 — MOLIT 시세 확보 (반일)

### 목적

신탁공매 예정가격은 감정가 기준이나, 실제 유찰률·회수가는 **시장 실거래가에 수렴**한다. 감정가만으로 IRR을 계산하면 손실이 내재된다 (`npl-analysis` 실패유형 #1).

### 조회 규칙 (3대 엄격 조건)

**① 소스 — `real-estate` MCP 국토부 실거래가만 사용**

도구 매핑
- 아파트: `get_apartment_trades`, `get_apartment_rent`
- 오피스텔: `get_officetel_trades`, `get_officetel_rent`
- 빌라·연립: `get_villa_trades`, `get_villa_rent`
- 단독·다가구: `get_single_house_trades`, `get_single_house_rent`
- 상업용: `get_commercial_trade`
- 토지: 관련 도구

> ⚠ 계정판 기준과 다름 — 우선 규칙: 시세 조회 순서는 DuckDB(경매창고.duckdb) → PlayMCP kakaoRealEstate → real-estate MCP → datagokr (출처 게이트 적용). real-estate MCP 단독 사용 아님

**금지 소스**
- KB시세(kbland.kr)·호갱노노·아실·부동산지인·리치고·네이버 호가
- 위 소스는 "존재하지 않는 소스"처럼 취급 (검색·인용·산출물 포함 모두 금지)

**② 대상 — 동일 단지 + 동일 면적 엄격 필터**
- 단지명: **완전 일치** (예: "래미안OO" ≠ "래미안OO2차", "청솔마을 주공9단지" ≠ "청솔마을(유천)")
- 전용면적: **완전 일치** 원칙. 동일 아파트 내부 소수점 차이(84.97 vs 84.92㎡)는 동일 구조로 판단되는 경우에만 허용
- **조건 미달 시 추정·보간·유사단지 대체 금지** → "데이터 없음" 명시

**③ 기간 — 최근 6개월 고정**
- 분석일 기준 6개월 전까지 각 달 순차 호출
- 거래 건수 부족해도 **기간 확장 금지** (12개월로 늘리기 금지)
- 예: 분석일 2026-04-21 → 2025-11, 2025-12, 2026-01, 2026-02, 2026-03, 2026-04 (6개월)

### 조회 절차

1. `get_region_code`로 5자리 법정동 코드 확보
2. 물건 유형별 MCP를 **최근 6개월 각 월 순차 호출** (`deal_ymd=YYYYMM`)
3. **`num_of_rows` 충분히 확보**: 분당·강남·서초·송파 등 거래 많은 지역 = 1000. `total_count > items.length` 이면 재조회
4. 필터링: 단지명·면적 완전 일치 + **해제 거래 제외** (`cdealType="O"` 또는 해제사유 有)
5. **전월세 병행 조회는 "임차 리스크 검증"의 핵심 단계 — 항상 병행** (아래 별도 규정 준수)

---

### 📌 전월세 병행 조회 규정 (임차 리스크 검증 — 필수)

**전월세 조회는 선택이 아닌 필수**. 신탁NPL의 최대 실패유형은 **숨은 임차보증금 인수**이며, 실제 시장 전월세 데이터 없이는 **임차 1억 가정이 낙관인지 비관인지 판단 불가**하다.

#### 조회 대상 MCP 도구

- 아파트: `real-estate:get_apartment_rent`
- 오피스텔: `real-estate:get_officetel_rent`
- 빌라·연립: `real-estate:get_villa_rent`
- 단독·다가구: `real-estate:get_single_house_rent`

> ⚠ 계정판 기준과 다름 — 우선 규칙: 시세 조회 순서는 DuckDB(경매창고.duckdb) → PlayMCP kakaoRealEstate → real-estate MCP → datagokr (출처 게이트 적용). real-estate MCP 단독 사용 아님

조회 기간·단지·면적 조건은 **매매와 동일**(최근 6개월·동일 단지·동일 면적 엄격 필터).

#### 3단계 집계 규칙

동일 단지 전월세 거래가 부족한 경우가 많으므로 **3단계 벤치마크**를 순차 구축:

| 단계 | 대상 | 용도 |
|-----|------|------|
| **Tier 1 — 동일 단지** | 분석 대상 단지 전수 | 최우선 참조 |
| **Tier 2 — 동일 동 + 유사 평형** | 동일 읍면동 + 면적 ±20% | Tier 1 0건 시 |
| **Tier 3 — 유사 신축 + 유사 평형** | 전 지역 + 건축연도 ±3년 + 면적 ±15% | Tier 2 부족 시 벤치마크 |

각 Tier에서 **전세(월세 0)·반전세·월세** 3종으로 분류하여 집계.

#### 보증금 가정 검증 (3단계 판정)

사용자 또는 분석자가 가정한 임차 보증금을 **유사 단지 전세 중앙값과 비교**하여 판정:

| 판정 | 조건 | 의미 |
|------|-----|------|
| 🟢 **보수적 가정** | 가정 보증금 ≥ 중앙값 × 1.2 | 최악 시나리오 반영. 신뢰 가능 |
| 🟡 **중립적 가정** | 중앙값 × 0.8 ≤ 가정 < 중앙값 × 1.2 | 시장 평균선. 추가 상하 시나리오 병행 권장 |
| 🔴 **낙관적 가정 (위험)** | 가정 보증금 < 중앙값 × 0.8 | **실제 임차가 더 높을 가능성 ↑**. 재시뮬 필수 |

→ 판정 결과를 G2 임차인 판정표·G4 배분시뮬에 **자동 반영**하여 시나리오를 재계산.

#### 깡통 전세 리스크 판정 (결정적)

유사 신축 동일 평형의 **전세/매매가 비율**을 산출하여 아래 기준으로 위험 판정:

| 전세/매매 비율 | 판정 | 의미 |
|-------------|------|------|
| < 70% | 🟢 안전 | 매각 차익 여유 有 |
| 70~90% | 🟡 주의 | 전세금 거의 시세 근접, 매각 차익 제한적 |
| **≥ 90%** | 🔴 **깡통 전세** | 전세금 ≥ 매각가 → **매입 원금 회수 불가능 구조** |

→ 깡통 전세 확정 시 **G1 즉시반려 스크리닝 6번째 항목**으로 격상 처리. 매입 포기 권고.

#### 월세 시장 병행 확인

전세가 부족하면 **월세 환산 보증금**으로 병행 검증:
- 환산 보증금 = 보증금 + (월세 × 100) *(통상)*
- 상가 임대차는 환산보증금 기준으로 상임법 적용 여부 결정됨

### 표본 충실도 판정

| 거래 건수 | 판정 | 처리 |
|---------|------|------|
| 5건 이상 | 충분 | 평균가 기준 낙찰가 산정, 한계 고지 불필요 |
| 3~4건 | 제한적 | 평균가 사용 + 한계 고지 박스 명시 |
| 1~2건 | 부족 | 평균가 참고만, 할인 폭 확대, 한계 고지 필수 |
| 0건 | 데이터 없음 | 감정가 × 0.60~0.65 보수 추정, 한계 고지 필수 |

> ⚠ 계정판 기준과 다름 — 우선 규칙: 표본 0건이면 "데이터 없음" 명시, 감정가 배율 추정·보간 금지(계정판 SKILL.md G3.5)

### 낙찰가 예측 연계

- **기준 시세** = 최근 6개월 동일 단지·동일 면적 평균
- **표준 낙찰가** = 기준 시세 × 0.60~0.70
- **시세 하락 추세**: × 0.55~0.65 추가 할인
- **표본 1~2건**: 위 결과에서 추가 5%p 할인
- **데이터 없음(0건)**: 감정가 × 0.60~0.65 참고값, 한계 고지 박스에 "실거래가 기반 낙찰가 예측 불가" 명시

> ⚠ 계정판 기준과 다름 — 우선 규칙: 표본 0건이면 "데이터 없음" 명시, 감정가 배율 추정·보간 금지(계정판 SKILL.md G3.5)

### 한계 고지 박스 (투명성 필수)

MCP 호출했으나 한계 1개 이상 있으면 **PPTX 시세 슬라이드 하단**에 아래 형식을 **그대로** 삽입한다. 회색 배경·검정 테두리로 시각 구분.

```
솔직히 답변드립니다. MCP 호출은 했지만 다음 N가지 한계가 있었습니다:

1. [한계 항목 1 — 구체적으로 기술]
2. [한계 항목 2 — 구체적으로 기술]
...
```

**N 규칙**: 1개면 "1가지", 2개면 "2가지", 3개 이상이면 실제 숫자. 0개면 박스 생략.

**한계 항목 작성 예시**
- "최근 6개월간 동일 단지(OO아파트) + 동일 면적(84.97㎡) 매매 실거래 0건 확인. 유사 면적·인근 단지 보조 조회도 수행하지 않아 시세 근거 부족"
- "최근 6개월간 동일 단지·동일 면적 실거래 2건만 확인. 표본 부족으로 평균 대표성 낮음"
- "국토부 MCP 호출 시 2025-12월, 2026-02월 일부 응답 타임아웃"
- "확인된 5건 중 3건이 해제 거래로, 실제 유효 거래 2건만 반영"
