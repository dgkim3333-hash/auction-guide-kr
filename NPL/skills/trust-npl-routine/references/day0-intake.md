### 파일명 동의어 관대 매칭

법원·금융기관·신탁사에서 받는 서류는 **표기 차이**가 있으므로 아래 동의어 목록으로 매칭한다. **부분 포함 매칭**이면 동일 문서로 간주한다.

| 대표 문서명 | 동의어 (부분 포함) | 용도 |
|-----------|------------------|-----|
| 신탁원부 | `신탁원부`, `신탁계약서`, `부동산담보신탁계약서`, `담보신탁계약서` | G2 권리관계 |
| 우선수익권증서 | `우선수익권증서`, `수익권증서`, `우선수익자확인서`, `수익권확인서` | 매입 대상 특정 |
| 수탁자 양도동의서 | `양도동의서`, `수익권양도동의서`, `양도승낙서`, `사전동의서` | G3 수탁자 타진 |
| 수탁자 질권설정동의서 | `질권설정동의서`, `질권동의서`, `질권승낙서` | 레버리지 검토 |
| 임대차 동의서 | `임대차동의서`, `임대차승낙서`, `임대승인서`, `임대차동의확인서` | G2 임차인 판정 |
| 법원 문건접수 | `법원물건접수`, `법원문건접수`, `법원접수내역`, `송달내역` | 경매 전환 대비 |
| 매각물건명세서 | `매각물건명세서`, `매각물건`, `물건명세서` | 권리관계 |
| 감정평가서 | `감정평가서`, `감정서`, `평가서` | G3.5·G4 |

**운용 원칙**
- 파일명에 동의어 중 **하나라도 부분 포함**되면 동일 문서로 처리
- 동의어 목록에 없는 새로운 표기 발견 시 분석에는 사용하되, 사용자에게 "동의어 등록 필요" 안내
- 여러 파일이 매칭되면 **수정일 최신** 우선, 내용 차이 의심 시 사용자 확인
