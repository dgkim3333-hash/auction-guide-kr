## Day 0.5 — 신탁원부 A+C Word 추출 (필수 선행 산출물)

> **사용자 확정 표준 (2026-04-23 영구 적용)**: 신탁원부 PDF가 스캔본인 경우 반드시 **A+C 조합**으로 Word 문서화한다. 단순 OCR 덤프는 금지된다.

### 왜 A+C 표준인가

2026-04-23 강남팰리스 305호 분석 중, 200 DPI OCR 단순 덤프 방식으로 생성한 Word 문서가 **원문 판독 불가·조항 구조 미흡·분석 해설 부족**으로 실무 활용 불가 판정을 받았다. 향후 모든 신탁NPL 분석에서 아래 A+C 표준을 **고정 적용**한다.

### A. 고해상도 OCR + 전체 조항 구조화

1. **300 DPI 렌더링** (200 DPI 금지 — 문자 인식률 부족)
2. `easyocr` 한국어+영어 OCR (`gpu=False`, `paragraph=True`)
3. OCR 결과에서 **"제N조" 패턴 자동 감지** → 조항 단위 재구성
   - 정규표현식: `제\s*\d+\s*조`, `제\s*\d+\s*조\s*\([^)]+\)` 등 다중 패턴
4. 조항마다 **조항번호 · 제목 · 페이지 · OCR 원문 · 분석자 판독** 5요소 기재

### C. PDF 페이지 이미지 직접 삽입

1. 각 PDF 페이지를 **300 DPI PNG로 렌더링**
2. 해당 조항이 있는 페이지 이미지를 Word에 **직접 삽입** (폭 16cm 기준 축소)
3. 이미지 바로 아래 OCR 텍스트 + 분석자 해설 병기 → **시각적 원문 대조 가능**

### 문서 구성 (고정)

| # | 구성 | 내용 |
|---|-----|------|
| 1 | 표지 | 기본정보·수탁자·신탁원부 번호·OCR 한계 고지 |
| 2 | 목차 | 조항별 자동 생성 목차 |
| 3 | 제1부 등기사항증명서 | p1~5, 24~25 (이미지 + OCR) |
| 4 | 제2부 신탁계약서 본문 | **조항별 섹션**: 원본 페이지 이미지 + OCR 원문 + 분석자 해설 |
| 5 | 제3부 핵심 임대차 조항 상세 | 제10·11·18·19·23조 전문 해설 |
| 6 | 제4부 수탁자 확인 체크리스트 | 7~10개 질문 (신탁사 유선 확인용) |
| 7 | 부록 | 전체 페이지 원본 이미지 (썸네일) |

### ⚠️ Windows 경로 함정 (필수 준수)

**사용자 폴더 경로는 반드시 영문 기본 경로를 사용한다**. 한글 표시명으로 저장하면 사용자가 찾지 못한다 (2026-04-23 발견).

| 폴더 | 올바른 경로 (디스크 실체) | Windows 파일탐색기 표시 |
|------|----------------------|----------------------|
| 다운로드 | `%USERPROFILE%\Downloads\` | "다운로드" |
| 문서 | `%USERPROFILE%\Documents\` | "문서" |
| 바탕화면 | `%USERPROFILE%\Desktop\` | "바탕 화면" |
| 사진 | `%USERPROFILE%\Pictures\` | "사진" |

**금지**: `%USERPROFILE%\다운로드\`, `%USERPROFILE%\문서\` 등 한글 이름 폴더에 저장 (별도 하위 폴더로 존재하여 혼동 유발).

**예외**: 작업 폴더 안은 한글 이름 그대로 사용 (`C:\AI\NPL\신탁NPL\` 등). 이는 사용자가 의도적으로 한글로 만든 업무 폴더이며, 영문 시스템 폴더와 구분된다.

파일명은 반드시 `신탁원부_A+C_추출.docx` 로 고정 (버전 관리 시 `_v2`, `_v3` 접미사 추가 가능).

### 금지 사항

- ❌ 200 DPI 이하 해상도 사용
- ❌ OCR 원문만 덤프 (페이지 이미지 미삽입)
- ❌ 조항 단위 재구조화 없이 페이지 순서만으로 출력
- ❌ 분석자 해설 섹션 생략
- ❌ 수탁자 확인 체크리스트 미포함
- ❌ 파일명 임의 변경

### 구현 의존성

- Python 패키지: `PyMuPDF`(fitz), `easyocr`, `python-docx`, `Pillow`, `numpy`
- 저장 폰트: **맑은 고딕** (`<w:eastAsia>` 속성 적용)
- 이미지 삽입 시 `Inches(6.3)` 또는 `Cm(16)` 폭으로 통일

### 품질 검증 체크리스트

Word 파일 생성 후 아래 5항목 모두 충족 확인:

1. OCR 텍스트에서 "제1조" ~ "제마지막조"까지 순차 식별되는가?
2. 각 조항 섹션에 원본 페이지 이미지가 삽입되어 있는가?
3. 핵심 임대차 조항 5개(제10·11·18·19·23) 분석 해설이 포함되어 있는가?
4. 표지에 OCR 한계 고지 박스가 있는가?
5. 부록에 전체 25페이지 이미지가 있는가?

하나라도 미충족 시 **재생성 필수**.
