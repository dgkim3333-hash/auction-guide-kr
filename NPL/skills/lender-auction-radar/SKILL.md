가드 3중 — 아래를 글자 그대로 복사해 실행한다. 경로를 다시 치지 않는다.

```bash
BASE=$(ls -d /sessions/*/mnt/NPL | head -1)

[ -d "$WK" ] || { echo "GUARD1_FAIL 상위 폴더 없음"; exit 0; }      # 가드 1: 상위 실재 확인, 없으면 만들지 않음
[ -d "$WK/$WEEK_MON" ] || mkdir "$WK/$WEEK_MON"                      # 가드 2: 한 단계만 생성, -p 금지
cp "$SRC" "$WK/$WEEK_MON/" && cmp "$SRC" "$WK/$WEEK_MON/$(basename "$SRC")" && echo COPY_OK
ls -d "$BASE"/이번* ; ls -la "$WK/$WEEK_MON/$(basename "$SRC")"     # 가드 3: 루트 「이번*」이 정확히 1개인지
```

|---|---|
| 가드 1 실패 | 폴더를 만들지 않고 사본만 건너뛴다. 보고에 「분석용 사본 상위 폴더 없음 — 복사 생략」 |

### 1-다. EUC-KR 인코딩은 필수다 ★★

사이트가 EUC-KR 이다. 한글 파라미터를 UTF-8 로 보내면 **에러 없이 조건이 통째로 무시되고 전량이 돌아온다.**
건수가 **줄지 않고 늘어나기 때문에** 성공으로 착각하기 쉽다.

인코딩 값을 손으로 적지 말고 **역매핑 테이블을 만들어 쓴다.** 추측하면 틀린다.

```js
const dec = new TextDecoder('euc-kr'); const MAP = new Map();
for (let hi = 0xA1; hi <= 0xFE; hi++) {
  const buf = new Uint8Array((0xFE - 0xA1 + 1) * 2); let k = 0; const los = [];
  for (let lo = 0xA1; lo <= 0xFE; lo++) { buf[k++] = hi; buf[k++] = lo; los.push(lo); }
  const s = dec.decode(buf);
  if (s.length === los.length) for (let i = 0; i < s.length; i++) if (!MAP.has(s[i])) MAP.set(s[i], [hi, los[i]]);
}
const eucEnc = (str) => {
  let o = '';
  for (const ch of str) {
    if (/[\x00-\x7F]/.test(ch)) { o += encodeURIComponent(ch); continue; }
    const b = MAP.get(ch);
    if (!b) throw new Error('EUC-KR 미매핑 문자: ' + ch);
    o += '%' + b[0].toString(16).toUpperCase() + '%' + b[1].toString(16).toUpperCase();
  }
  return o;
};
```

응답도 EUC-KR 이다. `new TextDecoder('euc-kr').decode(await r.arrayBuffer())` 로 디코딩한다.
`r.text()` 를 쓰면 한글이 깨진다.

검증용 고정값 — 생성 결과가 아래와 다르면 테이블이 잘못된 것이다.

### 1-라. 파싱

가장 행이 많은 표를 잡는다. **1행 헤더 + 물건당 2행** 구조다.
(관심물건 목록은 3행 구조다. 혼동하지 않는다.)

셀 순서 — `[체크박스, 사건번호, 물건기본내역, 청구액+alg시세, 개시일+배당종기, 구분]`
**두 번째 금액은 감정가가 아니라 alg 추정시세다.**
`채권자 :` `채무자 :` `소유자 :` 로 시작하는 조각에서 값을 뗀다. 상세페이지는 열지 않는다.

**물건기본내역 셀(3번째)의 DOM 구조**:

| 선택자 | 값 |
|---|---|
| `.fontColor_Gray` | `[강제경매]` / `[임의경매]` → 대괄호 떼고 `경매구분` |
| `.fontColor_Blue` | `아파트` `다세대` `근린시설` `임야` `집합건물` … → **`용도`** |

| A500:X(500+R) | 원본 표 `TBL_LENDER` — **보고대상 R건만**(STEP 6-1) |

```

C5 =SUBTOTAL(109,TBL_LENDER[청구액(원)])
```

1. 파싱 결과를 2차원 배열로 만들 때 **날짜는 `YYYY.MM.DD` → `YYYY-MM-DD` 로 바꾼다.**
   [확정] 2026-09-25 실측: `2026.09.15` 처럼 점 3단 문자열은 도구 출력에서 `[BLOCKED: JWT token]` 으로 가려진다.
   금액은 콤마를 떼고 숫자 문자열로 둔다.
2. `document.body.innerHTML=''` 후 `<pre id="dump">` 에 `JSON.stringify(배열)` 을 넣고 `get_page_text` 로 받는다(최대 약 50,000자).
3. 받은 JSON을 파일 도구로 작업공간에 저장한다(예: outputs/raw_YYYYMMDD.json).
4. **전사 검산 필수** — 브라우저와 bash 양쪽에서 같은 값을 계산해 대조한다. 하나라도 다르면 진행하지 않는다.
   - 건수, 청구액 합계
   - 문자열 해시: 각 행을 `|` 로 잇고 행 사이를 `\n` 으로 이은 문자열 s 에 대해 `h = (h*31 + 코드포인트) mod 2^32`
   ```js
   const A=JSON.parse(document.getElementById('dump').textContent); let h=0;
   const s=A.map(r=>r.join('|')).join('\n'); for (const ch of s){h=(h*31+ch.codePointAt(0))>>>0;}
   ({n:A.length, claim:A.reduce((a,r)=>a+(+r[9]||0),0), h, len:s.length})
   ```
   ```python
   import json; A=json.load(open(path)); s='\n'.join('|'.join(r) for r in A); h=0
   for ch in s: h=(h*31+ord(ch))&0xffffffff
   print(len(A), sum(int(r[9]) for r in A if r[9].isdigit()), h, len(s))
   ```
   (r[9] = 청구액 열 위치. 배열 열 순서를 바꾸면 인덱스도 맞춘다.)
5. 원본 CSV(`ggi_wait_lender_v2_YYYYMMDD.csv`, UTF-8 BOM, 24열)는 bash 로 저장 폴더에 직접 쓴다.

[확정] 2026-09-25 회차: 242행 · 청구액 합계 200,259,704,378원 · 해시 2253610573 · 길이 33,232자가 양쪽에서 일치했다.

### 9-A. 기본 경로 — openpyxl + Excel MCP + XML 패치

1. **openpyxl**: 데이터·헤더·라벨·안내문·행 높이·열 폭·결과영역 서식·Z열 수식 작성.
   `ws.freeze_panes='A15'`도 **여기서** 걸어 둔다.
   **구조적 참조(TBL_LENDER[...])를 openpyxl로 쓰지 않는다** — 표가 아직 없어 로드 시 깨진다.
2. **Excel MCP**: `table(create, A500:X…, TBL_LENDER)` → **그 다음** C4:C9 KPI 수식과 A15 스필 수식을
   `range(set-formulas)`로 작성 → 슬라이서 7개 → 피벗 3종 → 대시보드 KPI·차트.
3. Excel 세션 닫기.
4. **XML 패치**(압축 해제 → 부품 수정 → 재압축):
   - 차트 경계선: `</c:chart>` **바로 뒤**에 `<c:spPr>` 삽입 (흰 배경 + `1F4E79` 1pt)
   - 슬라이서 좌표: 각 `<xdr:twoCellAnchor>`를
     `<xdr:absoluteAnchor><xdr:pos x y/><xdr:ext cx cy/>…</xdr:absoluteAnchor>`로 교체.
     pt × 12700 = EMU. **Excel 재저장 후에도 absoluteAnchor는 유지된다**(실측 확인).
   - 재압축 전 `xml.etree.ElementTree.parse()`로 수정한 부품을 전부 **파싱 검증**한다.
5. 파일을 다시 열었다 저장해 Excel이 수용하는지 확인.

**★ XML 패치는 문자열 치환으로 한다. ElementTree로 쓰지 않는다.**
슬라이서 앵커에는 `mc:Choice Requires="sle15"` 가 들어 있는데 ElementTree로 다시 쓰면
네임스페이스 prefix가 바뀌어 **`Requires` 참조가 끊긴다.** 파싱은 검증용으로만 쓴다.

**★ 재압축은 원본 엔트리 순서를 그대로 따른다.**
`zip -r` 로 디렉터리 엔트리까지 넣지 말고, 원본 `namelist()` 순서대로 `zipfile.write()` 한다.
`[Content_Types].xml` 이 **첫 엔트리**여야 한다.
파이썬이 재압축한 파일은 Excel이 쓴 것보다 작게 나온다(실측 164KB) — 정상이다.
**Excel이 한 번 열었다 저장하면 정상대역으로 돌아온다**(실측 178KB).

### 9-B. 대체 경로 — Excel MCP + VBA 브리지 (2026-09-15 대표 승인으로 등재)

**bash 작업공간이 죽으면 openpyxl·XML 패치를 쓸 수 없다.**
(2026-09-08 이후 Windows 업데이트로 `failed to mount … Plan9 share "c" is not mounted` 발생 실측)
이때 회차를 버리지 말고 아래 경로로 완주한다. 2026-09-14 회차에서 실측 검증됐다.

1. **데이터 전달** — 브라우저에서 파싱한 2차원 배열을 **JSON 파일로 다운로드**하고
   `range(set-values, values_file=<json 경로>)` 로 읽힌다.
   - **CSV를 values_file로 주지 않는다.** Excel MCP의 CSV 파서가 따옴표 안의 콤마를
     열 구분자로 읽어 `청구액 규모대`·주소에서 열 수가 어긋난다(실측 24열 → 28열).
   - `range_address` 는 `A500:X695` 처럼 **정확한 크기**로 준다. `A500` 만 주면 열 수 불일치 오류.
   - `javascript_tool` 응답은 ~1,500자에서 잘린다. **데이터를 응답으로 끌어오려 하지 말고
     반드시 파일로 내린다.**
2. **자리 이동** — 다운로드 폴더는 세션 연결 폴더가 아니라 bash·파일 도구로 닿지 않는다.
   VBA `FileSystemObject.CopyFile` 로 옮긴다.
3. **범위 지정 사고 주의 ★** — `set-values` 에 `B499:Z500` 같은 **두 행짜리 범위**를 주면
   두 번째 행 전체가 빈 문자열로 덮여 **A500 표 헤더가 날아간다.**
   실측으로 한 번 겪었다. 안내문과 보조열 헤더는 **행마다 따로** 쓴다.
4. **틀고정·슬라이서 pt 좌표** — Excel MCP에 해당 도구가 없다.
   `.xlsm` 브리지를 만들어 VBA로 처리한다.
   - 브리지는 **연결 폴더 밖**(예: `%USERPROFILE%\Downloads\_bridge_lender.xlsm`)에 만든다.
   - 대상 `.xlsx` 는 **MCP 세션을 먼저 닫아 저장한 뒤** VBA가 `Workbooks.Open` 으로 연다.
   - `ActiveWindow.FreezePanes` 는 시트를 `Activate` 하고 `Range("A15").Select` 한 뒤에 건다.
   - 슬라이서는 `ws.Shapes(이름).Top/.Left/.Width/.Height` 로 pt 직접 지정.
   - VBA 반환값은 MCP 응답에 실리지 않는다. **결과를 브리지 시트 셀에 써 넣고 읽어서** 확인한다.
5. **마스터 병합**도 VBA `ADODB.Stream` 으로 한다.
   - 인코딩을 추측하지 말고 UTF-8로 읽어 `수협` 같은 한글이 보이는지 확인한 뒤,
     안 보이면 `korean`(CP949)으로 다시 읽는다. **읽은 인코딩 그대로 되쓴다.**
   - UTF-8로 쓸 때는 BOM을 떼고 저장한다.
6. bash가 살아나면 **9-A의 XML 패치(차트 경계선·absoluteAnchor)를 나중에라도 적용한다.**
   VBA로 잡은 pt 위치는 twoCellAnchor라서 열 폭이 바뀌면 밀린다.

**정상 파일 크기는 175,000~195,000바이트**다. 70,000바이트대면 슬라이서·피벗·차트가
통째로 빠진 껍데기다(2026-08-14 실측). 그런 파일은 납품하지 않는다.

### ★ recalc.py(LibreOffice)를 이 파일에 돌리지 않는다
