# auction-failure-guard — 경매·공매 실패 예방 게이트

## 왜 이 스킬이 있나

경매에서 보증금을 날리거나 거액의 인수액을 떠안은 사례를 모아 보면, 대부분 **서류에 이미 적혀 있던 위험을 읽지 않았거나, 입찰 직전·잔금 직전에 서류를 다시 보지 않아서** 생겼다. 같은 물건에서 몰수가 3~7번 반복된 사례(광양 5회, 부여 7회, 대전 갈마 4회, 산청 6회)가 그 증거다. 이 스킬은 실제 실패 사례를 「물건에서 보이는 신호 → 확인할 서류 → 판정 → 금액 영향」으로 바꾼 점검표다.

권리분석·입찰가 산정·NPL 매입가 산정 자체는 다른 스킬이 한다. 이 스킬은 그 결과물에 덧씌우는 **실패 예방 레이어**다.

| 함께 쓰는 스킬 | 역할 분담 |
|---|---|
| auction-property-review / auction-property-card / residential·commercial·land·small-building-auction | 물건 분석 본체. 이 스킬은 그 뒤 「실패위험 점검표」를 추가 |
| auction-bid-price / bid-win-curve | 입찰가 산정. 이 스킬의 인수액·숨은비용을 차감한 상한을 넘겨준다 |
| npl-analysis / ggi-interest-npl-scan / trust-npl-analysis | NPL 매입가. 이 스킬은 낙찰가율 하향 요인·회수 지연·반려 사유를 넘겨준다 |
| priority-payment-date-rule / real-estate-tax-calculator / property-tax-apportionment | 최우선변제·세금 계산의 정본. 이 스킬은 계산식을 새로 만들지 않고 이들을 호출한다 |

## 1단계. 모드 판정

- **모드 A (직접 입찰)**: 우리가 낙찰자가 되는 경우. 경매·공매 직접 입찰, NPL 매입 후 유입(채권자 직접 낙찰·상계)도 포함.
- **모드 B (NPL 매입)**: 우리가 근저당·채권을 사고 제3자 낙찰로 배당받는 경우. 실패 요인이 「제3자 입찰자를 쫓아내 낙찰가를 떨어뜨리는지」, 「우리 배당 순위 위에서 돈을 가져가는지」, 「절차 자체를 멈추는지」로 바뀐다.

유입 가능성이 있는 NPL은 모드 B로 매입가를 보고, 유입 시나리오에 모드 A 3게이트를 그대로 붙인다.

## 2단계. 서류 확보 — 「미확인」은 「통과」가 아니다

| 서류 | 왜 필요한가 (실제 실패) |
|---|---|
| 매각물건명세서 **최신본** (비고란·「소멸되지 않는 권리」란·하단 특기사항까지) | 인수 문구·조합원 불가·허가 필요 문구가 이미 적혀 있었는데 놓침 (성수 강변임광, 부여, 안성 동광) |
| 등기부 건물·토지 **입찰 당일 재열람** (인터넷등기소) | 사설 사이트 등기부는 갱신이 늦다. 낙찰 직전 근저당 말소로 18,760,000원 몰수 (오산) |
| 건축물대장 표제부 + **전유부(호별 용도)** + 위반건축물 표시 | 「오피스텔」 명칭인데 호실 용도는 다세대 → 취득세 중과 (신림) |
| 감정평가서 (평가 대상 범위·사진·제시외) | 토지 제외·건물만, 매각제외 수목, 개 사육장, 폐기물 |
| 현황조사서 + 전입세대열람 | 선순위 전입자·폐문부재·진술 보증금 |
| 문건/송달내역 (배당요구서 접수일, 권리신고, 채권자 의견서) | 종기 후 배당요구인데 비고란에 표시 없었음 (안양 호계). 채권자 의견서가 낙찰 후 삭제 (경희궁자이) → **입찰 직전 캡처** |
| (공매) 온비드 재산명세서 최신본·공고문·조세 법정기일 목록 | 갱신본에 근저당 말소 반영돼 있었음 (오산). 조세 선배분 (서초 오피스텔) |
| 신탁원부 (신탁 물건) | 수탁자 동의 없는 임대차·분양 (당산 임차인 피해 10,000,000,000원, 용인 그대가) |
| 토지이용계획·건축허가대장 (토지) | 공익용산지·농업진흥구역·건축허가 승계 불가 |

없는 서류는 표에 「서류없음」으로 남기고, 그 서류에 걸린 유형은 판정을 보류한다. 보증금 미상을 0원으로 처리하지 않는다 — 전입 당시 같은 단지·같은 면적 전세 실거래의 **최댓값**을 쓰고 [추정]으로 표시한다(시세·실거래 조회 순서는 npl-analysis 원칙을 따른다: DuckDB(03단원 창고 C:\AI\경매창고.duckdb) → PlayMCP → real-estate → datagokr).

## 4단계. 핵심 계산 — 낙찰가가 아니라 실질 취득가로 판단한다

```
실질 취득가 = 낙찰가
            + 인수액 (T1~T5: 미배당 대항력 보증금, 인수 전세권, 조세 선배분으로 생긴 부족분)
            + 숨은비용 (T7·T10: 조합 분담금, 공용관리비, 폐기물, 이행강제금, 명도·동물 보관, 토지 사용료)
            + 취득세 등 (과세표준에 인수 보증금 포함 — [검증필요], 공용관리비는 불포함 — [확정])
입찰 상한 = 시세 − (인수액 + 숨은비용 + 취득세 + 목표마진)
```

- 시세가 입찰 상한보다 낮게 나오면 「어떤 가격으로도 실익 없음」으로 판정한다(광양: 보증금 87,000,000원 > 시세 53,000,000원).
- 인수액이 있는 물건은 경락대출이 사실상 안 된다고 보고 **전액 현금 조달 가능 여부**를 별도 줄로 적는다.
- 최우선변제 안분·기준일은 priority-payment-date-rule, 세금은 real-estate-tax-calculator로 계산한다.

## 5단계. 모드 A — 3게이트

### G1. 입찰 전 (매각기일 7일 전 명세서 공개 후)
11개 유형을 전수 판정하고 「실패위험 점검표」(7단계 출력 형식)를 만든다. 「위험」이 하나라도 있으면 입찰 상한에 금액을 반영했는지 확인하고, 반영할 수 없는 위험(소유권 상실·허가 불가·현금청산)은 입찰 보류를 권고한다.

### G2. 입찰 당일 아침
1. 인터넷등기소 등기부 재열람 → 어제와 달라진 줄이 있는지 대조 (특히 말소기준 근저당 존재·금액).
2. 매각물건명세서(공매는 재산명세서) 최신본 재열람 → 비고란 변경 대조.
3. 법원경매정보 문건/송달내역·채권자 의견서 화면 캡처 (낙찰 후 삭제될 수 있음).
4. 입찰표 자기점검:
   - 숫자 금액을 한글로 소리 내 읽기 (예: 412,000,000원 → 「사억일천이백만원」).
   - 입찰가 ÷ 최저가 배율을 계산한다. 1.0배 미만은 무효(최저가 미만), 2.0배를 넘으면 멈추고 다시 쓴다. 자릿수 실수 7건은 모두 10배 이상이었다.
   - 사건번호·**물건번호**·보증금(재매각은 20~30%) 확인. 가격을 고친 입찰표는 무효이므로 새 용지에 쓴다.
   - 대리입찰이면 인감증명·위임장 확인.

### G3. 낙찰 후 허가결정 전(7일) / 확정 후 잔금 전
1. 등기부·명세서 재열람, 현장 재확인(화재·훼손).
2. 농취증·주무관청 허가서 등 제출 서류를 **허가결정기일 전에** 제출. 농지위원회 심의(최대 14일)가 걸리면 법원에 기일 연기 가능 여부를 낙찰 당일 문의.
3. 대출 실제 승인 확인 (인수액·위반건축물·오픈형 상가·건물만은 거절이 흔함).
4. 문제가 발견되면 구제 경로를 시점별로 고른다 (`references/legal-basis.md`):
   - 허가결정 전: 매각불허가 신청 — 천재지변·자기책임 없는 훼손 또는 중대한 권리관계 변동(민사집행법 제121조 제6호) [확정]
   - 허가결정 확정 뒤 대금 납부 전: 매각허가결정 취소신청(같은 법 제127조) [확정]
   - 입찰가 오기: 불허가 사유 아님(대법원 2009마2252) [확정] → 신청채권자에게 연체이자 등 변제 후 취하 협의(의왕 사례, 낙찰 후 취하는 최고가매수인 동의 필요)
   - 재매각 기일 3일 전까지는 대금+지연이자+절차비용을 내면 재매각 취소(같은 법 제138조 제3항) [확정]
5. 손절 비교: 「보증금 몰수액」 vs 「잔금 납부 후 예상 손실」을 같은 표에 놓고 대표가 판단하게 한다.

## 6단계. 모드 B — NPL 매입 분석에 적용

실패 유형을 NPL 회수에 미치는 경로로 다시 분류한다. 상세는 `references/checklist.md`의 각 유형 「NPL 영향」 줄.

| 경로 | 해당 유형 | 매입가 반영 방법 |
|---|---|---|
| ① 제3자 입찰자 기피 → 낙찰가율 하락 | T1 인수(배당요구 없는 선순위), T3, T7 현금청산, T8, T10, T11 | 입찰자가 차감할 인수액·숨은비용을 시세에서 빼고 예상낙찰가를 다시 잡는다. 낙찰가율 계수 자체는 npl-analysis·auction-bid-price 소관 — 이 스킬은 하향 방향과 금액 근거만 넘긴다 |
| ② 우리 배당 순위 위에서 직접 가져감 | T1 (배당요구한 선순위 확정일자 임차인), T4 조세·당해세, 최우선변제 | 예상 배당표에서 우리 근저당 앞줄에 넣는다 |
| ③ 미납 반복·재매각 → 회수 지연 | T1·T2·T3·T5·T6이 걸린 물건의 재매각 이력 | 몰수 보증금은 배당할 금액에 들어간다(민사집행법 제147조 제1항 제5호) [확정]. 단 기본 시나리오에는 넣지 말고 민감도로만 보고, 회수기간을 재매각 1회당 늘린다 |
| ④ 절차 자체가 멈추거나 기각 | T9 주무관청 허가 필요 법인 + 허가받은 근저당 아님, 농취증 불가 농지 | 부여 임야는 7회 낙찰·불허가 뒤 경매가 기각됐다. **반려 권고** 사유로 올린다 |
| ⑤ 유입 시 우리가 낙찰자 | 전 유형 | 모드 A 3게이트를 유입 시나리오에 그대로 적용 |

재매각·미납 이력이 있는 물건은 「앞 낙찰자가 무엇을 놓쳤는지」를 먼저 찾는다. 대개 그 원인이 다음 입찰자들의 차감 요인이 되어 낙찰가율을 끌어내린다.

## 7단계. 출력 형식

항상 아래 구조로 쓴다.

```
## 실패위험 점검표 — [사건번호 / 물건 주소] ([모드 A 게이트 G1·G2·G3 / 모드 B])

| # | 유형 | 신호 (서류·위치) | 판정 | 금액 영향 | 조치 | 유사 실패사례 |
|---|---|---|---|---|---|---|
| T1 | 대항력 인수 | 명세서: 전입 2021.4.21 < 말소기준 2023.11.14, 배당요구 공란 | 위험 | 인수 [추정] 236,250,000원 | 입찰 상한에서 차감, 현금 조달 확인 | 파주 책향기마을 (U5tTQ3dnsqM) |
| ... 11개 유형 모두, 해당 없으면 해당없음, 서류 없으면 서류없음 ...

### 실질 취득가 (모드 A) / 낙찰가·배당 영향 (모드 B)
(4단계 계산식에 숫자 대입, 원 단위 풀 콤마)

### 다음 게이트에서 할 일
(G2·G3 체크 항목 중 이 물건에 해당하는 것만)

### 판단 요약
위험 n건 / 확인필요 n건 / 서류없음 n건. 입찰 보류·반려 권고 사유가 있으면 근거와 함께. 최종 결정은 대표가 한다.
```

판정 값: 위험 실제 손해 경로가 서류로 확인됨 / 확인필요 신호는 있으나 서류·현장 확인 전 / 해당없음 서류로 해당 없음 확인 / 서류없음 서류 없음.

## 표기·검증 규칙

- 사실·수치·법령에는 [확정]/[검증필요]/[추정] 라벨을 붙인다. `references/legal-basis.md`의 [확정] 항목도 산출물마다 MCP로 다시 조회해 식별자(mst·판례 ID)를 적어야 [확정]으로 쓸 수 있다. 조회하지 않았으면 [검증필요].
- 사례집 인용은 「[검증필요] 박철호의 경매TV 자막 근거, 영상ID」로 표시한다. 자막은 자동생성이라 숫자·사건번호가 깨진 곳이 있다.
- 금액은 표·계산식뿐 아니라 **본문 설명 문장까지** 원 단위 풀 콤마로 쓴다. 「2,600만 원」「2억 3천만 원」 같은 말투도 축약이다(시험에서 실제로 새어 나온 표현). 답을 내기 전에 본문에서 `억`·`만 원`·`천만`을 검색해 남아 있으면 고친다 (number-format-guard).
- 시세는 국토부 실거래가만 쓴다. 제3자 시세 사이트 금지.
