# 경매·공매 입찰가 산정 프로토콜

## 핵심 명제 세 가지

> **1. 낙찰가는 유찰회차가 아니라 응찰자 수가 결정한다.**
> 유찰회차는 *가격대*를 정하고, 경쟁강도는 그 안에서 *어느 분위를 쓸지*를 정한다.
>
> **2. 그런데 "몇 명이 붙을지"는 회차가 결정한다.**
> 실측상 응찰 발생률은 1회유찰 1.7% → 9회유찰 45.8%로 단조 증가한다.
> 따라서 진짜 질문은 "얼마 쓸까"가 아니라 **"이번 회차에 사람이 붙을 확률이 얼마인가"** 다.
>
> **3. 그리고 회차가 뜻하는 가격은 법원마다 다르다.**
> 서울 법원은 **20% 저감**, 경기 대부분은 **30% 저감**이다.
> 같은 "1회 유찰"이 서울은 최저가 80%, 경기는 70%다. 이걸 섞으면 전부 무너진다.

이 스킬은 1,346,670원(1.7%) 차이로 2순위 패찰한 사건을 계기로 만들어졌다.

## ★ 이상치 트림 규약 (2026-08-09 신설)

회귀·중앙값 산출 시 **매각가율이 `[하한, 200]` 밖이면 제외**한다.

- **하한** = `min(그 회차의 사다리 명목값, 그 사건의 최저가율)`.
  회차 역산은 ±3%p 로 느슨한데 트림 하한만 명목값을 쓰면,
  최저가율 47%(2회, 명목 49) 물건이 47%에 낙찰됐을 때 버려진다.
  **자기 최저가를 넘긴 낙찰은 정상이다.** 잘리는 쪽이 늘 단독응찰이라 편향이 한 방향으로 쌓인다
- **상한** = 200%. 감정가 2배 초과 낙찰은 데이터 오류다

공매 【B】에는 트림 규약이 있었는데 경매에는 없었다. 실제로 **매각가율 664% 한 건이
20% 저감 2회 회귀의 r을 0.440 → 0.071로 무너뜨리고** 있었다.

**함께 고칠 것 — 일괄매각의 부분 유찰**: 한 사건에서 일부만 팔리고 나머지가 유찰되면,
유찰 물건의 매각가율 0이 중앙값에 섞여 낙찰가율이 통째로 내려간다.
**매각가율·응찰자수 중앙값은 팔린 물건만으로 낸다.**
(실측: 혼재 사건 50건이 평균 **31.4%p** 눌려 있었다)

**그리고 정제 그룹 키에는 매각기일이 들어간다.** 빼면 같은 사건의 1회 유찰과 3회 매각이
한 덩어리가 되어 **실재하지 않는 2회**가 만들어진다(2026-08-09 실측 6건).

## A-STEP 0 — 신건이면 먼저 거른다 (2026-08-25 신설 · 대표 승인)

**원칙: 신건(유찰 0회)은 입찰하지 않는다.** 계산에 들어가기 전에 거른다.

근거는 통계가 아니라 **구조**다. 신건의 최저매각가격은 곧 감정가이므로
낙찰가율은 정의상 100% 이상일 수밖에 없다. 실측에서도 예외가 없었다.

| | 30% 저감 | 20% 저감 |
|---|---:|---:|
| 매각 | 81건 | 77건 |
| 낙찰률 | 5.8% | 7.5% |
| 매각가율 중앙 | 108% | 113% |
| P75 / P90 | 122% / 135% | 131% / 152% |
| **감정가 미만 낙찰** | **0.0%** | **0.0%** |

(2026-08-25 실측, 지지옥션 서울·경기. 신건 기일 2,432건 중 매각 158건 — **감정가 미만 0건**)

**신건에 입찰한다 = 감정가 이상을 내겠다는 뜻이고, 이기려면 흔히 20~30%를 더 얹어야 한다.**
감정가 대비 할인 취득이 전제인 사업과 구조적으로 맞지 않는다.
예측 정확도도 MAE 13%p 로 전 회차 중 최악이다(「예측 정확도의 한계」 참조).

### 예외 — 실거래로만 연다

**감정가가 실거래보다 현저히 낮은 경우**만 예외다. 감정평가가 오래됐거나
그 사이 시장이 올랐으면 감정가 100% 도 실거래 대비 싼 값일 수 있다.

```
감정가 ≤ 인근 실거래 × 0.80  이 실측으로 확인되면  → 계산을 진행한다
그 밖에는                                        → 계산하지 말고 반려한다
```

- 실거래는 `real-estate` MCP 로 **직접 조회**한다. **감정평가서에 적힌 시세 추정치를 쓰지 않는다**
- **감정평가일을 함께 확인한다.** 1년 이상 지났으면 예외 검토 대상이다
- 예외로 진행하면 **대조한 실거래(단지·면적·거래일·금액)를 답변에 반드시 명시**한다
- 안전율 0.80 은 관행값이라 [검증필요]다 — 「실거래 대조」 절 참조

**반려할 때는 결론 첫머리에 쓴다.** 예:
`신건(유찰 0회) — 원칙 반려. 감정가 미만 낙찰 실측 0건. 실거래 예외 미해당`

(상업업무 −1.75 / 토지 −1.34 / 공업 −0.45 / 주거 +0.44. 층 12개·3,210건).
낙찰가율의 분모가 **감정가**라 용도·입지·면적이 이미 상쇄되기 때문이다.

같은 검정에서 다음 셋은 신호가 없었다. **계수 축으로 넣지 마라.**

| 변수 | 낙찰가율 잔차와의 관계 | 판정 |
|---|---|---|
| 건물면적 | r = +0.013 | 신호 없음 |
| 토지면적 | r = −0.013 | 신호 없음 |
| 시도(서울/경기) | 잔차 ±0.1%p · 비교가능 층 **0개** | **저감률 축에 이미 흡수됨** (서울=20%, 경기=30%) |
| 응찰자수 | **r = +0.501** | A-STEP 2 의 축 |

축을 늘리면 정밀해지는 게 아니라 근거가 사라진다 — 저감률×회차 14셀 중 표본 100건↑ 이 7개인데,
용도군을 더하면 53셀이 되고도 100건↑ 은 **여전히 7개**이며 중앙 표본이 111건 → 11건으로 부서진다.

**그래서 용도군은 낙찰가율 보정이 아니라 응찰자수(경쟁강도) 예측에만 쓴다.**

### 용도군 판정

순서대로 본다. 상업 키워드를 품은 주거를 먼저 건져야 한다.

1. `오피스텔(주거용)` `주상복합(아파트)` `근린주택` → **주거**
2. 괄호 없는 `오피스텔` → **상업업무**
3. `아파트형공장` `상가` `근린` `점포` `숙박` `사무` `업무` → **상업업무**
4. `아파트` `다세대` `연립` `단독주택` `다가구` `주택` → **주거**
5. `전` `답` `임야` `대지` `도로` `잡종지` `과수원` `목장용지` → **토지**
6. `공장` `제조업소` `창고` → **공업**
7. `차량` `중기` `선박` `항공` → 부동산이 아니다. **계산 대상에서 제외**

### ★ 그런데 조회수로 낙찰가를 예측하면 중앙값보다 낫지 않다

같은 홀드아웃 942건으로 세 방식을 비교했다.

| 예측 방식 | 표본 | MAE | ±3%p | ±5%p | ±10%p |
|---|---:|---:|---:|---:|---:|
| A. 회귀식 + **실제** 응찰자수 (오라클) | 894 | **5.50%p** | 32.7% | **56.4%** | 90.6% |
| B. 회귀식 + 조회수밴드 추정 (실전) | 894 | 6.81%p | 24.4% | 48.2% | 82.8% |
| C. **회차 중앙값만** (경쟁정보 없음) | 942 | 6.89%p | 29.2% | **52.0%** | 82.7% |

**B 와 C 가 사실상 같다.** MAE 차이는 0.08%p 이고 ±5%p 적중률은 **C 가 3.8%p 높다.**

이유는 분명하다. 응찰자 1명과 2명의 낙찰가율 차이는 기울기만큼(30% 1회 기준 1.6%p)인데
**잔차 표준편차가 8%p 대**다. 밴드가 1·2·3명 세 값밖에 못 내놓으므로
그 1.6%p 를 옮겨봐야 잡음에 묻힌다. **회귀식의 이득은 응찰자수를 실제로 알 때만 나온다.**

**따라서 조회수만 있는 상태에서는 회귀식을 주값으로 쓰지 않는다.**

**상한 계산에 곱하지 않는다.** "이 가격에 사도 손해가 아닌가"만 본다.

```

```

> **★ 안전율의 실측값은 아직 없다. [검증필요]**
> 낙찰가 ÷ 실거래를 구하려면 공매 물건을 국토부 실거래와 건별로 맞춰야 하는데

# 출력 형식

답변 첫머리에 **판별 결과**를 쓴다. 경매면 **저감률까지** 밝힌다.

| 단계 | 계산 | 결과 |
|---|---|---|
| STEP 0 | 서류 판별 근거 + 재산유형 | 경매 / 공매(0007) |
| **STEP 0-C** | **관할 법원 → 저감률, 최저가율 → 회차** | **20% 저감 / 2회 유찰(최저 64%)** |
| **A-STEP 0** | **신건인가** | **신건 아님 → 계속 / 신건 → 반려** |
| STEP 1 | **응찰발생률 ○% (회차 ○회, 용도 ○○)** | 확률 |
| STEP 2 | 저감률별 회귀 → 응찰 ○명 시 ○% | ○○○원 |
| STEP 3 | 상한B ○○○ (없으면 "동지번 매각 이력 없음") | ○○○원 |
| STEP 4 | 최종 밴드 | **○○○원 ~ ○○○원** |

**경매는 다음을 반드시 밝힌다.**
- **신건이면 A-STEP 0 반려 판정과 그 근거** (예외로 진행했다면 대조한 실거래를 명시)
- **저감률과 그 판정 근거** (법원명 또는 최저가율 역산)
- 용도군과 그 셀의 표본수
- A-STEP 1 / 1B / 2 중 어느 것을 썼는지와 그 이유
- **응찰자수의 근거가 ①·②·③ 중 어디인지** (조회수뿐이면 ②다 — 회귀식은 병기만)
- 세 값이 3%p 넘게 벌어지면 세 값을 모두 병기
- 조회수 기반 단독확률 (조회수를 모르면 확인을 요청한다)
- **권장가가 최저매각가격으로 눌렸으면 반드시 경고한다** — 저감률 오판 신호다

공매는 **회차 대기 비교표**와 **취소 위험(54.9%)**을 반드시 추가한다.

- 금액은 **원 단위 풀 콤마**. 억·만 축약 금지
- 경쟁강도는 **어느 항목에 가점·감점했는지 항목명을 나열**한다
- 표본이 얇으면 숨기지 말고 "표본 ○건, [검증필요]"라고 쓴다
- **포기 판정**: 밴드 하단 + 부대비용 > 실거래 × 안전율 → 입찰 포기를 결론 첫머리에 명시

# 반드시 확인을 요청할 것

**경매**: **관할 법원(저감률 판정용)** / **신건이면 감정평가일과 인근 실거래** / 지지옥션 "동지번 매각" 탭(직전 낙찰가) / **물건 화면의 조회수** / 등기 재열람 / 국토부 실거래가
**공매**: 재산유형 코드 / 과거 회차 응찰 이력 / 체납관리비 원금·연체료 구분 / **체납자 폐업 여부(취소 위험)** / 공매재산명세서 「매각으로 효력을 잃지 아니하는 것」란

## 연계 스킬

- **`ggi-collect`** — 지지옥션 수집·집계 규칙. 저감 사다리·트림 원칙이 여기 있다
- `bid-win-curve` — 승률곡선·기대이익 최대화. **점 추정 대신 얼마를 얹을지는 여기서 정한다**
- `bid-result-log` — 입찰 결과·2순위 금액 기록, 예측 오차 누적
- `coefficient-auto-update` — 계수 자동 반영·롤백 규약
- `coefficient-self-diagnosis` — 홀드아웃 자가진단. 위 정확도 표가 여기서 나온다
- `onbid-api-caller` — 온비드 API 호출 규칙, 재산유형 코드표
- `trust-npl-analysis` — 신탁공매 / `npl-analysis` — NPL 매입가 산정
