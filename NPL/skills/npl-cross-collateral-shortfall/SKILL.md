# 토지:건물 비율 · 교차 담보 잉여 배분 · 잔존채권 추심 · 선순위 국세 판정 · 전입 차단 계약 조항 (강사 운영본 2026-10-08)

NPL 채권 매입 분석(npl-analysis)과 직접 낙찰 분석(auction-property-card)을 할 때 이 스킬을 함께 연다.
사용자가 따로 요청하지 않아도 아래 다섯 가지를 계산하고 PPTX·엑셀에 넣는다. 결론이 일찍 보여도 생략하지 않는다.

| 블록 | 언제 | 무엇을 |
|---|---|---|
| A. 토지 : 건물 비율 | 토지와 건물이 함께 매각되는 모든 물건 (항상) | 비율 계산 → PPTX 배당 폭포 장 하단 + NPL수익률 엑셀 하단 |
| B. 교차 담보 잉여 배분 | 아래 B-1 조건 중 하나라도 해당 | 잉여를 토지분·건물분으로 나눠 누구에게 가는지 계산 → 배당표·폭포·엑셀 연동 |
| C. 잔존채권 추심 | 우리 채권 중 예상 배당이 청구액에 못 미치는 것이 하나라도 있을 때 | 「배당 뒤 채무자에게 할 일」 장을 PPTX에 신설 |
| D. 선순위 국세 판정 | 등기부에 세무서·지자체 압류가 있거나 체납이 많다는 말이 들어왔을 때 | 누구의 세금인지 · 당해세인지 · 법정기일이 설정일보다 빠른지 판정 → 판정 장 + 민감도 장 |
| E. 전입 차단 계약 조항 | 채권 매입 건이고 담보물에 주택이 있으며 경매개시결정 등기가 아직 없을 때 | 「계약 때 매도 금융기관에 요구할 것」 장(7가지)을 최우선변제 민감도 장 바로 뒤에 신설 · 그 뒤에 양수도계약서 대조 장(npl-tenant-rent-check E) |

주택 임차인이 있으면 **npl-tenant-rent-check**(임차인 서류 대조 · 전입세대 · 월세 연체 공제 · 월세 압류 순서 · 양수도계약서 대조)를 함께 연다. 계약 조항의 정본은 이 스킬 E-3, 그 근거 장은 그 스킬이다.

금액은 원 단위 풀 콤마, 사실·수치·법령에는 [확정]/[검증필요]/[추정] 라벨을 붙인다(개인 설정 §1·§3).
법령·판례는 **쓸 때마다 korean-law MCP로 다시 조회**한 뒤에만 [확정]으로 쓴다. 이 문서에 적힌 MST·ID는 2026-10-07 조회 값이며 근거가 아니다.

## A. 토지 : 건물 비율 (항상)

### A-1. 값의 출처 (위에서부터)
1. 법원 감정평가서의 토지·건물 평가액(최저매각가격 비율) → [확정]
2. 담보 감정평가서(은행 제공)의 토지·건물 평가액 → 금액은 [확정 원문], 비율은 「법원 감정은 별도」라 [추정]
3. 둘 다 없으면 토지 = 개별공시지가 × 면적, 건물 = 건물 시가표준액 또는 추정 감정가(npl-analysis 원칙 24)의 토지·건물 분해 → [추정]

### A-2. 계산
```
토지 비율 = 토지분 ÷ (토지분 + 건물분 + 제시외 건물)
건물 비율 = 1 − 토지 비율
```
- 물건이 여럿이면(A·B) 물건마다 따로 낸다. 소수 둘째 자리까지(예: 71.04% : 28.96%).
- 근거: 일괄매각 대금과 집행비용은 각 재산의 최저매각가격 비율로 나눈다(민사집행법 §101②, 2026-10-07 조회 MST 268837).

### A-3. 넣는 곳 (세 곳 모두)
- **PPTX 배당 폭포 장 하단**: 도표(`_charts.py` waterfall) 아래 띠의 둘째 줄에
  `토지 : 건물 비율 (감정가 기준)  A 71.04% : 28.96% (토지 0원 · 건물 0원)  B …`
  B 블록에 해당하면 셋째 줄에 `A에서 ①을 갚고 남는 0원 → 토지분 00.00% = 0원은 ②로, 건물분 00.00% = 0원은 건물 2순위에게`.
  발표자 노트에 「담보 감정가 기준 — 실제 배당은 법원 감정 비율」을 적는다.
- **NPL수익률 엑셀 분석 시트 하단**: 감정평가 표(B30:C33) 옆 `D30` = `비율 (토지 : 건물)`, `D31` = `=C31/$C$30`, `D32` = `=C32/$C$30`, `D33` = `=C33/$C$30`, 표시 형식 `0.00%`, 왼쪽 정렬. `D30` 메모에 출처·라벨·§101②. 양식의 다른 서식은 건드리지 않는다.
- **분석 엑셀 「배당」 시트**: 토지 비율 행(셀 수식).

## B. 교차 담보 잉여 배분

### B-1. 해당 조건 (등기부 을구를 토지·건물 따로 읽어 판정)
- 우리가 사려는 채권이 2건 이상이고, 한 채권이 **다른 물건의 토지(또는 건물)에만** 후순위 근저당을 갖고 있다.
- 한 물건 안에서 토지의 2순위 권리자와 건물의 2순위 권리자가 다르다(토지 근저당이 건물 신축보다 먼저 설정된 물건에서 흔하다).
- 공동담보목록에 다른 필지·다른 건물이 함께 올라 있다(npl-analysis 체크리스트 ⑰·㉑).

해당하면 권리분석 표를 「토지 순위표」와 「건물 순위표」 둘로 나눠 만든다. 해당하지 않으면 PPTX에 「교차 담보 없음 — 토지·건물 권리자 동일」 한 줄만 남긴다.

### B-2. 배당 순서 (정식)
1. 매각대금과 집행비용을 토지·건물로 나눈다(최저매각가격 비율, 민사집행법 §101②).
2. 대지 권리자와 건물 권리자가 다르면 대금마다 따로 배당표를 만든다(대법원 2001다66291, ID 194340).
3. 각 대금에서 그 부동산이 부담할 선순위(최우선변제 · 당해세)를 뺀다.
4. 토지·건물 공동 1순위 채권은 두 대금에서 **비례해** 받는다. 비례 기준 「경매대가」는 경매비용과 선순위채권을 뺀 잔액이다(민법 §368①, MST 284415 · 대법원 2014다213783, ID 297888).
5. 토지에 남는 돈은 토지의 차순위에게, 건물에 남는 돈은 건물의 차순위에게 간다. **한쪽에 권리가 없는 채권은 그쪽 잉여를 한 푼도 받지 못한다.**

### B-3. 간이식 (선순위 공제가 토지·건물에 비례할 때만)
```
잉여     = MAX(0, 낙찰가 − 선순위 − 집행비용 − 최우선변제 − 당해세 − 1순위 청구액)
토지분   = ROUND(잉여 × 토지 비율, 0)      → 토지 차순위에게
건물분   = 잉여 − 토지분                   → 건물 차순위에게 (그 채권최고액 한도)
1순위 전액회수 낙찰가 = 선순위 + 집행비용 + 최우선변제 + 당해세 + 1순위 청구액
```
- 받는 쪽 채권의 배당 = 자기 물건에서 받는 돈 + 다른 물건의 토지분(또는 건물분). 합계는 채권최고액과 청구액 중 작은 값을 넘지 못한다.
- 「낙찰가율 1%p마다 토지분이 얼마 늘어나는지」(= 감정가 × 1% × 토지 비율)를 함께 적는다.

### B-4. 간이식을 쓰면 안 되는 경우
- 최우선변제를 건물 대금에서만 내주는 경우(대지 저당권 설정 뒤 신축 — priority-payment-date-rule, 대법원 2009다101275 [쓸 때 재조회]) → B-2 정식으로 대금별 계산. 기준은 보수(대지 포함), 판례 적용은 상방으로 병기한다.
- 한쪽 대금에만 걸린 선순위(토지에만 있는 선순위 근저당·압류)가 있을 때.
- 물건들이 다른 시점에 배당될 때(이시배당) → 민법 §368② 차순위자 대위를 검토하고 [검증필요]로 표시한다.
- 법원 감정이 나오면 비율을 바꿔 다시 계산한다.

### B-5. 모델 · 검산
`_model.py`에 물건별 `surplus`(잉여) · 토지분 · 건물분을 두고 아래를 assert 한다.
- 낙찰가 − 집행비용 − 최우선변제 − 당해세 = 1순위 배당 + 토지분 + 건물분 (+ 후순위)
- |잉여 × 토지 비율 − 토지분| < 1원, 잉여 − 토지분 = 건물분
- 배당표 = 배당 폭포 = NPL수익률 엑셀 E16 = 우리 채권 배당 합계

### B-6. PPTX
- **예상 배당표 장**: 물건마다 「순서 / 받는 사람 / 가져가는 돈 / 남는 돈」 표를 따로 두고(남는 돈은 누적, 마지막 행 0원), 아래에 「우리 채권 / 청구액 / A에서 / B에서 / 합계 / 못 받는 돈」 표를 둔다. 한 표에 섞지 않는다.
- **배당 폭포 장**: A-3의 하단 띠 세 줄. 받는 쪽 물건의 「대출 배당」 막대 설명에 「여기에 A 토지분 0원을 더해 미회수 0원」처럼 다른 물건에서 오는 돈을 적는다(빠지면 숫자가 안 맞아 보인다 — 2026-10-07 사용자 질문).
- 발표자 노트: 「잉여가 다른 경매의 재원으로 옮겨 가는 것이 아니라, 그 채권이 토지 2순위 근저당권자로서 그 경매에서 직접 받는다」.

### B-7. NPL수익률 엑셀 연동 (물건별 파일이 따로일 때)
템플릿에는 교차배당 칸이 없으므로 받는 쪽 파일의 선순위금액(C16)에 **음수**로 넣는다. 고정값으로 두지 않는다 — 원천 물건의 낙찰가가 바뀌면 따라 바뀌어야 한다.

**원천 파일(잉여가 생기는 물건) F19:G24 「잉여 배분 (교차 담보)」**
| 칸 | 수식 |
|---|---|
| G20 1순위 앞에서 빠지는 금액 | `=C16+C18+C19+C20` |
| G21 1순위 변제 뒤 잉여 | `=MAX(0,C15-G20-E14)` |
| G22 토지 비율 | `=C31/(C31+C32+C33)` |
| G23 토지분 | `=ROUND(G21*G22,0)` |
| G24 건물분 | `=MIN(건물 차순위 채권최고액,G21-G23)` |

**받는 파일 F19:G25 「연동」 + C16**
| 칸 | 수식 |
|---|---|
| G20 원천 예상낙찰가 | `=[1]분석!$C$15` |
| G21 원천 1순위 앞 공제 | `=[1]분석!$C$16+[1]분석!$C$18+[1]분석!$C$19+[1]분석!$C$20` |
| G22 원천 1순위 권리가액 | `=[1]분석!$E$14` |
| G23 잉여 | `=MAX(0,G20-G21-G22)` |
| G24 원천 토지 비율 | `=[1]분석!$C$31/([1]분석!$C$31+[1]분석!$C$32+[1]분석!$C$33)` |
| G25 토지분 | `=ROUND(G23*G24,0)` |
| C16 선순위금액 | `=-G25` |

건물분을 받는 구조면 G24·G25를 건물 비율로 바꾼다. 라벨(F열)은 F16, 값(G열)은 G16의 서식을 복사한다. 블록을 넣기 전에 그 칸들이 비어 있는지 assert 한다.

**외부 연결 만들기 (openpyxl) — 실측 사고가 있었던 부분**
- `ExternalLink(externalBook=ExternalBook(sheetNames=…, sheetDataSet=…, id="rId1"))`에 `file_link = Relationship(type="externalLinkPath", Target=…, TargetMode="External", Id="rId1")`를 달아 `wb._external_links`에 넣고, 수식은 `[1]분석!$C$15` 형태로 쓴다.
- ★ **Target은 한글을 그대로 두고 빈칸만 `%20`으로 바꾼다.** `urllib.parse.quote`로 한글까지 %코드로 바꾸면 Excel이 그 문자열을 파일 이름 그대로 읽어 원본을 찾지 못하고, 값이 따라 바뀌지 않는다(강사 실측 2026-10-07: LibreOffice에서는 통과했지만 Excel에서 실패). Excel이 직접 저장한 파일도 한글 그대로 + `%20` 표기다.
- `sheetDataSet`에 연결한 칸의 현재 값(캐시)을 넣는다. 원천 파일을 먼저 만들고 재계산한 값을 읽어 넣는다.
- 연결 대상은 같은 폴더의 파일 이름이다. 물건 폴더 루트 쌍과 `02_분석` 사본 쌍은 파일 이름이 다르므로 쌍마다 따로 만든다.
- 검증: ① LibreOffice 재계산으로 C16·E16이 모델 값과 같은지 ② 원천 사본의 낙찰가율을 바꾼 뒤 연결 업데이트를 켜고 C16이 따라 바뀌는지 ③ 실제 Excel에서 연결 대상 이름이 올바로 잡히는지(Excel로 다시 저장된 파일의 `externalLinks/_rels`에 `%25`가 보이면 실패). ③을 못 했으면 「Excel에서 확인 필요」를 사용자에게 알린다.
- 메모(F19·C16)에 사용법을 적는다: 두 파일은 같은 폴더·같은 이름 / 함께 열어 두면 바로 반영 / 받는 파일만 열면 원천 파일에 저장된 값을 읽으며 「콘텐츠 사용」 또는 「연결 업데이트」를 눌러야 한다 / 연결이 끊기면 G20·G21·G22·G24에 직접 입력.
- Office가 파일을 열고 있으면 덮어쓰지 않는다. 닫아 달라고 알리고 기다린다. 덮어쓰기 전 `백업\`에 사본을 둔다.
- 생성 스크립트(`02_분석\_npl_excel.py`)에 블록 함수로 남긴다.

## C. 잔존채권 추심 장 (배당이 청구액에 못 미칠 때)

### C-1. 조건
기준 시나리오(누적 매각 확률이 50%를 처음 넘는 회차)에서 우리 채권 중 하나라도 `예상 배당 < 청구액(배당일 기준)`이면 PPTX에 장을 만든다.
기준에서는 부족이 없고 민감도 하방(낙찰가율 −5%p 등)에서만 생기면 민감도 장 아래에 「이때 잔존채권 0원 발생」 한 줄과 함께 같은 장을 부록으로 넣는다. 어느 경우에도 부족이 없으면 결론 장에 「잔존채권 없음」 한 줄만 적는다.

### C-2. 계산
```
잔존채권     = 청구액(원금 + 배당일까지 이자) − 예상 배당
이자 충당    = 배당금은 비용 → 이자 → 원금 순 → 배당 > 이자 합계면 잔존은 전부 원금
잔존 뒤 이자 = 잔존 원금 × 약정 연체이율 (연 금액 병기)
월세 압류    = 임대차현황의 현재 월세 합계 × 경매 개시 ~ 매각 개월 수 [추정 상한]
```
- 손익·IRR 계산에는 잔존채권 회수를 **0원**으로 둔다. 장에 「여기서 받는 돈은 전부 추가 이익」이라고 적는다.
- 이자율·원금은 대출원장·매각 명세서의 약정 값을 쓴다.

### C-3. 장 구성 (덱 기준 템플릿 그대로)
- 위치: 배당 폭포 장 바로 뒤. 섹션 라벨 「관점 1 · 채권 매입」.
- 제목 = 결론 한 문장: `②가 다 못 받으면 — 남는 0원은 집행권원을 받아 따로 추심한다`
- 부제: 배당일 가정 · 청구액 − 배당 · 「손익 계산에는 잔존채권 회수를 0원으로 뒀다」
- 표 「시점 / 할 일 / 근거 / 효과 · 주의」 7행(아래 표준 행). 그 물건에 맞게 금액·호실을 채운다.
- 표 아래 한 줄: 추심 연락은 채권추심법 §9를 지킨다(야간 21시~8시 방문·전화, 제3자에게 채무 사실을 알리는 행위 금지) · 실제 추심 방법은 사용자가 정한다.
- 「한 줄로 말하면」: 배당으로 끝나지 않는다. 경매 중에는 월세를 압류하고, 배당 뒤에는 지급명령으로 집행권원을 받아 남은 원금을 추심한다.
- 발표자 노트: 충당 계산식, 월세 상한 계산, [검증필요]·[정보부족] 항목.
- 출처 장에 이번에 조회한 조문·판례 번호를 추가한다. `00_물건카드.md`에도 잔존채권 금액과 할 일을 한 단락으로 적는다.

## D. 선순위 국세 판정 · 민감도 (세무서 압류나 체납 전언이 있을 때)

### D-1. 조건
- 등기부 갑구에 세무서(권리자 「국」)나 지자체 압류가 하나라도 있다.
- 채무자나 그 가족의 세금 체납이 많다는 말이 들어왔다(공인중개사 · 채권은행 · 사용자 전언).

둘 다 없으면 권리 장에 「조세 압류 없음」 한 줄만 적는다.
npl-analysis 원칙 13(당해세) · 원칙 26, auction-property-card STEP 4-C와 함께 쓴다. 이 블록은 「근저당 대 국세」 판정과 덱 구성을 정한다.

### D-2. 순서
1. 등기부 전부(필지·건물마다)의 갑구에서 압류를 표로 뽑는다: 권리자 · 처분청 · 접수일 · 표기 숫자. 금액·세목이 없으면 「미표기」라고 적는다.
2. 소유권 취득 원인을 본다(매매 / 증여 / 상속). 체납했다는 가족의 이름이 소유 · 압류 · 가압류 어디에 있는지 확인한다.
3. 우리 근저당 설정일을 필지·건물마다 따로 적는다. 분필·합병·일부포기 뒤 재설정, 건물 추가설정은 날짜가 다르다(건물이 가장 늦은 경우가 많다).
4. 국세기본법 §35(지방세는 지방세기본법 §71)를 다시 조회하고 D-3 표로 판정한다.
5. 금액을 모르면 0원으로 굳히지 않는다. 모델 기준은 X = 0원으로 두되 민감도 장을 만들고 「확인해야 할 것」 최우선에 올린다.

### D-3. 판정표

- 한 줄로 적는다: 「법정기일이 가장 이른 설정일보다 빠른 국세는 전부 우리 앞, 가장 늦은 설정일보다 늦은 국세는 전부 뒤, 그 사이는 필지·건물마다 다르다」.
- 압류가 근저당 설정 몇 년 뒤에 처음 들어왔다는 점은 [추정] 단서일 뿐이다. 순위 결론으로 쓰지 않는다.
- 들은 말은 [전언] 라벨로 적고 공식 기록과 섞지 않는다. 사용자가 금액·세목을 알고 있으면 계산 전에 묻는다.

### D-4. 민감도 (모델에 `taxx`)
앞서는 국세 X = 0원(지금 모델) · 100,000,000원 · 200,000,000원 · 300,000,000원 · 500,000,000원 · 1,000,000,000원에 대해 우리 채권 배당 · 세전 손익 · 세후 IRR을 낸다.
- 가장 불리한 쪽(우리 채권이 이미 부족한 물건)에 전부 걸리는 것으로 계산한다. 그때 손익분기 X = 기준 세전 이익이다.
- 교차 담보 건은 「다른 물건 쪽이면 최대 얼마 덜 줄어든다」(= 그 물건 잉여 중 남의 몫)를 부제에 적는다.
- 검산: 민감도 기준 행 = 기준 시나리오, 부족한 쪽에서 X 1원 = 배당 1원 감소.
- 종부세 당해세는 연 금액을 [추정]으로 내고 체납 연수를 곱한 범위를 노트에 적는다. 세율을 이번에 조회하지 않았으면 그렇게 적는다.

### D-5. 확인 경로 (장에 그대로 적는다)
1. 매도 금융기관이 받은 압류통지서 사본을 받는다 — 세무서장은 재산을 압류하면 저당권자에게 통지해야 한다(국세징수법 §40). 세목과 체납액을 본다.
2. 세목이 당해세인지, 신고일·고지서 발송일이 가장 늦은 설정일보다 앞인지를 본다.
3. 매매계약 가격 조정 조항에 「근저당에 앞서 배당되는 국세·지방세 전부」를 넣는다. 소액임차인·당해세만 적힌 문구로는 부족하다.
4. 경매 개시 뒤 교부청구서로 법정기일을 다시 확인하고, 순위가 틀리면 배당이의를 한다.
- 미납국세 열람(국세징수법 §109)은 임차하려는 사람만 신청할 수 있어 채권 매수인은 쓰지 못한다.
- 세무서의 별도 공매 가능성은 조회하기 전에는 [검증필요]로 둔다.

- 권리 장 묶음에 두 장을 넣는다.
  - 판정 장: 제목 예 `국세 체납이 많아도, 법정기일이 근저당 설정일보다 늦으면 우리 뒤다`. D-3 표(5행 안팎, 「구분 / 등기 · 사실 / 우리 근저당과의 순위 / 배당 영향」) + 「우리 근저당 설정일」 가로 표 + 한 줄 설명. 부제에 전언의 출처와 날짜.
  - 민감도 장: 제목 예 `국세가 우리 앞에 서면 1원당 1원이 줄어든다 — 0원을 넘으면 손실이다`. 왼쪽 D-4 표, 오른쪽 「확인하는 방법」 4줄, 아래 등기부 단서 [추정].

## E. 전입 차단 — 계약 조항 장 (매입 계약 ~ 경매개시결정 등기 사이)

소액임차인은 경매신청 등기 전에 전입과 점유를 갖추면 최우선변제를 받는다. 그래서 채권 매입 계약일부터 경매개시결정 등기일까지는 새 임차인이 끼어들어 우리 배당을 줄일 수 있는 기간이다. 민감도 장이 「얼마가 줄어드는지」를 보여 준다면, 이 장은 「그래서 계약 때 무엇을 요구하는지」를 답한다. 민감도 장만 있고 이 장이 없으면 미완성이다.

### E-1. 조건
- 장을 만든다: NPL 채권 매입 건 + 담보물에 주택(다가구 · 근린주택 · 주거로 쓰는 근생 포함)이 있다 + 경매개시결정 등기가 아직 없다(경매 미개시, 또는 개시 전에 매입 계약).
- 이미 개시결정 등기가 된 건: 장을 만들지 않는다. 최우선변제 판정 장에 「경매개시결정 등기일 YYYY-MM-DD — 그 뒤 전입자는 최우선변제 없음」 한 줄을 적고, 등기 전 전입자 명단이 현황조사서 · 매각물건명세서 · 전입세대확인서와 같은지 대조한다.
- 주택이 없는 상가 건물: 상가 소액임차인도 같은 구조(경매신청 등기 전 사업자등록 + 인도)인지 상가건물 임대차보호법 §14를 그 답변에서 조회한 뒤, 「전입」을 「사업자등록」으로 바꿔 같은 장을 만든다.

### E-2. 원칙
- 금융기관은 전입신고를 금지할 수 없다. 전입신고는 임차인이 주민센터에 하고 임대는 소유자(채무자)가 정한다. 사용자가 「전입 금지 요청」이라고 말해도 장 제목과 답변 첫 문장에 이 사실을 먼저 적고, 요구할 수 있는 것으로 바꿔 정리한다.
- 근거는 쓸 때 다시 조회한다: 주택임대차보호법 §8① 후문(경매신청의 등기 전에 §3①의 요건), 주민등록법 §29의2②(전입세대확인서 신청인).
- 위험 금액은 모델의 「최우선 추가 위험」과 같은 값을 쓴다: 공실 호수 × 최우선변제액 + 임대차현황에 없는 전입세대주 + 종전 임차인 잔류 + 상가 계약 임차인의 전입 + 소유자 가족의 임차인 주장. 민감도 장의 그 행과 1원도 다르면 안 된다.

### E-3. 표준 행 「순서 / 매도 금융기관에 요구할 것 / 내용 / 이 물건에서 막는 것」
| 순서 | 요구할 것 | 내용 | 막는 것 (그 물건 금액으로 채운다) |
|---|---|---|---|
| 1 | 임차인 명단 고정 | 금융기관 임대차현황(출력일 표기)을 계약서 별지로 붙이고, 그 뒤 새 임대차·전입을 알지 못한다는 진술·보장을 받는다 | 기준 최우선변제 인원 · 금액 고정 |
| 2 | 전입세대확인서 재발급 | 계약일과 잔금일 두 번 + 외국인 체류확인. 감정평가법인이나 신용조사회사를 통해 받는다(E-5) | 미확인 전입세대주 · 종전 임차인 잔류 |
| 3 | 가격 조정 조항 | 별지에 없는 임차인 때문에 최우선변제가 늘면 그 금액만큼 매매대금을 깎거나 해제할 수 있게 적는다 | 추가 위험 합계를 매도인 부담으로 |
| 4 | 경매 신청 앞당기기 | 계약 직후 매도 금융기관 명의로 임의경매를 신청하고 잔금 뒤 채권자 지위를 승계한다. 안 되면 잔금 당일 신청 | 공실 · 상가 임차인의 새 전입 |
| 5 | 계약 ~ 잔금 사이 의무 | 금융기관이 채무자의 새 임대차에 동의하지 않고, 새 임차·전입을 알게 되면 즉시 알린다 | 소유자 가족의 임차인 주장 조기 파악 |
| 6 | 월세 압류 협조 | 개시결정 등기 직후 금융기관 명의로 임차인 전원 월세 압류 · 추심명령 + 진술최고, 잔금 뒤 매수인 승계에 협조한다 · 임차인별 월세 · 관리비 납부 내역과 계약서 전부를 넘긴다 | 연체 한 달마다 우리 배당 증가분(npl-tenant-rent-check C) |
| 7 | 선순위 국세 · 지방세 조정 | 근저당보다 앞서 배당되는 국세 · 지방세 전부를 가격 조정 대상에 넣는다(D-5의 3) | 국세 손익분기 X |

- 4번이 효과가 가장 크다. 금융기관이 응할지는 협의 사항이다. 승계는 이전 부기등기된 등기사항증명서로 증명하고 법원이 채무자 등에게 통지한다(민사집행규칙 §193 · 민사집행법 §264② 준용 — 쓸 때 재조회, 2026-10-08 조회 MST 272631 · 268837). 부기등기를 마친 양수인은 채권양도 대항요건과 관계없이 저당권을 실행할 수 있다(대법원 2004다29279, ID 193808).
- 업계 양수도계약서는 「현 상태 양도 · 진술보장 없음 · 면책」이 기본이다(2026-10-08 양식 2건 대조). 그래서 7가지는 모두 특약으로 넣고 「본문 면책 조항보다 우선한다」를 적도록 권고한다(효력은 변호사 확인 [검증필요]). 대조 장은 npl-tenant-rent-check E.
- 조항을 넣을지와 문구는 사용자가 정한다. 계약서 조항 문안은 사용자가 요청할 때 쓴다.

### E-4. 장 구성 (덱 기준 템플릿 그대로)
- 위치: 민감도 장 가운데 「최우선변제 범위」(우리 앞에서 빠지는 돈)를 다루는 장 바로 뒤. 그 장이 없으면 최우선변제 판정 장 바로 앞. 섹션 라벨 「관점 1 · 채권 매입」.
- 제목 = 결론 한 문장: `전입은 은행도 막지 못한다 — 계약 조항 7가지와 빠른 경매 신청으로 0원을 막는다` (국세를 국세 장에서 따로 다루면 6가지로 쓰고 7번은 그 장에)
- 부제: 주택임대차보호법 §8① 한 줄 + 「위험 구간 = 계약일 ~ 경매개시결정 등기일」
- 표: E-3의 7행(머리글 포함 8행, fs 11 · rowH 0.5 안팎 — 렌더해서 아래 한 줄과 겹치지 않는지 본다). 4열은 그 물건의 호실과 금액.
- 표 아래 한 줄: `막지 못하고 0원이 전부 생기면 세전 손익은 0원, 질권대출 이자를 빼면 0원` + 사후 방어 두 가지(E-6)와 「소송이 필요하므로 계약 조항으로 미리 막는 쪽이 싸다」.
- 「한 줄로 말하면」: 전입 자체는 막을 수 없다. 임차인 명단을 계약서에 고정하고, 늘어나는 몫은 매도인 부담으로 적고, 경매개시결정 등기를 하루라도 앞당긴다.
- 발표자 노트: 금융기관이 금지할 수 없는 이유, 전입세대확인서 경로, [검증필요] 항목, 조회 번호.
- 검산(생성 스크립트에 chk): 4열에 적은 금액의 합 = 모델 추가 위험 합계 = 민감도 장의 그 행 / 질권 손익 = 세전 손익 − 질권 이자 − 근질권 설정비.
- 함께 고치는 곳: 「결정 전 닫을 3가지」 계약 조항 카드 · 「확인해야 할 것」 최우선(매도 금융기관 초안의 특약 7가지 + 「면책보다 우선」, 전입세대 재열람) · 실패위험 점검표의 개시 전 전입 행 · 출처 장 · `00_물건카드.md` 단락. 채팅 요약에도 7가지를 표로 적는다.
- 바로 뒤 장: 양수도계약서 대조(npl-tenant-rent-check E).

### E-5. 전입세대확인서를 누가 뗄 수 있나
주민등록법 §29의2②가 신청인을 정해 둔다: 소유자·임차인 본인과 세대원, 매매·임대차 계약자, 이들의 위임을 받은 자, 경매참가자, 신용조사회사·감정평가법인(임차인 실태 확인), 근저당을 설정하려는 금융회사, 집행관, 국가·지자체.
- 채권자(근저당권자)라는 이유만으로는 목록에 없다. 그래서 「금융기관에 재발급 요청」이라고만 쓰지 않고 「감정평가법인이나 신용조사회사를 통해」라고 경로를 적는다. 담보 감정평가서에 붙어 온 확인서의 발급일을 확인해 1년이 넘었으면 그 사실을 적는다.
- 경매가 개시된 뒤에는 경매참가자로 직접 뗄 수 있다.
- 외국인은 전입세대확인서에 나오지 않을 수 있다. 외국인 체류확인서를 따로 요청한다.

## 예시 — 설명용 가상 숫자 (실제 물건 아님)
강사가 2026-10-07 근린주택 2동 일괄 NPL 매입 건에서 겪은 구조를 둥근 숫자로 다시 만든 것이다. 계산 순서를 따라 해 보는 용도다.
- 구조: 대출 ① = A 토지·건물 1순위 / 대출 ② = B 토지·건물 1순위 + A **토지에만** 2순위 / A 건물 2순위는 다른 근저당권자.
- 비율(담보 감정가): A 토지 2,000,000,000원 · 건물 1,000,000,000원 → 토지 비율 = 2,000,000,000 ÷ 3,000,000,000 = 66.67%, 건물 33.33%.
- A 낙찰가 2,100,000,000원(낙찰가율 70%), 집행비용 20,000,000원, 최우선변제 100,000,000원, 당해세 0원, ① 청구액 1,900,000,000원
  → 잉여 = 2,100,000,000 − 20,000,000 − 100,000,000 − 0 − 1,900,000,000 = 80,000,000원
  → 토지분 = ROUND(80,000,000 × 2,000,000,000 ÷ 3,000,000,000) = 53,333,333원은 ②로, 건물분 = 80,000,000 − 53,333,333 = 26,666,667원은 건물 2순위에게. (엑셀 수식처럼 비율은 반올림하지 않은 값으로 곱한다.)
- ① 전액회수 낙찰가 = 2,020,000,000원(67.33%). 그 아래면 잉여 0원이고, 그 위로 낙찰가율 1%p마다 ②가 받는 토지분이 20,000,000원씩 늘어난다(감정가 3,000,000,000원 × 1% × 토지 비율 2/3).
- ② 배당 = B에서 받는 돈 + A 토지분 53,333,333원. 그래도 청구액에 못 미치면 C 블록(잔존채권 추심 장)을 만든다.
- 전입 차단(E): 공실 1호 × 최우선변제액 50,000,000원 + 임대차현황에 없는 전입세대주 2명 × 50,000,000원 = 추가 위험 150,000,000원. 이 합계가 민감도 장의 그 행과 같아야 한다.
