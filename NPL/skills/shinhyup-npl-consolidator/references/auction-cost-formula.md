# 경매신청비용(가지급금) 산정 공식

## 개요

가지급금은 경매를 신청하고 진행하는 데 드는 비용이다.
감정가(기준금액)와 채권최고액(채권금액)을 입력값으로 사용한다.

```
가지급금 = 신청비용 소계 + 예납금 소계
```

## 입력값 매핑

| 산정 입력값 | 마스터 파일 컬럼 | 설명 |
|------------|-----------------|------|
| 기준금액 | O (감정가) | 감정평가액 |
| 채권금액 | V (채권최고액) | 근저당 채권최고액 |
| 이해관계인 수 | 기본값 5명 | 파악 가능 시 실제값 사용 |
| 목적물 수 | 기본값 1개 | 파악 가능 시 실제값 사용 |

## 1. 신청비용 소계

```
신청비용 소계 = 등록면허세 + 지방교육세 + 송달료 + 등기신청수수료
```

### 1-1. 등록면허세

```
등록면허세 = 채권금액 × 0.002 (0.2%)
```

### 1-2. 지방교육세

```
지방교육세 = 등록면허세 × 0.2 (20%)
```

### 1-3. 송달료

```
송달료 = (이해관계인 수 + 3) × 10회 × 5,200원
```

- 기본 이해관계인 수: 5명 (파악 가능 시 실제값 사용)
- 예시: (5 + 3) × 10 × 5,200 = 416,000원

### 1-4. 등기신청수수료

```
등기신청수수료 = 목적물 수 × 3,000원
```

- 기본 목적물 수: 1개
- 예시: 1 × 3,000 = 3,000원

## 2. 예납금 소계

```
예납금 소계 = 감정료 소계 + 현황조사수수료 + 신문공고료 + 매각수수료
```

### 2-1. 감정평가수수료 (기준금액 구간별)

| 기준금액 구간 | 감정평가수수료 |
|-------------|-------------|
| 140,909,090원 이하 | 240,000원 (정액) |
| 140,909,090원 초과 ~ 5억원 이하 | 기준금액 × 0.0011 + 84,000원 |
| 5억원 초과 ~ 10억원 이하 | 기준금액 × 0.0009 + 184,000원 |
| 10억원 초과 ~ 50억원 이하 | 기준금액 × 0.0006 + 484,000원 |
| 50억원 초과 ~ 100억원 이하 | 기준금액 × 0.0005 + 984,000원 |
| 100억원 초과 | 기준금액 × 0.0004 + 1,984,000원 |

### 2-2. 감정평가 실비

```
감정평가 실비 = 감정평가수수료 × 0.2 (20%)
```

### 2-3. 감정료 소계

```
감정료 소계 = (감정평가수수료 + 감정평가 실비) × 1.1 (부가세 10%)
```

### 2-4. 현황조사수수료

```
현황조사수수료 = 70,000원 (기본 정액)
```

- 도서지역 등 특수한 경우에는 추가 발생 가능 (이 스킬에서는 기본값 사용)

### 2-5. 신문공고료

```
신문공고료 = 220,000원 (기본)
```

- 기본 22만원
- 목적물이 2건 초과하면 초과 건당 110,000원 추가
- 예시: 목적물 1개 → 220,000원, 목적물 4개 → 220,000 + (2 × 110,000) = 440,000원

### 2-6. 매각수수료 (기준금액 구간별)

| 기준금액 구간 | 매각수수료 |
|-------------|-----------|
| 1천만원 이하 | 200,000원 |
| 1천만원 초과 ~ 5천만원 이하 | (기준금액 - 1천만원) × 0.015 + 200,000원 |
| 5천만원 초과 ~ 1억원 이하 | (기준금액 - 5천만원) × 0.01 + 803,000원 |
| 1억원 초과 ~ 3억원 이하 | (기준금액 - 1억원) × 0.008 + 1,303,000원 |
| 3억원 초과 ~ 5억원 이하 | (기준금액 - 3억원) × 0.006 + 2,903,000원 |
| 5억원 초과 ~ 10억원 이하 | (기준금액 - 5억원) × 0.004 + 4,103,000원 |
| 10억원 초과 ~ 30억원 이하 | (기준금액 - 10억원) × 0.002 + 6,103,000원 |
| 30억원 초과 | (기준금액 - 30억원) × 0.001 + 10,103,000원 |

## 3. 최종 가지급금

```
가지급금 = 신청비용 소계 + 예납금 소계
```

원 단위 이하 절사(내림) 처리한다.

## 4. 계산 예시

**입력**: 감정가(기준금액) = 1억원, 채권최고액(채권금액) = 2억원

| 항목 | 금액 | 산식 |
|------|------|------|
| 등록면허세 | 400,000원 | 2억 × 0.002 |
| 지방교육세 | 80,000원 | 40만 × 0.2 |
| 송달료 | 416,000원 | (5+3) × 10 × 5,200 |
| 등기신청수수료 | 3,000원 | 1 × 3,000 |
| **신청비용 소계** | **899,000원** | |
| 감정평가수수료 | 240,000원 | 1.4억 이하 정액 |
| 감정평가 실비 | 48,000원 | 24만 × 0.2 |
| 감정료 소계 | 316,800원 | (24만+4.8만) × 1.1 |
| 현황조사수수료 | 70,000원 | 정액 |
| 신문공고료 | 220,000원 | 기본 |
| 매각수수료 | 1,303,000원 | (1억-5천만) × 0.01 + 803,000 |
| **예납금 소계** | **1,909,800원** | |
| **가지급금 총계** | **2,808,800원** | |

## Python 구현 참고

```python
import math

def calc_auction_cost(appraisal_value, bond_amount, stakeholders=5, properties=1):
    """
    경매신청비용(가지급금)을 산정한다.
    
    Args:
        appraisal_value: 감정가(기준금액) - 원 단위
        bond_amount: 채권최고액(채권금액) - 원 단위
        stakeholders: 이해관계인 수 (기본 5명)
        properties: 목적물 수 (기본 1개)
    
    Returns:
        dict: 항목별 비용 및 총계
    """
    # 1. 신청비용
    registration_tax = int(bond_amount * 0.002)        # 등록면허세
    education_tax = int(registration_tax * 0.2)         # 지방교육세
    delivery_fee = (stakeholders + 3) * 10 * 5200       # 송달료
    registration_fee = properties * 3000                 # 등기신청수수료
    application_subtotal = registration_tax + education_tax + delivery_fee + registration_fee
    
    # 2. 감정평가수수료 (구간별)
    v = appraisal_value
    if v <= 140_909_090:
        appraisal_fee = 240_000
    elif v <= 500_000_000:
        appraisal_fee = int(v * 0.0011 + 84_000)
    elif v <= 1_000_000_000:
        appraisal_fee = int(v * 0.0009 + 184_000)
    elif v <= 5_000_000_000:
        appraisal_fee = int(v * 0.0006 + 484_000)
    elif v <= 10_000_000_000:
        appraisal_fee = int(v * 0.0005 + 984_000)
    else:
        appraisal_fee = int(v * 0.0004 + 1_984_000)
    
    appraisal_expense = int(appraisal_fee * 0.2)        # 감정평가 실비
    appraisal_subtotal = int((appraisal_fee + appraisal_expense) * 1.1)  # 감정료 소계 (부가세 포함)
    
    # 3. 현황조사수수료
    survey_fee = 70_000
    
    # 4. 신문공고료
    newspaper_fee = 220_000
    if properties > 2:
        newspaper_fee += (properties - 2) * 110_000
    
    # 5. 매각수수료 (구간별)
    if v <= 10_000_000:
        sale_fee = 200_000
    elif v <= 50_000_000:
        sale_fee = int((v - 10_000_000) * 0.015 + 200_000)
    elif v <= 100_000_000:
        sale_fee = int((v - 50_000_000) * 0.01 + 803_000)
    elif v <= 300_000_000:
        sale_fee = int((v - 100_000_000) * 0.008 + 1_303_000)
    elif v <= 500_000_000:
        sale_fee = int((v - 300_000_000) * 0.006 + 2_903_000)
    elif v <= 1_000_000_000:
        sale_fee = int((v - 500_000_000) * 0.004 + 4_103_000)
    elif v <= 3_000_000_000:
        sale_fee = int((v - 1_000_000_000) * 0.002 + 6_103_000)
    else:
        sale_fee = int((v - 3_000_000_000) * 0.001 + 10_103_000)
    
    # 예납금 소계
    prepayment_subtotal = appraisal_subtotal + survey_fee + newspaper_fee + sale_fee
    
    # 총계
    total = application_subtotal + prepayment_subtotal
    
    return {
        'registration_tax': registration_tax,       # 등록면허세
        'education_tax': education_tax,             # 지방교육세
        'delivery_fee': delivery_fee,               # 송달료
        'registration_fee': registration_fee,       # 등기신청수수료
        'application_subtotal': application_subtotal, # 신청비용 소계
        'appraisal_fee': appraisal_fee,             # 감정평가수수료
        'appraisal_expense': appraisal_expense,     # 감정평가 실비
        'appraisal_subtotal': appraisal_subtotal,   # 감정료 소계
        'survey_fee': survey_fee,                   # 현황조사수수료
        'newspaper_fee': newspaper_fee,             # 신문공고료
        'sale_fee': sale_fee,                       # 매각수수료
        'prepayment_subtotal': prepayment_subtotal, # 예납금 소계
        'total': total                              # 가지급금 총계
    }
```
