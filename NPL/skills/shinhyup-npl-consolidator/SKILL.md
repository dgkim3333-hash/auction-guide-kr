# 신협 NPL 전체현황 통합 스킬

## 목적

신협 NPL 관련 Excel 파일을 읽어서 기존 마스터 파일(`신협NPL_전체현황.xlsx`)에
추가·갱신하고, **대출잔액·대출이자·가지급금을 자동 산정**하여 입력한다.
기존 데이터는 그대로 유지한다.

## ⚡ 핵심 원칙: 기존 데이터 보존 + 신규만 처리 + 자동 계산

| 항목 | 처리 방식 |
|------|----------|
| 기존 마스터 데이터 | **절대 수정·삭제하지 않음** — 그대로 유지 |
| 신규 업로드 파일 | 마스터 파일 마지막 행 아래에 **추가** |
| 중복 물건 | 채무자 + 담보물 소재지 + 신협명이 동일하면 해당 행만 **갱신** |
| Update된 일자 | 신규 추가 또는 갱신된 행만 오늘 날짜(YYYY-MM-DD) 기록 |
| 감정가 | AI시세 기준 **최저 금액** 자동 입력 |
| 지점명 | 건물등기 권리자 및 기타사항에서 **자동 추출** |
| 대출잔액 | 채권최고액 ÷ 1.2로 **자동 산정** |
| 대출이자 | 청구금액 - 대출잔액으로 **자동 산정** |
| 상환 추정 | 청구액 < 대출잔액이면 대출잔액 × 0.9 (10% 상환 추정) |
| 가지급금 | 감정가·채권최고액 기반 경매비용 **자동 산정** |
| 서식 | 기존 서식 유지, 신규 행에도 동일 서식 적용 |
| No. 순번 | 전체 재부여 |

2. **마스터 파일 식별**: `신협NPL_전체현황.xlsx` 파일을 찾는다
3. **신규 파일 분류**: 마스터 파일이 아닌 신협/NPL 관련 Excel 파일 = 신규 파일

```bash
ls -lt /mnt/user-data/uploads/
```

### 파일 분류 기준

- **마스터 파일**: 파일명에 `신협` + `전체현황`이 포함된 `.xlsx` 파일
- **신규 파일**: 마스터 파일을 제외한, 파일명에 `신협` 또는 관련 키워드가 포함된 `.xlsx` / `.xls` / `.csv` 파일
- **무관 파일**: 위 조건에 해당하지 않는 파일 → 무시

## 핵심 워크플로우

### Step 1: 신규 파일만 식별 (빠른 분류)

업로드된 파일 중 마스터 파일이 아닌 신협/NPL 관련 파일만 골라낸다.
**마스터 파일에 이미 들어있는 기존 데이터는 건드리지 않는다.**

### Step 2: 신규 파일 일괄 읽기 및 데이터 추출

각 신협 NPL 파일을 읽을 때 다음 규칙을 적용한다:

#### 2-1. 이자율 파싱 규칙

| 원본 표현 | 이자율(%) | 연체 이자율(%) |
|-----------|-----------|---------------|
| `이자 3.5/12.0` | 3.5 | 12.0 |
| `3.5/12.0` | 3.5 | 12.0 |
| `연체 12.0%` | (비워둠) | 12.0 |
| `이자율 3.5%` | 3.5 | (비워둠) |

- `x.xx/y.yy` 형식: 슬래시 앞이 이자율, 뒤가 연체 이자율
- 퍼센트 기호(%)는 제거하고 숫자만 저장

#### 2-2. 주소 조합 규칙

담보물 소재지가 명확하지 않은 경우:
1. 문서에서 "시/군/구/동" 정보를 찾는다
2. "지번" 정보를 찾는다
3. 두 정보를 합쳐서 주소를 만든다

#### 2-3. "붙임 자료 참조" / "붙임" 처리 규칙

문서 내에 "붙임 자료 참조" 또는 "붙임"이라는 표현이 있는 경우:
1. 같은 폴더 내에 별도 첨부 파일이 있는지 확인한다
2. 별도 파일이 없으면, 해당 문서의 아래쪽 전체 내용(모든 시트, 모든 행)을 끝까지 확인한다
3. 숨겨진 시트가 있는지도 확인한다

#### 2-4. 감정가 산정 규칙 (AI시세 기준)

감정가(O컬럼)는 경매정보 파일에서 **AI시세**를 확인하여 입력한다.

- 경매정보 파일 내에 "AI시세", "AI 시세", "AI추정가", "AI감정가" 등의 항목을 찾는다.
- **여러 감정가가 존재하는 경우(감정가, AI시세, 시세 등), 그 중 가장 낮은 금액을 O컬럼에 입력한다.**
  - 보수적 관점에서 최저 금액을 기준으로 삼아야 NPL 매입 리스크를 줄일 수 있기 때문이다.
- AI시세가 없는 경우에만 일반 감정가를 사용한다.
- 비고(Y컬럼)에 감정가 출처를 기록한다 (예: "AI시세 기준", "감정가 중 최저액 적용").

**우선순위**: AI시세 > 감정가 > 기타 시세 (단, 항상 가장 낮은 금액을 선택)

#### 2-5. 지점명 추출 규칙 (건물등기 기반)

지점명(D컬럼)은 건물등기 내용의 **"권리자 및 기타사항"** 란에서 추출한다.

- 등기부등본의 권리자 및 기타사항에서 "XX지점", "XX출장소" 패턴을 찾는다.
- 예시 패턴:
  - "○○신용협동조합 **강남지점**" → 지점명: "강남지점"
  - "○○신협 **역삼출장소**" → 지점명: "역삼출장소"
  - "○○신용협동조합" (지점명 없음) → 지점명: 비워둠 (본점으로 간주)
- 근저당권 설정 내역에서 채권자(권리자)가 해당 신협이고 지점명이 기재된 경우에만 추출한다.
- 하나의 물건에 여러 근저당이 있으면, 해당 신협의 근저당에서 지점명을 추출한다.

#### 2-6. 금액 파싱 규칙

- 쉼표(,)가 포함된 숫자는 쉼표를 제거하고 숫자로 변환
- "천원", "만원", "백만원", "억원" 단위가 있으면 원 단위로 환산
- "원" 글자는 제거
- 빈 셀이나 "-"는 0 또는 빈 값으로 처리

### Step 3: 대출잔액·대출이자·가지급금 자동 산정 (핵심 계산 로직)

이 단계가 본 스킬의 **핵심 차별점**이다.
신규 파일에서 추출한 데이터를 기반으로 아래 계산을 자동 수행한다.

#### 3-1. 대출잔액 산정

```
대출잔액 = 채권최고액 ÷ 1.2
```

- 건물등기의 채권최고액(V컬럼)을 1.2로 나눈 값을 대출잔액(P컬럼)에 입력한다.
- 채권최고액은 일반적으로 실제 대출금의 120%로 설정되므로, 역산하여 원금을 추정한다.
- 원 단위 이하는 절사(내림) 처리한다.

#### 3-2. 대출이자 산정

```
대출이자 = 청구금액 - 대출잔액
```

- 청구금액(채권합계, T컬럼)에서 대출잔액(P컬럼)을 뺀 금액이 대출이자이다.
- **"청구금액"의 출처**: 원본 파일에서 "청구액", "청구금액", "채권합계", "합계", "채권총액" 등의 컬럼명으로 표시된 금액이다. 원본에 명시적 청구금액이 없으면 채권합계(T컬럼)를 사용한다.
- 산정된 대출이자(청구금액 - 대출잔액)는 **Q컬럼(정상이자)에 전액 입력**한다.
  - R컬럼(연체이자)에는 별도로 연체이자 정보가 원본 파일에 명시된 경우에만 입력한다.
  - 원본에 연체이자 정보가 없으면 R컬럼은 비워둔다.

#### 3-3. 상환 추정 (청구액 < 대출잔액인 경우)

```
청구금액 < 대출잔액(채권최고액÷1.2) 인 경우:
  → 대출잔액(P컬럼) = 채권최고액 ÷ 1.2 × 0.9 (10% 상환 추정)
  → 대출이자 = 청구금액 - 보정된 대출잔액
```

- 청구액이 추정 대출잔액보다 작다는 것은 일부 상환이 이루어졌음을 의미한다.
- 이 경우 대출잔액에서 10%가 상환된 것으로 **1회만** 추정하여 재계산한다.
- **반복 적용하지 않는다** — 보정 후에도 여전히 청구액 < 대출잔액이면 추가 보정 없이 그대로 입력하고, 비고에 "추가 상환 가능성"으로 표기한다.
- 비고(Y컬럼)에 "10% 상환 추정 적용"이라고 기록한다.

#### 3-4. 가지급금(경매신청비용) 자동 산정

가지급금은 경매 신청 및 진행에 소요되는 비용이다.
감정가(기준금액)와 채권최고액(채권금액)을 기반으로 산정한다.
**상세 산정 로직은 `references/auction-cost-formula.md`를 참조한다.**

스킬 실행 시 반드시 `references/auction-cost-formula.md`를 읽어서 정확한 계산 공식을 적용한다.

```
가지급금 = 경매비용 총계
         = 신청비용 소계 + 예납금 소계
```

- 계산된 가지급금을 S컬럼에 입력한다.
- 기본값: 이해관계인 수 = 5명, 목적물 수 = 1개로 가정한다.
  - 실제 이해관계인 수를 파악할 수 있으면 해당 값을 사용한다.

### Step 4: 마스터 파일 업데이트 (기존 데이터 보존)

1. **기존 마스터 파일 로드**: `openpyxl`로 기존 파일을 열어 헤더, 서식, 병합셀, 기존 데이터 모두 유지
2. **기존 데이터 절대 삭제 금지**: 기존 행은 읽기 전용으로 취급
3. **중복 체크**: 채무자 + 담보물 소재지 + 신협명으로 동일 물건 여부 판별
   - 동일 물건이 있으면 → 해당 행만 **갱신**, Update된 일자를 오늘로 변경
   - 새 물건이면 → 마지막 행 아래에 **추가**
4. **Update된 일자**: 신규/갱신된 행의 F컬럼에만 오늘 날짜 입력
5. **No. 재부여**: 전체 순번을 1부터 다시 매김

### Step 5: 신협명 필터 적용

마스터 파일의 C열(신협명)에 Excel 자동 필터(AutoFilter)를 설정한다.

```python
ws.auto_filter.ref = f"B3:Y{last_row}"
```

## ⚡ 고속 처리 전략: "Recalculate formulas" 완전 제거

### 핵심 원칙: Excel 수식 대신 Python 값 직접 입력

기존 방식에서 Excel 수식 재계산(Recalculate formulas)이 병목이었다.
본 스킬은 **모든 계산을 Python에서 수행하고, 결과를 "순수 값(value only)"으로 셀에 입력**한다.
Excel 파일에 수식(=)이 단 하나도 들어가지 않으므로, 열 때 재계산이 발생하지 않는다.

| 항목 | 기존 방식 (느림) | 개선 방식 (빠름) |
|------|-----------------|-----------------|
| 대출잔액 | `=V4/1.2` (Excel 수식) | Python `int(bond_max / 1.2)` → 값 입력 |
| 대출이자 | `=T4-P4` (Excel 수식) | Python `claim - balance` → 값 입력 |
| 가지급금 | 복잡한 중첩 수식 | Python `calc_auction_cost()` → 값 입력 |
| 파일 열기 | Recalculate 대기 | **즉시 열림** |

### 고속 스크립트 사용법

**`scripts/fast_calc_and_write.py`를 우선 실행한다.**
이 스크립트는 마스터 파일의 모든 행에 대해 대출잔액·이자·가지급금을 Python으로 계산하고, 순수 값으로 입력한다.

```bash
python scripts/fast_calc_and_write.py \
  /mnt/user-data/uploads/신협NPL_전체현황.xlsx \
  /mnt/user-data/outputs/신협NPL_전체현황.xlsx
```

스크립트가 처리하지 못하는 부분(신규 파일 파싱, 비정형 데이터 등)만 직접 openpyxl로 처리한다.

### 추가 속도 최적화 규칙

1. **신규 파일만 처리**: 마스터 파일의 기존 데이터는 읽기만 하고 수정하지 않는다
2. **일괄 읽기 → 일괄 쓰기**: 모든 신규 파일을 먼저 읽고, 마스터 파일에 한 번만 쓴다
3. **불필요한 재처리 방지**: 이미 마스터에 있는 데이터를 다시 파싱하지 않는다
4. **openpyxl data_only 미사용**: `data_only=False`로 열어야 서식이 유지된다. 대신 기존 수식 셀은 Python 계산값으로 덮어쓴다
5. **셀에 수식 입력 금지**: `ws.cell().value = "=V4/1.2"` 형태 절대 금지. 반드시 `ws.cell().value = 83333333` 형태로 입력

## 주의사항

- 원본 파일은 절대 수정하지 않는다. 마스터 파일만 업데이트한다.
- **기존 마스터 데이터는 절대 삭제하지 않는다.** 신규 파일 데이터만 추가/갱신한다.
- 데이터 파싱에 실패한 필드는 빈 셀로 남기고, 비고(Y)컬럼에 "파싱 실패" 표기한다.
- 하나의 파일에 여러 물건이 있을 수 있다. 모든 물건을 빠짐없이 추출한다.
- 숨겨진 시트나 행이 있을 수 있으므로 확인한다.
- 대출잔액·이자·가지급금 산정 시 음수가 나오면 비고에 "산정 이상" 표기 후 원본 값 유지한다.
