## 1. 동의서 위조·진위 확인 리스크

### 문제

위탁자가 수탁자(신탁사)의 인감을 도용하거나 문서를 위조하여 가짜 동의서를 만드는 사례가 빈번하다.
임차인이 이를 진본으로 믿고 입주하면, 공매 시 '무동의 불법 임대차'로 판정되어 즉시 명도 대상이 된다.

### NPL 매입자 관점에서의 영향

- **유리한 점**: 동의서가 위조인 경우 해당 임차인은 대항력이 없으므로 공매 시 인수 보증금 없이 매각 가능 → 배분 가능액 증가
- **불리한 점**: 위조 여부를 둘러싼 법적 분쟁이 장기화될 수 있음 → 공매 지연 리스크
- **불리한 점**: 위조 동의서를 진본으로 착각하고 인수 보증금을 산정하면 → 매입가 과소 산정으로 실질 손실

### 확인 방법

1. 신탁사 담당자에게 유선 또는 공문으로 동의 여부를 직접 교차 확인
2. 동의서의 신탁사 직인·법인인감 진위 확인
3. 신탁사에 '임대차 동의 현황' 확인서 징구 (동의한 임차인 명단 + 동의일자)
4. 동의서 원본이 아닌 사본만 있는 경우 위조 가능성 높음 → 원본 확인 필수

## 2. 대표대주(Representative Lender) 논리와 동의 구조

### 개념

신탁원부상 '우선수익자 전원의 동의'를 요구하는 조항이 있더라도, 실무에서는 대주단 중 **대표대주**가 선정되어 있으면 그 한 명(법인)의 동의로 전체 우선수익자의 의사를 갈음할 수 있다.

### NPL 매입자 관점에서의 영향

- **매입 후 우선수익자로서의 지위**: 당사가 1순위 우선수익권을 매입하면, 임대차 동의권도 승계됨. 대표대주가 당사가 아닌 경우 동의 절차에서 소외될 수 있음
- **확인 필수**: 대주단 약정서(Syndication Agreement)에서 대표대주 지정 여부 및 동의 권한 범위 확인
- **매입 전 대표대주 변경 가능 여부**: 수익권 양도 후 대표대주가 변경되는지, 또는 당사가 대표대주 지위를 승계하는지 확인

### 실무 포인트

- 다수 대주가 참여한 PF 대출 담보신탁의 경우, 대표대주 1인의 동의로 임대차 동의가 이루어진 임차인이 존재할 수 있음
- 이 경우 해당 임차인은 '우선수익자 동의를 받은 임차인'으로 분류 → 공매 시 대항력 인정 가능
- 매입 시 대표대주가 동의한 임차인 목록과 보증금 총액을 확인하여 인수 부담 정확히 산정

## 3. 신탁사의 임차인 권리 강등 시도 (재계약 유도)

### 문제 구조

신탁 설정 전에 이미 대항력을 갖춘 임차인(전입신고 + 인도 완료)은 공매 시 **당연 승계** 대상이다.
그런데 일부 신탁사가 이들에게 "소유자가 바뀌었으니 계약서를 다시 쓰자"며 **신탁 후 재계약**을 유도한다.

- 신탁 전 임차인(대항력 有, 당연 승계) → **정산순위 상위** (낙찰자 인수)
- 신탁 후 수탁자 동의 임차인 → **정산순위 하위** (공매대금에서 배분, 부족하면 미반환)

이 재계약은 임차인 입장에서 **명백한 권리 강등**이다.

### NPL 매입자 관점에서의 영향

- **유리한 점**: 신탁 전 임차인이 재계약하여 신탁 후 동의 임차인으로 전환된 경우 → 대항력 약화 → 인수 보증금 감소 가능 → 공매 배분 가능액 증가
- **불리한 점**: 재계약 여부를 정확히 파악하지 못하면 임차인 대항력 판정 오류 → 매입가 산정 오류
- **법적 리스크**: 임차인이 재계약 강요에 대해 부당이득반환 또는 불법행위 소송을 제기하면 → 공매 절차 복잡화

### 확인 방법

1. 신탁 설정일 전 전입세대열람과 현재 임대차계약서의 계약일자를 대조
2. 동일 임차인이 신탁 설정 후에 새로운 계약서를 작성한 흔적이 있는지 확인
3. 최초 전입일이 신탁 전이나 계약서 작성일이 신탁 후 → 재계약 유도 정황
4. 신탁사에 '재계약 경위' 확인 요청

## 4. 보증금 입금 계좌 리스크 (이중 변제 위험)

### 문제 구조

신탁원부상 보증금 수납 권한이 신탁사에 있는 경우, 위탁자 개인 계좌에 보증금을 입금하면 법적으로 '적법한 변제'로 인정되지 않을 수 있다. 이 경우 임차인은 보증금을 이중으로 부담해야 하는 위험이 있다.

### NPL 매입자 관점에서의 영향

- 위탁자 계좌로 입금된 보증금은 신탁사가 인정하지 않을 수 있음 → 해당 임차인의 보증금 반환채무 범위 분쟁
- 공매 시 정산에서 위탁자 계좌 입금 보증금의 처리 방식이 신탁사마다 상이
- **확인 필수**: 임차인별 보증금 입금 계좌가 수탁자(신탁사) 명의인지, 위탁자 명의인지 구분

### 매입가 산정 반영

- 신탁사 계좌 입금 보증금 → 정산 시 인정 가능성 높음 → 인수 또는 공제 대상으로 산정
- 위탁자 계좌 입금 보증금 → 신탁사 미인정 가능성 → 법적 분쟁 리스크로 할인율 반영

## 5. 공매 공고 '보증금 반환 의무 낙찰자 전가' 조항

### 문제 구조

최근 일부 신탁사가 공매 공고에 '임차보증금 반환 의무를 낙찰자에게 전가'하는 특약을 삽입하는 사례가 증가하고 있다. 이는 우선수익자(채권자)의 배분 가능액을 극대화하기 위한 신탁사의 전략이나, 실질적으로는 입찰가를 하락시키는 요인이 된다.

### NPL 매입자 관점에서의 영향

- **공매가 하락 요인**: 낙찰자가 보증금 반환 의무를 인수해야 하므로 입찰가를 그만큼 낮춰 산정 → 1순위 배분 가능액 감소
- **시뮬레이션 반영 필수**: 공매 공고 특약 내용에 따라 보증금이 공제 대상인지, 낙찰자 인수인지 구분하여 회수 시뮬레이션
- **확인 방법**: 공매 공고문의 매각조건 및 특약사항 원문 확인, 과거 해당 신탁사 공매 사례에서 유사 조항 존재 여부 조사

### 배분 시뮬레이션 영향

| 시나리오 | 보증금 처리 방식 | 1순위 배분 영향 |
|----------|------------------|-----------------|
| 보증금 공매대금에서 공제 후 배분 | 우선공제 항목에 포함 | 배분 가능액 직접 감소 |
| 보증금 반환 의무 낙찰자 인수 | 낙찰자가 별도 부담 | 입찰가 하락으로 간접 감소 |
| 보증금 신탁사가 정산 후 반환 | 정산순위에 따라 배분 | 정산순위에 따라 상이 |

## 6. 신탁공매 시 임대인 지위 승계 4유형 세분화

SKILL.md 섹션 3의 판정표를 보완하는 심화 분류이다.
아래 4유형으로 모든 임차인을 분류하고, 각각의 공매 후 효과를 정확히 판정한다.

| # | 유형 | 임대인 지위 승계 | 보증금 반환 의무 부담 주체 | 공매 후 효과 |
|---|------|------------------|---------------------------|-------------|
| 1 | 신탁등기 전 임대차 (대항력 有) | **승계** | **낙찰자** (당연 승계) | 낙찰자가 보증금 반환 의무 인수, 주임법/상임법 보호 |
| 2 | 수탁자가 직접 체결한 임대차 | **승계** | **낙찰자** (당연 승계) | 가장 안전한 형태, 수탁자=임대인이므로 승계 당연 |
| 3 | 수탁자 동의를 받은 임대차 (신탁후) | **미승계** | **신탁사** (공매대금 정산순위로 배분) | 낙찰자에게 직접 청구 불가, 정산에서 후순위 배분 |
| 4 | 무동의 불법 임대차 | **미승계** | **위탁자** (사실상 회수 불가) | 즉시 명도(퇴거) 대상, 임차인 보증금 회수 불능 |

### NPL 매입자 관점 핵심 포인트

- **유형 1, 2 임차인**: 공매가에서 보증금을 사실상 차감하는 효과 → 매입가 산정 시 인수 보증금으로 반영
- **유형 3 임차인**: 공매대금 정산순위에서 배분되므로 1순위 수익자 배분 가능액 감소 → 우선공제에 반영
- **유형 4 임차인**: 명도 대상이므로 인수 부담 없음. 단, 명도 소송 비용·기간 발생 → 회수 전략 비용에 반영
- **유형 분류 오류의 위험**: 유형 1을 유형 3으로 잘못 분류하면 인수 보증금 누락 → 공매 배분 시뮬레이션 오류 → 매입가 과대 산정

## 7. 유치권 행사 불가능성 — 법리적 근거 보강

SKILL.md 체크리스트 ⑰을 보완하는 법리 상세이다.

### 핵심 법리

신탁부동산에서 유치권 행사는 사실상 불가능하다. 그 이유:

1. **적법한 점유 요건 결여**: 유치권은 '적법한 점유'를 전제로 함 (민법 제320조). 신탁사 동의 없는 점유자는 법리상 '불법 점유자'이므로 유치권 성립 요건 자체가 결여
2. **신탁재산 독립성**: 신탁법 제22조에 의해 신탁재산은 위탁자의 고유재산과 분리됨. 위탁자에 대한 채권으로 신탁재산에 유치권 주장 불가
3. **공사대금 유치권의 제한**: 위탁자가 발주한 공사의 대금채권으로 신탁부동산에 유치권 주장 시, 수탁자가 공사를 승인하지 않았다면 유치권 불인정

### NPL 매입자 관점

- 신탁부동산의 유치권은 일반 경매 물건보다 인정 가능성이 **현저히 낮음** → 유치권 리스크 할인율을 일반 경매 대비 낮게 설정 가능
- 단, 수탁자가 직접 발주한 공사의 공사대금은 유치권 인정 가능 → 이 경우에만 유치권 리스크 반영
- 유치권 주장자가 있더라도, 신탁 구조상 법적으로 인정되지 않을 가능성이 높으므로 → 과도한 할인율 적용은 불필요할 수 있음

## 8. 금감원 민원을 통한 사후 동의 강제 전략

### 개념

수탁자·우선수익자의 동의 없이 위탁자와 임대차계약을 체결한 임차인이라도, 우선수익자의 실질적 동의가 있었던 경우 금융감독원 민원이나 내용증명을 통해 신탁사의 '사후 동의'를 강제할 수 있다.

### NPL 매입자 관점에서의 위험

- **기존 무동의 임차인이 사후 동의를 획득하면**: 무동의 → 동의 임차인으로 전환 → 공매 시 대항력 인정 가능 → 인수 보증금 발생
- **매입 검토 시점과 실제 공매 시점 사이에 임차인이 금감원 민원으로 사후 동의를 획득하는 사례** → 매입 시 산정한 임차인 현황이 변동
- **대응**: 매입 전 신탁사에 '향후 추가 동의 가능성' 확인, 금감원 민원 진행 중인 임차인 유무 파악

### 매입가 산정 반영

- 현재 무동의 임차인이라도, 금감원 민원 등으로 사후 동의 가능성이 있는 경우 → 보수적으로 해당 보증금을 인수 가능 항목에 포함하여 시뮬레이션
- 신탁사에 '사후 동의 불가' 확인서를 징구할 수 있으면 리스크 경감

## 9. 전세권 설정 등기 — NPL 매입자 관점의 리스크

### 개념

임차인이 전세권 설정 등기를 한 경우, 단순 임차권보다 강력한 물권적 효력을 갖는다.
전세권자는 경매 신청권과 우선변제권을 동시에 보유하며, 대항력 발생 시차(익일 0시)의 공백이 없다.

### NPL 매입자 관점에서의 위험

- **전세권이 신탁등기보다 선순위인 경우**: 공매에서도 전세권자의 보증금을 반드시 인수 → 인수 보증금 증가 → 배분 가능액 대폭 감소
- **전세권이 신탁등기보다 후순위인 경우**: 원칙적으로 공매로 소멸. 단, 수탁자 동의 하에 전세권이 설정된 경우 신탁계약에 따라 정산순위에서 우선 배분 가능성
- **확인 방법**: 등기사항전부증명서 을구에서 전세권 설정일자와 신탁등기일자 비교, 전세금액 확인

### 매입가 산정 반영

| 상황 | 공매 후 효과 | 매입가 산정 반영 |
|------|-------------|-----------------|
| 전세권 신탁등기 전 설정 | 낙찰자 인수 (소멸 불가) | 전세금 전액 인수 보증금으로 차감 |
| 전세권 신탁등기 후 + 수탁자 동의 | 정산순위에 따라 처리 | 정산순위 확인 후 우선공제 반영 |
| 전세권 신탁등기 후 + 무동의 | 공매로 소멸 | 인수 부담 없음, 명도 비용만 반영 |

## 10. 신탁 임대차 구조의 근본적 비대칭성

### NPL 매입 분석 시 유의할 구조적 특성

담보신탁은 '소유권(수탁자)'과 '임대 관리(위탁자)'가 분리되는 기형적 구조를 가진다.
이 구조적 비대칭성이 NPL 매입 분석에 미치는 영향:

1. **위탁자 독단 임대의 만연**: 신탁사가 관리를 위탁자에게 위임하면서, 위탁자가 신탁사 동의 없이 임대차계약을 체결하는 사례 다수 → 무동의 임차인 비율이 예상보다 높을 수 있음
2. **신탁사의 관리 소홀**: 신탁보수 하락으로 신탁사가 임대 관리에 소극적 → 임차인 현황 파악이 어려움 → 현장 실사 중요성 증대
3. **임차인 정보의 비대칭**: 임차인 자신이 담보신탁 사실을 모르는 경우 빈번 → 공매 시 임차인 항변·분쟁 가능성
4. **보증금 반환의 책임 전가**: 신탁사는 소유권자이면서도 보증금 반환 의무를 위탁자에게 전가 → 공매 시 보증금 처리를 둘러싼 분쟁 빈발

### 매입 실무 반영

- 임차인 현황 조사 시 신탁사 자료만 믿지 말고, 현장 실사 + 전입세대열람 + 임차인 직접 면담 병행
- '무동의 임차인 비율'을 보수적으로 산정하여 명도 비용에 반영
- 신탁사에 임대차 동의 현황 확인서를 반드시 징구
