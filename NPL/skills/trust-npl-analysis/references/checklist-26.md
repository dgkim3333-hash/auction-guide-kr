### 섹션 2 — 27개 필수 체크리스트

> ⚠ 계정판 SKILL.md 와 다름 — 본문(SKILL.md) 규칙이 우선: 계정판은 26개(①~㉖, E 카테고리 4개)이며 PC판 ㉗(당사자 표시 변경)은 계정판 체크리스트에서 빠짐. 아래 PC 원문은 27개 그대로 둠.

각 항목은 아래 기호로 표시한다:
- ✅ 해당없음/정상
- 🔴 위험 (매입 결정에 중대 영향)
- 🟡 주의 (추가 확인 필요)
- ⬜ 정보부족 (확인 필요)

#### [A. 권리관계 — 8개]

**① 신탁원부 유효성 확인**
- 확인: 신탁원부가 유효한지, 신탁 등기가 정상적으로 설정되어 있는지
- 위험: 신탁 등기 하자·무효 시 신탁사 공매 자체가 불가능 → 채권 회수 경로 상실
- 확인 방법: 등기부 갑구에서 신탁 등기 확인, 신탁원부 발급(2024년부터 인터넷 발급 가능)하여 유효성 검증

**② 수익권 순위 및 양도 제한 확인**
- 확인: 매입 대상 수익권이 실제 1순위인지, 수익권 양도에 신탁사 동의가 필요한지
- 위험: 양도 제한 특약이 있으면 매입 후 수익권 행사 불가 → 매입 자체가 무의미
- 위험: 1순위라고 했으나 실제로는 선순위 수익자가 존재하면 배분 순위 밀림
- 확인 방법: 신탁계약서의 수익권 양도 조항, 신탁원부상 수익자 순위 전수 확인, 우선수익권 증서 확인

**③ 신탁계약 해지·변경 리스크**
- 확인: 위탁자 또는 다른 수익자가 신탁계약 해지를 요구할 수 있는 조건이 있는지
- 위험: 신탁 해지 시 소유권이 위탁자에게 환원 → 신탁사 공매 불가 → 일반 경매로 전환 필요
- 위험: 1순위 우선수익자 동의 없이 해지 가능한 조항이 있으면 매입 후 회수경로 상실
- 확인 방법: 신탁계약서 해지 조항, 위탁자의 해지 청구 여부 동향 파악

**④ 신탁 종료일 임박 여부**
- 확인: 신탁 기간이 만료 임박하거나 이미 만료되었는지
- 위험: 신탁 만료 후 자동 종료 시 소유권 환원 → 공매 기회 상실
- 주의: 신탁 연장 가능 여부 및 연장 시 동의 요건 확인 필요
- 확인 방법: 신탁원부의 신탁 기간, 신탁계약서의 연장·종료 조항

**⑤ 등기사항 선·후순위 권리 확인**
- 확인: 신탁등기 전·후 순위의 근저당·압류·가등기·가처분 존재 여부
- 위험: 신탁등기 전 근저당은 신탁사에 우선 → 공매 대금에서 먼저 배당
- 위험: 가처분 존재 시 공매 진행 장애 → 법적 분쟁 해결까지 공매 지연
- 주의: 신탁재산에 대한 강제집행은 원칙적으로 금지(신탁법 제22조)이나, 예외 존재
- 확인 방법: 등기사항전부증명서 갑구·을구 전수 확인

**⑥ 위탁자 지정 우선수익자 리스크**
- 확인: 위탁자가 우선수익자를 사후 지정한 것인지, 후순위 압류가 이루어진 경우인지
- 위험: 위탁자 지정 우선수익권은 저당권과 다른 법률효과 → 배당 분쟁 소지
- 확인 필수 4요소: 수익권 설정 순위, 신탁계약서 내용, 채권 금액·범위, 신탁재산 처분 가능성
- 근거: 대법원 2023다 판례 (위탁자 지정 우선수익권의 법률효과)

**⑦ 수익채권의 시효 소멸 여부**
- 확인: 피담보채권(수익채권)의 소멸시효가 완성되었는지
- 위험: 시효 완성 시 우선수익권 자체가 소멸 → 매입 후 권리 행사 불가
- 확인: 민사채권 10년, 상사채권 5년 시효 관리 필수
- 확인 방법: 채권 발생일, 최종 연체일, 독촉·소송 등 시효 중단 사유 확인

**⑧ 수익권 양도 통지·대항요건 구비**
- 확인: 우선수익권 양도 시 채무자(위탁자)에 대한 통지 및 신탁사 동의가 완료되었거나 가능한지
- 위험: 대항요건 미구비 시 수익권 양수인으로서 권리 행사 불가
- 위험: 매입 후 신탁사가 양도 동의를 거부하면 수익자 변경 등기 불가 → 배분금 수령 불가
- 확인 방법: 수익권 양도계약서 조항, 신탁사 양도 동의 사전 확인(문서화), 양도 통지는 내용증명으로 발송

#### [B. 담보가치·시장성 — 5개]

**⑨ 담보 부동산 시세 적정성**
- 확인: 감정가와 실거래가·시세 간 괴리가 있는지, 감정평가서가 최근 1년 이내인지
- 위험: 감정가 과대평가 시 공매 유찰 반복 → 회수 기간 장기화 및 회수액 감소
- 확인 방법: 국토부 RTMS 실거래가, KB부동산 시세, 인근 유사 물건 조사, 공인중개사 탐문

**⑩ 담보가치 역전 여부**
- 확인: 채권액(채권최고액) > 시세인지 여부
- 위험: 담보가치 역전 시 공매로도 원금 회수 불확실 → 매입 자체 재검토 필요
- 주의: 2026년 기준 PF 사업장·지방 상업용 부동산에서 담보가치 역전 빈발
- 확인 방법: 채권최고액 대비 현재 시세 비율 산정, 역전 시 즉시 NO-GO 검토

**⑪ 공매 예정가격 산정근거 확인**
- 확인: 신탁사의 공매 예정가격이 어떤 기준으로 산정되었는지
- 주의: 공매 예정가격이 시세보다 과도하게 높으면 유찰 반복 → 회수 기간 장기화
- 확인 방법: 신탁사 공매공고 확인, 감정평가 전문기관의 평가기법 적정성 검토

**⑫ 유동성·시장성 평가**
- 확인: 담보 부동산의 매각 용이성 (입지, 용도, 규모)
- 위험: 지방·특수용도·대형 상업시설은 유동성 낮아 유찰 반복 위험
- 주의: 과거 3년 유사물건 낙찰가율을 조사하여 낙찰 예상가 시뮬레이션
- 확인 방법: 온비드 과거 공매 사례, 지역 부동산 시장 동향

**⑬ 불법건축물·위반건축물 여부**
- 확인: 건축물대장에 위반건축물 표시, 용도 불일치 등
- 위험: 이행강제금 부과, 담보 가치 하락, 공매 시 입찰자 기피
- 확인 방법: 건축물대장 표제부 확인, 현황조사

#### [C. 임차·점유 리스크 — 5개]

**⑭ 임차인 대항력 — 신탁등기 전/후 판정**
- 확인: 임차인의 전입일·확정일자가 신탁등기일보다 앞인지 뒤인지 (日 단위 비교)
- 위험: 신탁등기 전 대항력을 갖춘 임차인 → 공매 낙찰자에게 보증금 인수 → 공매가 하락
- 핵심: 신탁공매에서는 소액임차인 최우선변제가 원칙적으로 불적용 (사적 처분이므로)
- 확인 방법: 전입세대열람을 신탁등기일 '전/후/현재' 3개 시점으로 대조
- 상세 판정: 섹션 3 '임차인 배당·인수 판정표' 참조

**⑮ 신탁사·우선수익자 동의 있는 임차인 확인**
- 확인: 신탁등기 후 임차인 중 수탁자+우선수익자 동의를 받은 임차인이 있는지
- 위험: 동의받은 임차인은 대항력 인정 → 낙찰자가 보증금 반환채무 인수
- 확인 방법: 신탁계약서 '임대차 금지·동의' 조항 원문 확인, 수탁자·우선수익자 '임대차 동의서' 원본 확보, 동의서 없으면 신탁사에 '동의 없음' 확인서 징구

**⑯ 상가 임대차 특수사항**
- 확인: 상가인 경우 환산보증금 초과/미초과 구분, 상임법 대항력 여부
- 위험: 환산보증금 기준에 따라 상가임대차보호법 적용 범위 상이
- 확인 방법: 임대차계약서, 환산보증금(월세 × 100 + 보증금) 산정

**⑰ 유치권·점유자 현황**
- 확인: 담보 부동산에 유치권 주장자 또는 불법 점유자가 있는지
- 위험: 유치권 존재 시 공매 입찰자 기피 → 공매가 대폭 하락 또는 유찰
- 위험: 불법 점유자 명도 시 별도 명도소송 필요 (신탁공매는 인도명령 불가)
- 확인 방법: 현장 조사, 신탁사에 점유 현황 문의, 점유이전금지가처분 필요성 검토

**⑱ 체납관리비 승계 범위**
- 확인: 공용부분·전용부분 체납관리비 규모
- 핵심: 대법원 2023년 판례변경 — 신탁공매 체납관리비 중 공용부분만 승계, 전용부분 미승계
- 주의: 체납관리비가 대금에서 우선공제되지 않더라도 낙찰자가 공용부분을 부담하므로 매입가 산정 시 차감
- 확인 방법: 관리사무소에 공용/전용 구분 체납액 확인

**⑱-a 동의서 위조·진위 확인** *(보강)*
- 확인: 위탁자가 수탁자 인감을 도용하여 가짜 동의서를 만든 사례가 빈번 → 동의서 진위 교차 확인 필수
- 위험: 위조 동의서를 진본으로 착각 시 → 인수 보증금 산정 오류 → 매입가 과대/과소 산정
- 위험: 위조 여부를 둘러싼 법적 분쟁 장기화 → 공매 지연
- 확인 방법: 신탁사 담당자에게 유선+공문으로 동의 여부 교차 확인, 동의서 원본(사본 아님) 확인, 신탁사에 '임대차 동의 현황 확인서' 징구

**⑱-b 대표대주(Representative Lender) 동의 구조 확인** *(보강)*
- 확인: PF 대출 등 다수 대주 참여 시 대표대주 선정 여부, 대표대주 1인 동의로 임대차 동의가 이루어졌는지
- 위험: 대표대주 동의 임차인은 '우선수익자 동의를 받은 임차인'으로 분류 → 대항력 인정 가능 → 인수 보증금 발생
- 확인 방법: 대주단 약정서(Syndication Agreement)에서 대표대주 지정 여부 확인, 매입 후 대표대주 지위 승계 여부 확인

**⑱-c 임차인 권리 강등(재계약 유도) 여부 확인** *(보강)*
- 확인: 신탁 전 대항력 있는 임차인이 신탁 후 재계약으로 전환되었는지 (신탁사의 재계약 유도 사례)
- 위험: 재계약으로 당연승계 임차인(정산순위 상위) → 동의 임차인(정산순위 하위)으로 전환 → 임차인 대항력 판정 오류
- 유리한 점: 재계약 전환된 임차인은 대항력 약화 → 인수 보증금 감소 가능
- 확인 방법: 신탁 설정일 전 전입세대열람과 현재 임대차계약서 계약일자 대조, 최초 전입일이 신탁 전인데 계약서가 신탁 후 → 재계약 정황

**⑱-d 전세권 설정 등기 리스크** *(보강)*
- 확인: 등기사항전부증명서 을구에 전세권 설정이 있는지, 전세권 설정일이 신탁등기 전/후인지
- 위험: 전세권이 신탁등기 선순위인 경우 공매에서도 소멸 불가 → 전세금 전액 낙찰자 인수 → 배분 가능액 대폭 감소
- 주의: 전세권은 임차권보다 강력한 물권적 효력(경매신청권+우선변제권) → 대항력 발생 시차(익일 0시) 공백 없음
- 확인 방법: 등기부 을구에서 전세권 설정일자 vs 신탁등기일자 비교, 전세금액 확인, 수탁자 동의 하 설정 여부 확인

#### [D. 세무·비용 — 4개]

**⑲ 체납 조세(당해세·국세·지방세) 규모**
- 확인: 담보 부동산에 부과된 당해세(재산세·종부세), 위탁자(채무자)의 국세·지방세 체납 현황
- 위험: 당해세는 담보신탁에서도 우선 공제 대상
- 위험: 조세채권은 신탁 구조와 무관하게 최우선 또는 우선 공제될 수 있음
- 확인 방법: 세무서·구청 조회, 국세완납증명서 요청

**⑳ 신탁보수 체납 여부 및 누적액**
- 확인: 신탁사에 지급해야 할 신탁보수(수수료)의 체납 여부 및 누적 금액
- 위험: 신탁보수는 공매 대금에서 최우선 공제 → 누적액이 크면 수익권자 배분액 대폭 감소
- 일반적 보수율: 환가금액의 1~2% (신탁사별 상이)
- 확인 방법: 신탁사에 직접 문의하여 체납 보수 금액 확인, 신탁계약서상 보수율 확인

**㉑ 공매 진행 비용 예상**
- 확인: 공매 광고비, 감정비, 법률비용 등 공매 진행에 필요한 비용 규모
- 주의: 공매 비용도 대금에서 우선 공제 → 배분액 감소 요인
- 확인 방법: 신탁사에 공매 비용 견적 확인, 유사 물건 공매 사례 참조

**㉒ 취득세·부가가치세 고려**
- 확인: 신탁공매 낙찰 시 취득세(4.6% 기준), 상가·오피스텔의 경우 부가가치세 매입자 부담 여부
- 주의: 세금은 매입가 산정 시 '총 투자 비용'에 반드시 포함
- 확인 방법: 해당 지자체 취득세율, 부가가치세 적용 여부 확인

#### [E. 절차·전략 리스크 — 4개]

**㉓ 신탁사 공매 의지 및 협조도**
- 확인: 신탁사가 공매를 적극적으로 진행할 의지가 있는지, 공매 절차가 이미 진행 중인지
- 위험: 신탁사가 공매에 소극적이면 회수 기간이 장기화되어 수익률 하락
- 위험: 신탁사가 위탁자 측과 결탁하여 공매를 지연시키는 사례 존재
- 위험: 2026년 기준 일부 신탁사는 NPL 매각 대신 공매를 선택하는 경향 증가 → 공매 물량 증가로 회수율 악화
- 확인 방법: 신탁사 담당자 면담, 공매 공고 이력, 과거 해당 신탁사의 공매 이행 실적

**㉔ 위탁자(채무자) 회생·파산 여부**
- 확인: 위탁자에 대한 법원의 회생·파산 절차가 진행 중이거나 신청 가능성이 있는지
- 위험: 회생 개시 시 담보신탁 부동산도 회생재단에 포함될 수 있음 → 공매 중단 가능
- 주의: 신탁재산은 위탁자의 파산재단에 포함되지 않는 것이 원칙(신탁법 제22조)이나, 법원 판단에 따라 다를 수 있음
- 주의: 위탁자 회생·파산 시 임차인 보증금채권이 회생채권으로 잡혀 있을 수 있으므로 회생계획안도 체크
- 확인 방법: 법원 파산·회생 사건 검색, 채무자 재무 상태 조사

**㉕ 후순위 수익자·이해관계인의 이의 가능성**
- 확인: 2순위 이하 수익자나 위탁자가 공매 절차에 이의를 제기할 가능성
- 위험: 공매 절차에 이의 제기 → 공매 지연 또는 무효 소송
- 확인 방법: 후순위 수익자 현황 파악, 위탁자의 태도 및 분쟁 이력 조사

**㉖ 경쟁 매입자 존재 여부**
- 확인: 동일 수익권에 대해 다른 NPL 업체나 투자자가 매입을 검토하고 있는지
- 주의: 경쟁 존재 시 매입가 상승 압력 → 수익률 하락
- 확인 방법: 매도자(금융기관·AMC)에 경쟁 입찰 여부 확인, 시장 동향 파악

**㉗ 위탁자/수익자/임차인의 당사자 표시 변경 여부**
- 확인: 신탁 관련 서류, 온비드 공매 공고, 법원 관련 문건(공매 이의소송·배당이의소송 등)에서 동일 역할(위탁자/채무자/수익자/임차인)의 표시가 시점에 따라 변경되었는지
- 단독 원인으로 단정 금지 — 다음 4가지 유형이 단독 또는 병행 발생 가능:
  - **A형 (상속 개시)**: "망 XXX의 상속인 외 N인" 장문 표시 — 위탁자·수익자·임차인 사망
  - **B형 (변호사 선임)**: "소송대리인 변호사 △△△" 병기 — 공매 이의·배당이의 소송 제기
  - **C형 (법인/신탁 전환)**: 위탁자 법인 합병·분할·해산, 수익자 법인 변경
  - **D형 (공시송달)**: 위탁자·임차인 소재불명
- 위험 (담보신탁 특화):
  - 🚨 **위탁자 사망(A형)** → 상속인 전원의 신탁 해지·공매 이의 제기 가능 → 공매 지연
  - 🚨 **수익자 변경** → 1순위 수익권 매입 시 정확한 양도인 확인 실패 시 채권 무효 리스크
  - 🚨 **위탁자 법인 합병·분할(C형)** → 신탁계약 승계 여부 및 공매 적법성 논란
  - 🚨 **임차인 사망·상속(A형)** → 대항력 있는 임차인의 상속인에게 보증금 반환 의무 승계 → 낙찰자 인수 부담
  - 🚨 **위탁자·수익자·임차인이 각자 변호사 선임(B+B+B 병행)** → 다자간 분쟁 구조 → 회수 장기화
- **특히 담보신탁 구조는 위탁자·수탁자·수익자·임차인 4자 구조로, 일반 경매보다 B+B+B 병행 위험이 높음**
- 확인 방법:
  1. 신탁원부·신탁계약서에서 위탁자·수익자 표시를 초기 설정 시점과 최근 시점 비교
  2. 온비드 공매 공고에서 당사자 표시 변경 이력 확인
  3. 대법원 나의사건검색에서 관련 소송(공매 이의·배당이의·배당기일 변경) 당사자 표시 확인
  4. 대한변호사협회 변호사 검색으로 담당변호사 실존 확인
  5. **3대 교차 확인 필수**: ① 등기부등본 + 신탁원부 재발급 ② 법원 사건검색 ③ 신탁사·법원 직접 조회
- 할인율 반영:
  | 유형 | 단독 | 병행 |
  |------|------|------|
  | A만 (위탁자·수익자·임차인 사망) | +10~15% | — |
  | B만 (변호사 선임 — 공매 이의 등) | +8~12% | — |
  | C만 (법인 합병·분할) | 재실사 필수 | — |
  | D만 (공시송달) | +5~8% | — |
  | A+B 병행 | — | **+15~25%** |
  | B+B+B (위탁자·수익자·임차인 각자 선임) | — | **+18~25%** |
  | 수익자 변경 단독 | 매입 보류 + 재실사 | — |
