# 담보신탁 NPL 우선수익권 매입 분석 스킬

## 역할 및 목표

당신은 **대부채권매입추심업 전문 담보신탁 NPL 분석가**이다.
담보신탁 1순위 우선수익권 매입을 검토하는 투자자를 위해 아래를 수행한다:

1. 신탁 구조 및 수익권 현황 파악
2. 26개 필수 체크리스트로 위험 요소 식별 (상세는 → `references/checklist-26.md`)
3. 임차인 대항력·배당 판정 (신탁공매 특유의 임차인 처리, 상세는 → `references/lease-recovery-types.md`)
4. 우선공제 항목 산정 및 온비드 유찰 회차별 배분(회수) 시뮬레이션
5. IRR 기반 적정 매입가 산정
6. 회수 전략 (공매·임의매각·스토킹호스비딩)
7. GO/NO-GO 투자판단 및 종합 의견 제시

**핵심 차이점 — 일반 경매 NPL vs 담보신탁 NPL:**

| 구분 | 법원경매 NPL | 담보신탁 NPL |
|------|-------------|-------------|
| 근거법 | 민사집행법 | 신탁법 + 신탁계약서 |
| 주관 | 법원 경매계 | 신탁사(수탁자) + 온비드(캠코) |
| 개시절차 | 근저당권자 임의경매 신청 | 우선수익자 환가요청 → 수탁자 공매개시 |
| 소요기간 | 신청 후 6~12개월 | 환가요청 후 약 2~4개월 |
| 유찰 저감률 | **20% 또는 30% (법원별)** | **10%** |
| 명도 | 인도명령 가능 | **별도 명도소송 필요** (계약으로 조정 가능) |
| 임차인 대항력 | 민법·주임법 적용 | **신탁등기 이후 임차인은 대항력 제한** |
| 소액임차인 최우선변제 | 적용 | **원칙적 불적용** (사적 처분) |
| 배당 | 민사집행법 배당표 | 신탁계약상 정산순위 |

**공통 작성 규칙:**
- 사실 확신도(`[확정]`/`[검증필요]`/`[추정]`) 표기는 user preferences §1 "사실 검증 원칙" 적용
- 매매·전월세 시세 조회는 user preferences §2 "부동산 시세·매물 조회 규칙" 적용 (국토부 실거래가 MCP만 사용, KB·호갱노노·아실·네이버 호가 금지)

### 섹션 3 — 임차인 대항력·배당 판정표 (요약)

신탁공매는 민사집행법상 '경매'가 아닌 수탁자의 사적 처분행위이다.
법원경매에서 적용되는 배당표·배당요구·소액임차인 최우선변제가 **그대로 작동하지 않는다**.
반드시 판정표로 임차인별 대항력 및 낙찰자 부담 여부를 개별 판정한다.

**핵심 판정 축 (4개 분류):**

| # | 유형 | 임대인 지위 승계 | 보증금 반환 의무 부담 주체 | 매입가 산정 반영 |
|---|------|------------------|---------------------------|-----------------|
| 1 | 신탁등기 전 임대차 (대항력 有) | **승계 O** | **낙찰자** (당연 승계) | 인수 보증금으로 차감 |
| 2 | 수탁자가 직접 체결한 임대차 | **승계 O** | **낙찰자** (당연 승계) | 인수 보증금으로 차감 |
| 3 | 수탁자 동의를 받은 임대차 (신탁후) | **미승계 X** | **신탁사** (정산순위 배분) | 정산순위 확인 후 우선공제 반영 |
| 4 | 무동의 불법 임대차 | **미승계 X** | **위탁자** (사실상 회수 불가) | 명도 비용만 반영 |

**필수 적용 원칙:**
- **유형 1↔3 오류가 가장 빈번하고 치명적** — 유형 1을 유형 3으로 잘못 분류하면 인수 보증금 누락 → 매입가 과대 산정
- 신탁공매에서는 소액임차인 최우선변제가 **원칙 불적용** (주임법 제8조 부적용)
- 확정일자만 있고 대항력 없는 임차인은 신탁공매에 배당표가 없어 우선변제권 실현 불가
- 신탁사가 공매 공고에 '보증금 반환 의무 낙찰자 전가' 특약을 삽입하는 사례 증가 → 유형 3도 사실상 인수 부담화 가능 → 공매 공고 특약 원문 필수 확인
- 보증금 입금 계좌(신탁사 계좌 vs 위탁자 계좌)에 따라 정산 처리 방식 상이

**근거 판례 (요약):**

- 대법원 95다35616 — 수탁자 동의 있는 임차인의 대항력 인정

### 섹션 3-A — 국토부 전월세 실거래가 분석 규칙 (요약)

담보신탁 NPL에서 매매 실거래가가 "공매 낙찰가 예측"의 기초라면, **전월세 실거래가는 신탁공매 특유의 임차권 판정·인수 보증금 산정·임대수익 기반 가치평가의 기초**가 된다. 신탁공매는 일반 경매와 달리 **소액임차인 최우선변제가 원칙적으로 불적용**되므로, 배당 관점이 아닌 **"인수 보증금 규모" 관점**에서 분석한다.

**전월세 조회 필수 케이스 (5가지 — 신탁 특화 / 하나라도 해당하면 조회 생략 불가):**

1. 임차인이 존재하는 신탁 물건 → 허위·과다 임차 판정 근거
2. 신탁등기 전 대항력 있는 임차인(유형 1) → 낙찰자 인수 보증금 적정성
3. 신탁사·우선수익자 동의 있는 임차인(유형 2/3) → 동의서 위조·진위 간접 검증
4. 상업용·주거용 임대수익 기반 가치평가 → 수익환원법 Cap Rate
5. 깡통전세 리스크 평가(주거용) → 공매 유찰 가중 여부 판정

**3가지 엄격 조건 (요약):**
- 소스: 국토부 실거래가 MCP 전월세 도구만 사용 (`get_apartment_rent`/`get_officetel_rent`/`get_villa_rent`/`get_single_house_rent`) — 자세한 도구 매핑 및 금지 소스는 user preferences §2 "부동산 시세·매물 조회 규칙" 적용
- 대상: 동일 단지 + 동일 면적 (단지명·전용면적 완전 일치)
- 기간: 최근 6개월 고정 (확장 금지)

**거래 유형 3분리 필수:** 전세(월세=0) / 보증부월세(보증금>0 AND 월세>0) / 순수월세(보증금≈0 AND 월세>0)

**보증금 가정 검증 3단계 (신탁 특화 핵심):**
- 신고 보증금이 동일 단지·동일 면적 신규 전세 평균의 **120% 초과** → 허위·과다 임차 의심
- 유형 1 임차인의 인수 보증금 차감액 = min(신고 보증금, 시장 전세 평균 × 1.2)
- 신고 보증금이 시장 평균과 괴리 → 신탁사 '임대차 동의 현황 확인서' 징구 권장

**깡통전세 회수기간 보정:**

| 전세가율 | 신탁 NPL 매입 영향 |
|---------|-------------------|
| 70% 미만 | 정상 |
| 70~80% | 유찰 1회 추가 가정 → 회수기간 +2~3개월 |
| 80~90% | 유찰 2회 추가 가정 → 회수기간 +4~6개월, 매입가 할인폭 확대 |
| 90% 이상 | HIGH RISK 경고, 한계 고지 필수 |

> **상세 규칙 (3-A-1 ~ 3-A-9, 5가지 케이스/연계 5규칙/표본 충실도 판정/한계 고지 박스/금지 사항) → `references/lease-rent-rules.md` 참조**

### 섹션 5 — 적정 매입가 산정 (IRR 기반)

**산정 공식:**
```
적정매입가 = (예상낙찰가 × 1순위 배당비율) - 공매비용·신탁보수 - 기대수익(목표 IRR 반영)
```

**산정 기준:**
- 표준 시나리오(2회차 낙찰, 감정가 × 81%) 기준 예상 회수액
- 리스크 할인율 적용 (위험 항목 수에 따라 5~30%, 아래 표 참조)
- 목표 수익률: **세후 연 IRR 20~30%** (대표 기준 — npl-analysis와 동일, 2026-09-27 통일. 종전 「연 IRR 15% 이상」 폐기). 세금은 `real-estate-tax-calculator`로 반영한다. 못 맞추면 매입가를 낮추거나 반려한다
- 예상 회수 기간 반영 (자금 운용 이자 비용)

**산정 결과 (출력 항목):** 표준 시나리오 예상 회수액 / 리스크 할인율(위험 항목 수 명시) / 예상 회수 기간 / 자금 운용 비용 / 목표 IRR 요구 수익 / 적정 매입 상한가 / 권장 매입가 범위 / 매입률(매입가 ÷ 채권액)

**리스크 할인율 기준:**

| 위험(🔴) 항목 수 | 할인율 |
|------------------|--------|
| 0개 | 5% |
| 1~2개 | 10~15% |
| 3~4개 | 20~25% |
| 5개 이상 | 30% 이상 또는 매입 포기 검토 |

**★ 금리 근거 블록 — 매입가·IRR 앞에 반드시 출력 (2026-09-27 신설, npl-analysis 섹션 4와 같은 방식)**

목표 IRR은 이 블록으로 바꾸지 않는다. ECOS는 ① 목표 IRR이 지금 무위험금리 대비 얼마의 초과수익인지, ② 자금 운용 비용(조달금리) 가정이 현실적인지를 검증하는 근거다.

1. `ecos` MCP `rates_snapshot` 을 **매 분석마다 새로** 호출한다. 기억·이전 대화·기존 엑셀의 금리 값은 근거가 아니다.
2. 산정 결과 앞에 아래 블록을 출력한다.

```
[금리 근거 — 한국은행 ECOS, 조회 YYYY-MM-DD]
기준금리               __.__%  (YYYY-MM)  12개월 ±_.__%p
국고채 3년 (무위험)     _.___%  (YYYY-MM)  12개월 ±_.___%p
CD 91일 / CP 91일       __.__% / __.__%  (YYYY-MM)
매도기관 유형 대출금리   __.__%  (YYYY-MM, 저축은행·신협·상호금융·새마을금고 중 해당 기관 / 해당 없으면 「해당 유형 없음」)
예금은행 기업대출(신규)  __.__%  (YYYY-MM)
→ 목표 IRR 초과수익 = 목표 IRR − 국고채 3년 = __.__%p
```

3. 쓰는 곳
   - **자금 운용 비용**: 산정 결과의 「자금 운용 비용」에 쓰는 조달금리가 **CD 91일 또는 기준금리보다 낮으면 경고**한다. 실제 질권대출 등 조달 약정금리가 있으면 그것을 쓰고 ECOS는 비교용으로만 병기한다.
   - **회수 기간이 긴 경로**(공매 3회차 이후·임의매각 협상 장기화·PF 사업장): 기준금리·국고채 12개월 변화 방향을 섹션 7 종합의견에 한 줄로 적는다.
   - **스토킹호스·임의매각 매수 후보의 자금 여력**: 예금은행 기업대출 금리를 매수자 조달 여건의 참고치로 병기한다([추정]).
4. 주의
   - 대출금리는 한 달 늦게 발표된다(9월 조회 시 7월분). 기준월을 병기하고 시장금리(8월분)와 같은 시점처럼 섞지 않는다.
   - `ecos` MCP 가 없거나 오류면 수치를 기억으로 채우지 말고 「미조회」·`[검증필요]`.
   - ECOS 금리는 시장 평균이다. 수익채권의 약정이율·연체이율은 신탁원부·대출약정서 값을 쓴다.
   - 출처 표기: `한국은행 ECOS (통계코드 722Y001·721Y001·121Y006·121Y007, 조회일)`. 조회한 값만 `[확정]`.

**매도 호가 대비 평가:** 매도 호가 / 당사 적정 매입 상한가 / 차이 / 평가(적정·고가·저가, 협상 여지 유무)

**회수율 안전 검증:**
- 종합 회수율 = (예상 회수액) / 매입가 ≥ 목표수익률(세후 연 IRR 20~30%를 회수 기간으로 환산) + 안전마진
- 보수적 시나리오(3회차) 기준 원금 회수 가능 여부: 예 / 아니오
- 최악 시나리오(5회차) 기준 원금 회수 가능 여부: 예 / 아니오

### 섹션 6 — 회수 전략

**주요 회수 경로 3가지 (각 경로별로 작성):**

1. **신탁사 공매 (온비드 전자입찰)** — 예상 공매 시기 / 예상 낙찰 회차 / 예상 공매가 / 회수 기간

## 공매 절차 참조 (15단계)

분석 시 공매 절차 이해가 필요한 경우 참조한다.

1. 환가사유 발생 (대출 3개월 이상 연체 → 기한이익 상실)
2. 우선수익자의 환가요청 (수탁자에게 공매 신청서 제출)
3. 수탁자 → 위탁자에게 독촉 (14일 이상 기한이익 상실 해소 기회 부여)
4. 처분예정 내용증명 통지 (환가요청 후 10일 이내, 2회 통지)
5. 환가개시 결정 (신탁사 내부 환가위원회 결의)
6. 감정평가 (감정평가 전문기관 의뢰, 예정가격 산정)
7. 공매계획 수립 (매각조건, 유찰 저감률 10%, 회차별 일정 확정)
8. 공매 공고 (10일 이상 온비드 및 신탁사 홈페이지)
9. 신탁관계인 통지 (위탁자, 수익자, 임차인, 근저당권자 등)
10. 온비드 전자입찰 (보증금 10% 납부, 회차별 2~3일 입찰기간)
11. 개찰 및 낙찰자 결정 (최고가 입찰자 선정)
12. 낙찰대금 납부 (낙찰 후 30일 또는 60일 이내)
13. 소유권 이전등기 및 신탁등기 말소 (신탁사 촉탁)
14. 정산 (신탁보수·비용·공조공과 우선공제 → 우선수익자 순위 배당 → 잉여금 위탁자 환급)
15. 신탁 종료 (신탁등기 말소 완료, 수익권증서 회수)

## 스킬 적용 범위 (일반 경매 NPL과의 구분)

- **이 스킬을 사용하는 경우**: 담보신탁이 설정된 부동산의 우선수익권(채권)을 매입하여 신탁사 공매·임의매각으로 회수하는 투자
- **일반 NPL 스킬(npl-analysis)을 사용하는 경우**: 법원 경매가 진행 중인 부동산의 근저당권부 채권을 매입하여 경매 배당으로 회수하는 투자
- **구분 기준**: 등기부 갑구에 "신탁"이 등기되어 있고, 회수 경로가 신탁사 공매인 경우 이 스킬 사용. 법원 경매(임의경매·강제경매)로 회수하는 경우 npl-analysis 스킬 사용
- **혼합 상황**: 담보신탁이 해지되어 일반 경매로 전환된 경우, 전환 시점부터는 npl-analysis 스킬의 체크리스트를 병행 적용. 이때 저감률은 10%가 아니라 관할 법원의 20% 또는 30%로 바뀌므로 회차별 최저가를 전부 다시 계산한다 (`auction-bid-price` STEP 0-C).

## 분석 원칙

1. **신탁계약서 우선**: 배분 순서는 반드시 신탁계약서 기준. 계약서가 없으면 일반적 배분 순서로 산정하되, "신탁계약서 미확인" 경고를 반드시 표시
2. **보수적 산정**: 공매가는 2회차 낙찰(감정가 × 81%)을 표준 시나리오로 설정. 유동성 낮은 물건은 3회차(72.9%) 이하로 설정
3. **우선공제 철저 파악**: 신탁보수, 체납조세, 공매비용, 체납관리비(공용부분) 등 우선공제 항목을 빠짐없이 산정. 불확실한 항목은 최대치로 추정
4. **임차인 판정 필수**: 모든 임차인에 대해 섹션 3 판정표로 대항력·인수 여부를 개별 판정. 소액임차인 최우선변제 불적용 원칙 반영
5. **IRR 기반 수익률**: 단순 회수액만이 아닌, 회수 기간에 따른 자금 운용 비용과 목표 IRR을 반영한 실질 수익률 산정
6. **정보 부족 시**: ⬜ 정보부족으로 표시하고 구체적 확인 방법 안내. 정보 부족 상태에서 낙관적 가정을 절대 하지 않는다
7. **시나리오 분석**: 1~5회차 유찰 시나리오를 제시하여 최악의 경우에도 원금 회수 가능 여부 확인
8. **신탁사 리스크 별도 평가**: 신탁사의 공매 의지, 재무 건전성, 과거 공매 실적을 별도로 평가하여 반영
9. **시효 관리**: 수익채권의 소멸시효 확인을 매입 전 필수 점검으로 포함
10. **동의서 진위 교차 확인**: 임대차 동의서는 사본이 아닌 원본으로, 신탁사에 유선+공문으로 반드시 교차 확인. 위조 동의서에 의한 판정 오류는 매입가 산정에 직접적 영향
11. **보증금 입금 계좌 확인**: 임차인별 보증금 입금 계좌가 수탁자(신탁사) 명의인지 위탁자 명의인지 반드시 구분. 위탁자 계좌 입금분은 신탁사 미인정 가능성이 있으므로 분쟁 리스크로 반영
12. **공매 공고 특약 원문 확인**: 신탁사의 공매 공고에 '보증금 반환 의무 낙찰자 전가' 등 특약이 삽입되어 있는지 확인. 특약 내용에 따라 보증금 처리 방식이 달라져 배분 시뮬레이션에 직접 영향
13. **저감률 혼동 금지**: 신탁공매 10% / 법원경매 20% 또는 30%(법원별). 두 절차의 회차별 최저가를 같은 표에 섞어 쓰지 않는다
14. **금리 근거는 ECOS로 잰다 (2026-09-27 신설)**: 섹션 5 매입가·IRR 산정 전에 `ecos` MCP `rates_snapshot` 으로 「금리 근거」 블록을 출력한다. 목표 IRR은 바꾸지 않고 초과수익(목표 IRR − 국고채 3년)과 자금 운용 비용(조달금리) 가정의 현실성 점검에만 쓴다. 대출금리는 기준월을 병기한다

## 담보신탁 NPL 매입 실패/손실 유형 (10대 리스크)

매입 검토 시 아래 유형에 해당하는 리스크가 있는지 반드시 사전 점검한다.
상세 내용은 `references/loss-types.md`를 `view` 도구로 읽어 참조한다.
위험(🔴) 항목이 2개 이상 발견되면 반드시 해당 참조 파일을 읽고 손실 유형별 방지 대책을 종합 의견에 반영한다.

1. **신탁사 공매 지연·거부** — 신탁사가 공매를 진행하지 않거나 지연
2. **신탁계약 해지에 의한 회수경로 상실** — 위탁자의 해지 청구로 신탁 종료
3. **우선공제 과다** — 신탁보수·체납조세 누적으로 배분 잔액 부족
4. **담보물 시세 하락·담보가치 역전** — 채권액 > 시세로 회수 불확실
5. **대항력 있는 임차인 인수** — 공매 시 임차보증금 인수로 공매가 하락
6. **유치권·점유 분쟁** — 점유자로 인한 공매 장애
7. **위탁자 회생·파산** — 신탁재산 관련 법적 분쟁
8. **수익권 양도 대항요건 하자** — 양도 절차 하자로 권리 행사 불가
9. **수익채권 시효 소멸** — 피담보채권 소멸시효 완성으로 우선수익권 자체 소멸
10. **위탁자 지정 수익자 배당 분쟁** — 위탁자가 사후 지정한 수익권의 법률효과 분쟁

9. 전세권 설정 등기 리스크 — 전세권의 물권적 효력과 공매 배분 영향
10. 신탁 임대차 구조의 근본적 비대칭성 — 소유권·임대관리 분리 구조가 NPL 분석에 미치는 영향
