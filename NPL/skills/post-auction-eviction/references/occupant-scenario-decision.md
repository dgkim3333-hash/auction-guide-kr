# 점유자 시나리오 판정 트리

낙찰 후 명도 전략은 점유자 유형에 따라 완전히 달라진다. 잘못 판정하면 인도명령 vs 명도소송 선택이 어긋나서 시간·비용 손실이 발생한다.

## 판정 순서 (위에서 아래로 순차 적용)

```
START
  │
  ├─ Q1. 매각물건명세서에 임차인 기재 있는가?
  │     ├─ NO  → A 또는 B 분기 (Q5로)
  │     └─ YES → Q2로
  │
  ├─ Q2. 임차인의 전입신고일 + 점유개시일이 최선순위 (근)저당설정일보다 빠른가?
  │     ├─ YES → C 시나리오 (대항력 있는 임차인)
  │     └─ NO  → Q3로
  │
  ├─ Q3. 임차인이 배당요구를 했고 보증금 전액을 배당받았는가?
  │     ├─ YES → D 시나리오 (배당받은 임차인)
  │     └─ NO  → C 또는 D의 변형 (Q4로 보강)
  │
  ├─ Q4. 매각물건명세서에 유치권 신고가 있는가?
  │     ├─ YES → E 시나리오 (유치권 대응) — 우선 적용
  │     └─ NO  → 직전 결론 유지
  │
  └─ Q5. 점유자가 협조적이고 자진 이주 의사가 있는가?
        ├─ YES → B 시나리오 (명도합의 우선)
        └─ NO  → A 시나리오 (일반 채무자)
```

**중요**: 시나리오 E(유치권)는 다른 시나리오와 중첩 가능하다. 예를 들어 임차인이 동시에 유치권을 주장하는 경우 **E를 우선 적용**하고, 유치권 부정 후 원래 시나리오(C 또는 D)로 복귀한다.

---

## 시나리오 A: 일반 채무자/소유자 점유

### 식별 지표
- 매각물건명세서 "임차인 현황" 칸에 기재 없음 또는 "채무자 본인 점유"
- 등기부 갑구 소유자 = 점유자
- 점유자가 협조 거부 또는 무응답

### 적용 절차
1. 잔금납부 직후 **부동산인도명령 신청** (집행권원 확보, 인지 1,000원)
2. 인도명령 결정 송달 (보통 2~4주)
3. 송달 후 14일 이내 **즉시항고 없으면 확정**
4. 확정 후 **강제집행 신청** (집행관 사무소)
5. 집행 통지서 → 1차 계고 → 2차 계고 → 강제집행
6. 평균 D+60 ~ D+90에 명도 완료

### 비용 추정
- 인도명령 인지: 1,000원
- 송달료: 5만원 내외
- 강제집행 비용: 200만 ~ 500만원 (물건 규모 따라)
- 노무비·이삿짐 보관료 별도

[검증필요] 강제집행 비용은 집행관 사무소·물건 크기에 따라 변동. 사전 견적 필요.

---

## 시나리오 B: 명도합의 우선 (이사비 협상)

### 식별 지표
- 점유자가 협조적, 단기 자진 이주 의사
- 이사비·이사기한 협의 가능
- 강제집행보다 합의가 비용·시간 측면 유리

### 적용 절차
1. 잔금납부 후 즉시 **명도협상 미팅** (대면 또는 통화)
2. 이사비 합의 (시세 기준 50만원 ~ 500만원)
3. **명도합의서** 작성 (공증 권장)
4. 이사비 일부 선지급 → 이주 완료 시 잔액 지급
5. 이사 완료일에 **이사비 영수증** 수령 + 열쇠 인수
6. 평균 D+30 ~ D+45 완료

### 합의서 필수 조항
- 이주 완료일 (확정일자)
- 이사비 금액 + 지급 방법 (선·잔금 분할)
- 미이주 시 위약금 + 강제집행 동의 (집행권원 명시)
- 시설물 원상 유지 의무
- 잔존 동산 처분 권한 위임

### 보험 차원의 병행 조치
**합의 결렬 대비** 인도명령은 미리 신청해두는 것이 안전. 결렬 시 즉시 강제집행 진입.

## 시나리오 C: 대항력 있는 임차인

### 식별 지표
- 전입신고 + 점유개시 시점이 **최선순위 (근)저당 설정일보다 빠름**
- 보증금이 배당으로 전액 회수되지 않음 (미배당분 존재)

### 핵심 원칙
**낙찰자는 임차인의 보증금을 인수**한다 (주택임대차보호법 §3③, 상가건물임대차보호법 §3②).

### 적용 절차
1. **인도명령 신청 불가** — 인도명령은 대항력 없는 점유자만 대상
2. 잔금납부 후 **임대차 관계 검토**
   - 임대차 잔여기간 확인
   - 보증금 인수 부담 확정
3. 두 가지 선택지:
   - **선택 1**: 임대차 승계 → 임대인 지위 인수 → 잔여기간 임대료 수령
   - **선택 2**: **명도소송 제기** (대항력 인수 후 보증금 반환 + 명도 청구)
4. 명도소송 절차:
   - 소장 제출 → 송달 → 1차 변론 → 판결 → 항소 가능성 → 강제집행
   - 평균 6개월 ~ 1년 소요

### 비용 추정
- 소장 인지: 보증금 인수액 기준 산정 (예: 보증금 1억 → 인지 약 45만원)
- 송달료, 변호사 선임료(선택)
- 보증금 인수 자금 별도

### 리스크
- 보증금 반환 채무 인수가 입찰가에 반영되지 않으면 **수익률 음전환** 가능
- 임차인이 임대차 갱신 주장하면 추가 분쟁

[검증필요] 인지액 산정은 민사소송법 인지법에 따름. 대법원 인지액 자동계산기로 확인.

---

## 시나리오 D: 배당받은 임차인

### 식별 지표
- 임차인이 **배당요구 종기 내 배당요구**
- 보증금 전액 또는 일부를 배당으로 회수
- 배당표 확정

### 핵심 원칙
배당받은 임차인은 **배당과 동시에 인도 의무** 발생 (주택임대차보호법 §3의2 등).

### 적용 절차
1. 배당기일 종료 + 배당 수령 확인
2. 잔금납부 후 **인도명령 신청** (배당 수령 사실 명시)
3. 인도명령 결정 → 확정 → 강제집행
4. 만약 임차인이 미배당 잔여 보증금이 있으면 → 시나리오 C 일부 적용

### 주의점
- 배당기일에 임차인이 배당금 수령을 거부했다 하더라도 **수령 의제** (공탁)
- 인도명령 신청 시 배당표 사본 첨부

## 시나리오 E: 유치권 주장

### 식별 지표
- 매각물건명세서 "유치권 신고" 기재
- 공사대금·임차료·임치료 등 채권 주장
- 점유 사실 + 견련성 주장

### 진성 vs 허위 유치권 판단

**진성 유치권 요건** (모두 충족):
1. 적법한 점유 (불법침입 아닐 것)
2. 채권의 변제기 도래
3. 채권과 목적물의 견련성 (그 물건에 관한 채권일 것)
4. 유치권 배제 특약 없음

**허위 유치권 의심 지표**:
- 경매개시결정 기입등기 **이후** 점유 시작
- 점유 사실의 객관적 증거 부족 (CCTV·전기·수도 명의)
- 채권 발생 시점이 의심스러움 (서류 위조 의심)
- 채권 금액이 비현실적으로 큼
- 채무자와 유치권자가 친인척·관계회사

### 적용 절차

**Case 1: 허위 유치권으로 강하게 의심**
1. 점유 증거 수집 (현장 확인, CCTV, 진술)
2. **유치권 부존재확인 소송** 제기
3. 가능하면 **점유이전금지 가처분** 동시 신청
4. 승소 시 → 시나리오 A 또는 D로 복귀
5. 평균 8개월 ~ 1년 6개월 소요

**Case 2: 진성 유치권 가능성 있음**
1. 채권액 협상 (감액 협의)
2. 부분 변제 + 자진 인도 합의
3. 합의 결렬 시 채권액 공탁 후 인도명령

### 리스크
- 유치권은 인수주의 → 낙찰가 + 유치권 채권액 = 실제 비용
- 부존재확인 소송 패소 시 막대한 추가 비용
- **반드시 변호사 선임 권장**

[검증필요] 유치권 관련 법리는 대법원 판례에 따라 변동. 최신 판례 확인 (예: 대법원 2009다25148 등).

## 시나리오 판정 후 다음 단계

판정이 끝나면 SKILL.md의 Stage 4 ~ Stage 6에 따라 시나리오별 문서 생성으로 진행한다.

| 시나리오 | Stage 4 (1차 문서) | Stage 6 (2차 문서) |
|---|---|---|
| A | 인도명령신청서 + 내용증명 | 강제집행신청서 |
| B | 명도합의서 초안 + 내용증명 | (병행) 인도명령신청서 |
| C | 명도소송 소장 | 부당이득반환청구 소장 |
| D | 인도명령신청서 + 내용증명 (배당 수령 사실 명시) | 강제집행신청서 |
| E | 유치권 부존재확인 소장 | (승소 후) 인도명령신청서 |
