### 섹션 4 — 시장가치 평가 [STEP 3: 시장분석/감정평가사]

#### 4-1. 가격 비교 분석

| 비교 항목 | 금액/단가 | 비고 |
|-----------|-----------|------|
| 감정가 | | (감정 기준시점) |
| 개별공시지가 | ㎡당 ___원 | (기준연도) |
| 감정가 vs 공시지가 배율 | __배 | (적정: 1.2~2.0배) |
| 인근 유사토지 실거래가 | ㎡당 ___원 | (최근 2년 이내) |
| 인근 경매 낙찰 사례 | ㎡당 ___원 (낙찰가율 ___%) | (최근 1년) |

#### 4-2. 지역 개발 호재/악재

| 구분 | 내용 | 영향도 |
|------|------|--------|
| 호재 1 | | 상/중/하 |
| 호재 2 | | 상/중/하 |
| 악재 1 | | 상/중/하 |
| 악재 2 | | 상/중/하 |

#### 4-3. 적정 낙찰가 산정

```
[산정 기준]
- 비교사례법: 인근 유사토지 평균 거래단가 × 면적
- 수익환원법: 연간 예상 임대수익(NOI) ÷ 기대수익률(Cap Rate)
- 인근 경매 낙찰가율: 해당 지역 유사 토지 평균 낙찰가율

[산정 결과]
- 비교사례 기준가    : ___________원
- 수익환원 기준가    : ___________원
- 리스크 할인율      : ___% (위험 항목 _개 반영)
- 적정 낙찰가 범위   : ___________원 ~ ___________원
- 권장 입찰 상한가   : ___________원
- 감정가 대비 비율   : ___%
```

> ⚠ 계정판 SKILL.md 와 다름 — 본문(SKILL.md) 규칙이 우선: PC판은 여기서 「권장 입찰 상한가」를 직접 산정하나, 계정판은 이 값을 가치 상한으로만 보고 실제 입찰가는 `auction-bid-price` 스킬로 확정한다.

**리스크 할인율 기준**

| 위험 항목 수 | 할인율 |
|-------------|--------|
| 0개 | 5% |
| 1~2개 | 10~15% |
| 3~4개 | 20~25% |
| 5개 이상 | 30% 이상 또는 투자 포기 검토 |

### 섹션 5 — 금융/대출/세금 분석 [STEP 4: 금융/대출 전문가]

#### 5-1. 토지담보대출 가능성

| 분석 항목 | 내용 |
|-----------|------|
| 토지 유형별 LTV | (대지 50~70% / 계획관리 40~60% / 농지 30~50% / 임야 20~40%) |
| 예상 대출 가능액 | ___________원 (감정가 × LTV) |
| 예상 금리 | 연 ___% |
| 상환 조건 | (만기일시/원리금균등/거치기간) |
| 1금융권 가능 여부 | (가능/불가 → 사유) |
| 2금융권 대안 | (저축은행/캐피탈 등 조건) |
| 필요 자기자본 | ___________원 |

#### 5-2. 세금 분석

| 세금 항목 | 예상 금액 | 납부 시기 | 비고 |
|-----------|-----------|-----------|------|
| 취득세 | ___원 | 취득 후 60일 | 농지 3.0% / 기타 4.6% |
| 재산세 | 연 ___원 | 매년 7·9월 | 종합합산/별도합산/분리과세 구분 |
| 종합부동산세 | 연 ___원 | 매년 12월 | 법인 종부세율 주의 |
| 양도소득세 (예상) | ___원 | 양도 후 2개월 | 보유기간별 장기보유특별공제 적용 |

#### 5-3. 총 투자비 및 수익률 산정

```
[총 투자비 산정]
(A) 낙찰가              : ___________원
(B) 취득세              : ___________원
(C) 법무비용            : ___________원
(D) 토목/기반시설 비용  : ___________원
(E) 대출 이자 (6개월)   : ___________원
(F) 기타 비용           : ___________원
(G) 총 투자비 = A+B+C+D+E+F : ___________원

[수익률 산정]
- 연간 예상 임대수익(NOI)     : ___________원
- 임대수익률                  : ___% (NOI ÷ 총 투자비)
- 매각 시 기대 수익률 (연환산): ___%

[목표 기준 판단]
- 임대수익률: 연 5% 이상 → 적정 / 3~5% → 보통 / 3% 미만 → 미달
- 총 수익률: 연 15% 이상 → 우수 / 10~15% → 적정 / 10% 미만 → 미달
```
