### 섹션 2 — 입지/상권 심층 분석

각 항목을 체크리스트로 점검한다.

#### 2-1. 교통 접근성 체크리스트

| # | 점검 항목 | 내용 | 평가 |
|---|-----------|------|------|
| 1 | 최인접 지하철역 | (역명, 노선, 도보 거리/분) | |
| 2 | 역세권 등급 | 초역세권(3분) / 역세권(5분) / 준역세권(10분) / 비역세권 | |
| 3 | 버스 접근성 | 주요 노선 수, 정류장 도보 거리 | |
| 4 | 차량 접근성 | 건물 접면 도로 폭, 주요 도로 거리 | |
| 5 | 주차 여건 | 건물 자체 주차 대수, 호실당 배정, 인근 공영주차장 | |

**교통 접근성 등급**: A(우수) / B(양호) / C(보통) / D(미흡) / F(불량)

#### 2-2. 상권 분석 체크리스트

| # | 점검 항목 | 내용 |
|---|-----------|------|
| 1 | 상권 유형 | (오피스 상권 / 주거 배후 / 유흥 / 대학가 / 복합) |
| 2 | 주요 배후 수요 | (직장인, 거주민, 학생, 유동인구 등) |
| 3 | 유동인구 수준 | (많음 / 보통 / 적음 — 평일·주말 구분) |
| 4 | 인근 주요 시설 | (대형 오피스, 아파트 단지, 대학교, 병원, 관공서 등) |
| 5 | 상권 성숙도 | 성장기 / 안정기 / 쇠퇴기 |
| 6 | 경쟁 환경 | 유사 상가·오피스 공급 현황, 공실률 체감 |
| 7 | 해당 층의 상권 특성 | (1층 vs 지하/상층: 업종 제한, 가시성, 접근성 차이) |

> **구분소유 핵심**: 같은 건물이라도 **층별 상권 가치 차이**가 매우 크다. 1층 대비 지하층은 30~50%, 2층은 50~70%, 3층 이상은 40~60% 수준이 일반적이다. 해당 호실의 층수에 따른 실질적 상권 가치를 반드시 평가한다.

#### 2-3. 개발 호재 및 규제 체크리스트

| # | 점검 항목 | 내용 |
|---|-----------|------|
| 1 | 도시계획 변경 | (재개발/재건축, 도시재생, 역세권 개발 등) |
| 2 | 신규 교통 인프라 | (신설 노선, 역 개통 예정) |
| 3 | 인근 대규모 개발 | (신규 아파트, 오피스, 상업시설 예정) |
| 4 | 규제 요인 | (고도제한, 일조권, 정비구역, 용도 제한 등) |

#### 3-2. 수익률 산정

```
[수익률 분석]
- 연 임대수익(월세×12)     : ___________원
- 낙찰 예상가              : ___________원
- 취득세(약 4.6%)          : ___________원
- 중개·법무·기타 비용       : ___________원
- 총 투자비 추정           : ___________원
- 표면 수익률(Cap Rate)     : ___%
- 순 수익률(NOI 기준)       : ___% (관리비·재산세·수선충당금 차감)

[지역 시세 비교]
- 해당 지역 유사 호실 평균 수익률 : ___%
- 해당 지역 유사 호실 평균 임대료 : ___원/㎡
- 판단: 시장 대비 상회 / 적정 / 하회
```
> ⚠ 계정판 SKILL.md 와 다름 — 본문(SKILL.md) 규칙이 우선: 「낙찰 예상가」를 직접 추정하지 않고 `auction-bid-price` 스킬 산출값(저감률 20%/30% 판정 포함)을 넣는다.

#### 3-3. 공실 리스크 체크리스트

| # | 점검 항목 | 내용 | 상태 |
|---|-----------|------|------|
| 1 | 현재 공실 여부 | | ✅/🚨 |
| 2 | 건물 전체 공실률 | ___% | |
| 3 | 해당 층 공실률 | ___% | |
| 4 | 지역 평균 공실률 | ___% | |
| 5 | 공실 시 수익률 변동 | 수익률 ___% → 0% | |
| 6 | 예상 공실 기간 | (업종·지역 기반 추정) | |
| 7 | 임차인 교체 난이도 | 상 / 중 / 하 | |

> **구분소유 핵심**: 건물 전체와 달리 호실 1개이므로, **공실 = 수익 0%**이다. 공실 리스크 평가가 특히 중요하다.
