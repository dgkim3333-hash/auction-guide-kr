- ✅ 정상/해당없음

- 🚨 위험 (투자 결정에 중대 영향)
- ❓ 정보부족

| 2 | 근저당/저당권 설정 현황 | | (설정액, 채권자, 순위) |
| 3 | 가압류/가처분 여부 | | |

| 13 | 권리금 회수 방해 금지 규정 적용 여부 | | |
| 14 | 배당요구 취하 여부 | | |

> **구분소유 핵심**: 상가임대차보호법 적용 여부(환산보증금 기준)와 권리금 회수 방해 금지 규정이 호실 경매에서 특히 중요하다. 환산보증금 = 보증금 + (월세 × 100)으로 계산하여 해당 지역 기준 초과 여부를 반드시 확인한다.

#### 권리관계 종합 판단

```
[인수되는 권리 목록]
- (낙찰 후에도 소멸되지 않고 인수해야 하는 권리)

[예상 인수 부담금]: ___________원

[상가임대차보호법 적용 판단]
- 환산보증금: ___________원 (보증금 + 월세×100)
- 해당 지역 기준액: ___________원
- 적용 여부: 적용 / 미적용
- 소액임차인 해당 여부: 해당 / 미해당

[권리관계 위험 등급]: 안전 / 주의 / 위험 / 매우 위험
```

## 부록 A — 말소기준권리 분석 가이드

권리분석의 핵심은 **말소기준권리**를 정확히 찾는 것이다. 말소기준권리란 낙찰자가 잔금을 납부하면 어떤 권리가 소멸되고 어떤 권리가 인수되는지의 기준이 되는 권리이다.

### 말소기준권리가 될 수 있는 권리

- (근)저당권
- 압류 및 가압류
- 담보가등기
- 경매개시결정등기
- 배당요구를 한 선순위 전세권

### 소멸되는 권리 vs 인수되는 권리

| 구분 | 소멸되는 권리 | 인수되는 권리 |
|------|---------------|---------------|
| **등기부 권리** | 말소기준권리 후순위 저당권, 근저당권, 압류, 가압류, 담보가등기 | 말소기준권리 선순위 지상권, 지역권, 전세권(미배당), 가등기, 가처분 |
| **미등기 권리** | 대항력 없는 임차권, 보증금 전액 배당받은 임차권 | 대항력 있는 임차권(미배당), 유치권, 법정지상권, 분묘기지권 |

> **분석 시 적용**: 섹션 4 권리관계 분석에서 등기부 갑구·을구를 검토할 때, 반드시 말소기준권리를 먼저 특정한 후 각 권리의 소멸/인수 여부를 판단한다.

## 부록 B — 임차인 대항력 판단 세부 기준

임차인의 대항력 유무는 구분상가 경매에서 가장 중요한 분석 항목 중 하나이다.

### 대항력 발생 요건

- **주택**: 인도(실제 점유) + 주민등록 전입신고 → 대항력 발생 (다음날 0시부터)
- **상가**: 사업자등록 + 점유 → 대항력 발생

### 대항력 판단 기준

| 조건 | 결과 |
|------|------|
| 전입일(또는 사업자등록일)이 말소기준권리 설정일보다 **빠름** | ✅ 대항력 있음 (선순위 임차인) |
| 전입일이 말소기준권리와 **같은 날** 또는 **이후** | ❌ 대항력 없음 |
| 대항력 + 확정일자(말소기준권리보다 빠른 경우) | ✅ 우선변제권 취득 |

### ⚠️ 실무 주의사항

- 전입일과 확정일자 사이에 근저당권이 설정된 경우, **대항력은 있으나 우선변제권은 후순위**가 될 수 있다. 이 경우 배당을 받지 못하면서 대항력만 존재하는 상황이 발생하여, 낙찰자가 보증금을 인수해야 할 수 있다.
- 선순위 대항력 임차인이 있으면 **경락잔금대출 거절** 가능성이 높다.
- 보증금 이상 임차인 조사 시, 부동산 중개사의 정보를 맹신하지 말고 **임대차계약서 원본**을 반드시 직접 확인한다.

> **분석 시 적용**: 섹션 4 항목 #4(임차인 현황 및 대항력)과 #5(선순위 임차인 보증금 인수 여부) 분석 시 이 기준을 적용한다.

## 부록 C — 유치권 검증 실무 포인트

유치권은 등기부등본에 나타나지 않아 **현장조사가 필수**이며, 등기순위에 관계없이 매수인에게 인수된다(민사집행법 제91조 제5항).

### 유치권 물건의 특징

- 유찰이 2~4회 반복되며 최저매각가 20~60% 하락
- 허위 유치권 주장이 매우 빈번 (현수막 게시, 용역 배치 등)

### 유치권 검증 4대 포인트

| # | 검증 항목 | 확인 방법 |
|---|-----------|-----------|
| 1 | **점유의 연속성** | 실제 계속 점유하고 있는지 현장 확인 |
| 2 | **채권의 소멸시효** | 공사대금 채권 소멸시효 3년. 시효 중단 조치 없이 3년 경과 시 채권 소멸 → 유치권도 소멸 (부종성의 원리) |
| 3 | **객관적 증거** | 공사계약서, 세금계산서, 대금 지급 내역 확인 |
| 4 | **형사 대응 가능성** | 허위 유치권자에 대해 경매방해죄 고소 가능 |

> **분석 시 적용**: 섹션 4 항목 #6(유치권 신고 여부) 분석 시, 매각물건명세서의 유치권 신고 내역뿐 아니라 위 4가지 검증 포인트를 반드시 점검한다.

## 부록 D — 법정지상권 판단 기준

법정지상권은 토지와 건물이 각각 다른 소유자에게 속한 경우 건물소유자가 토지를 사용할 수 있는 권리이다. 설정 시기에 관계없이 **무조건 매수인에게 인수**된다.

### 판단 기준시점

| 경매 유형 | 기준시점 |
|-----------|----------|
| 임의경매 | **저당권 설정 당시** 토지와 건물이 동일인 소유인지 판단 |
| 강제경매 | **압류 효력 발생 시점** 기준 판단 |
| 가압류 → 본압류 이행 시 | **가압류 효력 발생 시점** 기준 |

> **구분상가 적용**: 구분상가의 경우 토지와 건물의 소유자가 분리되는 경우는 드물지만, 특히 **토지 지분 경매** 또는 **지분 경매 물건**에서 법정지상권 이슈가 발생할 수 있으므로, 섹션 4 항목 #7 분석 시 반드시 확인한다.

## 부록 F — 배당 우선순위 참조표

배당순서는 NPL 수익률을 결정하는 핵심 요소이며, 구분상가 투자 시에도 배당 시뮬레이션에 활용한다.

### 배당 우선순위 (순서대로)

```
1순위: 경매비용 (집행비용)
2순위: 최우선변제권 — 소액임차보증금, 최종 3개월분 임금, 최종 3년간 퇴직금
3순위: 당해세 (국세·지방세)
4순위: 담보물권 — 근저당권, 전세권, 우선변제권 있는 임차권 (등기순서에 따라)
5순위: 일반채권
```

### ⚠️ 배당 관련 실무 주의사항

- 배당요구서 기재의 정확성이 매우 중요하다
- 임금채권과 퇴직금채권은 각 인정근거와 산정방식이 다르므로 구분하여 명시해야 한다
- 소액임차인의 최우선변제금은 다른 담보물권자보다 먼저 배당되므로, 예상 배당금 산정 시 반드시 공제한다

> **분석 시 적용**: 섹션 3 수익률 산정과 섹션 4 권리관계 분석에서 예상 배당표를 작성할 때 이 우선순위를 적용한다.
