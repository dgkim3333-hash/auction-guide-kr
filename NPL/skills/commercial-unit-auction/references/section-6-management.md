### 섹션 6 — 관리 현황 분석 (구분소유 특화)

이 섹션은 건물 전체 경매(꼬마빌딩)에는 없는, 구분소유 호실 경매만의 핵심 체크 영역이다.

| # | 점검 항목 | 상태 | 세부 내용 |
|---|-----------|------|-----------|
| 1 | 관리단(입주자대표회의) 구성 여부 | | (정상 운영 / 미구성 / 분쟁 중) |
| 2 | 관리비 수준 | | (월 ___원/㎡, 총 ___원) |
| 3 | 관리비 대비 시장 수준 | | (적정 / 과다 / 과소) |
| 4 | 관리비 체납 여부 (해당 호실) | | (체납액 ___원 — 낙찰자 승계 여부 확인) |
| 5 | 관리규약 특이사항 | | (업종 제한, 영업시간 제한 등) |
| 6 | 건물 전체 공실률 | | (관리비 분담금 증가 리스크) |
| 7 | 장기수선충당금 적립 현황 | | (적정 / 부족 / 미적립) |
| 8 | 관리업체 및 관리 품질 | | (전문위탁 / 자체관리 / 무관리) |
| 9 | 주요 시설 교체 이력/예정 | | (승강기, 방수, 설비 등) |
| 10 | 관리단 분쟁/소송 여부 | | |

> **핵심 주의사항**:
> - 관리비 체납금은 낙찰자에게 승계될 수 있다. 특히 공용부분 관리비 체납은 특별승계인(낙찰자)에게 청구 가능하므로 반드시 확인한다.
> - 건물 전체 공실률이 높으면, 남은 호실 소유자의 관리비 분담이 증가하여 보유 비용이 올라간다.
> - 관리규약에 업종 제한이 있으면 임대 시 업종 선택이 제한되어 공실 리스크가 커질 수 있다.
