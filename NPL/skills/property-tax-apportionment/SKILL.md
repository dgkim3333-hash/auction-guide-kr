# 공시가격 확보와 세목별 안분 — 확정 규칙

주택과 근린생활시설이 한 동에 섞인 물건(근린주택·주상복합)의 세금을 계산하기 전에 **반드시** 이 절차를 먼저 밟는다.

> **이 스킬이 정본이다.** `auction-property-card` 8-E 2번(「개별주택가격은 전국 통합 자료가 없다 → 감정평가액 × 60% 가정」)과 8-G(「연면적으로 안분한다」)는 **2026-08-27 폐기됐다.** 두 규칙이 충돌하면 언제나 이 스킬을 따른다.
>
> **2026-09-27 개정 — 개별주택가격 조회 순서가 바뀌었다.** ① `vworld-landuse` MCP `get_house_price` (API 자동 조회) → ② ①이 실패했거나 `stale_warning` 이 붙었을 때만 부동산공시가격 알리미 수동 조회 → ③ 둘 다 실패했을 때만 감정평가액 × 60%. 상세는 1-B.

## 0. 종전 규칙이 왜 틀렸나 — 실측으로 확인된 두 가지 오류

### 오류 ① 「개별주택가격은 조회할 수 없다」

종전 스킬은 이렇게 적고 있었다.

> 개별주택가격은 전국 통합 자료가 없다(지자체별로 흩어져 있다). 조회를 시도하되 못 찾으면 가정을 쓴다.

**통합 다운로드 자료가 없는 것**과 **개별 물건을 조회할 수 없는 것**은 전혀 다른 얘기다. 종전 규칙이 둘을 섞어 놓아, 도구 호출 몇 번이면 끝나는 일을 가정으로 넘겼다.

**실측 (2026타경10860 · 서울 중랑구 면목동 673-42 · 2026-08-27 조회)**

| 구분 | 값 |
|---|---|
| 「감정평가액 × 60%」 가정치 | 910,768,601원 |
| **실제 개별주택가격 (2026.01.01)** | **588,000,000원** |
| 가정치 ÷ 실측치 | **1.55배 과대** |

이 하나 때문에 아래가 전부 틀렸다.

- 개인 종합부동산세: 「비거주 공제 900,000,000원 **초과** → 과세」 → **「미달 → 0원」으로 결론이 뒤집혔다**
- 법인 종합부동산세: 37,172,172원 → **24,171,120원** (13,001,052원 과대)
- 재산세: 시가표준액 900,000,000원 이하라 **1세대1주택 특례세율(지방세법 §111의2) 적용 대상**이었는데 가정치로는 대상에서 빠져 있었다

### 오류 ② 「취득세도 연면적으로 안분한다」

종전 스킬은 이렇게 적고 있었다.

> ★ 취득세도 같은 방식으로 안분한다. 연면적 비율로 건물과 토지를 함께 나눠 …

**연면적 안분은 신축·증축 취득 전용이다.** 지방세법 시행령 §19③이 그렇게 한정하고 있다. 경매 낙찰·매매 같은 **승계취득은 §19② 시가표준액 안분**이다. 조문을 안 보고 「보유세와 같은 방식이겠거니」 하고 쓴 것이 원인이다.

## 1. 공시가격 확보 — 가정하기 전에 반드시 조회한다

### 1-A. 공동주택(아파트·연립·다세대) → duckdb

`경매창고.duckdb` 의 `주택공시가격` 테이블(국토교통부 호별 공시가격)에서 조회한다.

```sql
SELECT 기준연도, 단지명, 동명, 호명, 전용면적, 공시가격
FROM 주택공시가격
WHERE 법정동코드 = ? AND 본번 = ? AND 부번 = ?;
```

좁히는 순서: **지번 → 단지명 → 건축물대장PK**. 건축물대장PK는 `datagokr building_expos` 의 `mgmBldrgstPk` 와 같은 값이다.

`WHERE 기준연도 = (SELECT MAX(기준연도) FROM 주택공시가격)` 으로 최신분을 집는다.

### 1-B. ★★ 단독·다가구·다중·근린주택 → ① vworld `get_house_price` 로 먼저 조회한다 (2026-09-27 신설)

`vworld-landuse` MCP 의 `get_house_price` 가 국토교통부 개별주택가격(브이월드 `getIndvdHousingPriceAttr`)을 API로 가져온다. 브라우저 폼을 채울 필요가 없다.

```
get_house_price(address="서울특별시 ○○구 ○○동 000-0")      # 주소로
get_house_price(pnu="1111014600100110001")                    # 19자리 PNU 로 (지번이 확실할 때 우선)
get_house_price(pnu="…", year="2025")                         # 특정 연도
```

**응답 필드 ↔ 1-C 네 값**

| 응답 필드 | 1-C 의 값 |
|---|---|
| `housePc_total` / `buildings[].housePc` | 개별주택가격 (원) |
| `buildings[].ladRegstrAr` / `calcPlotAr` | 대지면적 전체 / **산정** |
| `buildings[].buldAllTotAr` / `buldCalcTotAr` | 건물연면적 전체 / **산정** |
| `year` · `month` | 가격기준연도·월 |
| `history[]` | 연도별 추이 (1-E 연도별 면적 비교에 쓴다) |

**반드시 확인할 것 네 가지**

1. **`stale_warning` 이 붙으면 그 값을 세금 기준값으로 쓰지 마라.** 마지막 공시연도가 올해분(5월 이후) 또는 작년분(4월 이전)보다 오래됐다는 뜻이다. 멸실·용도변경·다세대 전환·필지 분할을 의심하고 건축물대장과 ② 알리미로 현재 상태를 확인한다.
   - 실측 (2026-09-27): 강북구 수유동 190-1 은 마지막 값이 **2019년분 192,000,000원**이었다. 경고 없이 쓰면 7년 전 값으로 세금을 계산하게 된다.
2. **`resolved_addr` 가 입력 지번과 다르면** 지오코딩이 옆 부번에 떨어진 것이다. 올바른 PNU 로 `pnu=` 를 지정해 다시 조회한다. (실측: 「가회동 11」 입력 → 11-1 로 잡힘)
3. **`multi_building_warning` 이 true 면** 한 필지에 동이 여럿이다. 동별 `buildings[]` 를 모두 적고 합계와 함께 병기한다.
4. **`count: 0`** 은 「자료 없음」이 아니다. 공동주택(→1-A)·비주거·나대지·다른 대표지번(→1-F) 가능성을 먼저 본다.

**도구가 알아서 처리하는 것**: 같은 연도·같은 동의 정정 이력 중복(2024·2025년에 실측)은 `lastUpdtDt` 최신본 1건만 쓴다. 브이월드가 간헐적으로 내는 `URL_TYPE`(잘못된 URL) 응답은 1초 뒤 1회 자동 재시도한다.

**실측 (2026-09-27)**: 종로구 가회동 11-1 → 2026년분 **579,000,000원** (반영일 2026-05-21), 2005~2026년 22개 연도 이력. `[확정]` 출처 표기: `vworld get_house_price (국토교통부 개별주택가격, YYYY-MM-DD 조회)`.

### 1-C. 결과 표의 네 값을 전부 옮겨 적는다

개별주택가격만 보고 나머지를 버리면 안분 근거를 통째로 놓친다.

| 열 | 무엇인가 | 어디에 쓰나 |
|---|---|---|
| **개별주택가격** | 주택 건물 + 주택 부속토지 **일체**의 시가표준액 | 재산세 주택분 과세표준 · 종부세 과세표준 |
| **대지면적 (전체 / 산정)** | 산정 = 지자체가 정한 **주택 부속토지 면적** | 취득세 §19② 안분 · 근생 부속토지 역산 |
| **건물연면적 (전체 / 산정)** | 산정 = 지자체가 본 **주택분 건물면적** | 안분 검산 |
| **가격기준연도** | 공시기준일 | 산출물에 반드시 병기. 연도 없는 공시가격은 쓰지 않은 것과 같다 |

**실측 예시**

| 기준일 | 대지 전체/산정 | 건물연면적 전체/산정 | 개별주택가격 |
|---|---|---|---|
| 2026.01.01 | 162.7 / **96.24㎡** | 317.49 / 213.61㎡ | **588,000,000원** |
| 2025.01.01 | 162.7 / 96.24㎡ | 361.11 / 213.61㎡ | 560,000,000원 |

### 1-D. ★ 부속토지 면적을 역산해 검산한다 — 지자체가 어떻게 나눴는지 드러난다

```
주택 부속토지 96.24 ÷ 대지 전체 162.70 = 59.155%
건물 전체 317.49㎡ × 59.155% = 187.81㎡
187.81 = 159.85(3~5층 주택) + 18.44(옥탑 다락) + 9.52(옥탑 계단실)
→ 지자체는 옥탑 다락과 계단실을 「전부 주택분」으로 보았다. 안분하지 않았다
```

**이 검산이 맞아떨어지면 안분 비율을 지자체와 똑같이 맞출 수 있다.** 반드시 한다.

건축물대장 항목으로 딱 떨어지지 않으면 그 사실을 `[추정]` 으로 적고 구청 확인 항목에 올린다.

### 1-E. 연도별 면적이 달라 보이면 건축물대장 변동사항을 먼저 본다

「건물연면적 전체」가 연도마다 다르면 건물이 바뀐 것인지 지자체 기재가 바뀐 것인지 가른다.

```
1) 건축물대장 「변동사항」란 확인 — 신규작성(신축) 1건뿐이면 건물은 그대로다
2) datagokr building_title 의 totArea 확인 — 대장 원본값
3) 「산정 ÷ 전체」 비율이 연도별로 같은지 확인
```

**실측 사례**: 361.11 → 317.49 로 43.62㎡ 줄었으나 건축물대장 변동사항은 「2022.5.11 신규작성(신축)」 한 줄뿐이었다. 그런데 **산정÷전체 비율은 두 해 모두 59.155%로 동일**했고, 2026년 전체(317.49)만 건축물대장과 일치했다. → 「전체」란을 고치면서 「산정」란을 같이 고치지 않은 **지자체 기재 정정** 으로 판정 `[추정]`. 개별주택가격은 오히려 5.0% 올라, 면적 정정이 가격 산정에 반영되지 않았음을 뒷받침했다.

**안분에 쓰는 값(부속토지 면적·비율)이 연도별로 일관되면 결론에 영향이 없다.** 그 사실을 밝히고 넘어간다.

| 세목 | 근거 조문 | 안분 기준 | 실측 사례 |

| **취득세 (승계취득)** | **지방세법 시행령 §19②** | **시가표준액 비율** | 주택 **57.50%** / 근생 42.50% |
| 취득세 (신축·증축) | 같은 조 **§19③** | 연면적 비율 | 경매·매매 취득에는 해당 없음 |
| **재산세 · 종합부동산세** | **지방세법 §106②1호** | **건물 면적비율** | 주택 **59.15%** / 근생 40.85% |

**두 값이 다른 것이 정상이다.** 같게 나오면 한쪽을 잘못 계산한 것이다.

### 2-A. 취득세 — 지방세법 시행령 §19② 시가표준액 안분

경매·공매·매매는 취득가액 총액 하나뿐이라 「각 과세물건의 취득 당시의 가액이 구분되지 않는 경우」에 해당한다. §19① 이 일반 규정이고, **주택·건축물과 그 부속토지를 한꺼번에 취득하면 §19② 가 우선한다**(「제1항에도 불구하고」).

```
                  (건축물 중 주택 부분의 시가표준액[법 §4②])
주택 부분      전체    + (부속토지 중 주택 부분의 시가표준액[법 §4①])
취득당시   =  취득   ×  ──────────────────────────────────
가액          가액        건축물과 부속토지 전체의 시가표준액

주택 외 부분 = 전체 취득가액 × (주택 외 건축물 + 주택 외 부속토지) ÷ 전체
```

**분자에 개별주택가격을 넣지 마라.** 조문이 「건축물 중 주택 부분은 **법 §4②**」라고 못박았다. §4② 는 건물신축가격기준액 방식이고, 개별주택가격(§4①)은 재산세·종부세용이다.

**§19④ 는 §19① 에만 걸린다.** 시가표준액이 없는 과세물건이 섞여 시장·군수·구청장이 비율을 정하는 규정인데, §19② 에는 준용되지 않는다.

### 2-B. 건축물 시가표준액 (지방세법 시행령 §4①1의2호)

```
㎡당 금액   = 건물신축가격기준액 × 구조지수 × 용도지수 × 위치지수 × 경과연수별 잔가율
시가표준액  = ㎡당 금액 × 면적 × (1 + 가감산율)
```

★ **안분 비율만 필요하면 기준액·위치지수·잔가율을 몰라도 된다.**

같은 건물의 주택분과 근생분은 **구조지수·위치지수·잔가율이 같다.** 그리고 2026년 건물신축가격기준액은 주거용·상업용이 **둘 다 860,000원/㎡** 라 분자·분모에서 상쇄된다. **남는 변수는 용도지수와 가감산율뿐이다.**

| 항목 | 값 |
|---|---|
| 구조지수 — 철근콘크리트조·라멘조·석조·프리캐스트콘크리트조 | 100 |
| 구조지수 — 철골(철골철근)콘크리트조 | 120 |
| 구조지수 — 스틸하우스조·철골조·연와조 | 100 |
| **용도지수 — 단독주택(단독·다중·다가구)** | **91** |
| 용도지수 — 아파트 / 연립·다세대 / 도시형생활주택 | 100 / 91 / 91 |
| **용도지수 — 상점·일반음식점·휴게음식점·제과점·서점·사진관 등 판매영업시설** | **112** |
| **용도지수 — 사무실용 건물(사무소·금융업소·부동산중개사무소·출판사 등)** | **112** |
| 용도지수 — 주거용 오피스텔 / 사무용 오피스텔 | 123 / 108 |
| 용도지수 — 의원·치과의원·한의원 / 종합병원 | 112 / 124 |
| 용도지수 — 노래연습장·안마시술소 / 단란주점 / 유흥주점 | 112 / 121 / 124 |
| 용도지수 — 공장 / 창고 / 주차장 | 80 / 80 / 71 |
| 용도지수 — 학원(무도학원 제외)·운전학원 | 113 |
| **가산율 — 5~10층 건물의 1층 상가부분** | **+17%** |
| 가산율 — 11~20층 / 21~30층 / 30층 초과 건물의 1층 상가부분 | +27% / +32% / +36% |
| 가산율 — 11~20층 / 21~30층 / 30층 초과 건물의 2층 상가부분 | +4% / +5% / +6% (5~10층은 0%) |
| 감산율 — 5~10층 건물의 5층 이상 상가부분 | −12% |
| 감산율 — 지하1층 상가부분 (10층 이하 / 10층 초과) | −25% / −20% |
| 감산율 — 지하2층 이상 상가부분 | −40% |
| 감산율 — 단독주택 1구 60~85㎡ / 60㎡ 이하 | −3% / −5% (**다가구주택은 적용 제외**) |
| 감산율 — 주택의 차고 | −45% (복합건축물의 차고는 제외) |

출처: 행정안전부 「지방세 시가표준액 조사·산정 기준」 별표 · 「건물신축가격기준액 고시」.

> **층수 계산에서 지하층과 옥탑은 뺀다.** 지상 5층이면 「5층 이상 10층 이하」다.
> 가감산율은 **해당 층 부분에만** 곱한다. 건물 전체에 곱하지 마라.

### 2-C. ★ K 민감도를 반드시 확인하고 밝힌다

`K = 위치지수 × 경과연수별 잔가율` (주택·근생 공통이라 상쇄되지만 완전히 사라지지는 않는다)

```
K 를 0.70 ~ 1.30 으로 흔들어 주택 비율의 폭을 잰다
  폭 ≤ 1%p  → 「K 미확정이나 결론이 바뀌지 않는다」고 쓰고 K = 1.00 을 채택한다
  폭 >  1%p → 건축물 시가표준액을 실제로 조회해야 닫힌다
```

**실측 사례**: K = 0.70~1.30 에서 주택 비율 57.16~57.90%, **폭 0.74%p** → K=1.00 채택.

### 2-D. 건축물 시가표준액을 실제로 조회해야 할 때

| 지역 | 경로 |
|---|---|
| 서울 외 전국 | 위택스 `https://www.wetax.go.kr/tcp/loi/J030401M01.do` |
| **서울** | **위택스에서 조회되지 않는다** → 서울이택스 `https://etax.seoul.go.kr` |

위택스 화면의 경고를 그대로 옮겨 적는다.

> 해당 조회 결과는 당해연도 **재산세** 산출지수를 활용한 금액이므로 **취득세 과세표준으로 활용하기에 적합하지 않을 수 있습니다.**

즉 위택스 값을 §19② 분자에 그대로 넣으면 안 된다. 구청 세무과 확인이 최종이다.

### 2-E. 재산세·종합부동산세 — 지방세법 §106②1호 건물 면적비율 안분

> 1동(棟)의 건물이 주거와 주거 외의 용도로 사용되고 있는 경우에는 주거용으로 사용되는 부분만을 주택으로 본다. 이 경우 **건물의 부속토지는 주거와 주거 외의 용도로 사용되는 건물의 면적비율에 따라 각각 안분**하여 주택의 부속토지와 건축물의 부속토지로 구분한다.

**그런데 실무에서 직접 안분할 일은 거의 없다.** 지자체가 이미 나눠 놓았기 때문이다.

```
개별주택가격                      → 재산세 주택분 · 종부세 과세표준
대지면적(산정)                    → 주택 부속토지 면적. 나머지가 근생 부속토지
건축물 시가표준액                  → 재산세 건축물분 (근생 건물)
개별공시지가 × 근생 부속토지 면적   → 재산세 토지분 (별도합산)
```

**1-C 의 조회 결과를 그대로 쓴다.** 직접 안분하는 것은 지자체 값을 못 구했을 때뿐이다.

관련 판정 규칙:
- **1구(構)의 건물**이 주거·비주거 겸용이면 **주거용 면적이 50% 이상일 때 전체를 주택으로 본다** (§106②2)
- 무허가 주거용 면적이 전체의 50% 이상이면 **건축물 전체를 주택으로 보지 않고**, 그 부속토지는 종합합산과세대상이 된다 (§106②2의2)
- 공부상 등재현황과 사실상 현황이 다르면 **사실상 현황**에 따른다. 다만 그렇게 해서 세부담이 낮아지는 경우 등은 공부상 현황에 따른다 (§106③)

### 2-F. 옥탑 다락·계단실은 어디에 넣나

- **연면적에서 제외되는 부분도 취득세 과세대상 건축물이다.** 지방세법 §6 4호의 「건축물」은 건축법 §2①2호 건축물이고, 바닥면적 산입 여부와 무관하다. 빠뜨리면 과세표준이 줄어든다
- 옥탑 다락이 **특정 호실 전용**으로 건축물대장·감정평가서에 적혀 있으면 **그 호실의 용도를 따라간다**
- 계단실은 공용이라 면적비 안분이 원칙으로 보이지만, **지자체가 전부 주택분으로 본 실측 사례가 있다.** 1-D 의 부속토지 역산으로 **지자체가 실제로 어떻게 나눴는지 먼저 확인**하고 그 값에 맞춘다. 우리가 임의로 안분하면 지자체 고지서와 어긋난다

### 2-G. 세율 적용 — 안분된 금액 전체에 곱한다

안분된 **주택분 전체**(건물 + 부속토지)에 주택 세율을, **근생분 전체**(건물 + 부속토지)에 4%를 적용한다.

**토지를 따로 떼어 전부 4%를 적용하면 크게 과소 계상된다.** 지방세법 §11①8 의 「주택」은 주거용 건축물**과 그 부속토지**를 함께 가리킨다.

**근생 건물 자체는 종합부동산세 과세대상이 아니다.** 그 부속토지만 별도합산(8,000,000,000원 공제) 대상이다.

## 5. 자체 점검 (답변 내보내기 전)

1. **개별주택가격을 실제로 조회했는가?** 「전국 통합 자료가 없다」는 이유로 가정하지 않았는가. vworld 응답에 **`stale_warning` 이 붙은 값을 그대로 쓰지 않았는가**
2. 조회 결과의 **대지면적(산정)** 을 옮겨 적었는가. 개별주택가격만 보고 버리지 않았는가
3. **부속토지 역산 검산**을 했는가. 지자체 구분과 우리 구분이 같은가
4. 취득세를 **연면적으로 안분하지 않았는가** — 신축·증축이 아니면 §19②다
5. 취득세와 보유세의 안분 비율이 **서로 다른가.** 같다면 한쪽이 틀렸다
6. §19② 분자에 **개별주택가격을 넣지 않았는가** — 「건축물 중 주택 부분」은 §4②다
7. **K 민감도**를 재고 폭을 밝혔는가
8. 가감산율을 **해당 층에만** 곱했는가. 건물 전체에 곱하지 않았는가
9. 옥탑 다락·계단실을 취득세 과세대상에서 **빼지 않았는가**
10. 공시 **기준연도**를 병기했는가
11. 낙찰가 시나리오가 여러 개일 때 **보유세 행이 전부 같은 값인가**

## 6. 하지 않는 것

- **단독·다가구인데 공시가격을 가정하기** — vworld `get_house_price` 로 조회되고, 안 되면 realtyprice.kr 에서 개별 조회된다
- **`stale_warning` 이 붙은 개별주택가격을 세금 기준값으로 쓰기** — 몇 년 전 값일 수 있다. 알리미·건축물대장으로 현재 상태를 확인한다
- **아파트인데 공시가격을 가정하기** — duckdb 에 실제 값이 있다
- **`datagokr building_housing_price` 를 다시 시도하기** — 2024년 값만 나오고 단독·다가구는 0건이다
- **취득세를 연면적으로 안분하기** — 연면적 안분은 신축·증축 전용이다
- **취득세와 재산세의 안분 비율을 같게 만들기** — 근거 조문이 §19② 와 §106②1 로 다르다
- **§19② 분자에 개별주택가격을 넣기** — 「건축물 중 주택 부분」은 §4② 건물 시가표준액이다
- **옥탑 다락·계단실을 취득세 과세대상에서 빼기** — 연면적 제외와 과세대상 제외는 다르다
- **가감산율을 건물 전체에 곱하기** — 해당 층 부분에만 곱한다
- **위택스 건축물 시가표준액을 취득세 과세표준에 그대로 쓰기** — 화면에 부적합 경고가 있다
- **공시가격의 분모를 낙찰가로 잡기** — 언제나 감정평가액이다
- **공시 기준연도를 빼고 공시가격만 쓰기**
- **K 민감도를 안 재고 단일 비율만 제시하기**

## 7. 근거 조문 (인용 시 이 표를 쓴다)

| 항목 | 조문 | 내용 |
|---|---|---|
| 부동산 등의 시가표준액 | 지방세법 §4①·② | 토지·주택은 공시가격(§4①) / 그 밖의 건축물은 지자체장 결정가액(§4②) |

| 시가표준액 없는 물건 | 지방세법 시행령 §19④ | §19① 에만 적용. 시장·군수·구청장이 비율 결정 |

| 사실상 현황 과세 | 지방세법 §106③ | 공부와 다르면 사실상 현황. 세부담이 낮아지면 공부상 현황 |
| 주택 유상취득 세율 | 지방세법 §11①8 | 「주택」은 주거용 건축물 **과 그 부속토지** |
