# Excel 산출물 구조 명세

## 1. 파일명 규칙

```
post-auction-loan-simulation_<물건명_단축>_<YYYYMMDD>.xlsx
```

예시:
- `post-auction-loan-simulation_강남구역삼동아파트_20260506.xlsx`
- `post-auction-loan-simulation_2024타경12345_20260506.xlsx`

## 2. 시트 구조 (5개 시트)

```
Workbook
├── Sheet 1 — "1.입력가정값"
├── Sheet 2 — "2.3시나리오비교"
├── Sheet 3 — "3.월별현금흐름"
├── Sheet 4 — "4.임계LTV분석"
└── Sheet 5 — "5.민감도분석"
```

## 3. Sheet 1 — 입력 가정값

### 3-1. 레이아웃

```
A         | B            | C       | D
─────────────────────────────────────────
[기본 정보]
물건명     | (입력)        |         |
물건유형   | (선택)        |         |
주소       | (입력)        |         |
사건번호   | (입력)        |         |
─────────────────────────────────────────
[금액 정보]                          단위: 만원
낙찰 예상가| (입력)        |         |
감정가     | (입력)        |         |
월 임대료  | (입력)        |         |
─────────────────────────────────────────
[차주 정보]
명의 유형  | (드롭다운)    |         |
시장 기준금리(%) | (입력)  |         |
─────────────────────────────────────────
[대출 조건]
대출 기간(년)   | (입력)   |         |
보유 기간(년)   | (입력)   |         |

─────────────────────────────────────────
[시나리오 가정값]              보수    중립    공격
LTV (%)             |         |       |       |
적용 금리 (%)       |         |       |       |
공실률 (%)          |         |       |       |
운영비율 (%)        |         |       |       |
매각가 배수         |         |       |       |
매각비용 비율 (%)   |         |       |       |
─────────────────────────────────────────
```

### 3-2. 색상 규칙

| 셀 종류 | 글씨 색 | 배경 색 |
|---|---|---|
| 사용자 입력 (하드코딩) | 파랑 (0000FF) | 노랑 (FFFF00) |
| 라벨 | 검정 (000000) | 연회색 (D9D9D9) |
| 헤더 | 흰색 (FFFFFF) | 진청 (1F4E78) |
| 경고/주의 | 흰색 | 빨강 (C00000) |

### 3-3. 데이터 검증 (드롭다운)

- 물건유형: 아파트 / 다가구 / 다세대 / 오피스텔 / 구분상가 / 꼬마빌딩 / 토지
- 명의 유형: 대부업체 / SPC / 개인(다주택) / 개인(1주택) / 법인사업자
- 상환 방식: 원리금균등 / 원금균등 / 만기일시

### 3-4. 디폴트 자동 채우기

명의 유형 선택 시 LTV·금리 가산값을 자동으로 시나리오 셀에 채운다.
(VLOOKUP 또는 IF 중첩 함수로 구현)

```excel
=VLOOKUP($B$명의셀, 매핑표, 2, FALSE)  // 보수 LTV
=VLOOKUP($B$명의셀, 매핑표, 3, FALSE)  // 중립 LTV
...
```

매핑표는 Sheet 1 하단에 숨겨진 영역(또는 별도 행)에 배치.

## 4. Sheet 2 — 3시나리오 비교

### 4-1. 레이아웃

```
A                    | B (보수)  | C (중립)  | D (공격)
─────────────────────────────────────────────────────
[입력 인자]
LTV                  | =인풋!B22 | =인풋!C22 | =인풋!D22
적용 금리            | =인풋!B23 | =인풋!C23 | =인풋!D23
공실률              | =인풋!B24 | =인풋!C24 | =인풋!D24
운영비율            | =인풋!B25 | =인풋!C25 | =인풋!D25
─────────────────────────────────────────────────────
[자금조달]
대출 가능액 (만원)  | =낙찰가×LTV | ... | ...
자기자본 (만원)     | =낙찰가-대출 | ... | ...
─────────────────────────────────────────────────────
[월간 현금흐름]
월 임대료          | =인풋!B14 | ... | ...
월 NOI(공실차감)   | =월임대×(1-공실) | ... | ...
월 실효임대수익    | =NOI×(1-운영비) | ... | ...
월 원리금(PMT)     | =PMT(r/12,n*12,-P) | ... | ...
월 순현금흐름      | =실효임대-PMT | ... | ...
─────────────────────────────────────────────────────
[연간 지표]
연간 NOI           | =월NOI*12 | ... | ...
연간 원리금        | =월PMT*12 | ... | ...
DSCR              | =NOI연/원리금연 | ... | ...
캐시 일드(자기자본) | =순현금연/자기자본 | ... | ...
─────────────────────────────────────────────────────
[매각 시나리오 (보유 기간 종료)]
매각 예상가        | =낙찰가*매각배수 | ... | ...
매각비용          | =매각가*매각비율 | ... | ...
잔존 대출원금     | =대출+CUMPRINC(...) | ... | ...
세전 매각 회수    | =매각가-비용-잔존 | ... | ...
─────────────────────────────────────────────────────
[수익률 종합]
세전 자기자본 IRR | =IRR(현금흐름) | ... | ...
세전 NPV (할인율 5%) | =NPV(...) | ... | ...
─────────────────────────────────────────────────────
[판정]
GO/NO-GO 의견     | =IF(IRR>15%,"GO","검토") | ... | ...
```

### 4-2. 시각화

- DSCR 막대 차트 (3시나리오 비교)
- 자기자본 IRR 막대 차트
- 월 순현금흐름 영역 차트

### 4-3. 조건부 서식

| 지표 | 안전 (녹색) | 주의 (노랑) | 위험 (빨강) |
|---|---|---|---|
| DSCR | ≥ 1.25 | 1.0 ~ 1.25 | < 1.0 |
| 월 순현금흐름 | ≥ 0 | -50만 ~ 0 | < -50만 |
| 자기자본 IRR | ≥ 15% | 8% ~ 15% | < 8% |

## 5. Sheet 3 — 월별 현금흐름

### 5-1. 레이아웃

```
A     | B           | C        | D     | E       | F         | G
월차  | 대출잔액(보수)| 이자(보수)| 원금  | 월NOI  | 월순현흐름 | 누적현흐름
─────────────────────────────────────────────────────────────────
0     | =대출액     | (시점0 자기자본 -)
1     | =B0-D1      | =B0*r/12 | =PMT-C1 | =NOI    | =E1-F1   | =F1
2     | =B1-D2      | ...      | ...   | ...     | ...      | =G1+F2
...   | ...         | ...      | ...   | ...     | ...      | ...
N     | (잔존원금)  | ...      | ...   | (매각)  | (회수)   | (총회수)
```

각 시나리오별로 같은 구조의 컬럼군(B-G, H-M, N-S) 또는 시트 분리.

### 5-2. 매각 시점(보유 종료) 행 처리

```
매각 시점 행:
- 월 NOI 컬럼: 마지막 월 임대료
- 월 순현흐름 컬럼: 일반 + 매각 회수액
- IRR 계산용 별도 컬럼에 매각 회수 분리
```

## 6. Sheet 4 — 임계 LTV 분석

### 6-1. 레이아웃

```
A           | B           | C        | D
LTV         | 대출원금    | 월 PMT   | DSCR
30%         | =낙찰가*30% | =PMT(...)| =NOI/(PMT*12)
35%         | ...         | ...      | ...
40%         | ...         | ...      | ...
45%         | ...         | ...      | ...
50%         | ...         | ...      | ...
55%         | ...         | ...      | ...
60%         | ...         | ...      | ...
65%         | ...         | ...      | ...
70%         | ...         | ...      | ...
75%         | ...         | ...      | ...
80%         | ...         | ...      | ...
─────────────────────────────────────
임계 LTV (DSCR=1.0): [수식 역산값]
임계 LTV (DSCR=1.25): [수식 역산값]
```

### 6-2. 차트

LTV vs DSCR 선 차트.
- X축: LTV (30~80%)
- Y축: DSCR
- 가로선: DSCR=1.0, DSCR=1.25
- 가로선과 곡선 교점에 데이터 라벨

### 6-3. 임계 LTV 역산 공식

```
대출원금_임계 = 연간NOI / (PMT_factor_연간)

PMT_factor 계산용 셀:
  월금리 = 금리/12
  PMT_per_원 = PMT(월금리, 대출기간*12, -1)
  PMT_factor_연간 = PMT_per_원 * 12

임계 대출원금 = 연간NOI / PMT_factor_연간
임계 LTV = 임계 대출원금 / 낙찰가
```

## 7. Sheet 5 — 민감도 분석

### 7-1. 매트릭스 1: 금리 × 매각가 (중립 시나리오 기준)

```
                매각가-10%  매각가 기준  매각가+10%
금리-1%p         IRR_LL      IRR_LM       IRR_LH
금리 기준        IRR_ML      IRR_MM       IRR_MH
금리+1%p         IRR_HL      IRR_HM       IRR_HH
```

### 7-2. 매트릭스 2: 공실률 × 임대료 (중립 시나리오 기준)

```
                공실+10%p   공실 기준    공실-5%p
임대료-10%       IRR_LL     IRR_LM       IRR_LH
임대료 기준      IRR_ML     IRR_MM       IRR_MH
임대료+10%       IRR_HL     IRR_HM       IRR_HH
```

### 7-3. 토네이도 차트 데이터

```
변수          | -10% IRR | 기준 IRR | +10% IRR | 변동폭(절댓값)

금리          | ...      | ...      | ...      | ...
공실률        | ...      | ...      | ...      | ...
임대료        | ...      | ...      | ...      | ...
운영비율      | ...      | ...      | ...      | ...
```

변동폭 큰 순서로 정렬 → 토네이도 차트 (가로 막대 차트)

### 7-4. 조건부 서식

매트릭스 셀에 색상 스케일 적용:
- 녹색: 높은 IRR
- 노랑: 중간 IRR
- 빨강: 낮은 IRR

## 10. 산출물 검증 체크리스트

Excel 파일 생성 후 LibreOffice로 재계산하고 다음 확인:

- [ ] 수식 오류 0개 (#REF!, #DIV/0!, #VALUE!, #NAME?)
- [ ] 모든 시나리오의 자기자본이 양수 (대출액이 낙찰가 초과 불가)
- [ ] DSCR 계산값이 임계 LTV 분석과 일관성 있음
- [ ] IRR 계산 결과가 -100% ~ +100% 범위 내 (이상치 검증)
- [ ] 시트 1 입력값 변경 시 시트 2-5 자동 재계산 확인
- [ ] 차트 데이터 범위 정확
- [ ] 조건부 서식 정상 작동
- [ ] 한글 폰트 정상 표시 (맑은 고딕)

## 11. 사용자 안내 노트

Sheet 1 상단에 다음 안내문 삽입:

```
⚠️ 시뮬레이션 사용 시 주의사항
1. 본 시뮬레이션의 LTV·금리 가정값은 일반적 시장 기준이며,
   실제 한도는 거래 은행 직접 확인 필수
2. 정부 부동산 규제(LTV·DSR)는 자주 변동되므로,
   시뮬레이션 시점의 최신 규제 확인 필수
3. 노란 배경 셀은 사용자 입력 항목으로,
   값을 변경하면 모든 시트가 자동 재계산됩니다
4. DSR 40% 적용 차주는 LTV 한도가 본 시뮬레이션보다
   실제로는 더 낮아질 수 있습니다
```
