# DSCR·IRR·임계 LTV 계산 공식 모음

## 1. 월 원리금균등상환액 (PMT)

### 1-1. 공식
```
PMT = P × [r(1+r)^n] / [(1+r)^n - 1]

P = 대출원금 (만원)
r = 월 이자율 (연이율 / 12)
n = 총 상환 개월수 (대출 기간 × 12)
```

### 1-2. Excel 함수
```
=PMT(연이율/12, 대출기간*12, -대출원금)
```
음수 부호 주의 (현금 유출이므로 음수 입력)

### 1-3. real-estate MCP 호출
```
calculate_loan_payment(
    principal_10k_krw=낙찰가 × LTV,
    annual_rate_pct=시나리오 금리,
    years=대출 기간
)
```

## 2. 월 순영업소득(NOI)과 실효 임대수익

### 2-1. 공식
```
월 NOI = 월 임대료 × (1 - 공실률)
월 실효 임대수익 = 월 NOI × (1 - 운영비율)
                = 월 임대료 × (1 - 공실률) × (1 - 운영비율)
```

### 2-2. 운영비율에 포함되는 항목
- 관리비 (위탁관리 시)
- 재산세·종부세 (보유세 안분)
- 임대 공실 마케팅 비용
- 시설 유지보수 예비비
- 보험료
- 미수 임대료 손실 충당

### 2-3. 운영비율 디폴트 가이드
| 부동산 유형 | 운영비율 (보수) | 운영비율 (중립) | 운영비율 (공격) |
|---|---|---|---|
| 아파트 (단일) | 15% | 10% | 7% |
| 다가구·다세대 | 25% | 20% | 15% |
| 구분상가 | 20% | 15% | 10% |
| 꼬마빌딩 | 30% | 25% | 20% |
| 토지 (임대) | 10% | 7% | 5% |

## 3. DSCR (Debt Service Coverage Ratio, 부채상환능력비율)

### 3-1. 공식
```
DSCR = 연간 NOI / 연간 부채상환액
     = (월 임대료 × (1 - 공실률) × 12) / (월 PMT × 12)

또는 운영비 차감 기준:
실효 DSCR = (월 실효 임대수익 × 12) / (월 PMT × 12)
```

### 3-2. 판정 기준

| DSCR 범위 | 판정 | 의미 |
|---|---|---|
| ≥ 1.50 | 매우 안전 | 임대수익 여유, 우량 |
| 1.25 ~ 1.50 | 안전 | 은행 일반 요구 수준 |
| 1.00 ~ 1.25 | 보통 | 자체 상환 가능, 마진 적음 |
| 0.80 ~ 1.00 | 주의 | 일부 자기자본 보충 필요 |
| < 0.80 | 위험 | 역레버리지, 매월 손실 |

### 3-3. Excel 수식 예
```
=NOI_연간 / (PMT_월 * 12)
=(월임대료*(1-공실률)*12) / (PMT*12)
```

## 4. 임계 LTV (DSCR=1.0) 역산

### 4-1. 역산 논리

DSCR = 1.0 → 연간 NOI = 연간 부채상환액

```
연간 NOI = 대출원금_임계 × PMT_factor_연간

대출원금_임계 = 연간 NOI / PMT_factor_연간

임계 LTV = 대출원금_임계 / 낙찰가
```

### 4-2. PMT_factor_연간 계산

```
PMT_factor_월 = r(1+r)^n / [(1+r)^n - 1]
            (대출원금 1원당 월 상환액 비율)

PMT_factor_연간 = PMT_factor_월 × 12
```

### 4-3. 역산 예시

가정:
- 낙찰가: 10억 (100,000 만원)
- 월 임대료: 400만원
- 공실률 5%, 운영비율 15%
- 금리 5%, 대출기간 20년

계산:
```
월 NOI(실효) = 400 × (1-0.05) × (1-0.15) = 323 만원
연간 NOI = 323 × 12 = 3,876 만원

월 금리 r = 5% / 12 = 0.004167
n = 240개월

PMT_factor_월 = 0.004167 × (1.004167)^240 / [(1.004167)^240 - 1]
            = 0.006600 (대출 1원당 월 상환액)
PMT_factor_연간 = 0.006600 × 12 = 0.07920

대출원금_임계 = 3,876 / 0.07920 = 48,939 만원

임계 LTV = 48,939 / 100,000 = 48.9%
```

→ "본 물건은 LTV 48.9%까지는 임대수익으로 부채상환 가능"

### 4-4. Excel 수식
```
대출원금_임계 = (월임대료 × (1-공실률) × (1-운영비율) × 12) / 
              (PMT($금리/12, $대출기간*12, -1) * 12 * -1)
임계LTV = 대출원금_임계 / 낙찰가
```

(PMT의 결과가 음수이므로 -1 곱하기)

## 5. 자기자본 IRR (Internal Rate of Return)

### 5-1. 현금흐름 구조

```
시점 0:
  현금 유출 = 자기자본(낙찰가 - 대출액) + 취득세·기타비용

시점 1 ~ N (보유 기간 동안 매월):
  현금 유입 = 월 NOI(실효) - 월 PMT
            = 월 순현금흐름

시점 N (매각):
  현금 유입 = 매각가 - 매각비용 - 양도세 - 잔존 대출원금

IRR = 위 현금흐름의 내부수익률
```

### 5-2. Excel 함수
```
연간 IRR:
=IRR(현금흐름_연간_범위)

월간 IRR을 연환산:
=(1 + IRR(현금흐름_월간_범위))^12 - 1
```

### 5-3. 잔존 대출원금 계산 (매각 시점)

원리금균등상환의 경우, 보유 기간 종료 시점의 잔존 대출원금:

```
잔존원금 = 대출원금 × [(1+r)^n - (1+r)^k] / [(1+r)^n - 1]

n = 총 상환 개월수
k = 보유 기간 (월)
r = 월 이자율
```

Excel:
```
=CUMPRINC(연이율/12, 대출기간*12, 대출원금, 1, 보유기간*12, 0) + 대출원금
```
(CUMPRINC는 누적 원금상환액의 음수, 잔존원금 = 원금 + CUMPRINC)

### 5-4. 매각 차익 계산

```
세전 매각차익 = 매각가 - (매각가 × 매각비용비율) - 잔존원금 - (낙찰가 + 취득세 - 잔존원금)
            = 매각가 × (1 - 매각비용비율) - 매각가 - 취득세

(취득세 등 매입비용은 시점 0의 자기자본에 이미 반영)

매각 시점 자기자본 회수 = 매각가 × (1 - 매각비용비율) - 잔존원금 - 양도세
```

## 6. 민감도 분석 매트릭스 공식

### 6-1. 변수별 변동 범위

| 변수 | -10% | 기준 | +10% |
|---|---|---|---|
| 금리 | 기준 - 1.0%p | 기준 | 기준 + 1.0%p |
| 공실률 | 기준 - 5%p (최소 0%) | 기준 | 기준 + 10%p |
| 매각가 | 기준 × 0.9 | 기준 | 기준 × 1.1 |

(공실률은 -10%p 적용 시 음수가 될 수 있으므로 -5%p 또는 0% 하한)

### 6-2. 2변수 매트릭스 (3×3)

각 셀은 IRR 값. 색상 스케일 조건부 서식 적용.

```
            매각가-10%  매각가 기준  매각가+10%
금리-1%p     IRR_LL      IRR_LM       IRR_LH
금리 기준    IRR_ML      IRR_MM       IRR_MH
금리+1%p     IRR_HL      IRR_HM       IRR_HH
```

### 6-3. 토네이도 차트 데이터 구조

각 변수별 ±10% 변동 시 IRR 변동폭을 절댓값 기준 정렬:

```
변수            | -10% IRR | 기준 IRR | +10% IRR | 변동폭
매각가          | IRR_S-   | IRR_S0   | IRR_S+   | |IRR_S+ - IRR_S-|
금리            | IRR_R-   | IRR_R0   | IRR_R+   | |IRR_R+ - IRR_R-|
공실률          | IRR_V-   | IRR_V0   | IRR_V+   | |IRR_V+ - IRR_V-|
임대료          | IRR_L-   | IRR_L0   | IRR_L+   | |IRR_L+ - IRR_L-|
```

변동폭 큰 순서대로 정렬하여 토네이도 차트 작성.

## 7. 세후 IRR 계산 (real-estate-tax-calculator 연동)

### 7-1. 추가 차감 항목

```
세후 매각 회수 = 세전 매각 회수 - 양도세 - 지방소득세 - 농어촌특별세
세후 보유 현금흐름 = 세전 보유 현금흐름 - 종합소득세(임대소득 분)

(법인은 법인세 적용)
```

### 7-2. 세율 호출 절차

real-estate-tax-calculator 스킬에 다음 정보 전달:

```
- 차주 유형: 개인/법인
- 낙찰가, 매각가
- 보유 기간 (1년 미만/1~2년/2년 이상 등)
- 조정대상지역 여부
- 다주택자 여부 (개인의 경우)
- 임대수익 (보유 기간 동안)
```

호출 결과를 IRR 계산 현금흐름에 반영.

## 8. 주요 함수 Cheat Sheet

| 계산 | Excel 함수 | 비고 |
|---|---|---|
| 월 PMT | `=PMT(r/12, n*12, -P)` | 결과 음수 |
| 월 이자분 | `=IPMT(r/12, k, n*12, -P)` | k 시점 이자 |
| 월 원금분 | `=PPMT(r/12, k, n*12, -P)` | k 시점 원금 |
| 누적 이자 | `=CUMIPMT(r/12, n*12, P, 1, k, 0)` | 1~k 누적 |
| 누적 원금 | `=CUMPRINC(r/12, n*12, P, 1, k, 0)` | 1~k 누적 |
| IRR | `=IRR(현금흐름)` | 시점별 현금흐름 |
| NPV | `=NPV(할인율, 현금흐름)` | 시점0 별도 |
| FV | `=FV(r, n, PMT, P)` | 미래가치 |

- [ ] LTV 변동 시 임계 LTV는 변하지 않아야 함 (NOI·금리·기간만 영향)

- [ ] 매각 시점 잔존원금이 음수 또는 원금 초과 시 오류
