# 차주 유형별 LTV·금리 매핑 상세

## ⚠️ 본 매핑값의 성격

**[검증필요]** 본 문서의 LTV·금리 디폴트 값은 일반적 시장 통념을 기반으로 한 디폴트입니다.
- 실제 한도는 거래 은행마다 다름
- 정부 규제는 분기·반기 단위로 변동
- 차주의 신용등급·기존 대출 보유 현황에 따라 차등
- 본 매핑값은 "시작점"이며, 시뮬레이션 시점에 거래 은행 직접 확인 필수

## 1. 대부업체 명의

### 1-1. 일반 특성
- 대부업법상 자기자본비율 규제 적용 (자기자본 대비 대출잔액 한도)
- 부동산 직접 보유 시 자산건전성 분류 영향
- 일부 시중은행만 취급하며 한도 협상 필수
- 부동산 가격 상승 시 매각차익에 대한 세금 부담 큼 (법인세 + 양도세 합산)

### 1-2. LTV·금리 디폴트
| 시나리오 | LTV | 금리 가산 |
|---|---|---|
| 보수 | 40% | 시장+3.0%p |
| 중립 | 50% | 시장+2.0%p |
| 공격 | 60% | 시장+1.5%p |

### 1-3. 추가 고려사항
- 대부업체가 부동산 보유 시 사업 본질 외 자산으로 분류될 수 있어 금감원 검사 시 지적 가능
- NPL 회수 목적임을 입증할 수 있는 서류(매입 감정서, 회수 계획서) 필요
- 단기(1~2년) 보유 후 매각이 일반적

## 2. SPC(특수목적법인, 대부업 자회사)

### 2-1. 일반 특성
- 부동산 PF 대출로 분류될 가능성
- 대부업체 본체와 회계 분리, 신용 차단
- 자본금 적은 SPC는 대출 한도 제한
- NPL 매입·회수 전용 SPC 설립 시 일반적인 차주 유형

### 2-2. LTV·금리 디폴트
| 시나리오 | LTV | 금리 가산 |
|---|---|---|
| 보수 | 50% | 시장+1.5%p |
| 중립 | 60% | 시장+1.0%p |
| 공격 | 70% | 시장+0.5%p |

### 2-3. 추가 고려사항
- SPC 설립 시 자본금 최소 5천만원 ~ 1억원 일반적
- 모회사(대부업체) 연대보증 또는 후순위 자기자본 투입 시 한도 상향 가능
- 매각 시 SPC 청산 절차 필요 (시간 소요)

## 3. 개인 (다주택자)

### 3-1. 일반 특성
- 정부 부동산 정책의 직접 규제 대상
- DSR 40% 강제 적용
- 다주택자 가산세율 적용 (취득세, 보유세, 양도세)
- 조정대상지역 지정 시 추가 규제

### 3-2. LTV·금리 디폴트
| 시나리오 | LTV | 금리 가산 |
|---|---|---|
| 보수 | 30% | 시장+0.5%p |
| 중립 | 40% | 시장+0.3%p |
| 공격 | 50% | 시장+0.0%p |

### 3-3. 추가 고려사항
- 2주택 이상 보유 시 종부세 합산 과세
- 단기 매각(1년 미만) 시 양도세 70%, 1~2년 60%
- DSR 한도 초과 시 LTV 무관 대출 불가
- 임대사업자 등록 시 일부 완화 (취득세·재산세 감면, 단 기간 내 매각 금지)

## 4. 개인 (1주택·실수요자)

### 4-1. 일반 특성
- 가장 우대받는 차주 유형
- 생애최초·신혼부부·청년 등 추가 우대 가능
- 그러나 NPL 매입자 입장에서는 비현실적 시나리오

### 4-2. LTV·금리 디폴트
| 시나리오 | LTV | 금리 가산 |
|---|---|---|
| 보수 | 50% | 시장+0.3%p |
| 중립 | 60% | 시장+0.0%p |
| 공격 | 70% | 시장-0.3%p |

### 4-3. 추가 고려사항
- 본인 거주 의무 (보통 2년)
- 거주 의무 위반 시 추징
- NPL 회수 목적의 단기 매각 부적합

## 5. 법인사업자(부동산 임대업)

### 5-1. 일반 특성
- 임대업 등록 시 일부 세제 혜택
- 대출은 사업자대출 라인 적용 (가계대출 규제 회피)
- 임대료 매출 인정으로 DSR 산정 시 유리

### 5-2. LTV·금리 디폴트
| 시나리오 | LTV | 금리 가산 |
|---|---|---|
| 보수 | 50% | 시장+1.0%p |
| 중립 | 60% | 시장+0.5%p |
| 공격 | 70% | 시장+0.0%p |

### 5-3. 추가 고려사항
- 임대사업자 등록 시 의무 임대 기간(통상 8년·10년) 발생
- 의무 기간 내 매각 시 과태료 + 세제 혜택 환수
- 사업자대출은 만기 일시상환 비율 높음 → 재금융 리스크
- NPL 회수 목적이라면 임대사업자 등록은 부적합

## 6. 차주 유형 선택 가이드

### 6-1. 의사결정 트리

```
NPL 매입 후 회수 목적인가?
├─ Yes
│  ├─ 매입 후 1년 이내 매각 예정?
│  │  ├─ Yes → 대부업체 명의 (단기 회수)
│  │  └─ No  → SPC (중기 보유 후 매각)
│  └─ 임대수익 중심 장기 보유?
│     ├─ 법인사업자 (3년 이상)
│     └─ 또는 SPC + 임대 운영
└─ No (직접 투자 목적)
   ├─ 1주택 실수요 → 개인(1주택)
   ├─ 추가 투자 → 개인(다주택)
   └─ 임대사업 본격 → 법인사업자
```

### 6-2. 명의별 출구 전략 매칭

| 명의 | 권장 보유 기간 | 출구 전략 |
|---|---|---|
| 대부업체 | 6개월~2년 | 단기 매각, 차익 회수 |
| SPC | 1~3년 | 매각 또는 임대 후 매각 |
| 개인(다주택) | 2년 이상 | 양도세 단기 중과 회피 |
| 법인사업자 | 8년+ | 임대 후 장기 매각 |

## 7. 정부 규제 동향 (시점별 확인 필수)

### 7-1. 변동성 높은 항목
- LTV 한도 (지역·주택 가격대별)
- DSR 적용 범위 (1억 초과·전체)
- 조정대상지역·투기지역 지정/해제
- 다주택자 양도세 중과율 및 유예 기간

### 7-2. 확인 방법
- 금융감독원 보도자료 (최신 LTV·DSR 규제)
- 국토교통부 보도자료 (조정대상지역 등)
- 거래 은행 직접 견적 (실효 한도)
- web_search/web_fetch로 시뮬레이션 시점 확인 필수

## 8. 본 매핑표 사용 시 주의

1. **반드시 [검증필요] 라벨로 표기**
2. 사용자가 정확한 한도를 원하면 거래 은행 견적서 요청
3. 시뮬레이션 결과는 의사결정의 시작점이지 종착점이 아님
4. NPL 회수 목적의 매입은 일반 부동산 투자 대출 라인과 다른 PF성 자금조달일 가능성 → 별도 협의
