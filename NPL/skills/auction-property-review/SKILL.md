# 경매·공매 물건 분석

## 이 스킬의 목적

물건 하나에 대해 다음 세 가지를 **매번 같은 순서, 같은 기준으로** 판단한다.

1. 들어가도 되는가
2. 얼마를 쓸 것인가
3. 낙찰 후 무엇이 기다리는가

바빠서 한두 항목을 빠뜨리면 바로 그 항목에서 사고가 난다. 그래서 이 스킬의 핵심은 분석 능력이 아니라 **순서 강제**다. 아래 단계를 건너뛰지 마라.

---

## 사실 확신도 라벨 (모든 문장에 적용)

- `[확정]` — 이 답변에서 직접 조회한 출처가 있다. 출처를 명시한다(파일명+페이지, MCP명, URL, 조회일).
- `[검증필요]` — 기억 또는 간접 정보. 사용자 의사결정 전 원본 확인이 필요하다.
- `[추정]` — 정황상 유추. 사실이 아니다.

**법령 조문·세율·최우선변제 한도·저감률은 기본 `[검증필요]`다.** 그 답변에서 직접 조회했을 때만 `[확정]`으로 올린다. 이전 대화나 기존 문서에 적혀 있다는 것은 근거가 아니다.

---

## STEP 0 — 경매인가 공매인가 (가장 먼저)

둘은 진행기관도 근거법도 다르다. 여기서 갈리면 입찰가·명도계획·일정이 전부 달라진다.

| 구분 | 법원경매 | 공매(온비드) |
|---|---|---|
| 진행 | 법원 | 캠코(한국자산관리공사) |
| 식별 | 사건번호 `2025타경12345` | 물건관리번호 |
| 개시 | 채권자 신청 | 세금 체납 압류(압류재산) 등 |
| 입찰 | 법원 출석 | 인터넷 |
| 유찰 저감 | 법원별 20% 또는 30% — **물건마다 확인** | 회차별로 다름(경매와 폭이 다름) |
| 문건접수내역 | 공개 | **비공개** |
| 인도명령 | 있음 | **없는 것으로 알려져 있음** `[검증필요]` |

**판별 기준**: 사건번호에 `타경`이 있으면 경매. 온비드 공고·물건관리번호가 있으면 공매. 둘 다 없으면 사용자에게 묻는다. 추측하지 마라.

### 반드시 검증하고 넘어갈 두 가지

아래 두 명제는 실무상 알려진 것이나 **이 스킬은 이를 확정으로 취급하지 않는다.** 분석 시점에 `korean-law` 또는 `korea-law-search` MCP로 국세징수법·민사집행법 조문을 직접 조회하고, **조문 번호와 조회일을 본문에 적은 뒤에만** `[확정]`을 붙인다.

1. `[검증필요]` 공매에는 인도명령 제도가 없어, 점유자가 불응하면 명도소송으로 가야 한다.
2. `[검증필요]` 신탁회사가 진행하는 공매는 법원 배당절차가 아니므로 소액임차인 최우선변제가 원칙적으로 적용되지 않는다.

조회 결과가 사용자가 알고 있는 것과 다르면, **법이 맞다.** 그 사실을 사용자에게 명시적으로 보고한다.

공매는 문건접수내역이 없어 정보량 자체가 적다. **자료가 적다는 사실을 위험으로 계산에 넣어라** (STEP 3의 「확인 못 함」 항목 수에 반영).

## STEP 1 — 서류 수집과 파일명 정규화

받는 서류(전부 있는 경우는 드물다):

- 경매: 사건정보 / 등기부등본 / 매각물건명세서 / 현황조사보고서 / 감정평가서 / 건축물대장 / 문건접수내역 / 전입세대열람
- 공매: 온비드 공고·물건상세 / 등기부등본 / 건축물대장 / 감정평가서 / 현장사진

### 파일명 오타 흡수 (필수)

법원·경매정보 사이트에서 받은 파일은 이름이 제각각이다. 같은 문서인데 **「문건접수」와 「물건접수」**처럼 한 글자가 바뀌어 있다. 이것을 다른 문서로 보고 건너뛰면 안 된다.

정규화 규칙:

1. 파일명에서 공백·괄호·하이픈·언더바를 제거하고 비교한다.
2. 앞뒤에 붙은 사건번호·날짜·기관명은 무시한다.
3. `문건접수` `물건접수` `문건송달` `문건/송달내역` `접수내역` — 전부 **법원 문건접수내역**으로 본다.
4. `현황조사` `현황조사서` `현황조사보고서` — 같은 문서.
5. `매각물건명세서` `물건명세서` `매각명세서` — 같은 문서.
6. `전입세대` `전입세대열람` `세대열람` `주민등록전입세대` — 같은 문서.
7. 위 어느 것과도 두 글자 이내 차이로 비슷한 새 표기가 나오면 **일단 해당 문서로 처리하되, 답변 끝에 "이런 파일명도 있었습니다: ○○○"라고 반드시 보고한다.**

### 없는 서류 처리

없으면 없는 대로 진행하되, **무엇이 없어서 무엇을 확정하지 못했는지 반드시 명시한다.**

```
[확인 못 함] 전입세대열람 미제출 → 서류에 없는 전입자 존재 여부 확인 불가
             확인처: 관할 주민센터 또는 정부24 전입세대열람 (낙찰 전 열람 가능)
```

없는 것을 있는 척 채우는 것이 가장 위험하다. **"확인 못 함" + 확인 방법**이 그럴듯한 추정보다 백배 낫다.

## STEP 2 — 점유자 저항 분석 (경매만)

돈이 가장 많이 새는 곳은 값이 아니라 사람이다. 싸게 받아도 점유자가 1년을 버티면 남는 게 없다.

법원 문건접수내역을 **시간 순으로 이어 붙여 하나의 이야기로 만든 뒤** 판단한다.

읽을 때 지킬 것:

- **단서 하나로 단정하지 마라.** "송달불능" 한 줄로 잠적을 결론짓지 마라. 앞뒤 기록을 연결한 뒤 판단한다.
- **가려진 이름을 너그럽게 읽어라.** 법원 문서는 `홍○○`처럼 마스킹한다. 글자가 안 맞는다고 다른 사람으로 보면 안 된다.

### 당사자 변동 — 용어를 엄격히 구분하라

겠보기는 비슷하지만 뜻이 완전히 다르다. 첫 번째와 나머지를 헷갈리면 판단이 통째로 틀어진다.

| 기재 | 의미 |
|---|---|
| 경정결정 / 당사자표시정정 | **서류상 오기 정정. 실질 변동 없음** |
| 승계집행문 부여 | 상속·합병으로 권리가 실제로 승계됨 |
| 당사자변경 | 당사자가 실제로 교체됨 |
| 소유권이전등기 | 소유자가 실제로 교체됨 |

### 저항점수 (0~10점)

다음을 가점한다.

| 항목 | 점수 |
|---|---|
| 집행정지 신청 | +2 (건당) |
| 이의신청 | +2 (건당) |
| 즉시항고 | +3 (건당) |
| 유치권 권리신고 | +3 |
| 송달불능 반복(3회 이상) | +2 |
| 매각기일 변경·연기 반복 | +1 (건당) |
| 임차인 배당요구 취하 | +2 |

**6점 초과 = 명도 장기화 예상.** 그만큼 이자·관리비·명도비를 추가로 계산에 넣는다. 점수와 함께 「예상 명도 소요기간」과 「추가 비용(원)」을 반드시 금액으로 낸다.

또한 문건접수내역에서 **제3자의 사건기록 열람**이 있으면 경쟁 입찰자 신호로 보고 STEP 3의 22번에 반영한다.

## STEP 3 — 권리분석 (말소기준권리)

낙찰로 등기부상 권리 대부분이 소멸하지만 전부는 아니다. **소멸하지 않고 따라오는 것은 낙찰자가 돈으로 갚는다.**

말소기준권리: 등기부상 **근저당권 · 압류 · 가압류 · 담보가등기 · 경매개시결정** 중 **가장 먼저 설정된 것**.

- 기준권리보다 **뒤** → 소멸
- 기준권리보다 **앞** → **인수**

인수 시 특히 위험한 것:

- 기준권리보다 앞선 임차인의 보증금
- 선순위 가처분
- 선순위 지상권·지역권
- 예고등기
- **유치권** (등기부에 나타나지 않는다 — 문건접수내역·현장에서 찾는다)
- **법정지상권** (토지와 건물 소유자가 달랐던 이력이 있으면 의심한다)

### 필수 산출 표

| 순위 | 권리 종류 | 권리자 | 설정일 | 금액(원) | 소멸/인수 |
|---|---|---|---|---|---|

그리고 인수 항목의 합계를 **한 줄로** 낸다. 이 줄이 없으면 입찰가를 잘못 쓴다.

```
이 물건은 낙찰가 외에 ___,___,___원이 추가로 듭니다.
```

## STEP 4 — 소액임차인 최우선변제금 판정 (절대 틀리면 안 됨)

**배당 계산보다 먼저 이 판정 결과를 보여준다.**

### ★ 기준일은 「등기부 을구 최선순위 근저당의 최초 설정일」이다

- 임차인의 계약일이 아니다
- 전입신고일이 아니다
- 확정일자일이 아니다
- 경매개시일이 아니다
- **오늘 날짜는 더더욱 아니다**

이유: 시행령 개정 시마다 부칙에 "시행 전에 담보물권을 취득한 자에 대하여는 종전 규정에 따른다"는 취지의 경과규정이 들어간다. 담보권자가 대출 실행 당시 알고 있던 기준을 사후에 바꿔 손해를 입힐 수 없기 때문이다. `[검증필요]`

**현행 기준을 그대로 가져다 쓰면 틀린다.** 이것이 실무에서 가장 흔한 오류다.

상세 절차·판정 서식은 `references/priority-tenant-payment.md`를 읽고 그대로 따른다.

요약하면:

1. 을구 최선순위 근저당의 **최초** 설정일을 찾는다 (채권최고액 증액 부기등기가 있어도 기준은 최초 설정일).
2. 그 날짜에 시행 중이던 시행령으로 한도를 찾는다. **기억으로 답하지 말고 법령을 직접 조회한 뒤 조회일과 출처를 본문에 적는다.** 못 찾으면 "확인 필요"라고 쓴다.
3. 배당액 = **min(실제 보증금, 그 시점 한도)**. 한도를 그대로 주지 않는다.
4. 배당요구 종기까지 배당요구를 안 한 임차인은 **0원**. 그리고 그가 선순위라면 **보증금 전액을 낙찰자가 인수한다** (최악).
5. 최우선변제금 총액은 **주택가액(매각대금 − 집행비용)의 1/2**을 넘을 수 없다. 넘으면 그 안에서 안분한다.
6. 1층 상가 + 위층 주택인 건물은 **건축물대장 면적으로 주거/상가를 나눈 뒤 각각 따로 1/2 한도**를 본다.
7. 상가임차인은 **환산보증금 = 보증금 + (월차임 × 100)** 으로 판정한다. **월차임의 부가가치세는 제외**한다.

판정 결과에는 다음이 한눈에 보여야 한다: 기준으로 잡은 근저당(설정일·권리자·채권최고액), 적용한 시행령 시점, 조회한 출처와 조회일, 임차인별 min 계산 과정.

**신탁공매는 이 규칙이 적용되지 않는다** (STEP 0의 검증 대상 2).

## STEP 5 — 임차인 원본 서류 확인

**현황조사보고서만 보고 임차인을 판단하지 마라.** 집행관이 방문 조사한 내용이라 보증금이 「미상」인 경우가 많다.

정확한 보증금·확정일자·배당요구 여부·배당요구액은 **「권리신고 및 배당요구 신청서」 원본**에만 제대로 적혀 있다. 그 서류를 찾아 읽는다.

- 스캔 PDF라서 텍스트가 추출되지 않으면 **페이지를 이미지로 렌더링해서라도 읽는다.**
- **「미상」인 채로 계산을 진행하지 마라.** 인수할 보증금을 모르면 입찰가를 낼 수 없다. 이 경우 STEP 3의 6번을 「확인 못 함」으로 두고, 입찰가 산정을 **보류**한다.

**전입세대열람을 반드시 대조한다.** 서류에 없던 전입자가 실제로 존재하는 경우가 있다.

임차인이 여럿이면 **사람마다 따로 판정한다.** 한 명이라도 선순위면 그 사람 보증금은 인수다.

### [넷] 배당 계산과 인수금액

계산 전에 아래 넷을 이 순서로 끝낸다.

① **최우선변제금 판정** (STEP 4)

② **매매 실거래가 조사** — 국토교통부 실거래가만 사용한다 (`real-estate` MCP 우선, 실패 시 `datagokr` realprice_*).
  조건: **같은 단지 · 같은 면적 · 최근 6개월** 세 가지를 모두 지킨다.
  조건에 맞는 거래가 없으면 **"데이터 없음"**이라고 쓴다. 유사 단지로 대체하거나, 중간값을 만들어내거나, 감정가로 때우지 마라.
  **민간 시세 사이트(KB부동산·호갱노노·아실·부동산지인 등) 수치는 어떤 경우에도 쓰지 않는다.**
  한계가 있었으면 그대로 적는다. 그게 더 도움이 된다.

③ **전월세 실거래가 조사** (임차인 있을 때) — 역시 국토부 자료. 보증금이 시세 대비 과다한지, 깡통전세·허위임차인 여부, 임대 시 예상 월세를 본다.

④ **당해세 확인** (등기부 갑구에 압류가 있을 때) — 해당 부동산 자체에 부과된 세금은 근저당보다 선순위다. 임차인 배당이 줄고 그만큼 인수액이 는다.
  압류 기관이 **그 물건 소재지의 관할**인지 본다. **구·면 단위까지 일치**해야 하며 시 단위로 넓게 보면 안 된다.
  등기부 기재 금액이 **천원 단위**인 경우가 있으니 환산해서 읽는다.

배당 순서:

| 순위 | 항목 |
|---|---|
| 1 | 집행비용 |
| 2 | 당해세 |
| 3 | 소액임차인 최우선변제금 |
| 4 | 최선순위 근저당 |
| 5 | 임금채권 |
| 6 | 확정일자부 임차인 (일자 순) — 단 **법정기일이 임차인 기준일보다 빠른 조세는 임차인 앞** (#24) |
| 7 | 일반 채권 |

**조세는 압류 등기일이 아니라 법정기일로 줄을 세운다.** 법정기일을 모르는 조세는 「선순위 조세 X」로 임차인 앞에 두고, X별(0원 / 100,000,000원 / 200,000,000원) 인수액을 함께 적는다.

계산 기준은 **최저매각가**로 잡는다. 실제 낙찰가가 달라지면 재계산이 필요하다고 명시한다.

마지막 한 줄:

```
낙찰가 외에 추가로 부담할 금액 : ___,___,___원
  (인수 보증금 ___원 + 체납관리비 ___원 + 명도비용 예상액 ___원)
```

### [다섯] 입찰가 산정

```
실거래가 기준 시세        :  ___,___,___원   (출처·조회일 명시)
추가 부담 금액            : -___,___,___원   ([넷]의 결과)
취득세·등기비용           : -___,___,___원
명도 비용·기간 손실       : -___,___,___원
수리비                    : -___,___,___원
목표 이익                 : -___,___,___원
위험 할인율               : -___%   (위험 __개)
용도 할인율               : -___%   (해당 없으면 0%)
────────────────────────────────────────────
입찰 상한가               :  ___,___,___원
권장 입찰가 범위          :  ___,___,___원 ~ ___,___,___원
```

**위험 개수별 할인율**

| 위험 개수 | 할인율 |
|---|---|
| 0개 | 5% |
| 1~2개 | 10~15% |
| 3~4개 | 20~25% |
| 5개 이상 | 30% 이상 또는 포기 검토 |

**용도 할인율** — 상가·근린생활시설로서 **1종만 가능**한 경우에만 적용한다.

| 입지 | 할인율 |
|---|---|
| 역세권 / 유흥상권 | 15~20% |
| 대학가 / 학원가 | 10~15% |
| 일반 상업지 | 10~15% |
| 오피스가 | 10~15% |
| 아파트 단지 내 상가 | 0~5% |
| 주택가 이면도로 | 0~5% |

주거용 아파트·다가구·다세대·토지에는 **용도 할인을 적용하지 않는다.**

**입찰가는 단일 금액으로 찍지 말고 반드시 범위로 낸다.** 그리고 다음 문장을 굵게 넣는다.

```
★ ___,___,___원을 넘으면 남는 것이 없습니다.
```

현장 분위기에 휩쓸려 이 선을 넘는 것이 가장 흔한 실패다.

## 항상 지킬 것

- **모르면 모른다고 한다.** "확인 못 함" + 확인 방법이 그럴듯한 추정보다 낫다.
- **위험은 나열하지 말고 금액으로 환산한다.**
  `확정일자 없음` (×) → `확정일자가 없어 보증금 80,000,000원을 인수하게 됩니다` (○)
- **금액은 원 단위 풀 콤마.** `240,000,000원` (○) / `2.4억` `24,000만원` (×). 자릿수 오독을 막기 위함이다.
- **시세는 국토교통부 실거래가만.** 민간 시세 사이트 수치는 인용도 금지.
- **임차인이 여럿이면 사람마다 따로.** 한 명이라도 선순위면 그 보증금은 인수다.
- **법령·세율은 직접 조회하고 조회일을 적는다.** 기억으로 답하지 않는다.
- **경매/공매에 따라 결론이 갈리는 대목에서는 어느 쪽 기준인지 밝힌다.**
