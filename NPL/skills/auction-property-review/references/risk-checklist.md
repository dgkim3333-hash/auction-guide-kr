# 24개 위험 항목 판정 기준

SKILL.md 출력 [셋]에서 **항상** 읽는다.

각 항목은 **괜찮음 / 위험 / 주의 / 확인 못 함** 넷 중 하나로 판정한다.
「위험」이면 **반드시 금액(원)으로 환산**한다. 금액을 못 내면 「확인 못 함」이다.

「위험」 개수가 [다섯] 입찰가 할인율을 결정하므로, 판정을 느슨하게 하면 입찰가가 부풀어 오른다.

---

## A. 임차인 관련 (1~8)

### 1. 선순위 임차인 존재 — 최우선 확인 항목

- **확인처**: 등기부(말소기준권리 설정일) vs 전입세대열람·현황조사서(전입일)
- **판정**: 전입일 < 말소기준권리 설정일 → **위험**
- **금액**: 해당 임차인의 보증금 중 배당받지 못하는 전액
- 임차인이 여럿이면 **사람마다 따로** 판정한다. 한 명이라도 선순위면 위험.

### 2. 확정일자 유무

- **확인처**: 권리신고 및 배당요구 신청서 원본, 매각물건명세서
- **판정**: 확정일자 없음 → 우선변제 순위가 없어 6순위 배당을 못 받음
- **금액**: 배당 못 받는 보증금 × (선순위면 인수, 후순위면 0)
- 예시 문장: `확정일자가 없어 보증금 80,000,000원을 인수하게 됩니다`

### 3. 배당요구 유무

- **확인처**: **문건접수내역** (공매는 확인 불가 → 「확인 못 함」)
- **판정**: 배당요구 종기까지 미제출 → **위험**
- **금액**: 선순위 임차인이면 **보증금 전액 인수**. 소액임차인이어도 최우선변제 0원.
- 이 항목은 STEP 4의 4단계와 동일한 판단이다. 결과를 일치시킨다.

### 4. 배당요구 취하

- **확인처**: 문건접수내역의 「배당요구 취하」 기재
- **판정**: 취하 있음 → 배당에서 빠지면서 **대항력이 되살아난다** → 위험
- **금액**: 보증금 전액 인수
- STEP 2 저항점수에도 +2 반영.

### 5. 임차권등기명령에 의한 임차권등기

- **확인처**: 등기부 을구
- **판정**: 등기 있음 → 임차인이 이사를 나가도 대항력·우선변제권이 유지됨
- **금액**: 등기된 보증금 중 미배당액
- 선순위 임차권등기면 **인수 확정**이다.

### 6. 보증금 미상 임차인

- **확인처**: 현황조사서에 「미상」 → **권리신고 및 배당요구 신청서 원본을 찾아 읽는다**
- 스캔 PDF면 이미지로 렌더링해서라도 읽는다.
- **판정**: 원본에서도 확인 불가 → **확인 못 함** (「괜찮음」으로 두지 마라)
- **결과**: 인수 보증금을 모르면 **입찰가 산정을 보류한다.** 이것이 원칙이다.

### 7. 전입세대열람 불일치

- **확인처**: 전입세대열람 vs 현황조사서·매각물건명세서
- **판정**: 서류에 없던 전입자 존재 → **위험** (미신고 임차인 가능성)
- **금액**: 확인 전까지는 산정 불가 → 「확인 못 함」과 병기하고 현장 확인 항목에 넣는다.

### 8. 전세보증보험(HUG 등) 대위

- **확인처**: 등기부, 배당요구 채권자 명의, 문건접수내역
- **판정**: 보증기관이 임차인 대신 채권자로 등장 → **주의**
- 확인할 것: **잔액 반환청구권 포기 조항** 유무. 포기 조항이 없으면 미배당 잔액이 낙찰자에게 청구될 여지 `[검증필요]`
- **금액**: 보증금 중 미배당 예상액

## B. 건물 자체 (9~12)

### 9. 위반건축물 / 불법건축물 등재

- **확인처**: 건축물대장 (위반건축물 표기), 현황조사서, 현장사진
- **판정**: 등재 있음 → **위험**
- **금액**: 이행강제금 (연 2회 부과 `[검증필요]`) × 예상 보유연수 + 원상복구 비용
- 부수 효과: **담보대출 불가·매각 곤란**. 대출을 전제한 자금계획이면 그 자체가 치명적이다 → [여섯] 자금 항목에 반영.

### 10. 근생 용도인데 실제 주거 사용

- **확인처**: 건축물대장 용도 vs 전입세대열람·현황조사서
- **판정**: 용도는 제2종근린생활시설인데 전입세대가 있음 → **위험**
- 문제: 주택임대차보호법 적용 여부 다툼 `[검증필요]`, 이행강제금, 대출 불가
- **금액**: 이행강제금 + 대출 불가에 따른 자기자금 추가분

### 11. 근생 1종/2종 구분 및 2종 전환 가능성

- **확인처**: 건축물대장 용도, 지자체 조례·해당 용도지역
- **판정**: **1종만 가능** → 입점 가능 업종이 제한되어 임대료가 낮다 → **위험**
- **금액**: [다섯] 용도 할인율로 반영 (역세권·유흥상권 15~20% 등)
- 2종 전환 가능 여부를 조회했으면 조회처와 조회일을 적는다. 못 했으면 「확인 못 함」.

### 12. 체납관리비

- **확인처**: 관리사무소 문의 (현장 확인 항목), 현황조사서 기재
- **판정**: 체납 있음 → **위험**. 공용부분 체납관리비는 낙찰자 부담이 될 수 있다 `[검증필요]`
- **금액**: 체납액 중 공용부분 상당액. 아파트·상가는 수백만원 규모가 흔하다.
- 확인 못 했으면 **「확인 못 함」으로 두고 현장 확인 목록 1번에 올린다.** 0원으로 가정하지 마라.

## C. 권리관계 복잡 (13~21)

### 13. 유치권 주장

- **확인처**: **문건접수내역**(유치권 권리신고), 현장 점유·현수막, 매각물건명세서 비고
- **판정**: 주장 있음 → **위험**. 등기부에 나타나지 않으므로 서류만으로는 안 보인다.
- 진위에 따라 결과가 극단적으로 갈린다. 확인할 것: 점유의 계속성, 견련성 있는 채권 존재, 경매개시결정 등기 전 점유 개시 여부 `[검증필요]`
- **금액**: 주장 금액 전액을 일단 인수로 놓고 계산하되, 진위 미확정임을 명시한다.
- STEP 2 저항점수 +3.

### 14. 법정지상권 성립 여지

- **확인처**: 등기부(토지·건물 각각), 건축물대장, 감정평가서
- **판정 트리거**: **토지만** 또는 **건물만** 경매에 나온 경우 → **반드시 검토**
- 확인할 것: 저당권 설정 당시 토지와 건물이 동일인 소유였는지, 건물이 존재했는지 `[검증필요]`
- **금액**: 성립하면 토지 사용이 장기간 제약된다. 지료 수준과 사용 제약을 금액화한다.

### 15. 지분경매

- **확인처**: 등기부 갑구 (지분 표시), 경매 물건 표시
- **판정**: 일부 지분만 매각 → **위험**
- 문제: 단독 사용 불가, 공유물분할 소송 수반, **다른 공유자의 우선매수권** `[검증필요]`
- **금액**: 소송비용 + 회수 지연 기간의 자금비용

### 16. 공동담보 (여러 물건이 하나의 근저당에 묶임)

- **확인처**: 등기부 을구 공동담보목록
- **판정**: 다른 물건이 먼저 매각되면 이 물건의 배당이 달라진다 → **주의**
- **금액**: 배당 시나리오를 최소 2개(다른 물건 선매각 / 동시매각) 만들어 차액을 제시한다.

### 17. 중복경매

- **확인처**: 등기부 갑구의 복수 경매개시결정, 사건정보
- **판정**: 중복 있음 → **주의**. 선행 사건 취하 시 절차가 바뀐다.

### 18. 소유자 ≠ 채무자

- **확인처**: 사건정보, 등기부
- **판정**: 다름 → **주의**. 물상보증인 또는 제3취득자의 권리가 별도로 존재한다 `[검증필요]`
- 확인할 것: 변제자대위, 제3취득자의 비용상환청구권

### 19. 소유자 파산선고

- **확인처**: 문건접수내역, 등기부 기재, 사건 진행 상황
- **판정**: 파산·회생 절차 진행 → **위험**. 절차가 정지될 수 있다 `[검증필요]`
- **금액**: 절차 지연 기간의 자금비용

### 20. 맹지 (토지 물건 필수)

- **확인처**: 지적도, `vworld-landuse` MCP (토지이용계획), 현장
- **판정**: 도로에 접하지 않음 → **위험**. 건축허가가 나지 않으면 가치가 반토막난다.
- **금액**: 진입로 확보 비용(사용승낙·매수) 또는 건축 불가 전제의 가치 하락분

### 21. 농지 (농지취득자격증명)

- **확인처**: 토지대장·등기부 지목, 토지이용계획
- **판정**: 지목이 전·답·과수원 → **농취증 필요** `[검증필요]`
- **금액**: 발급 실패 시 **입찰보증금 전액 몰수**. 이 금액을 그대로 적는다.
- 발급 요건과 기한을 미리 확인하고 확인처를 적는다.

## D. 경쟁 (22~23)

### 22. 제3자 사건기록 열람

- **확인처**: 문건접수내역 (「사건기록 열람」 기재)
- **판정**: 열람 이력 있음 → 경쟁 입찰자 존재 신호 → **주의**
- **영향**: 낙찰가율 상승. 권장 입찰가 범위의 **상단**을 사용해야 할 근거가 된다.

### 23. 조회수 이상 고저

- **확인처**: 경매정보 사이트 조회수, 온비드 조회수
- **판정**:
  - 유난히 높음 → 경쟁 과열 → **주의** (상단 입찰 필요)
  - 유난히 낮음 → **단독응찰 가능성** → 하단 입찰 여지 (위험이 아니라 기회)
- 조회수는 사이트·화면마다 세는 기준이 달라 절대값 비교는 위험하다 `[검증필요]`. 같은 회차·같은 화면 기준의 상대 비교만 한다.

### 24. 임차인 기준일 이후 조세 압류·교부청구 (법정기일 미확인) — 2026-10-02 신설

정본은 `auction-property-card` STEP 4-C.

- **확인처**: 등기부 갑구 압류(세무서·지자체·건보) · 경매 문건접수의 교부청구 · 공매재산명세서·권리분석 기초정보
- **원리**: 조세와 임차보증금의 순위는 **압류 등기일이 아니라 법정기일**로 정한다(국세기본법 §35①3·②). 압류는 독촉 기한이 지난 뒤에 하므로(국세징수법 §10·§31①) 법정기일은 압류일보다 앞선다. 대항력 임차인이 배분받지 못한 잔액은 매수인이 인수한다(대법원 97다11195).
- **판정**:
  - 임차인 기준일 T(대항요건 다음날과 확정일자 중 늦은 날) 이후 조세 압류·교부청구가 있고 법정기일 미확인 → **위험**
  - 압류·교부청구일 − T ≤ 6개월 → **위험(고위험 표시)**
  - 6개월 초과 → 「괜찮음」 금지, 최소 **주의**
  - 법정기일이 T보다 늦은 것이 서류로 확인됨 → 괜찮음
- **금액 환산**: 선순위 조세 X `[확인 못 함]` — X만큼 임차인 배당이 줄고 매수인 인수가 늘어난다. X = 0원 / 100,000,000원 / 200,000,000원 인수액을 병기한다. **낙찰가를 낮춰도 X는 줄지 않는다.**

## 위험 개수 집계 규칙

- **「위험」만 센다.** 「주의」와 「확인 못 함」은 세지 않는다.
- 다만 **「확인 못 함」이 3개 이상이면 등급을 한 단계 내린다** ([일곱] 종합의견).
- 6번(보증금 미상)이 「확인 못 함」이면 **입찰가 산정 자체를 보류**한다.
- 24번이 「위험」이고 1번(선순위 임차인)도 「위험」이면 X 확인 전까지 **입찰가 산정을 보류**한다.

| 위험 개수 | 할인율 |
|---|---|
| 0개 | 5% |
| 1~2개 | 10~15% |
| 3~4개 | 20~25% |
| 5개 이상 | 30% 이상 또는 포기 검토 |
