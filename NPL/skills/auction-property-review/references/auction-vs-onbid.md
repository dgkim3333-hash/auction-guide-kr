# 법원경매 vs 공매 — 결론이 갈리는 지점

SKILL.md STEP 0에서 읽는다. 공매 물건이거나, 절차 차이가 결론에 영향을 주는 대목에서 참조한다.

**이 문서의 내용은 기본 `[검증필요]`다.** 실무 통설을 정리한 것이며, 분석 시점에 `korean-law` / `korea-law-search` MCP로 **국세징수법 · 민사집행법 · 신탁법** 조문을 직접 조회한 뒤에만 `[확정]`으로 올린다. 조문 번호와 조회일을 본문에 적는다.

## 1. 절차 대조

| 항목 | 법원경매 | 공매(온비드) |
|---|---|---|
| 근거법 | 민사집행법 | 국세징수법 등 |
| 진행 주체 | 법원(집행법원) | 캠코(한국자산관리공사) |
| 식별자 | `2025타경12345` | 물건관리번호 |
| 개시 원인 | 채권자의 경매신청 | 조세 체납 압류(압류재산) 등 |
| 입찰 방식 | 법원 출석 기일입찰 | 인터넷(온비드) |
| 입찰 주기 | 통상 월 1회 기일 | 통상 주 단위 회차 |
| 문건접수내역 | **공개** | **비공개** |
| 매각물건명세서 | 있음 | 없음(공고·물건상세로 대체) |
| 현황조사보고서 | 있음 | 없음 |
| 유찰 저감 | 법원별 20% 또는 30% | 회차별, 경매와 폭이 다름 |
| 인도명령 | 있음 | **없음** `[검증필요]` |

## 2. 공매 재산 유형 구분

같은 「공매」라도 유형에 따라 규칙이 다르다. 반드시 어느 유형인지 먼저 판정한다.

| 유형 | 성격 | 주의점 |
|---|---|---|
| 압류재산 | 조세 체납으로 압류된 재산 | 공매의 대부분. 배당(배분) 절차가 있다 |
| 국유재산 / 수탁재산 | 국가·공공기관 재산 | 권리관계가 단순한 편 |
| 금융기관 담보재산 | 금융기관이 위임한 재산 | 조건이 개별 계약에 따른다 |
| **신탁공매** | 신탁회사가 진행 | **법원 배당절차가 아님. 최우선변제 원칙 배제** `[검증필요]` |

신탁공매를 만나면 STEP 4의 최우선변제 판정을 그대로 적용하지 말고, 신탁원부·우선수익권 순위를 별도로 확인한다.

## 3. 결론이 갈리는 지점

### (1) 명도 — 가장 큰 차이

`[검증필요]`

| | 경매 | 공매 |
|---|---|---|
| 수단 | 인도명령 신청 (잔금 납부 후) | 명도소송 |
| 기간 | 통상 수 주 ~ 2~3개월 | 통상 6개월 ~ 1년 이상 |
| 비용 | 상대적으로 적음 | 소송비용 + 장기 자금비용 |

→ **공매 물건은 [다섯] 입찰가 산정에서 명도 비용·기간 손실을 경매보다 크게 잡는다.**
→ 이 항목을 경매와 같게 잡는 것이 공매 실패의 전형이다.

### (2) 정보량

공매는 문건접수내역·현황조사보고서·매각물건명세서가 없다. 즉:

- STEP 2 (점유자 저항 분석) → **수행 불가**
- 위험항목 3·4·13·22 (배당요구·취하·유치권 신고·기록열람) → **「확인 못 함」**

**자료 부재 자체를 위험으로 계산에 넣는다.** 「확인 못 함」이 3개 이상이면 종합의견 등급을 한 단계 내린다.

대신 다음의 비중을 높인다:

- 전입세대열람 (주민센터·정부24에서 직접 발급)
- 현장 확인 (점유 상태, 관리사무소 체납, 유치권 표시물)
- 등기부 정밀 판독

### (3) 최우선변제

`[검증필요]`

- 압류재산 공매: 배분 절차가 있어 최우선변제 논의가 가능
- **신탁공매: 원칙적으로 적용되지 않음**

신탁공매인데 경매처럼 최우선변제를 계산하면 배당표 전체가 틀린다.

### (4) 잔금·보증금

| | 경매 | 공매 |
|---|---|---|
| 입찰보증금 | 최저매각가의 10% | 최저입찰가의 10% (통상) |
| 잔금 기한 | 통상 약 1개월 | 매각결정 후 지정 기한 |
| 미납 시 | 보증금 몰수 | 보증금 몰수 |

`[검증필요]` — 기한은 물건·회차마다 다르므로 **공고문에서 직접 확인**하고 그 문구를 인용한다.

### (5) 저감률

- 경매: 관할 법원이 20%씩 내리는 곳인지 30%씩 내리는 곳인지 **물건마다 확인한다.** 모르면 다음 회차 최저가를 잘못 계산한다.
- 공매: 회차별 저감 폭이 경매와 다르다. **공고문의 회차별 최저입찰가를 그대로 읽는다.** 계산으로 추정하지 마라.

## 4. 공매 물건 분석 시 STEP 조정

| STEP | 경매 | 공매 |
|---|---|---|
| 0 판별 | 사건번호 `타경` | 물건관리번호 + 재산유형 판정 추가 |
| 1 서류 | 8종 | 4종 (없는 것 명시) |
| 2 저항분석 | 수행 | **생략 — 「자료 없음」으로 기록** |
| 3 권리분석 | 수행 | 수행 (등기부 중심) |
| 4 최우선변제 | 수행 | 압류재산은 수행 / **신탁은 배제** |
| 5 임차인 원본 | 배당요구 신청서 | **원본 없음 → 전입세대열람·현장 비중 확대** |
| [여섯] 명도 | 인도명령 | **명도소송 전제로 기간·비용 상향** |

## 5. 조회해야 할 조문 (분석 시점에 직접)

아래를 `korean-law` 또는 `korea-law-search` MCP로 조회하고, 조문 번호·조회일을 본문에 적는다.

- 민사집행법 — 인도명령 관련 조문
- 국세징수법 — 공매 절차, 매수인의 권리, 인도 관련 조문
- 신탁법 — 신탁재산 처분과 수익권 순위
- 주택임대차보호법 시행령 / 상가건물 임대차보호법 시행령 — 해당 시점 판 및 부칙

조회 결과가 이 문서의 서술과 다르면 **법이 맞다.** 그 사실을 사용자에게 명시적으로 보고하고, 이 문서를 갱신할 것을 제안한다.
