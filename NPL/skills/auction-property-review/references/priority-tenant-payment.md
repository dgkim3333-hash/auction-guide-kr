# 소액임차인 최우선변제금 판정 절차

이 문서는 SKILL.md STEP 4에서 **항상** 읽는다. 여기 적힌 순서를 그대로 따른다.

---

## 왜 이것이 가장 위험한가

임차인이 배당으로 얼마를 받아가느냐에 따라, 못 받은 나머지를 낙찰자가 인수하는지가 갈린다. 그런데 "얼마까지가 소액이냐"는 기준이 **시기별·지역별로 다르다.** 시행령이 여러 차례 개정됐고, 개정 때마다 부칙에 경과규정이 들어갔다.

그래서 **현행 기준을 그대로 적용하면 틀린다.** 실무 오류 1위다.

---

## ★ 기준일

```
등기부 을구에서 가장 앞선 근저당권의 최초 설정일
```

**아닌 것들** (전부 오답이다):

- 임차인의 임대차계약일
- 전입신고일
- 확정일자 부여일
- 경매개시결정일 / 공매공고일
- 배당요구 종기
- 오늘 날짜

**이유** `[검증필요]`: 시행령 개정 부칙에 "이 영 시행 전에 임차주택에 대하여 담보물권을 취득한 자에 대하여는 종전의 규정에 따른다"는 취지의 경과규정이 반복적으로 들어간다. 담보권자가 대출 실행 당시 예측했던 부담을 사후 개정으로 늘릴 수 없기 때문이다.

→ 이 근거 자체도 분석 시점에 `korean-law` MCP로 **주택임대차보호법 시행령 부칙**을 직접 조회해 확인하고, 조문과 조회일을 본문에 적는다.

### 최초 설정일을 찾는 법

- 채권최고액을 **증액하는 부기등기**가 나중에 붙어 있어도 기준은 **최초 설정일**이다.
- 최선순위 근저당이 **말소되고** 다음 근저당이 최선순위가 된 경우, 현재 등기부상 남아 있는 것 중 최선순위를 본다.
- 근저당이 하나도 없고 압류·가압류가 최선순위이면, 그 설정일을 기준일로 삼되 **`[검증필요]`로 표시하고 사용자에게 확인을 요청한다** (담보물권이 아닌 권리를 기준으로 삼는 것은 다툼이 있다).

## 판정 5단계

### 1단계 — 기준일 확정

```
최선순위 근저당
  권리자   : ○○은행 ○○지점
  설정일   : 20XX-XX-XX      ← 기준일
  채권최고액: ___,___,___원
  근거     : 등기부등본 을구 순위번호 X (파일명, 페이지)
```

### 2단계 — 그 시점의 한도 조회

**기억으로 답하지 마라.** 반드시 `korean-law` 또는 `korea-law-search` MCP로 다음을 조회한다.

- 주택: 「주택임대차보호법 시행령」 — 소액임차인의 범위와 최우선변제 금액, 그리고 **해당 개정 당시 부칙**
- 상가: 「상가건물 임대차보호법 시행령」 — 동일

조회 후 본문에 반드시 적는다:

```
[확정] 적용 기준: 주택임대차보호법 시행령 (○○○○년 ○월 ○일 시행)
       보증금 범위 ___,___,___원 이하 / 최우선변제 한도 ___,___,___원
       조회: korean-law MCP, 법령 mst ______, 조회일 20XX-XX-XX
```

못 찾았으면 솔직하게:

```
[확인 필요] 20XX년 X월 기준 시행령을 조회하지 못했습니다.
            확인처: 국가법령정보센터 > 주택임대차보호법 시행령 > 연혁
            이 값이 확정되기 전에는 입찰가를 확정할 수 없습니다.
```

**지역 구분**도 함께 본다. 시행령은 서울특별시 / 수도권 과밀억제권역 / 광역시 등 / 그 밖의 지역으로 나뉜다. 물건 소재지가 어느 구분에 속하는지 명시한다.

### 3단계 — 임차인별 배당액 산정

```
배당액 = min(실제 보증금, 그 시점 한도)
```

한도를 그대로 주지 않는다.

| 임차인 | 실제 보증금 | 시점 한도 | 배당액 |
|---|---|---|---|
| A | 15,000,000원 | 20,000,000원 | **15,000,000원** |
| B | 45,000,000원 | 20,000,000원 | **20,000,000원** |

B는 나머지 25,000,000원을 확정일자 순위에 따라 6순위에서 다시 배당받는다.

### 4단계 — 자격 요건 확인 (셋 다 충족해야 함)

| 요건 | 확인처 | 미충족 시 |
|---|---|---|
| 대항요건 (인도 + 전입신고) | 전입세대열람, 현황조사서 | 최우선변제 0원 |
| 배당요구 종기까지 배당요구 | **문건접수내역**, 권리신고 및 배당요구 신청서 | **최우선변제 0원** |
| 경매개시결정 등기 전 대항요건 구비 | 등기부 + 전입일 대조 | 최우선변제 0원 |

**배당요구를 하지 않은 선순위 임차인 = 최악의 경우다.**
최우선변제 0원 + 대항력으로 **보증금 전액을 낙찰자가 인수**한다. 이 경우 반드시 굵게 경고한다.

**배당요구를 했다가 취하한 경우**도 확인한다. 배당에서 빠지면서 대항력이 되살아난다.

### 5단계 — 총액 한도 (주택가액의 1/2)

```
주택가액 = 매각대금 − 집행비용
최우선변제금 총액 ≤ 주택가액 × 1/2
```

초과하면 그 한도 안에서 **각자의 최우선변제 금액 비율대로 안분**한다.

계산 예시:

```
매각대금 300,000,000원 − 집행비용 5,000,000원 = 295,000,000원
1/2 한도 = 147,500,000원
최우선변제 합계 = 160,000,000원  → 초과
→ 각 임차인에게 147,500,000원을 비율 안분
```

## 특수 케이스

### 주상복합 (1층 상가 + 위층 주택)

건축물대장 면적으로 **주거 부분과 상가 부분을 안분**한 뒤, 각각 따로 1/2 한도를 본다. 하나로 합쳐서 계산하면 틀린다.

```
주거 안분액 = 주택가액 × (주거 연면적 / 총 연면적)
상가 안분액 = 주택가액 × (상가 연면적 / 총 연면적)
```

안분 비율의 근거(건축물대장 페이지)를 반드시 적는다.

### 상가임차인

```
환산보증금 = 보증금 + (월차임 × 100)
```

- **월차임의 부가가치세는 제외**하고 계산한다.
- 관리비는 월차임에 포함하지 않는다. 다만 실질이 차임이면 다툼이 있다 `[검증필요]`.
- 소액임차인 판정 기준액과 최우선변제 한도는 「상가건물 임대차보호법 시행령」을 따로 조회한다.

예시:

```
보증금 30,000,000원, 월차임 2,200,000원 (부가세 포함)
→ 부가세 제외 월차임 = 2,000,000원
→ 환산보증금 = 30,000,000 + (2,000,000 × 100) = 230,000,000원
```

### 신탁회사 공매

`[검증필요]` 법원 배당절차가 아니므로 최우선변제가 원칙적으로 적용되지 않는다. 이 경우 소액임차인이라도 배당 0원으로 보고, **대신 인수 위험을 별도로 판정한다.** 신탁원부와 우선수익권 순위를 확인한다.

```
━━ 최우선변제금 판정 ━━━━━━━━━━━━━━━━━━━━━━━

기준일   : 20XX-XX-XX  (○○은행 근저당 최초 설정일)
근거     : 등기부등본 을구 순위번호 X, 파일 「등기부등본.pdf」 p.3
소재지 구분: 서울특별시 / 과밀억제권역 / 광역시 등 / 그 밖의 지역
적용 시행령: 주택임대차보호법 시행령 (○○○○.○.○ 시행)
             보증금 ___,___,___원 이하 → 한도 ___,___,___원
조회     : korean-law MCP, 조회일 20XX-XX-XX   [확정]

임차인별
┌──────┬──────────────┬────────┬────────┬──────────────┬──────────────┐
│ 임차인│ 실제 보증금  │ 전입일 │확정일자│ 배당요구     │ 최우선변제액 │
├──────┼──────────────┼────────┼────────┼──────────────┼──────────────┤

└──────┴──────────────┴────────┴────────┴──────────────┴──────────────┘

   → 보증금 45,000,000원 전액을 낙찰자가 인수합니다.

총액 한도 검증: 합계 15,000,000원 ≤ 주택가액 1/2 (147,500,000원)  → 통과
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

이 표를 배당 계산보다 **먼저** 보여준다.
