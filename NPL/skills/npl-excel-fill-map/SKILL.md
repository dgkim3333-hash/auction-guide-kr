# NPL수익률 엑셀 — 셀 입력 정본표

`NPL수익률.xlsx`(지지옥션 신규등록 루트·수협 NPL 자동입력 루트, 두 벌) 을 채우는 **모든 스킬은 이 표를 따른다.**
개별 스킬(ggi-interest-npl-scan STEP 5, suhyup-npl-daily-scan STEP 7 등)의 셀 표와 다르면 **이 표가 우선**이다.

## 왜 이 스킬이 있나 (2026-09-28)
동부2계 2026-163(가락동 129-1) 엑셀에서 C6·C7·C9·C10·C31~C45·F30~F35가 비어 나왔다.
원인은 ggi-interest-npl-scan STEP 5 셀 표에 해당 칸이 **아예 없었기** 때문이다(수협 스캔에는 일부 있었음).
빈 C32·C34~C36 때문에 「법인세 부가세 취득세」 시트의 주거·상가 과세표준이 0이 되어 **취득세가 전액 토지 4%로 계산**됐다.
C13에는 스킬 지시대로 **지지옥션 alg AI시세**가 들어가 금지 소스 규칙과 충돌했다.

## 원칙
1. **모든 입력 칸은 값 또는 메모 중 하나를 반드시 갖는다.** 값이 없으면 빈칸으로 두되 `Comment`에 `[정보부족] 사유 — 언제·무엇으로 채울지`를 쓴다. 조용한 빈칸 금지.
2. 값을 넣은 칸에도 `Comment`로 출처 + `[확정]/[검증필요]/[추정]` 라벨.
3. 금액 원 단위, 면적 소수 둘째자리(`#,##0.00`).
4. 제3자 추정시세(지지옥션 alg·KB 등)는 어느 칸에도 넣지 않는다.
5. 파일이 Excel에 열려 있어 저장이 막히면(PermissionError) 버전 파일을 만들지 말고 닫아달라고 요청한다. 무인 실행이면 보고에 「잠김 — 미입력」을 남긴다.

집합건물(아파트·오피스텔·구분상가)은 감정평가서도 토지·건물 일체로 나오는 경우가 많다. 이때는 원가법을 쓰지 않고 C31·C32를 빈칸 + `[정보부족] 집합건물 — 감정평가서의 대지권·건물 배분 확인` 메모로 둔다.

### ★ 감정평가서가 없을 때 C31·C32 — 원가법 추정 (2026-09-28 신설)
감정평가 실무와 같은 구조(토지 = 비교방식, 건물 = 원가법)로 나눈다. **숫자가 아니라 수식으로 넣어** C13이 바뀌면 따라 움직이게 한다.

```
경과연수 N  = 기준연도 − 사용승인연도            (건축물대장)
내용연수 L  = 철근콘크리트·철골 50 / 벽돌·블록조 40 / 경량철골·목조 30   [추정]
            구조가 섞이면 연면적이 큰 쪽 구조를 쓴다
잔가율      = MAX(1 − N/L, 0.1)                   (정액법, 하한 10%)  [추정]
재조달원가  = 1,800,000원/㎡ 기본                 [추정]
            (민감도 1,500,000 ~ 2,100,000원/㎡을 메모에 병기)

C32 = ROUND(C34 × 재조달원가 × 잔가율, 0)
C31 = C13 − C32
```

**교차검증 (필수):** `C31 ÷ C37`(대지㎡당)을 C13 산정에 쓴 국토부 실거래 **대지㎡당 중앙값**과 비교한다.
- 차이 ±15% 이내 → 통과. 메모에 두 값과 차이율을 적는다.
- 벗어나면 → 값은 넣되 메모 첫 줄에 `⚠ 교차검증 불일치 N%` 를 쓰고 보고에 올린다. 신축·대수선 건물, 대지가 작은 고층 건물에서 잘 벗어난다.

**메모 예시(C32):** `[추정] 원가법 가안 — 연면적 548.46㎡ × 재조달원가 1,800,000원/㎡ × 잔가율 28%(내용연수 50년·경과 36년) = 276,423,840원. 재조달원가 1,500,000~2,100,000원이면 230,353,200~322,494,480원. 감정평가서 공고 후 실제 값으로 교체.`
**메모 예시(C31):** `[추정] C13 − 건물분 = 3,023,576,160원 → 대지㎡당 12,060,535원. 실거래 대지㎡당 중앙 12,178,388원과 1.0% 차이(통과). 감정평가서 공고 후 교체.`

감정평가서가 공고되면 **수식을 지우고 실제 값을 넣는다.** 메모도 `[확정] 감정평가서 p.N` 으로 바꾼다.
