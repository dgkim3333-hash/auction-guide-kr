### 규칙 1 — 모든 PDF는 시각 판독까지 완료해야 한다

폴더 내 모든 PDF에 대해 `pdfplumber`로 진단 후:
- `text_chars > 0`: 텍스트 추출
- `text_chars == 0` (스캔 이미지): **반드시** 200dpi 이상 렌더링 → 0/90/-90도 회전 → `Read` 도구로 시각 판독

시각 확인 없이 결론 내리면 작업 미완료.

### 규칙 2 — 추측 단어 사용 금지

skip 사유에 다음 단어 사용 금지: "추정", "추측", "~로 보임", "이미 처리됨 추정", "본문 첨부물로 추정"

유일하게 인정되는 skip 사유:
- (a) 마스터 행 N에 동일 데이터 존재 — **채무자+소재지+수협명 3개 키 일치 확인 + 행 번호 명시**
- (b) 본문 PDF/HWP의 텍스트에서 "붙임 N 자료 참고" 등 **명시적 첨부 선언을 직접 인용**

### 규칙 3 — 결과 보고에 "파일 처리 현황 표" 강제 포함

폴더의 모든 파일을 한 줄씩 다음 형식으로 표 작성:

```
| 파일명 | 진단 | 시각판독 | 처리 결과 | 사유 |
```

- "시각판독" 열에 ❌가 하나라도 있으면 **작업 미완료**
- "처리 결과"는 "추가(Row N)" / "갱신(Row N)" / "skip" 중 하나
- "사유"에는 위 규칙 2의 (a) 또는 (b) 근거 명시

### 규칙 4 — 자기 점검 4문항을 보고 끝에 포함

- ① 폴더의 모든 파일을 빠짐없이 진단했는가? (개수 명시)
- ② 스캔 이미지 PDF를 모두 시각 판독했는가? (Y/N + 파일명)
- ③ skip 처리한 파일마다 마스터 행 번호 또는 본문 첨부 근거를 명시했는가?
- ④ 신규 추가 행의 합계가 원본 PDF 합계와 일치하는가?

하나라도 N이면 보고서 **최상단에 "★ 미완료 작업 있음"** 명시.

## 핵심 워크플로우

### Step 1: 신규 파일만 식별 (빠른 분류)

업로드된 파일 중 마스터 파일이 아닌 수협/NPL 관련 파일만 골라낸다.
**마스터 파일에 이미 들어있는 기존 데이터는 건드리지 않는다.**

### Step 2: 신규 파일 일괄 읽기 및 데이터 추출

**시간 단축 핵심**: 신규 파일들을 한 번에 모두 읽어서 데이터를 추출한 후, 마스터 파일에 한 번만 쓴다.

각 수협 NPL 파일을 읽을 때 다음 규칙을 반드시 적용한다:

#### 2-1. 이자율 파싱 규칙

| 원본 표현 | 이자율(%) | 연체 이자율(%) |
|-----------|-----------|---------------|
| `이자 3.5/12.0` | 3.5 | 12.0 |
| `3.5/12.0` | 3.5 | 12.0 |
| `연체 12.0%` | (비워둠) | 12.0 |
| `이자율 3.5%` | 3.5 | (비워둠) |

- `x.xx/y.yy` 형식: 슬래시 앞이 이자율, 뒤가 연체 이자율
- `연체 x.xx%` 형식: 연체 이자율만 있음
- 퍼센트 기호(%)는 제거하고 숫자만 저장

#### 2-2. 이자 금액 통합 규칙 (필수 — 모든 이자를 정상이자에 합산)

**핵심 원칙**: 원본 파일(첨부)에서 언급되는 **모든 종류의 이자 금액**을 합산하여 **정상이자(Q열)** 에 넣는다. **연체이자(R열)는 항상 0**으로 설정한다.

수협 NPL 파일에는 이자가 다양한 명칭으로 분리되어 있을 수 있다:

| 원본 파일의 이자 항목 예시 | 처리 방법 |
|---------------------------|----------|
| 정상이자 | **합산 → Q열** |
| 연체이자 | **합산 → Q열** (R열에 넣지 않음) |
| 기도래이자 | **합산 → Q열** |
| 미도래이자 | **합산 → Q열** |
| 이자(기도래) | **합산 → Q열** |
| 이자(미도래) | **합산 → Q열** |
| 가산이자 | **합산 → Q열** |
| 지연이자 | **합산 → Q열** |
| 약정이자 | **합산 → Q열** |
| 이자 합계 | **합산 → Q열** |
| 이자 소계 | **합산 → Q열** |

**처리 규칙:**
1. 원본 파일에서 "이자"라는 단어가 포함된 모든 금액 항목을 찾는다
2. 이들 금액을 모두 더한다
3. 합산된 금액을 **정상이자(Q열)** 에 입력한다
4. **연체이자(R열)는 무조건 0**으로 설정한다 — 원본에 연체이자가 있더라도 Q열 합산에 포함하고 R열은 0

```python
# 예시: 이자 항목 합산 로직
interest_keywords = ['이자', '기도래', '미도래', '가산이자', '지연이자', '약정이자']

total_interest = 0
for col_name, value in row_data.items():
    if any(kw in str(col_name) for kw in interest_keywords):
        amount = parse_amount(value)  # 금액 파싱
        if amount:
            total_interest += amount

# 마스터 파일에 기록
row['정상이자'] = total_interest   # Q열: 모든 이자 합산
row['연체이자'] = 0                # R열: 항상 0
```

**주의**: 이 규칙은 이자 "금액"에 대한 것이다. 이자율(%)/연체이자율(%) 컬럼(W열, X열)의 파싱은 기존 2-1 규칙을 따른다.

#### 2-3. 주소 조합 규칙

담보물 소재지가 명확하지 않은 경우:
1. 문서에서 "시/군/구/동" 정보를 찾는다
2. "지번" 정보를 찾는다
3. 두 정보를 합쳐서 주소를 만든다

#### 2-4. PDF 회전 페이지 및 스캔 이미지 PDF 처리 규칙 (필수 — 3단계 프로세스)

수협 NPL 공고문 PDF에는 매각대상채권 명세서가 **가로 방향(landscape)으로 스캔된 이미지**로 포함되는 경우가 많다.
이 경우 텍스트 추출이 불가능하며, 주소·금액 등 핵심 데이터를 잘못 읽는 치명적 오류가 발생할 수 있다.
**반드시 아래 3단계 프로세스를 순서대로 수행**한다.

##### 단계 1: 텍스트 추출 가능 여부 진단

각 PDF 페이지에서 텍스트가 추출되는지 먼저 확인한다.

```python
import pdfplumber

def diagnose_pdf_pages(pdf_path):
    """각 페이지의 텍스트 추출 가능 여부와 이미지 포함 여부를 진단한다."""
    results = []
    with pdfplumber.open(pdf_path) as plumber:
        for i, page in enumerate(plumber.pages):
            chars = page.chars
            images = page.images
            has_text = len(chars) > 0
            has_images = len(images) > 0
            results.append({
                'page': i + 1,
                'has_text': has_text,
                'char_count': len(chars),
                'image_count': len(images),
                'is_scanned_image': (not has_text and has_images),
                'width': page.width,
                'height': page.height
            })
            print(f"Page {i+1}: text={has_text}({len(chars)}chars), images={len(images)}, scanned={'YES' if not has_text and has_images else 'no'}")
    return results
```

| 진단 결과 | 처리 방법 |
|-----------|----------|
| `has_text=True` | → 단계 1-A: 일반 텍스트 추출 (기존 방식) |
| `is_scanned_image=True` | → **단계 2: 이미지 렌더링 + 시각 확인** (아래) |

##### 단계 1-A: 텍스트 추출 가능한 페이지 — /Rotate 보정 후 추출

PDF 메타데이터에 `/Rotate` 값이 90도 또는 270도로 설정된 경우, 텍스트 추출 전에 0도로 보정한다.

```python
import pikepdf

def normalize_pdf_rotation(input_pdf, output_pdf):
    """회전된 PDF 페이지를 0도로 보정한다. 원본은 수정하지 않는다."""
    pdf = pikepdf.open(input_pdf)
    rotated = False
    for page in pdf.pages:
        rot = int(page.get("/Rotate", 0))
        if rot in (90, 270):
            page["/Rotate"] = 0
            rotated = True
    if rotated:
        pdf.save(output_pdf)
        pdf.close()
        return output_pdf
    pdf.close()
    return input_pdf  # 회전 없으면 원본 그대로
```

##### 단계 2: 스캔 이미지 PDF — 이미지 렌더링 + 회전 보정 + 시각 확인

**핵심 원칙**: 스캔된 이미지 PDF에서 텍스트가 0개인 페이지는,
이미지를 고해상도로 렌더링한 뒤 **올바른 방향으로 회전하여 직접 눈으로(view 도구로) 확인**해야 한다.
절대로 context window에 표시된 저해상도 축소 이미지만으로 주소·금액을 판독하지 않는다.

```python
import pdfplumber
from PIL import Image

def render_and_orient_page(pdf_path, page_index, output_dir='/home/claude'):
    """스캔 이미지 페이지를 고해상도 렌더링 후, 올바른 방향으로 회전하여 저장한다."""
    with pdfplumber.open(pdf_path) as plumber:
        page = plumber.pages[page_index]
        # 1) 고해상도 렌더링 (300dpi)
        img = page.to_image(resolution=300)
        raw_path = f"{output_dir}/page{page_index+1}_raw.png"
        img.save(raw_path)
        
        # 2) 원본 이미지 열기
        pil_img = Image.open(raw_path)
        w, h = pil_img.size
        
        # 3) 가로/세로 비율로 landscape 여부 판단 후 회전 시도
        #    landscape 스캔이면 세로로 읽히므로 회전 필요
        rotations_to_try = [0, 90, -90, 180]
        saved_paths = []
        for rot in rotations_to_try:
            if rot == 0:
                rotated = pil_img
            else:
                rotated = pil_img.rotate(rot, expand=True)
            path = f"{output_dir}/page{page_index+1}_rot{rot}.png"
            rotated.save(path)
            saved_paths.append((rot, path))
        
        return saved_paths
```

**처리 순서:**

1. `render_and_orient_page()`로 해당 페이지를 0도, 90도, -90도, 180도 회전한 이미지 4장을 생성한다
2. **`view` 도구로 각 이미지를 확인**하여 테이블이 정상적으로 읽히는 방향을 찾는다
3. 올바른 방향의 이미지에서 데이터를 직접 읽어 추출한다

```
# 실제 실행 예시
view /home/claude/page3_rot0.png    ← 원본 방향
view /home/claude/page3_rot90.png   ← 시계 반대 방향 90도
view /home/claude/page3_rot-90.png  ← 시계 방향 90도
# → 테이블이 정상적으로 보이는 이미지를 찾는다
```

##### 단계 3: 이미지에서 데이터 수동 추출 시 검증 규칙

스캔 이미지에서 읽은 데이터는 오독 위험이 높으므로, 반드시 다음 교차 검증을 수행한다:

| 검증 항목 | 방법 |
|-----------|------|
| **주소 정합성** | 명세서 페이지의 "담보물건 소재지"와, 회수예상조회 페이지(텍스트 추출 가능)의 관리점번호·대출일자 등으로 물건 매칭 확인 |
| **금액 정합성** | 명세서의 합계 = 원금 + 가지급금 + 이자(기도래) + 이자(미도래) 가 맞는지 산술 검증 |
| **경매번호** | 비고란에 기재된 경매번호와 법원명이 담보물 소재지의 관할법원과 일치하는지 확인 |
| **채무자명** | 명세서의 채무자와 회수예상조회의 고객정보 이름이 일치하는지 확인 |

**주소 오독이 발생하기 쉬운 패턴:**

| 오독 예 | 실제 | 원인 |
|---------|------|------|
| `걸포1로 마도1길 663-3` | `마산동 663-3` | 세로 스캔 테이블에서 인접 셀의 텍스트가 혼합 |
| `비전8길 471-1` | `용이동 471-1` | 동일한 원인 |
| `1마도 1길` | `마산동` | 숫자와 한글이 분리되어 잘못 조합 |

**대응**: 스캔 이미지 PDF의 주소는 **반드시 고해상도 회전 이미지에서 직접 확인**하고,
가능하면 같은 PDF의 다른 페이지(회수예상조회 등)나 공고문 본문의 정보와 교차 확인한다.

**주의**: 원본 PDF는 절대 수정하지 않는다. 모든 렌더링·회전 결과는 `/home/claude/` 임시 디렉토리에 저장한다.

#### 2-5. "붙임 자료 참조" / "붙임" 처리 규칙

문서 내에 "붙임 자료 참조" 또는 "붙임"이라는 표현이 있는 경우:
1. **먼저** 같은 폴더 내에 별도 첨부 파일이 있는지 확인한다
2. 별도 파일이 **없으면**, 해당 문서의 **아래쪽 전체 내용**을 확인한다
   - "붙임" 텍스트 이후의 모든 시트, 모든 행을 끝까지 확인한다
   - 숨겨진 시트가 있는지도 확인한다
3. 추출한 정보를 해당 물건의 데이터에 반영한다

#### 2-6. 금액 파싱 규칙

- 쉼표(,)가 포함된 숫자는 쉼표를 제거하고 숫자로 변환
- "천원", "만원", "백만원", "억원" 단위가 있으면 원 단위로 환산
- "원" 글자는 제거
- 빈 셀이나 "-"는 0 또는 빈 값으로 처리

#### 2-7. 금액 셀 콤마 서식 적용 규칙 (★ 필수)

금액 컬럼(O~V열)에 숫자를 쓸 때는 **반드시** `#,##0` 서식을 적용한다.
기존 행을 갱신할 때도, 신규 행을 추가할 때도 동일하게 적용한다.

```python
AMOUNT_COLS = {
    15: 'O(감정가)',
    16: 'P(대출잔액)',
    17: 'Q(정상이자)',
    18: 'R(연체이자)',
    19: 'S(가지급금)',
    20: 'T(채권합계)',
    21: 'U(매각희망)',
    22: 'V(채권최고액/우선수익금액)',
}
COMMA_FORMAT = '#,##0'

# 값을 쓴 직후 서식 적용
for col_idx in AMOUNT_COLS:
    cell = ws.cell(row=target_row, column=col_idx)
    if cell.value is not None and isinstance(cell.value, (int, float)):
        cell.number_format = COMMA_FORMAT
```

저장 전 전체 데이터 행(4행~마지막 행)을 순회하며 서식 누락 셀을 일괄 보정한다.

### Step 3: 마스터 파일 업데이트 (기존 데이터 보존)

1. **기존 마스터 파일 로드**: `openpyxl`로 기존 파일을 열어 헤더, 서식, 병합셀, 기존 데이터 모두 유지
2. **기존 데이터 절대 삭제 금지**: 기존 행은 읽기 전용으로 취급
3. **중복 체크**: 채무자 + 담보물 소재지 + 수협명으로 동일 물건 여부 판별
   - 동일 물건이 있으면 → 해당 행만 **갱신**, Update된 일자를 오늘로 변경
   - 새 물건이면 → 마지막 행 아래에 **추가**
4. **Update된 일자**: 신규/갱신된 행의 F컬럼에만 오늘 날짜 입력
5. **No. 재부여**: 전체 순번을 1부터 다시 매김

### Step 4: 수협명 필터 적용

마스터 파일의 C열(수협명)에 Excel 자동 필터(AutoFilter)를 설정한다.

```python
ws.auto_filter.ref = f"B3:Y{last_row}"
```

### Step 5: 서식 유지 및 저장

- 기존 파일의 서식(폰트, 셀 너비, 병합셀, 정렬 등)을 최대한 유지
- 새로 추가된 행에도 기존 행과 동일한 서식 적용
- **금액 컬럼(O~V)에는 반드시 `#,##0` 콤마 서식 적용** — 신규/갱신 행뿐만 아니라 저장 전 전체 행 일괄 보정
- 완성된 파일을 마스터 경로(`수협NPL 전체현황.xlsx`)에 저장 (Claude Code 환경), 또는 `/mnt/user-data/outputs/수협NPL_전체현황.xlsx` (Claude.ai 업로드 환경)

```python
# 저장 전 전체 금액 셀 서식 일괄 보정
AMOUNT_COLS = [15, 16, 17, 18, 19, 20, 21, 22]  # O~V
for row in ws.iter_rows(min_row=4, max_row=ws.max_row):
    if row[1].value is None:
        continue
    for col_idx in AMOUNT_COLS:
        cell = ws.cell(row=row[0].row, column=col_idx)
        if cell.value is not None and isinstance(cell.value, (int, float)):
            cell.number_format = '#,##0'
```

## 시간 단축 처리 전략

1. **신규 파일만 처리**: 마스터 파일의 기존 데이터는 읽기만 하고 수정하지 않는다
2. **일괄 읽기 → 일괄 쓰기**: 모든 신규 파일을 먼저 읽고, 마스터 파일에 한 번만 쓴다
3. **자동화 스크립트 우선 사용**: `scripts/extract_and_update.py`를 먼저 실행하고, 실패한 파일만 수동 처리
4. **불필요한 재처리 방지**: 이미 마스터에 있는 데이터를 다시 파싱하지 않는다

## 주의사항

- 원본 파일은 절대 수정하지 않는다. 마스터 파일만 업데이트한다.
- **기존 마스터 데이터는 절대 삭제하지 않는다.** 신규 파일 데이터만 추가/갱신한다.
- 데이터 파싱에 실패한 필드는 빈 셀로 남기고, 비고(W)컬럼에 "파싱 실패" 표기한다.
- 하나의 파일에 여러 물건이 있을 수 있다. 모든 물건을 빠짐없이 추출한다.
- 숨겨진 시트나 행이 있을 수 있으므로, `ws.sheet_state`와 `ws.row_dimensions`를 확인한다.
