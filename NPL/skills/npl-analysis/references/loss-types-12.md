## 매입 후 실패/손실 유형 분석 (12대 리스크)

NPL 매입 후 실패하거나 손실을 보는 대표적 유형을 아래에 정리합니다. 
매입 검토 시 각 유형에 해당하는 리스크가 있는지 반드시 사전 점검해야 합니다.

---

### 유형 1 — 담보물 시세 하락에 의한 배당 부족

- **발생 원인**: 매입 당시 감정가·시세 기준으로 배당액을 산정했으나, 경매 진행 중 부동산 시장 하락으로 낙찰가가 예상보다 크게 하락
- **손실 구조**: 매입가 > 실제 배당액 → 원금 미회수
- **실무 사례**: 부동산 경기 하락기에 감정가 대비 50~60%에도 유찰이 반복되어 최저매각가가 채권 매입가 이하로 하락
- **방지 대책**: 
  - 감정가가 아닌 실거래가·시세 기준으로 보수적 낙찰가 예측 (감정가의 60~70% 수준으로 산정)
  - 부동산 경기 하향 국면에서는 추가 할인율 10~20% 적용
  - 유동성 낮은 물건(비주거, 지방 소재, 특수용도)은 낙찰가 예측을 더욱 보수적으로 설정

### 유형 2 — 선순위 채권(조세·임금 등) 과다로 배당 잠식

- **발생 원인**: 매입 시 선순위 조세채권(당해세, 국세, 지방세), 최우선변제 임차인, 임금채권 등의 규모를 정확히 파악하지 못함
- **손실 구조**: 낙찰가에서 선순위 채권 배당 후 당사 순위까지 배당 잔액 부족
- **실무 사례**: 체납 국세·지방세가 수천만 원 존재하나 등기부에 나타나지 않아 사전 미파악 → 배당 시 당사 채권 전액 미배당
- **방지 대책**:
  - 국세·지방세 체납 여부 반드시 확인 (세무서·구청 조회 또는 채무자 탐문)
  - 최우선변제 소액임차인 존재 여부 및 보증금 규모 현장 확인
  - 임금채권(근로기준법상 최우선변제) 존재 가능성 확인 (법인 채무자의 경우)

### 유형 3 — 대항력 있는 임차인 인수 리스크

- **발생 원인**: 말소기준권리보다 선순위 대항력을 갖춘 임차인이 배당요구를 하지 않거나, 배당요구 후 취하한 경우
- **손실 구조**: 임차인 보증금이 낙찰자에게 인수 → 낙찰가 대폭 하락 → 배당액 급감
- **실무 사례**: 
  - 대항력 있는 임차인이 배당요구 취하 → 대항력 부활 → 낙찰가에서 보증금 공제 → 당사 배당액 대폭 감소
  - 근저당 설정 전 임차보증금 증액 사실을 미파악 → 숨은 대항력 보증금 발견 → 낙찰가 하락으로 배당 손실
- **방지 대책**:
  - 체크리스트 ①~④ 항목 철저 점검
  - 임차권등기명령 여부, 확정일자, 배당요구 여부, 취하 여부 전수 조사
  - 전입세대 확인서 열람 및 현장 탐문으로 실제 거주자·보증금 확인
  - 특히 근저당 설정 전 2년 이상 거주 임차인의 증액보증금 반드시 확인

### 유형 4 — 경매 장기 지연에 따른 기회비용 손실

- **발생 원인**: 채무자의 경매정지·취소 신청, 회생·파산 신청, 소유권 분쟁, 유치권 주장 등으로 경매가 장기간 지연
- **손실 구조**: 매입 자금 장기 묶임 → 이자 비용 누적 → 실질 수익률 대폭 하락 또는 마이너스 전환
- **실무 사례**: 채무자가 개인회생 신청 → 경매 중지 → 1~2년 이상 자금 회수 불가 → 질권 대출 이자만 계속 발생
- **방지 대책**:
  - 채무자 파산·회생 가능성 사전 조사 (⑯번 항목)
  - 유치권 신고 여부 확인
  - 소유권 관련 분쟁(가처분, 소유권이전청구소송 등) 존재 여부 확인
  - 자금 운용 기간을 보수적으로 6개월~1년으로 산정하고, 이자 비용 반영하여 매입가 산정

### 유형 5 — 유치권 주장에 의한 낙찰가 하락·매각 불능

- **발생 원인**: 담보 부동산에 공사대금 등을 이유로 유치권이 신고되어 있거나, 낙찰 후 유치권 주장 발생
- **손실 구조**: 유치권 존재 시 입찰자 기피 → 낙찰가 대폭 하락 또는 유찰 반복 → 배당액 급감
- **실무 사례**: 건물 신축 후 공사대금 미지급 → 시공사 유치권 행사 → 수억 원 유치권 주장으로 다수 유찰 → 최저가 폭락
- **방지 대책**:
  - 현황조사서에서 유치권 신고 여부 반드시 확인
  - 유치권 금액과 실체(점유 사실, 공사 실제 여부) 현장 조사
  - 유치권이 허위인 경우 법적 대응 비용·기간도 함께 산정
  - 유치권 존재 물건은 매입 매우 신중 또는 포기 검토

### 유형 6 — 공동담보 이시배당에 의한 배당액 감소

- **발생 원인**: 공동담보 물건 중 다른 물건에서 선배당이 이루어진 후, 당해 물건에서 후순위 채권자의 대위 발생
- **손실 구조**: 당사 예상 배당액보다 실제 배당액이 감소 → 매입가 대비 수익률 하락 또는 손실
- **실무 사례**: A, B 두 물건이 공동담보 → A에서 1순위 채권자가 전액 배당 → B에서 후순위 채권자가 대위하여 당사 배당 잠식
- **방지 대책**:
  - 체크리스트 ⑰·㉑번 항목 연계 검토
  - 공동담보목록 확인 후 다른 담보물의 경매 진행 상황 조회
  - 동시배당·이시배당 양 시나리오로 배당표를 각각 작성하여 최악 시나리오 기준 매입가 산정

### 유형 7 — 배드뱅크·정책 변동에 의한 강제 매각 손실

- **발생 원인**: 정부 정책(배드뱅크, 새출발기금 등)에 의해 보유 채권을 매입가 이하로 매각해야 하는 상황 발생
- **손실 구조**: 매입가 14% → 배드뱅크 매입 기준 5% → 약 65% 원금 손실
- **실무 사례**: 2025년 캠코 배드뱅크 운용 시 소상공인 장기연체 채권 매입 기준이 0.92~13.46%로 설정 → 고가 매입 업체 대규모 손실
- **방지 대책**:
  - 금융당국 정책 동향 상시 모니터링
  - 소상공인·서민 대상 채권은 정책 리스크 반영하여 매입가 보수적 산정
  - 특정 유형 채권(소상공인 연체 등)에 대한 집중도 분산
  - 질권·담보권 부 채권의 정책 매각 대상 포함 여부 사전 확인

### 유형 8 — 고가 매입 후 배당 부족 (과열 경쟁)

- **발생 원인**: 다수 NPL 업체 간 경쟁 입찰로 채권 매입가가 과도하게 상승, 또는 AMC의 고가 추천 물건을 무비판 매입
- **손실 구조**: 채권 매입가 > 실제 배당 예상액 → 구조적 손실 확정
- **실무 사례**: 
  - AMC 사업설명회에서 수익성 없는 물건을 수익성 있는 것처럼 추천 → 매입 후 유입(직접 낙찰) 강제 → 수수료·컨설팅비만 지출
  - 경쟁 입찰로 채권최고액의 80~90%에 매입 → 낙찰가 하락 시 원금 미회수
- **방지 대책**:
  - 체크리스트 ⑮번(기록열람신청서 접수) 확인으로 경쟁 강도 파악
  - 매입가는 반드시 자체 배당 분석 기준으로 산정 (AMC 추천가에 의존 금지)
  - 목표 수익률(최소 연 15% 이상) 확보 불가 시 과감히 포기
  - 매입률(매입가/채권액) 상한선 자체 기준 설정 및 준수

### 유형 9 — 지분 경매·공유물 분쟁으로 인한 처분 곤란

- **발생 원인**: 경매 목적물이 부동산 전체가 아닌 특정 지분(공유지분)인 경우
- **손실 구조**: 낙찰 받아도 단독 사용·수익 불가 → 매각·임대 곤란 → 자금 장기 묶임
- **실무 사례**: 공유자가 우선매수권 행사 → 실질 낙찰 무산, 또는 공유물분할 소송으로 추가 비용·시간 소요
- **방지 대책**:
  - 체크리스트 ⑱·⑲번 항목 점검
  - 지분 경매 물건은 공유자 수, 지분 비율, 공유자 의향 사전 조사
  - 지분 경매 물건의 매입은 원칙적으로 지양하거나, 할인율 대폭 상향 적용 (최소 30% 이상)

### 유형 10 — 불법건축물·위반건축물로 인한 담보 가치 하락

- **발생 원인**: 담보 부동산이 불법·위반건축물로서 이행강제금 부과, 담보대출 불가, 매각 곤란
- **손실 구조**: 입찰자 기피 → 유찰 반복 → 낙찰가 대폭 하락 → 배당 부족
- **실무 사례**: 건축물대장상 위반건축물 표시 미확인 → 매입 후 경매 시 다수 유찰 → 최저가 폭락
- **방지 대책**:
  - 체크리스트 ⑥·⑦번 항목 점검
  - 건축물대장 표제부 '위반건축물' 표시 반드시 확인
  - 공부상 용도와 실제 사용 용도 불일치 여부 현장 확인

### 유형 11 — 채무자 회생·파산에 의한 경매 중단

- **발생 원인**: NPL 매입 후 채무자가 개인회생·파산 신청 → 경매 절차 중지(자동정지)
- **손실 구조**: 경매 중단 → 자금 장기 묶임 → 회생계획 인가 시 채권 대폭 감축 가능
- **실무 사례**: 매입 직후 채무자 개인회생 신청 → 경매 중지 → 회생계획에서 채권 80% 감면 → 잔여 20%만 분할 수령
- **방지 대책**:
  - 체크리스트 ⑯번 항목 최우선 점검
  - 채무자의 재무 상태, 다른 채무 규모 사전 조사
  - 법원 파산·회생 사건 검색으로 기신청 여부 확인
  - 담보권자는 회생절차에서 별제권 행사 가능하나, 절차 지연 리스크는 불가피

### 유형 12 — 리스크 집중(포트폴리오 편중)에 의한 대규모 손실

- **발생 원인**: 특정 지역·물건 유형·단일 대규모 담보에 매입 자금이 편중
- **손실 구조**: 해당 지역·유형의 시장 악화 시 복수 물건에서 동시 손실 → 회사 전체 건전성 위험
- **실무 사례**: 수백억 원 규모의 단일 사업장 담보 NPL 인수 → 해당 사업장 경매 유찰 반복 → 리스크 분산 불가로 대규모 손실
- **방지 대책**:
  - 물건당 투자 한도 설정 (전체 운용 자금의 10~15% 이내)
  - 지역·용도·규모별 분산 투자 원칙 수립
  - 대규모 단일 담보 물건보다 소규모 다수 물건 포트폴리오 구성 선호
  - 은행권 NPL 묶음 매입 시 개별 물건별 분석 필수 (80~100건 묶음이라도 각 물건 검토)

## 손실 방지 종합 체크리스트 (매입 전 최종 점검)

매입 결정 전 아래 10가지 질문에 모두 "예"로 답할 수 있어야 합니다.

| # | 점검 항목 | 예/아니오 |
|---|----------|-----------|
| 1 | 감정가가 아닌 실거래가·시세 기준으로 보수적 낙찰가를 예측했는가? | |
| 2 | 선순위 채권(조세, 임금, 최우선변제 임차인) 규모를 모두 파악했는가? | |
| 3 | 대항력 있는 임차인의 보증금 및 배당요구/취하 여부를 확인했는가? | |
| 4 | 유치권 신고 여부 및 실체를 현장 조사로 확인했는가? | |
| 5 | 공동담보 여부 확인 후 이시배당 시나리오 배당표를 작성했는가? | |
| 6 | 채무자 회생·파산 신청 가능성을 조사했는가? | |
| 7 | 불법건축물·위반건축물 여부를 건축물대장에서 확인했는가? | |
| 8 | 경매 지연 시 이자 비용을 반영한 수익률을 산정했는가? | |
| 9 | 자체 배당 분석 기준으로 매입가를 산정했는가? (AMC 추천가 맹신 금지) | |
| 10 | 포트폴리오 집중 리스크를 점검했는가? (물건당 한도, 지역 분산) | |

**판정 기준**:
- 10개 모두 "예" → 매입 진행 가능
- 7~9개 "예" → 미확인 항목 보완 후 매입 재검토
- 6개 이하 "예" → 매입 보류 또는 포기 권장
