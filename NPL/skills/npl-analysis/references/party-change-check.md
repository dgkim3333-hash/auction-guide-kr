# 당사자(소유자/채무자) 표시 변경 체크리스트

## 목적

경매·공매 법원물건접수 또는 송달내역에서 **당사자 표시가 중간에 변경된 경우**를
놓치지 않고 식별하여, NPL 매입 전 **상속·변호사 선임·법인전환·공시송달 등 숨은 리스크**를
사전에 파악한다.

이 모듈은 npl-analysis, residential-auction, small-building-auction,
commercial-unit-auction, land-auction, trust-npl-analysis 등 모든 NPL/경매 분석
스킬에서 공통으로 사용한다.

---

## 🚨 핵심 원칙

> **당사자 표시 변경은 단일 원인으로 단정하지 않는다.**
> **상속·변호사 선임·법인전환·공시송달 등 여러 원인이 단독 또는 병행 발생할 수 있으므로,**
> **반드시 등기부등본 + 법원 사건검색 + 법원 직접 조회의 3대 교차 확인을 수행한다.**

---

## 🔍 당사자 표시 변경 패턴 — 4가지 유형 (단독 또는 병행)

### 【유형 A】 상속 개시 — 소유자/채무자 사망

**패턴:**
```
Before: "홍OO"
After:  "망 홍OO의 상속인 OOO 외 N인"
```

**트리거 키워드:**
- 송달내역에 "**송달간주**" 반복 발생
- 당사자 측 "**송달장소 및 송달영수인 신고서**" 제출
- 채권자 측 "**당사자표시정정신청**" 제출
- 법원의 "**경정결정정본**" 발송
- 경정 후 표시가 **장문 + 상속인 표기 구조**

**확정 방법:**
- 등기부등본 재발급 → **소유권 상속이전 등기** 확인
- 법원 사건검색 → "**망**" / "**상속인**" 표기 확인

**NPL 리스크:**
- 🚨 상속포기 / 한정승인 (사망일로부터 3개월)
- 🚨 상속인 전원 송달 완료 (+1~3개월)
- 🚨 미성년 / 해외거주 상속인 (+1~6개월)
- 🚨 상속재산분할협의 진행 시 일시정지

**할인율 반영: +10~15%**

---

### 【유형 B】 변호사 선임 — 소송대리인 표시 병기

**패턴:**
```
Before: "홍OO"
After:  "소유자 홍OO의 소송대리인 법무법인 △△ 담당변호사 □□□"
       또는
       "채무자 홍OO 대리인 ○○법률사무소 변호사 △△△"
```

**트리거 키워드:**
- 채무자/소유자 측 "**소송위임장**" 제출 ← 결정적 증거
- 채무자/소유자 측 "**의견서**" 제출 (변호사 작성 의견서)
- 채무자/소유자 측 "**매각부동산 재평가 신청서**" 제출
- 채무자/소유자 측 "**경매개시결정에 대한 이의신청**" 제출
- 채권자 측 "**당사자표시정정신청**" 제출 (상대방 대리인 병기 요청 포함)

**확정 방법:**
- 법원 사건검색 → "**소송대리인**" / "**변호사**" 표기 확인
- 대한변호사협회 변호사 검색 → 담당변호사 실존 확인
- 법원 "사건 당사자 및 대리인 열람" 직접 조회

**특히 물상보증 구조에서 주의:**
- 채무자와 소유자가 다른 경우(물상보증인)
- **채무자·소유자가 각자 변호사를 선임하는 B+B 병행**이 실무적으로 일반적
- 한 명이 선임했다고 해서 다른 쪽도 선임했다고 단정하지 말고, 반드시 교차 확인

**NPL 리스크:**
- 🚨 경매개시결정 이의신청 / 집행정지 가처분 (+3~6개월)
- 🚨 청구이의의 소 본안소송 (+6~12개월 + 채권 감액 리스크)
- 🚨 감정평가 이의 / 재평가 신청 (최저가 상향 + 유찰 유도)
- 🚨 즉시항고·재항고로 시간 끌기 (+6개월 누적)
- 🚨 일부변제 협상 카드로 할인 압박 (매입가 하향 압력)
- ⚠️ NPL 매수자 측 대응 변호사 선임 비용 추가

**할인율 반영: +8~12% (단독) / +12~18% (B+B 병행)**

---

### 【유형 C】 법인 전환 / 신탁 이전

**패턴:**
```
Before: "홍OO"
After:  "OO주식회사 대표이사 홍OO"  또는  "OO신탁 수탁자"
```

**트리거 키워드:**
- "**소유권이전**" 등기 발생
- "**신탁계약**" 설정
- "**법인 대표이사**" 명의로 송달

**NPL 리스크:**
- 🚨 신탁 이전 시 담보신탁 공매로 전환 (일반경매 무효)
- 🚨 사해행위 취소 대상 여부 (경매 시점 ±1년 이내 전환)
- 🚨 법인 도산·회생 시 자동 정지

**할인율 반영: 재실사 필수**

---

### 【유형 D】 송달 주소 불명 / 공시송달 대비

**패턴:**
```
Before: "홍OO"
After:  "소재불명 홍OO 최후주소 서울..."  또는  "공시송달 대상"
```

**트리거 키워드:**
- "**공시송달**" 결정
- "**송달간주**"가 3회 이상 반복
- "**주소불명**", "**폐문부재**" 기록

**NPL 리스크:**
- 🚨 공시송달 진행 시 절차상 하자 주장 가능 → 향후 소송 리스크
- 🚨 당사자 출현 시 경매 취소 소송 가능성

**할인율 반영: +5~8%**

## 🔀 병행 시나리오 — 여러 유형 동시 발생

| 조합 | 시나리오 | 추가 지연 | 할인율 |
|------|---------|----------|--------|
| **A + B** | 소유자 사망 → 상속인이 변호사 선임 | +6~12개월 | **+15~25%** |
| **B + B** | 채무자·소유자 각각 변호사 선임 (물상보증) | +6~9개월 | **+12~18%** |
| **A + D** | 상속인 소재불명 → 공시송달 | +6~9개월 | **+15~20%** |
| **B + C** | 법인 대표이사가 변호사 선임 | +6~9개월 | 재실사 + +10% |

**실무 주의사항:**
- 한 경정결정에서 **여러 유형이 동시에 반영**될 수 있음
- 당사자 표시가 길어진 이유가 "A 때문인지 B 때문인지" **단독 판정 금지**
- 반드시 **등기부등본 + 법원 사건검색 + 법원 직접 조회** 3가지 교차 확인
- 특히 **물상보증 구조**에서는 **B+B 병행**을 기본 가정으로 시작

## 📋 표준 체크리스트

### Step 1: 법원물건접수 정밀 스캔

```
[ ] 송달내역 전체를 시간순으로 확인
[ ] 동일 역할(소유자/채무자)의 표시가 변한 시점 식별
[ ] "송달간주" 표시 횟수 카운트 (3회 이상이면 D형 의심)
[ ] "당사자표시정정신청" 기록 확인
[ ] "경정결정정본" 발송 기록 확인
[ ] "소송위임장" 제출 기록 확인 (B형 결정적 증거)
[ ] "의견서" / "재평가 신청서" / "이의신청서" 제출 기록 확인
[ ] "보정명령" 또는 "보정서" 기록 확인
```

### Step 2: 변경 유형 판정 (단독 + 병행 동시 고려)

```
[1단계: B형 (변호사 선임) 우선 체크]
IF "소송위임장" OR "의견서" OR "재평가 신청" 제출:
    → B형 가능성 ★★★★★
    → 법원 사건검색에서 "소송대리인" 표기 확인

[2단계: A형 (상속) 체크]
IF "송달간주" 반복 AND "송달영수인 신고서" AND 경정 후 장문 표시:
    → A형 가능성 ★★★★☆
    → 등기부등본 재발급으로 상속이전 등기 확인

[3단계: 물상보증 구조 체크]
IF 채무자 ≠ 소유자:
    → B+B 병행 가능성을 기본 가정
    → 양쪽 모두 변호사 선임 여부 교차 확인

[4단계: 병행 가능성 종합]
IF B형 증거 AND A형 증거 모두 있음:
    → A+B 병행 (최악 케이스)
    → 양쪽 모두 리스크 반영

[5단계: C형 / D형 추가 체크]
IF "주식회사" / "대표이사" / "신탁": C형 추가
IF "공시송달" / "소재불명": D형 추가
```

### Step 3: 3대 교차 확인 (필수 — 하나만으로 단정 금지)

1. **등기부등본 재발급**
   - 소유권 상속이전 등기 → A 확정
   - 신탁·법인 이전 등기 → C 확정
   - 변경 없음 → B 또는 D

2. **법원 사건검색 (대법원 나의사건검색)**
   - `www.scourt.go.kr` → 사건번호 조회
   - 당사자 상세에서 "망", "상속인", "소송대리인", "변호사" 키워드 확인

3. **법원 경매계 직접 조회**
   - 전화 문의가 가장 빠르고 정확
   - 성남지원 경매7계 예시: 031-737-1327
   - "당사자 및 대리인 상세 표시 확인" 요청

### Step 4: 분석 리포트 필수 포함 섹션

```markdown
## ⚠️ 당사자 표시 변경 분석

| 항목 | 내용 |
|------|------|
| 최초 표시 (YYYY.MM.DD) | 홍OO |
| 변경 표시 (YYYY.MM.DD) | 소OO OOOO OOOOO OOO OOO |
| 시나리오 A (상속) 가능성 | ★★★☆☆ |
| 시나리오 B (변호사 선임) 가능성 | ★★★★☆ |
| A+B 병행 가능성 | ★★★☆☆ |
| 경정 계기 | 2026.01.09 채권자 당사자표시정정신청 |
| A형 증거 | 송달간주 반복, 송달영수인 신고서 제출 |
| B형 증거 | 소송위임장 제출, 재평가 신청 |
| 물상보증 여부 | 채무자 ≠ 소유자 → B+B 병행 기본 가정 |
| 추가 지연 예상 | 3~12개월 (시나리오별) |
| 교차 확인 필요 | ① 등기부등본 ② 법원 사건검색 ③ 경매계 직접 조회 |
| 핵심 리스크 | 변호사 전략 대응 + 상속 여부 불명 |
| 최종 할인율 반영 | +12~18% (A+B 병행 가정) |
```

### Step 5: GO/NO-GO 판정에 반영

| 유형 | 단독 | 병행 |
|------|------|------|
| A만 | +10~15% | — |
| B만 | +8~12% | — |
| C만 | 재실사 필수 | — |
| D만 | +5~8% | — |
| **A+B** | — | **+15~25%** |
| **B+B** (물상보증) | — | **+12~18%** |
| A+D | — | +15~20% |
| B+C | — | 재실사 + +10% |

## 📝 스킬 통합 지침

각 NPL/경매 분석 스킬의 워크플로우에 다음 단계를 **반드시 삽입**:

```markdown
### Step N: 당사자 표시 변경 체크 (필수)

법원물건접수 PDF 또는 송달내역 확보 시, 반드시
`references/party-change-check.md`를 읽어 체크리스트 수행.

변경 감지 시:
1. 유형 A/B/C/D 및 병행 가능성 분석
2. 물상보증 구조에서는 B+B 병행 기본 가정
3. 등기부등본 + 법원 사건검색 + 법원 직접 조회 3대 교차 확인
4. 리포트에 "당사자 표시 변경 분석" 독립 섹션 추가
5. GO/NO-GO 판정에 할인율 반영 (단독 vs 병행)
```

## 📌 핵심 교훈

> **"당사자 표시 변경은 한 가지 원인으로 단정하지 않는다."**
>
> **① 상속(A), ② 변호사 선임(B), ③ 법인·신탁(C), ④ 공시송달(D)**
>
> **특히 물상보증 구조(채무자 ≠ 소유자)에서는**
> **채무자·소유자가 각각 변호사를 선임하는 B+B 병행이 일반적이며,**
> **상속(A)과 결합하면 최악 시나리오(+15~25% 할인)가 된다.**
>
> **등기부등본 + 법원 사건검색 + 법원 직접 조회의 3대 교차 확인만이**
> **정확한 판정을 가능하게 한다.**
