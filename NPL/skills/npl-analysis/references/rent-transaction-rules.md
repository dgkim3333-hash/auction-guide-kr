## 국토부 전월세 실거래가 분석 규칙 (임차권·임대수익·배당 교차검증 필수 작업)

매매 실거래가가 "낙찰가 예측"의 기초라면, **전월세 실거래가는 임차권 리스크 판정·임대수익률 평가·소액임차인 배당 판정의 기초**가 된다. NPL 매입 실패의 주요 유형 중 "대항력 있는 임차인 보증금 인수" 및 "소액임차인 최우선변제 배당 누락"은 전월세 실거래가로만 정확히 검증되므로, 아래 경우 **반드시 전월세 실거래가 조회를 수행**한다.

### 전월세 조회 필수 케이스 (5가지)

하나라도 해당하면 전월세 실거래가 조회를 **생략할 수 없다**:

| 케이스 | 조회 목적 |
|--------|---------|
| **① 임차인이 존재하는 물건** | 보증금 적정성 검증 → 허위·과다 임차 판정 근거 |
| **② 대항력 있는 임차인 존재** | 시장 보증금 시세 대비 인수 부담액 산정 |
| **③ 소액임차인 해당 여부 판정 필요** | 소액임차인 기준 범위의 시장 보증금 분포 확인 |
| **④ 상업용·주거용 임대수익 기반 가치평가** | 수익환원법 Cap Rate 산정용 월세 시세 확보 |
| **⑤ 깡통전세 리스크 평가 (주거용)** | 전세가율 추적 → 낙찰 후 재매각 시 실매수 수요 판정 |

### 핵심 원칙 — 매매 규칙과 동일

**① 소스 — 국토부 실거래가 MCP 전월세 도구만 사용**

허용 도구 (유형별):

| 물건 유형 | 전월세 조회 도구 |
|----------|----------------|
| 아파트 | `real-estate:get_apartment_rent` |
| 오피스텔 | `real-estate:get_officetel_rent` |
| 빌라·연립 | `real-estate:get_villa_rent` |
| 단독·다가구 | `real-estate:get_single_house_rent` |
| 상업용 (구분상가·오피스 호실 등) | 국토부 전월세 상업용 도구 부재 — 인근 공실률·임대료 정보는 한계 고지에 명시 |
| 토지 | 해당 없음 |

금지 소스 — 매매 규칙과 동일 (KB부동산·호갱노노·아실·네이버 호가 등 모두 금지)

**② 대상 — 동일 단지 + 동일 면적 (매매 규칙과 동일)**

- 단지명 완전 일치, 전용면적 완전 일치
- 조건 미달 시 추정·보간·유사단지 대체 금지 → "데이터 없음" 명시 후 한계 고지

**③ 기간 — 최근 6개월 고정 (매매 규칙과 동일)**

- 거래 건수 부족해도 기간 확장 금지

### 조회 절차 (순서 준수)

**1단계 — 매매 실거래가 조회와 병행**
- 법정동 코드 확보 단계에서 매매·전월세 조회 범위를 동시 결정
- 동일 deal_ymd 범위 (최근 6개월)로 전월세 MCP 호출 병행

**2단계 — 거래 유형 분리 (필수)**

전월세 API 응답은 "전세 / 보증부월세 / 순수월세"가 혼재되어 있다. 아래 기준으로 분리한다:

| 거래 유형 | 판정 기준 | NPL 분석 활용 |
|----------|---------|--------------|
| **전세** | 월세(monthlyRent) = 0 | 전세가율·깡통전세·대항력 보증금 시세 판정 |
| **보증부월세** | 보증금 > 0 AND 월세 > 0 | 소액임차인 기준 판정·상가 임대수익 추정 |
| **순수월세** | 보증금 ≈ 0 AND 월세 > 0 | 임대수익률 산정 기초 (Cap Rate) |

**3단계 — 신규·갱신 구분 (임차인 대항력 판정용)**

MCP 응답의 신규·갱신 계약 구분 필드를 확인하여 분리한다:
- **신규 계약**: 현재 시장 시세를 가장 잘 반영 → 보증금 적정성 검증 주 근거
- **갱신 계약**: 5% 상한 제한으로 시세 괴리 가능 → 참고 데이터로만 사용

**4단계 — 해제 거래 제외 (매매 규칙과 동일)**
- 해제 관련 필드 확인 후 제외

### 출력 양식 (필수)

**전세 실거래 요약표**

| 계약일 | 전용면적(㎡) | 층 | 보증금(만원) | 신규/갱신 | 해제여부 |
|--------|-------------|-----|-------------|----------|----------|
| 2026-03-10 | 84.97 | 14층 | 55,000 | 신규 | - |
| ... | ... | ... | ... | ... | ... |

**보증부월세·월세 실거래 요약표**

| 계약일 | 전용면적(㎡) | 층 | 보증금(만원) | 월세(만원) | 신규/갱신 |
|--------|-------------|-----|-------------|-----------|----------|
| 2026-02-20 | 84.97 | 6층 | 10,000 | 180 | 신규 |
| ... | ... | ... | ... | ... | ... |

**통계 요약 (거래 유형별 분리):**
- 전세: 거래 건수 ___건 / 평균 보증금 ___원 / 최고·최저 ___
- 보증부월세: 거래 건수 ___건 / 평균 보증금 ___ / 평균 월세 ___원
- 순수월세: 거래 건수 ___건 / 평균 월세 ___원
- **전세가율**(주거용): 평균 전세 보증금 ÷ 매매 평균가 × 100 = ___%
- **시장 임대수익률**(상업용/월세): (월세 × 12) ÷ (매매가 − 보증금) × 100 = ___%

### NPL 분석 연계 규칙 (4가지 핵심 연결점)

**연계 ① — 체크리스트 임차권 항목과 교차 검증**

섹션 2 체크리스트 ①~④(임차권 관련 4개 항목) 판정 시 다음을 대조:

| 체크리스트 항목 | 전월세 실거래가 대조 포인트 |
|--------------|-------------------------|
| ① 임차권등기명령 | 등기된 보증금이 시장 시세의 ±15% 이내인지 |
| ② 확정일자 | 확정일자 시점의 시장 전세 보증금과 현재 등기 보증금 비교 |
| ③ 배당요구 | 임차인 신고 보증금 vs 동일 단지·동일 면적 신규 전세 평균 |
| ④ 배당요구 취하 | 취하 시점 전후 시장 보증금 변동 확인 |

**허위·과다 임차 판정**: 신고 보증금이 동일 단지·동일 면적 신규 전세 평균의 **120% 초과**이면 허위·과다 임차 의심 → 한계 고지에 명시

**연계 ② — 소액임차인 최우선변제 배당 판정**

전월세 실거래가의 보증금 분포는 **소액임차인 해당 여부 판정의 핵심 근거**다:

1. 해당 지역·해당 시점의 **주택임대차보호법 소액임차인 기준** 확인
2. 실거래 보증금 분포 중 기준 이하 건수 확인
3. 해당 물건 임차인 신고 보증금이 기준 이하인지 판정
4. 최우선변제금 한도 내 **배당 우선순위 선배당** 처리 → 섹션 3 배당표에 반영

**연계 ③ — 임대수익 기반 가치평가 (Agent 3 시세·가치평가)**

상업용·오피스텔·다가구 등 임대수익형 물건은 **수익환원법** 적용:

```
시장 임대수익 기반 가치 (만원) = (월세 평균 × 12 + 운영수입) ÷ Cap Rate
```

- Cap Rate: 지역·용도별 시장 기대수익률 (상가 5~8%, 오피스텔 4~6% 등)
- 거래사례비교법(매매 실거래) 기반 가치와 비교하여 낮은 값을 기준 시세로 채택 (보수주의)

**연계 ④ — 깡통전세 리스크 평가 (주거용)**

전세가율이 낙찰가율 기준선보다 높으면 깡통전세 리스크 존재:

| 전세가율 | 판정 | NPL 매입 영향 |
|---------|------|-------------|
| 70% 미만 | 안전 | 정상 리스크 |
| 70~80% | 주의 | 낙찰가 할인 폭 5%p 확대 고려 |
| 80~90% | 위험 | 낙찰 후 재매각 지연 리스크 → 회수기간 +3~6개월 반영 |
| 90% 이상 | 고위험 | 매입 신중 검토, 한계 고지 필수 |

### 표본 충실도 판정 (전월세 전용)

전월세는 매매보다 거래 빈도가 높은 반면 신규 vs 갱신 구분에 따라 유효 표본이 제한적일 수 있다:

| 신규 거래 건수 | 판정 | 처리 |
|-------------|------|------|
| 5건 이상 | 충분 | 신규 평균가 기준 시장 시세 판정 |
| 3~4건 | 제한적 | 신규 평균 + 갱신 참고, 한계 고지 명시 |
| 1~2건 | 부족 | 갱신 포함 전체 평균 사용, 시세 판정 신중 |
| 0건 (갱신만 있음) | 시세 왜곡 가능 | 갱신 평균 사용 시 "5% 상한 왜곡" 한계 고지 필수 |
| 완전 0건 | 데이터 없음 | 소액임차인·대항력 판정에 한계 고지 |

### PPTX 한계 고지 박스 (전월세용)

매매 한계 고지 박스와 **별도**로, 전월세 실거래가 관련 한계가 1개 이상 있으면 섹션 3 임차권 분석 슬라이드 **하단**에 삽입한다.

**한계 고지 문구 — 정해진 형식 (변경 금지)**

```
솔직히 답변드립니다. 전월세 실거래가 MCP 호출은 했지만 다음 N가지 한계가 있었습니다:

1. [한계 항목 1 — 구체적으로 기술]
2. [한계 항목 2 — 구체적으로 기술]
...
```

**한계 항목 작성 예시:**

| 상황 | 기술 예시 |
|------|---------|
| 전세 신규 거래 0건 | "최근 6개월 신규 전세 실거래 0건. 갱신 거래만 확인되어 5% 상한 제한에 따른 시세 왜곡 가능" |
| 상업용 전월세 데이터 부재 | "국토부 MCP는 상업용 전월세 실거래 미제공. 시장 월세 기반 Cap Rate 산정 불가" |
| 허위·과다 임차 의심 | "신고 보증금이 시장 평균의 N% 초과로 허위·과다 임차 의심. 배당 시점 증빙 요구 필요" |
| 전세가율 계산 불가 | "매매 실거래 0건으로 전세가율 산정 불가. 깡통전세 리스크 판정 제한" |

### 금지 사항 (매매 규칙과 공통)

❌ MCP를 호출하지 않고 "일반적으로 이 지역 전세는 ~정도" 식으로 추정
❌ 전세·보증부월세·순수월세를 구분 없이 평균 산정
❌ 갱신 거래만 있는 상태에서 시장 시세로 단정
❌ KB시세·호갱노노·네이버 호가 등 금지 소스 수치 인용
❌ 허위·과다 임차 의심 상황을 감지했음에도 한계 고지 생략

### 왜 이 모듈이 필수인가

매매 실거래가만으로는 **임차권 리스크와 배당 시나리오의 정확성이 보장되지 않는다**. 특히:

1. **허위·과다 임차 가장**은 실제 NPL 손실의 상위 원인 중 하나로, 시장 전세 시세 대조 없이는 판정 불가
2. **소액임차인 최우선변제**는 근저당보다 선순위 배당되어 NPL 회수금을 직접 감소시키므로, 지역 보증금 분포 확인이 필수
3. **임대수익형 물건**(상가·오피스텔·다가구)은 매매 사례 부족 시 수익환원법이 주요 가치평가 기법이며, 이는 전월세 실거래 없이는 불가
4. **깡통전세 리스크**는 낙찰 후 재매각 성공률을 결정하며, 전세가율 추적 없이는 출구전략 수립 불가

전월세 실거래가 분석은 매매 실거래가 분석과 **동등한 지위**로 취급되어야 하며, 임차인이 있는 모든 물건에서 생략할 수 없다.
