# Agent 0: 문건접수·송달내역 선행 분석

## 목적

NPL 분석 요청 시, 섹션 1(물건 기본 정보)~섹션 5(최종 판단) 시작 전에 반드시 이 Agent 0 단계로 법원 문건접수·송달내역을 먼저 분석한다.
문건접수 문서는 NPL 분석의 가장 중요한 문서이며, 채무자 저항 강도·매각 지연 리스크·이해관계인 동향을 유일하게 드러내는 자료다.

---

## 선행 분석 원칙

1. 문건접수 문서가 **있으면** → 최우선으로 꼼꼼히 분석
2. 문건접수 문서가 **없으면** → 분석을 중단하지 않고 진행하되, 다음을 명시:
   - "문건접수 미확보로 채무자 저항·매각 지연 리스크 파악 제한"
   - 리포트에 "Agent 0: 문건접수 분석 — 자료 미확보" 섹션 표시
   - 최종 GO/NO-GO 판단 시 "자료 미확보 리스크" 항목 포함
3. 분석 결과는 산출물(PPTX/리포트) Executive Summary 앞에 전용 섹션으로 별도 배치

---

## 필수 체크리스트 — 4개 카테고리 20항목

### 채무자 동향 (5항목)

- [ ] 소송위임장 제출 여부 및 시점 (변호사 선임 = 법률 대응 강화 신호)
- [ ] 의견서·이의신청·진술서 제출 여부
- [ ] 매각부동산 재평가·재감정 신청 여부
- [ ] 매각불허가 신청·매각허가결정 취소 신청 여부
- [ ] 즉시항고·재항고·특별항고 이력

### 채권자 동향 (5항목)

- [ ] 보정명령·보정서 제출 횟수
- [ ] 당사자표시정정신청·경정결정 발송 이력
- [ ] 채권양수도·승계집행문 부여 정황
- [ ] 송달장소 및 송달영수인 신고 변경 이력
- [ ] 소송대리인 선임 여부 및 시점

### 이해관계인 구성 (5항목)

- [ ] 근저당권자 현황 (순위·설정일·채권최고액)
- [ ] 압류권자 현황 (지방세·조세·과태료 구분)
- [ ] 교부권자 현황 (국민건강보험·국세·지방세 등)
- [ ] 조세채권 법정기일 vs 근저당권 설정일 (당해세 우선 여부)
- [ ] 임차인·점유자 현황 (현황조사서 교차 확인 대상)

### 절차 진행 상태 (5항목)

- [ ] 개시결정정본 송달 완료 여부 (채무자·소유자·채권자 각각)
- [ ] 매각기일 및 매각결정기일 통지서 발송 이력
- [ ] 매각기일 변경·연기·취소 이력
- [ ] 경정결정·보정명령 후속 처리 상태
- [ ] 최근 3개월 내 신규 문건 접수 동향 (매각 임박 여부)

## 산출 양식 — 리포트/PPTX 필수 포함

### 1. 시간순 타임라인 표

| 날짜 | 접수자 | 문건내용 | 해석 |
|------|--------|---------|------|
| (채무자/채권자/법원 등) | | 주요 전환점은 별도 강조 |

### 2. 채무자 저항 지수 (0~10점)

| 점수 | 수준 | 기준 |
|------|------|------|
| 0~2 | 무대응 (수동적) | 아무런 서류 제출 없음 |
| 3~5 | 일반적 대응 | 보정서·의견서 수준 |
| 6~8 | 적극 방어 | 변호사 선임 + 재평가 신청 등 |
| 9~10 | 강력 저항 | 항고·소송 병행 |

### 3. 매각 지연 리스크

- 예상 지연 기간 (개월 단위)
- 지연 근거 (진행 중인 신청·항고·절차)
- 회수 기간 조정 필요 여부

### 4. 이해관계인 맵

- 근저당권자·압류권자·교부권자 한눈에 정리
- 조세채권 경합 여부 및 당해세 리스크

### 5. NPL 매입 관점 시사점 (3~5줄)

- 위 4개 항목에서 도출된 매입 판단 요점

## 후속 연계 규칙

- 채무자 저항 지수 **6점 이상** 또는 매각 지연 **3개월 이상** 예상인 경우:
  → 배당표·IRR 계산 시 회수기간 보수적 반영
  → 최종 GO/NO-GO 판단에 HIGH RISK 경고 포함
- 당사자 표시 변경이 감지되면:
  → `references/party-change-check.md` 체크리스트 병행 수행
