## 근린생활시설 1종/2종 판정 규칙 (상가·근생 물건 매입가 산정 전 필수 선행 작업)

근린생활시설(구분상가·꼬마빌딩·복합상가) NPL 매입 시 **건축물대장상 1종/2종 구분은 담보가치에 직접적인 영향**을 미친다. 1종만 가능한 상가는 임차 가능 업종 제한·임대료 단가 하향·환금성 저하로 인해 매입가에서 추가 할인이 필요하다. 섹션 4(매입 적정가 산정) 작성 전에 반드시 본 모듈을 수행한다.

### 적용 대상 물건

본 모듈은 아래 물건에 **필수 적용**한다:

| 물건 유형 | 적용 여부 | 비고 |
|---------|---------|------|
| 구분상가 (상가 호실) | ✅ 필수 | 호실별 용도 확인 |
| 꼬마빌딩 (상업용 건물 전체) | ✅ 필수 | 층별 용도 확인 |
| 복합상가 (주상복합 상가부) | ✅ 필수 | 상가부분만 적용 |
| 주거용 오피스텔 | ⚠️ 조건부 | 용도가 근생인 경우만 |
| 근생 현황 주택 (⑥번 항목) | ✅ 필수 | 공부상 용도 기준 |
| 아파트·다가구·다세대 | ❌ 미적용 | 순수 주거용은 제외 |
| 토지 | ❌ 미적용 | |

### 건축물대장 확인 절차 (순서 준수)

**1단계 — 건축물대장 '용도' 항목 확인**

건축물대장 표제부에서 아래 항목을 전수 확인한다:

| 확인 위치 | 확인 내용 |
|---------|---------|
| 표제부 '주용도' | 건물 전체의 대표 용도 |
| 표제부 '층별 용도' | 층별·호실별 세부 용도 |
| 전유부 (구분상가) | 해당 호실의 전유 용도 |

**2단계 — 1종/2종 분류 식별**

| 대장 표기 | 분류 | 비고 |
|---------|------|------|
| `제1종근린생활시설` | 1종 | 단일 표기 |
| `제2종근린생활시설` | 2종 | 단일 표기 |
| `근린생활시설` (종 미표기) | ⚠️ 추가 확인 | 세부 업종으로 역산 판정 |
| `제1종+제2종 복합` | 복합 | 층별·호실별 분리 판정 |

**3단계 — 세부 업종 매칭 (종 미표기 시)**

건축물대장에 1종/2종 구분 없이 세부 업종만 기재된 경우, 아래 표로 판정:

| 세부 업종 기재 | 분류 |
|-------------|------|
| 소매점(1,000㎡ 미만), 휴게음식점(300㎡ 미만), 제과점, 이용원, 미용원, 목욕장, 세탁소, 의원, 치과, 한의원, 조산원, 주민센터·파출소(1,000㎡ 미만), 탁구장·체육도장(500㎡ 미만) | **1종** |
| **일반 사무소·사무실·오피스(500㎡ 미만)**, **부동산중개업소**, 일반음식점, 휴게음식점(300㎡ 이상), 제조업소, 수리점, 학원·교습소(500㎡ 미만), 서점, 안마시술소, 고시원, 노래연습장, 단란주점(150㎡ 미만), 체육도장(500㎡ 이상) | **2종** |
| 유흥주점, 숙박시설, 의료시설(병원급), **업무시설(사무소 500㎡ 이상)** | **별도 용도** (근생 아님) |

> **⚠️ 사무소 용어 및 면적 기준 주의**
> - "사무소", "사무실", "오피스", "부동산중개업소" 등은 모두 **일반 업무용 공간**을 의미하며, 건축법상 동일 용도로 취급한다.
> - **500㎡ 미만**: 제2종근린생활시설(사무소)
> - **500㎡ 이상**: 업무시설 (근생 아님, 1종/2종 판정 대상에서 제외)
> - 소형 오피스빌딩 대부분은 호실별로 500㎡ 미만이므로 2종근생으로 분류된다. 건축물대장 주용도가 "업무시설"로 기재된 경우에도 개별 호실이 500㎡ 미만이면 해당 호실은 2종근생 용도로 임대 가능성 검토가 가능하다.
> - 구분상가 NPL 분석 시 **호실 단위 전유면적**을 기준으로 판정한다.

**4단계 — 실사 확인 항목 (2종 전환 가능성 평가)**

1종만 가능한 물건에서 2종 전환 여부를 평가할 때 아래 항목을 교차 확인:

| 확인 항목 | 확인 위치 | 판정 기준 |
|---------|---------|---------|
| 주차면수 | 건축물대장 '부설주차장' | 2종 전환 시 법정 주차면수 충족 가능 여부 |
| 정화조 용량 | 건축물대장 '정화시설' | 일반음식점 기준 오수발생량 대비 용량 |
| 학교환경위생정화구역 | 토지이용계획확인원 | 학교 경계 200m 이내 여부 |
| 용도지역 | 토지이용계획확인원 | 2종 가능 용도지역 여부 (하단 표 참조) |
| 임차인 업종제한 특약 | 임대차계약서 | 동일 건물 업종 독점 계약 여부 |

| 준공업지역 | ✅ 가능 | ✅ 가능 | |

### 입지 특성별 할인율 산정표

본 모듈의 **핵심 산출물**. 섹션 4 매입가 산정 시 이 할인율을 추가 반영한다.

| 입지 특성 | 1종만 가능 | 2종 가능 | 할인율 (1종만) |
|---------|---------|---------|-------------|
| **역세권·유흥상권** | 임대수요 치명적 제한 | 고단가 임대 가능 | **15~20%** |
| **대학가·학원가** | 학원(2종) 임대 불가 | 학원 임대 가능 | **10~15%** |
| **일반 상업지** | 일반음식점 불가 | 고단가 임대 가능 | **10~15%** |
| **오피스 밀집지** | **사무소(2종) 임대 불가로 임대수요 급감** | 일반음식점·사무소 모두 임대 가능 | **10~15%** |
| **주거 밀집지 (아파트 단지 내)** | 1종 업종 안정적 수요 | 차이 미미 | **0~5%** |
| **주거지 이면도로** | 1종 업종 적합 | 차이 미미 | **0~5%** |

> **⚠️ 오피스 밀집지 주의**: 오피스 밀집지에서 "일반 사무소·사무실·오피스"는 2종근린생활시설이다. 1종만 가능한 물건은 해당 입지의 **주된 임대수요(사무소)** 자체가 원천 차단되므로, 기존 "중저단가 영향" 평가가 아닌 **역세권 수준의 할인율**이 필요한 경우가 많다. 단, 500㎡ 이상은 업무시설이므로 판정 대상에서 제외.

### 할인율 조정 요소 (가감 요인)

기본 할인율에서 아래 요소에 따라 ±5% 조정:

| 조정 요소 | 방향 | 폭 |
|---------|------|----|
| 현 임차인이 2종 업종으로 불법 영업 중 | **할인 +5%** | 시정명령·이행강제금 리스크 |
| 현 임차인이 1종 고단가 업종 (치과·피부과 등)으로 장기 계약 중 | 할인 -5% | 안정적 수익 |
| 주차면수 법정 기준 **대비 120% 이상** 확보 | 할인 -3% | 2종 전환 여지 |
| 주차면수 법정 기준 **대비 80% 미만** | 할인 +3% | 2종 전환 불가 확정 |
| 학교환경위생정화구역 저촉 | 할인 +5% | 유흥·노래연습장 영업 원천 불가 |
| 주변 동일 용도지역에 2종 가능 대체 물건 다수 | 할인 +3% | 경쟁 열위 |

### 근생 1종/2종 분석 출력 양식 (섹션 4 작성 전 필수 출력)

아래 표를 섹션 4 직전에 출력한다:

```
[근린생활시설 1종/2종 판정표]
```

| 확인 항목 | 확인 결과 | 판정 근거 |
|---------|---------|---------|
| 건축물대장 용도 | 제1종근린생활시설 | 표제부 주용도 |
| 세부 업종 | 소매점(200㎡) | 층별용도란 |
| 현재 임차 업종 | 편의점 (1종 적법) | 현황조사서 |

| 기본 할인율 | **15%** |

| **최종 할인율** | **15%** → 섹션 4에서 추가 반영 |

### 섹션 4 연계 규칙

본 판정표의 **최종 할인율**은 섹션 4 "매입 적정가 산정"에서 **기존 리스크 할인율에 추가 가산**한다:

```
[최종 할인율 계산]
기존 21개 체크리스트 리스크 할인율 : ___%
근생 1종/2종 할인율 (본 모듈)      : ___%
────────────────────────────────────
합산 할인율                        : ___% (상한 35%)
```

> **⚠️ 상한 35% 룰**: 합산 할인율이 35%를 초과하는 경우, NPL 매입 자체를 **포기 검토** 단계로 전환. 근생 1종 한계 + 21개 리스크 동시 다발은 과도한 불확실성을 의미하므로 매입가를 더 낮추기보다 포기가 합리적.

### PPTX 한계 고지 박스 (2종 판정 모호 시 필수)

건축물대장만으로 1종/2종 판정이 모호한 경우, PPTX 슬라이드에 아래 박스를 필수 삽입:

```
📋 근린생활시설 분류 한계 고지

본 분석은 건축물대장 기준 1종/2종 판정 결과를 반영하였으나, 다음 한계가 있습니다:

1. 건축물대장 세부 용도 기재가 모호하여 최종 판정은 관할 구청 건축과 확인 필요
2. 2종 전환 가능성은 주차·정화조 이외 추가 인허가 절차가 필요할 수 있음
3. 학교환경위생정화구역 저촉 여부는 교육청 정밀 확인 필요

입찰 전 관할 지자체 현장 확인을 권장합니다.
```

### 금지 사항

1. ❌ 건축물대장 미확인 상태에서 "2종 가능" 가정 금지
2. ❌ 네이버부동산·호갱노노 등 제3자 사이트의 "상가 용도" 표기 인용 금지
3. ❌ 현재 임차인 업종이 2종이라고 해서 건물 용도가 2종이라고 역추정 금지 (불법 영업 가능성)
4. ❌ 할인율 15~20%를 기계적 적용 금지 (입지·조정요소 반드시 반영)
5. ❌ "임차수요 많음" 등 추상적 판단으로 할인율 생략 금지

### 왜 이 모듈이 필수인가

1. **담보가치 과대평가 방지**: 1종 한계를 반영하지 않은 매입가는 재매각·임대 단계에서 손실로 직결
2. **임대수익 현실화**: 1종만 가능한 상가의 임대료 단가는 2종 대비 10~30% 낮은 경우가 많음
3. **환금성 리스크 반영**: 매각 시 매수자 풀이 좁아져 장기 보유 위험
4. **NPL 실패 유형 10번(불법건축물) 연계**: 용도변경 불가 + 현재 불법 영업 시 이행강제금까지 이중 리스크
