### 섹션 3 — 권리관계·법률 분석 (권리관계·법률 전문가)

각 항목은 ✅ 정상/해당없음 / ⚠️ 주의 / 🚨 위험 / ❓ 정보부족 으로 표시한다.

#### 3-1. 임차권 관련 체크리스트

| # | 점검 항목 | 상태 | 세부 내용 |
|---|-----------|------|-----------|
| ① | 임차권등기명령에 의한 임차권 여부 | | 퇴거 후에도 대항력·우선변제권 유지 → 보증금 인수 위험 |
| ② | 임차인별 대항력 분석 (전입일, 확정일자, 점유) | | 각 임차인을 개별 분석, 대항력 유무 명확히 판단 |
| ③ | 임차인 배당요구 여부 | | 배당요구 없는 대항력 있는 임차인 = 낙찰자 인수 |
| ④ | 임차인 배당요구 취하 여부 | | 취하 시 대항력 부활 → 인수 위험 |
| ⑤ | 보증금 미상 여부 | | "미상/불명" 기재 시 인수 보증금 산정 불가 → 현장 확인 |
| ⑥ | 최우선변제 소액임차인 해당 여부 | | 지역별 소액보증금 기준 확인, 최우선변제금 산정 |

> 임차인이 복수인 경우 각 임차인별로 ①~⑥ 항목을 개별 체크한다.

|---|-----------|------|-----------|
| ⑦ | 채무자와 소유자 동일인 여부 | | 상이 시 물상보증인/제3취득자 검토 |
| ⑧ | 가압류/가처분 여부 | | |

| ⑩ | 법정지상권 성립 여부 | | 토지·건물 소유자 상이 시 반드시 검토 |
| ⑪ | 지분 경매 여부 | | 다가구: 토지+건물 전체인지 / 다세대: 해당 세대 전체인지 |
| ⑫ | 공동담보 여부 | | 동시배당 vs 이시배당 구분 |

#### 3-4. 명도 분석 (근린주택 특화)

근린주택은 세대수가 많고 임차인이 다수이므로, 세대별로 명도 난이도를 분석한다.

```
[세대별 명도 난이도 분석]
— 점유자 유형: 채무자 / 임차인 / 불법점유자

[예상 명도 기간]: ___개월
[예상 명도 비용]: ___________원 (이사비, 합의금, 명도소송비)
[명도 전략 제안]: 협의 우선 / 인도명령 / 명도소송
```
