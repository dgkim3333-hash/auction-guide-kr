### 섹션 2 — 입지·시세 심층 분석 (입지·시세 분석가)

근린주택·아파트 투자의 성패는 입지에 달려 있으므로 이 섹션을 가장 상세하게 분석한다.

#### 2-1. 교통 접근성 (최우선 분석)

| 분석 항목 | 내용 | 평가 |
|-----------|------|------|
| 최인접 지하철역 | (역명, 노선, 도보 거리/분) | |
| 역세권 등급 | 초역세권(3분 이내) / 역세권(5분) / 준역세권(10분) / 비역세권 | |
| 버스 노선 | 주요 노선 수, 정류장 거리 | |
| 차량 접근성 | 접면 도로 폭, 주요 도로와의 거리 | |
| 주차 여건 | 자체 주차 대수, 인근 공영주차장 | |

**교통 접근성 종합 등급**: A(우수) / B(양호) / C(보통) / D(미흡) / F(불량)

> 등급 기준:
> - A: 초역세권 + 대로변 접면 + 주차 충분
> - B: 역세권 + 6m 이상 도로 + 주차 가능
> - C: 준역세권 + 4m 이상 도로
> - D: 비역세권이나 버스 접근 양호
> - F: 비역세권 + 도로 협소 + 접근 불량

#### 2-2. 생활 인프라 및 학군 (주거용 특화)

| 분석 항목 | 내용 |
|-----------|------|
| 초·중·고등학교 | (학교명, 도보거리, 학군 평판) |
| 대형마트·편의시설 | (종류, 거리) |
| 병원·공공기관 | (종류, 거리) |
| 공원·녹지 | (규모, 거리) |
| 혐오시설 | (장례식장, 쓰레기처리장, 고압전선 등 유무) |

#### 2-3. 주변 시세 분석

| 비교 항목 | 내용 |
|-----------|------|
| 인근 유사 물건 매매 시세 | (최근 6개월 실거래가) |
| 감정가 대비 시세 괴리율 | (감정가가 시세 대비 높은지/낮은지) |
| 인근 아파트 시세 동향 | (상승/보합/하락 추세) |
| 해당 지역 평균 낙찰가율 | (최근 6개월 유사물건 기준) |
| 토지 공시지가 추이 | (최근 3년) |

#### 2-4. 개발 호재 및 규제

| 항목 | 내용 |
|------|------|
| 도시계획 변경 | (재개발/재건축, 도시재생, 정비구역 지정 등) |
| 신규 교통 인프라 | (GTX, 신설 노선, 역 개통 예정 등) |
| 용도지역 상향 가능성 | |
| 규제 요인 | (고도제한, 일조권, 정비구역 행위제한 등) |

#### 2-5. 입지 종합 평가

```
[입지 종합 등급]: S / A / B / C / D / F

[핵심 강점]
- (2~3줄)

[핵심 약점]
- (2~3줄)

[입지 관점 투자 적합도]: 상 / 중 / 하
```
