### 섹션 4 — 금융·대출 분석 (금융·대출 전문가)

#### 4-1. 대출 가능성 분석

| 항목 | 내용 |
|------|------|
| 물건 유형별 LTV 기준 | 다가구( %) / 다세대( %) — 규제지역 여부 반영 |
| 예상 담보 인정가 | (감정가/시세 중 낮은 값 기준) |
| 최대 대출 가능 금액 | |
| 예상 대출 금리 | (고정/변동, 기간별) |
| DTI/DSR 검토 | (대부업 대표 소득 구조 반영) |
| 주택 수 규제 | (다주택자 중과세율, 취득세 중과 해당 여부) |

> 대부업체 대표 특수성: 사업소득 인정 범위, 법인/개인 명의 차이, 금융기관 심사 기준을 반영한다.

#### 4-2. 자금 조달 계획

| 구분 | 금액 | 비율 |
|------|------|------|
| 낙찰 예상가 | | |
| 취득세 (다주택자 기준 확인) | | |
| 법무·중개 비용 | | |
| 명도 비용 | | |
| 수선·리모델링 비용 | | |
| **총 투자비** | | **100%** |
| 은행 대출 | | % |
| **자기 자본 필요액** | | **%** |

#### 4-3. 대출 리스크

```
— 금리 상승 시나리오별 이자 부담:
  현행 금리: 월 ___만원
  +1%p 시: 월 ___만원
  +2%p 시: 월 ___만원
— 대출 만기 연장 리스크
— 규제지역 해제·편입 시 LTV 변동 영향
```

### 섹션 5 — 수익성·임대 분석 (수익성·임대 분석가)

#### 5-1. 임대 수익 현황 (세대별)

| 층/호 | 면적(㎡) | 보증금 | 월세 | 전세 | 공실 | 비고 |
|-------|----------|--------|------|------|------|------|
| ... | | | | | | |
| **합계** | | **총 보증금** | **총 월세** | | | |

#### 5-2. 수익률 산정

```
[현재 수익률 — 현 임대 조건 기준]
- 연 임대수익(월세 × 12)          : ___________원
- 총 투자비(낙찰가+취득세+부대비용+수선비) : ___________원
- 표면 수익률(총 투자비 대비)       : ___%
- 순 수익률(관리비·세금·수선충당·공실손실 차감) : ___%

[시장 비교]
- 해당 지역 유사 물건 평균 수익률: ___%
- 판단: 시장 대비 상회 / 적정 / 하회
```

#### 5-3. 현금흐름 분석 (월간)

| 항목 | 금액(월) |
|------|----------|
| (+) 월 임대수입 | |
| (-) 대출 이자 | |
| (-) 관리비·수선충당금 | |
| (-) 재산세·종부세(월할) | |
| (-) 공실 손실(공실률 적용) | |
| **= 월 순현금흐름** | |

> 연간 순현금흐름이 마이너스인 경우 반드시 경고한다.

#### 5-4. 공실 리스크

```
- 현재 공실률         : ___%
- 지역 평균 공실률    : ___%
- 공실 1세대 추가 시 수익률 변동: ___% → ___%
- 임차인 안정성       : 상 / 중 / 하 (근린주택 특성상 임차인 회전율 고려)
```

#### 5-5. 임대 시세 적정성

```
- 주변 유사 주택 월세 시세 비교
- 현재 임대료 대비 시세: 적정 / 고평가 / 저평가
- 임대료 상향 조정 가능성 및 예상 조정 금액
```
