# 재무 부실 지표·MCP 호출 명세·검색 키워드

## §1. 재무제표 조회 (fsc-financial-info)

### 3-1. 재무제표 자동 조회

`fsc-financial-info:search_company_financial_info`를 사용하여 **최근 3개 사업연도** 재무제표를 조회한다.

```
조회 예시:
- crno: 법인등록번호
- biz_year: 2024, 2023, 2022 (순차 조회)
```

**조회 실패 시:** 외부감사 비대상 법인이거나 API 미등록일 수 있음 → 사용자에게 재무제표 직접 제공 요청

## §2. 5대 부실 지표 계산식·위험 기준

### 3-2. 5대 부실 지표 계산 (자동)

| 지표 | 계산식 | 위험 기준 |
|---|---|---|
| **부채비율** | (부채총계 / 자본총계) × 100 | 400% 초과 위험 |
| **유동비율** | (유동자산 / 유동부채) × 100 | 100% 미만 위험 |
| **이자보상배율** | 영업이익 / 이자비용 | 1.0 미만 위험 |
| **자본잠식률** | (자본금 − 자본총계) / 자본금 × 100 | 양수(+)면 자본잠식, 100% = 완전잠식 |
| **영업이익률** | (영업이익 / 매출액) × 100 | 연속 (-) 위험 |

**계산 결과 3개년 시계열로 표 제시.**

## §3. 부실 위험 신호 체크리스트 (8개)

### 3-3. 부실 위험 신호 종합 판정

아래 신호 중 **3개 이상 해당 시 "재무 고위험"** 처리:

- [ ] 부채비율 400% 초과
- [ ] 유동비율 100% 미만
- [ ] 이자보상배율 1.0 미만 (3년 연속)
- [ ] 자본잠식 발생
- [ ] 영업손실 2년 연속
- [ ] 매출 3년 연속 감소
- [ ] 영업활동 현금흐름 2년 연속 (-)
- [ ] 당기순손실 3년 연속

## §4. 영업 실태 MCP 호출 명세

### 4-1. 사업자 상태 확인 (nts-business-verification MCP)

```
도구: nts-business-verification:check_business_status
입력: 사업자등록번호 (사용자 입력 시)

확인 결과:
□ 계속사업자 → 정상
□ 휴업자 → 🟠 고위험 신호
□ 폐업자 → 🔴 매입부적격 가능성
```

**사업자등록번호가 없으면** 사용자에게 요청한다.

> ⚠ 계정판 SKILL.md 와 다름 — 본문(SKILL.md) 규칙이 우선: 사업자 폐업은 「매입부적격 가능성」이 아니라 탈락 조건(즉시 🔴 매입부적격, 점수 합산 생략)이다.

### 4-2. 국민연금 가입자 추이 (nps-business-enrollment MCP) ⭐ 핵심 지표

```
도구: nps-business-enrollment:search_business (법인명으로 검색)
  → nps-business-enrollment:get_period_status (시계열 조회)

확인 기간: 최근 24개월
분석: 가입자 수 증감률 계산
```

(가입자 변동 등급표는 `risk-grading-criteria.md` §5)

### 4-3. 업계 뉴스 모니터링 (naver-search MCP)

```
추가 검색 키워드:
- "[법인명] 구조조정"
- "[법인명] 감원"
- "[법인명] 공장 중단"
- "[법인명] 대금 미지급"
- "[법인명] 체납"
```

부정적 뉴스 다수 발견 시 요주의 신호.

> ⚠ 계정판 SKILL.md 와 다름 — 본문(SKILL.md) 규칙이 우선: 부정적 뉴스는 「다수 발견 시 요주의 신호」가 아니라 5건 이상 발견 시 −15점 감점(`risk-grading-criteria.md` §2)으로 처리한다.

## §5. 회생·파산 이력 검색 키워드 (2단계)

### 2-1. MCP 자동 조회 (naver-search)

법인명으로 아래 키워드를 순차 검색한다:

```
검색1: "[법인명] 회생"
검색2: "[법인명] 파산"
검색3: "[법인명] 워크아웃"
검색4: "[법인명] 기업회생"
검색5: "[법인명] 법정관리"
검색6: "[법인명] 부도"
```

**발견 시 기록:** 최초 보도일, 언론사, 사건 단계(신청/개시결정/인가/폐지)

## §6. 경영진·기타 리스크 (5단계)

### §6-2.

### 5-2. 대표이사·임원 변동 (자동 모드에서는 체크리스트로 이관)

법인등기부등본은 MCP로 자동 조회 불가하다.

**자동 모드에서는 여기서 멈추지 않는다.** 아래 확인 사항은 리포트 말미의 "사용자 수동 확인 체크리스트" 섹션에 **기록만 해두고 다음 단계로 즉시 진행**한다. 해당 항목은 점수 산출 시 "미확인" 상태로 처리한다.

```
【 리포트 말미에 포함할 수동 확인 체크리스트 】

법인등기부등본(인터넷등기소 www.iros.go.kr)에서 아래를 확인해 주세요:
□ 최근 2년간 대표이사 변경 횟수: ____ 회
□ 최근 2년간 임원 변경 횟수: ____ 회
□ 본점 소재지 이전 횟수: ____ 회
□ 증자/감자 이력: _______________
```

| 변동 내역 | 위험 신호 |
|---|---|
| 대표이사 2년 내 3회 이상 변경 | 🟠 고위험 |
| 본점 이전 반복 | 🟡 요주의 (주소 숨기기 의심) |
| 감자 이력 (자본잠식 보전용) | 🟠 고위험 |

### §6-3.

### 5-3. 기타 리스크 신호

- 특수관계자(모회사·계열사) 부실 여부
- 최근 1년 내 담보 추가 제공 (유동성 위기 신호)
- 전환사채(CB)·신주인수권부사채(BW) 만기 임박
