# 회생·파산 공식 확인처 가이드

이 문서는 사용자에게 수동 확인을 요청할 때 구체적으로 안내하기 위한 참고 자료다.

## 1. 법원 공고 확인처

### 1-1. 대한민국 법원 전자공고 (필수)
- **URL:** https://www.scourt.go.kr/portal/notice/nstcnotice
- **검색 방법:** 
  - 법인명으로 검색
  - 공고 분류: "회생사건" / "파산사건" / "개인회생사건"
  - 기간: 최근 5년 권장
- **확인 항목:**
  - 회생절차 개시결정 공고
  - 파산선고 공고
  - 채권신고 공고 (채권신고 기간 내에 있는지 확인)

### 1-2. 대법원 나의 사건 검색
- **URL:** https://www.scourt.go.kr
- **검색 방법:** 사건번호로 조회 (예: 2024회합12345)
- **사건 분류 코드:**
  - 회합 = 회생 합의부 (법인 회생)
  - 회단 = 회생 단독 (간이회생)
  - 하합 = 파산 합의부
  - 하단 = 파산 단독

### 1-3. 서울회생법원 (대형 사건 집중)
- **URL:** https://slbgo.scourt.go.kr
- 수도권 대형 법인 회생·파산 사건 다수 처리
- 채권자협의회 공고, 관리인 선임 공고 등 확인 가능

### 1-4. 관보
- **URL:** https://gwanbo.go.kr
- 파산선고·회생개시결정은 관보 게재 의무
- 전자관보에서 과거 공고까지 전문 검색 가능
- 검색 팁: 법인명 + "파산" 또는 법인명 + "회생"

## 2. 신용·공시 정보

### 2-1. DART 전자공시 (상장사·외감법인)
- **URL:** https://dart.fss.or.kr
- **필수 확인 공시:**
  - 감사보고서 (계속기업 불확실성 의견 여부)
  - 주요사항보고서 (채권 회수불능, 부도, 해산결의 등)
  - 분기보고서·반기보고서
- **위험 신호:**
  - 감사의견: "의견거절" / "부적정" / "한정"
  - 계속기업 관련 중요한 불확실성
  - 관리종목 지정 / 상장폐지 실질심사

### 2-2. 크레탑 (KED)
- **URL:** https://www.cretop.com
- 기업신용평가 등급 확인
- 부도확률 지표 제공 (유료)

### 2-3. NICE 기업정보
- **URL:** https://www.nicebizinfo.com
- 신용등급, 부도확률, 회생·파산 이력
- 유료 서비스

### 2-4. 전국은행연합회 신용정보
- **URL:** https://www.kfb.or.kr
- 공공정보 등록 현황 확인
- 법원 도산 정보 자동 등록

## 3. 사업 활동성 확인처

### 3-1. 홈택스 (국세청)
- **URL:** https://www.hometax.go.kr
- 사업자등록 상태 조회
- 휴업·폐업 여부 공개 조회 가능

### 3-2. 4대보험 정보연계센터
- **URL:** https://www.4insure.or.kr
- 4대보험 체납 여부 (본인 또는 위임 동의 필요)

### 3-3. 국민연금공단 사업장 검색
- **URL:** https://www.nps.or.kr
- 사업장 가입자 수 공개 조회

## 4. 법인등기·지배구조 확인처

### 4-1. 인터넷등기소 (등기사항증명서)
- **URL:** https://www.iros.go.kr
- 법인등기부등본 열람 (수수료 약 1,000원)
- 확인 항목:
  - 대표이사 변경 이력
  - 임원 변동
  - 본점 이전 이력
  - 자본금 변동 (증자/감자)
  - 해산 결의

### 4-2. 공정거래위원회 기업집단포털
- **URL:** https://www.egroup.go.kr
- 공시대상기업집단 여부
- 계열사 정보
- 상호출자·순환출자 구조

## 5. 공시·판결문 참고

### 5-1. 대법원 판결문 검색
- **URL:** https://www.scourt.go.kr (종합법률정보)
- 법인 관련 민·형사 판결 확인
- 배임·횡령 등 대표이사 형사판결

### 5-2. 헌법재판소
- **URL:** https://www.ccourt.go.kr
- 위헌법률심판·헌법소원 (드물지만 거액 소송 법인 해당 가능)

## 6. 체크리스트 템플릿 (사용자 확인용)

사용자에게 수동 확인을 요청할 때 아래 양식을 활용한다:

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🔍 법인 채무자 회생·파산 수동 확인 체크리스트

[ ] 1. 법원 전자공고 검색 결과: 없음 / 발견 (____)
[ ] 2. 대법원 사건 검색 결과: 없음 / 발견 (____)
[ ] 3. 관보 검색 결과: 없음 / 발견 (____)
[ ] 4. DART 감사의견: 적정 / 한정 / 부적정 / 의견거절
[ ] 5. 계속기업 불확실성 의견: 없음 / 있음
[ ] 6. 사업자등록 상태: 계속 / 휴업 / 폐업
[ ] 7. 대표이사 2년 내 변경: ____회
[ ] 8. 본점 이전 이력 (2년): ____회
[ ] 9. 감자 이력 (5년): 없음 / 있음
[ ] 10. 관리종목 지정 (상장사): 미해당 / 해당
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 7. 유료 정보 서비스 (대형 NPL 실사 시)

| 서비스 | 제공기관 | 특징 |
|---|---|---|
| 크레탑 | 한국기업데이터 | 신용평가 등급, 부도확률 |
| NICE 기업정보 | NICE평가정보 | 신용리포트, 도산 이력 |
| 한경비즈니스 기업정보 | 한국경제 | 재무분석, 경영진 정보 |
| 기업마당 | 중소벤처기업부 | 중소기업 정보 종합 |
| 인더스트리 리포트 | 산업연구원 | 업종별 동향 |

NPL 청구채권액 10억 초과 사건에서는 유료 신용평가 리포트 활용을 권장한다.
