# 물건폴더_표준 사용법

이 폴더를 통째로 복사해 `C:\AI\NPL\<소재지 전체주소>\` 로 만든다. 복사 후 이 파일은 지운다.

```
C:\AI\NPL\서울 ○○구 ○○동 123-4\
 ├─ 00_물건카드.md      ← 먼저 채운다. 모든 스킬이 이 숫자를 본다
 ├─ 01_원본서류\        ← 등기부 · 건축물대장 · 감정평가서 · 매각물건명세서 · 현황조사서 · 문건접수내역 PDF
 ├─ 02_분석\            ← NPL수익률.xlsx · 시세 조사 · 분석 메모
 ├─ 03_산출물\          ← 물건카드 PPTX · 매수의향서 docx
 └─ 백업\               ← 덮어쓰기 전 사본
```

- 폴더명은 **사건번호가 아니라 소재지 전체주소**. 재경매로 사건번호가 바뀌어도 물건은 그대로다.
- `01_원본서류`는 비어 있는 게 정상이다. 서류를 받으면 `npl-doc-intake` 스킬로 표준 파일명으로 정리한다.
- 서류의 채무자·임차인 실명, 주민번호, 연락처는 남과 공유하기 전 반드시 가린다.
