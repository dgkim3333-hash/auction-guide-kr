## 고정 구성 (순서)

1. 표지
2. **한눈에 보기** — KPI 카드 4장(관점 1 매입 상한 · 예상 배당 · 최우선변제 · 관점 2 현금수익률) + 핵심 3줄
3. **두 관점 나란히** — 판정·핵심 금액·성과·손실 시나리오·먼저 닫을 것
4. **결정 전 반드시 닫을 3가지** — 항목마다 「사실 / 금액 영향 / 어디서」
5. 이후: 관점 1(매입 상한 산식 → 회차 시나리오 → 일괄·실측 → 배당 순서 → 최우선 → 보증기관 → 민감도) → 권리·문건(사다리 · 타임라인 · 체크리스트 위험·주의만 · 선순위 조세) → 시세·입찰 → 관점 2(레버리지 · 임대) → 세금 3장 → 입지 · 고유 리스크 · 명도 · 종합 점수 · 확인해야 할 것 → 출처
6. **부록**: 임차인 전원 표(10명씩) · 21개 체크리스트 전체

물건에 없는 장(예: 일괄매각 실측·HUG)은 빼고, 있는 쟁점은 같은 형식으로 장을 만든다. 앞 4장만 읽어도 결론이 서야 한다.

## 조건부 장 — 해당할 때만 넣는다 (2026-10-07)

장 번호는 물건마다 달라지므로 **자리(어느 장 바로 뒤)** 로 정한다. 계산·표 구성의 정본은 `npl-cross-collateral-shortfall` 스킬(괄호 안 블록)과 NPL 지침 ■ 이원 분석이다.

| 장 | 언제 | 자리 |
|---|---|---|
| 질권대출 반영 | 채권 매입에 질권대출을 쓸 때 | 매입가 검산(매입 상한) 장 바로 뒤 |
| 잔존채권 추심 — 배당 뒤 채무자에게 할 일 | 우리 채권의 예상 배당이 청구액에 못 미칠 때(민감도 하방에서만이면 부록) | 배당 폭포 장 바로 뒤 (C-3) |
| 국세 판정 · 국세 민감도 (2장) | 등기부에 세무서·지자체 압류가 있거나 체납 전언이 들어왔을 때 | 권리 장 묶음 안 (D-6) |
| 전입 차단 — 계약 조항 | 채권 매입 건 · 담보물에 주택 · 경매개시결정 등기 전 | 「최우선변제 범위」 민감도 장 바로 뒤 (E-4) |

- **배당 폭포 장 하단 띠**: 둘째 줄에 `토지 : 건물 비율 (감정가 기준)  A 00.00% : 00.00% (토지 0원 · 건물 0원)` 를 항상 넣는다. 교차 담보 건이면 셋째 줄에 잉여의 토지분·건물분이 누구에게 가는지(A-3).
- 해당하지 않으면 장을 만들지 않고 한 줄만 남긴다: 「교차 담보 없음 — 토지·건물 권리자 동일」 · 「조세 압류 없음」 · 「잔존채권 없음」 · 「질권대출 미사용 — 무차입 값만」.
