   NPL 건에서 유입은 「채권 매입 후 직접 낙찰」 전제로 총투입 = 채권매입금액 + 상계 후 잔금(낙찰가 − 배당액) + 취득 부대비용. 낙찰가 전액 기준 금지. 레버리지 장의 총투입과 같은 금액이어야 한다. 임대 NOI는 npl-analysis 원칙 25(전월세 실거래 중앙값).
② 세금 4종(필수, 개인·법인 두 경우): 산식·조회 절차는 auction-property-card STEP 8-A~8-H, 안분은 property-tax-apportionment, 계산기는 real-estate-tax-calculator. NPL 건이라고 STEP 8을 건너뛰지 않는다.

■ 당해세·최우선변제 — 계산과 그림이 같은 말을 해야 한다
같은 소재지 관할 구·면이 압류권리자인 지방세는 세목 표기와 무관하게 당해세로 보수 판정하고, 배당에서 근저당보다 앞선다(집행비용 → 당해세 → 최우선변제 → 1순위 근저당). 엑셀 C20에 넣는 것으로 끝내지 않는다.
- 권리 사다리: 회색 「소멸」로 그리지 않는다 → 주황(#D97706) 「당해세」 배지 + 금액. 소액임차인 최우선변제도 주황 「최우선」 배지 + 금액
- 배당표: 별도 행. 배당 폭포: 주황 행
- 검산: 사다리 = 엑셀 분석!C20 = 배당표 = 배당 폭포. 하나라도 다르면 원 데이터를 다시 본다. 계산에 들어갔어도 그림에 「소멸」로 남아 있으면 「반영 안 됨」

■ 핵심 명제 (공통)
- 낙찰가는 유찰회차가 아니라 응찰자 수가 결정한다. 회차는 가격대, 경쟁강도는 분위
- 유찰·무응찰 이력은 「그 가격대 비인기」 신호일 뿐. 최저가가 인근 실거래 대비 70% 아래로 처음 진입하는 회차엔 대기 수요가 일제히 진입 → 이력 무시하고 경쟁 밴드로 계산. 모든 물건에서 「이번 회차 최저가 ÷ 실거래」 비율을 먼저 명시
- 포기 판정: 경쟁 밴드 입찰가 + 부대비용 > 실거래 × 0.80 → 입찰 포기를 결론 첫머리에. 이때 패찰은 규율 준수

■ 계수 (auction-bid-price 본문이 정본, 전부 [추정])
- 【A】 법원경매: 분모 = 감정가. 저감률 20%/30% 법원을 먼저 가르고 회차별 기준선 → 응찰자수 회귀 → 상한A(실거래×0.80)·상한B(직전 낙찰가) → MAX(MIN(회귀, 상한), 최저가) → 끝자리
- 【B】 압류재산 공매: 분모 = 최저가, 100% 초과 정상. 경매 계수와 혼용 금지. 단독응찰이면 최저가+1원으로도 낙찰 — 경쟁 근거 없으면 100~101%
- 조회수 판정표·회차별 실측·용도군별 실측은 스킬 본문. 표본 30건 미만 [검증필요], 10건 미만 회귀 미적용
- 수강생판 계수는 강사가 특정 지역·기간 표본으로 뽑은 스냅샷이다. 6개월 지나면 「낡았다」, 12개월 지나면 참고치로만. 내 지역 낙찰 결과가 창고에 쌓이면 그것으로 다시 세운다

■ 시세 (출처 규칙 자체는 개인 설정)

■ 대출·레버리지 (판정 먼저 · 단일 시나리오 · 총투입은 3열 비교와 동일 기준)
포기 판정이 아닌 모든 물건에 레버리지 표를 붙인다. 보수·중립·공격 복수 시나리오 금지. 매각 가정·IRR은 내가 명시 요청할 때만.
대출가능금액 판정(먼저 한다):
  - 법인 명의 + 규제지역 주택(근린주택·다가구 포함) → 0원일 수 있음 [검증필요 — 은행업감독규정 별표 원문을 그 답변에서 확인]. 규제지역 여부는 최신 고시로 확인
  - 개인 명의 + 규제지역 + 주택 보유 세대 → 축소 또는 0원 [검증필요 — 최신 대책 원문 확인]
  - 비규제지역 또는 비주택 → 대출가능금액 = 낙찰가 × [80]% / 대출금리 연 [5.5]% (금융사 견적이 나오면 그것이 정본)
  - 대출 0원이면 무차입 Cash-on-Cash. DSCR은 「해당 없음」
총투입: NPL 매입 건 = 채권매입금액(수수료 포함) + 상계 후 잔금(낙찰가 − 배당액) + 취득 부대비용. 직접낙찰 건 = 낙찰가 + 취득 부대비용. 레버리지 총투입 = 3열 비교 유입 총투입 (검산)
제1 지표 = 자기자본 연 현금수익률(Cash-on-Cash) = 연 순현금흐름(NOI − 이자 − 첫 과세연도 보유세) ÷ 자기자본. 자기자본 = 총투입 − 대출 − 승계 보증금
산출 순서(표 1개): 채권매입 → 상계 후 잔금 → 취득 부대비용 → 총투입 → 대출가능금액(판정 근거) → 승계 보증금 → 자기자본 → 월 NOI → 월 이자 → 월 순현금 → 연 순현금(보유세 차감) → ★Cash-on-Cash → DSCR. 대출이 있을 때만 금리 ±1.0%p 민감도 한 줄
임대료 가정: 국토부 전월세 실거래 분포의 중앙값(npl-analysis 원칙 25). 환산 월세 = 월세 + 보증금×전환율/12, 면적대·연식별 m²단가 p25·중앙·p75. 사례 2~3건이나 호가로 잡지 않는다. 임대수입을 쓴 장에는 월세 실거래 표 + 출처(창고 수집일) 필수. 없으면 미이행
비율(낙찰가율·LTV·하한율)이 제목·KPI에 나오면 환산 금액을 괄호로 붙인다

■ 산출물 원칙
- 물건 분석 결과는 채팅 요약과 별도로 PPTX 브리핑 1부(03_산출물\). 구성: 결론(권장 입찰가 또는 매입가·포기 판정) 1장 선두 → 계산 근거 표 → 회차·낙찰가율 차트 → 시세 대조(추정 감정가 표) → 레버리지·수익률 → 세금 최소 3장 → 리스크·확인사항. NPL 매입 건은 앞에 채권 구조·권리분석·배당 시뮬레이션 장이 붙는다
