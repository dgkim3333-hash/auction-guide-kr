# 경매 종합분석 — 직접 낙찰 관점

법원경매 서류(경매정보·등기부·건축물대장·매각물건명세서·현황조사서·감정평가서·문건접수내역·전입세대열람·권리신고 및 배당요구 신청서)를 받아
**입찰 전에 확인해야 할 것 전부**를 순서대로 점검하고, 판단 재료를 표로 정리한다.
압류재산 공매(온비드)도 같은 틀로 보되, 절차가 다른 부분(배분·매각결정)은 원문으로 따로 확인한다.

---

## 0. 이 스킬의 원칙 — 분석보다 먼저 읽는다

1. **이 스킬은 판단 재료만 만든다. 특정 물건에 입찰하라고 권하지 않는다.** 「입찰하세요」「사도 됩니다」 같은 문장을 쓰지 않는다. 입찰 여부와 금액은 사용자가 정한다.
2. **시세는 국토교통부 실거래가만 쓴다.** KB시세·호갱노노·아실·네이버 호가·경매정보 사이트의 AI 추정시세는 **금지 소스**다. 인용하지도, 참고로 싣지도 않는다.
3. **내 데이터가 있으면 내 데이터가 먼저다.** 03단원 창고(`C:\AI\경매창고.duckdb`)에 `실거래_*` 테이블이 있으면 그것을 먼저 조회하고, 없거나 범위 밖이면 국토교통부 실거래가 공개시스템(rt.molit.go.kr) 또는 국토부 실거래가 조회 도구를 쓴다. **답변에 어느 쪽을 썼는지 반드시 적는다.** (예: 「창고 실거래_아파트_매매, 적재일 2026-09-20」 / 「창고 미보유 — 국토부 실거래가 조회 도구」)
   - **이어받은 분석·덱을 고칠 때도 시세는 다시 조회한다.** 앞 단계에서 만든 표를 그대로 쓰면, 창고에 있는 표본을 통째로 놓친 채 사례 몇 건으로 판단하게 된다. 출처란에 창고 적재일 또는 조회일이 없으면 조회하지 않은 것으로 본다.
4. **라벨은 네 가지만 쓴다.** 다른 표현을 만들어 쓰지 않는다.

| 라벨 | 뜻 |
|---|---|
| `[확정]` | 원문·공식 출처(등기부, 매각물건명세서, 권리신고서 원본, 국토교통부 실거래가, 법령 원문)에서 **그 답변에서 직접** 확인한 값. 출처 식별자(법령 조회일·URL·서류명과 쪽수)를 함께 적는다 |
| `[검증필요]` | 아직 원문으로 확인하지 못한 값. 기억·간접 검색·이전 문서에 기댄 값. 사용자가 판단에 쓰기 전 원본 확인이 필요하다 |
| `[추정]` | 통계·계수·가정으로 예측한 값. 사실이 아니다 |
| `[정보부족]` | 확인하려 했으나 공개되지 않아 얻을 수 없는 값. **왜 못 얻는지 사유를 함께 적는다** |

> **`[정보부족]` 게이트** — 이 라벨을 붙이기 전에 스스로 묻는다.
> ① 지금 가진 도구로 3~4번 호출 안에 확인되는가 → 그러면 **지금 호출한다. 라벨을 붙이지 않는다.**
> ② 사용자가 서류 하나만 올리면 해결되는가 → `[검증필요]`로 두고 「확인해야 할 것」에 무엇을 올리면 되는지 적는다.
> ③ 어느 쪽도 아닌가 → 그때만 `[정보부족]`이다.
> **확인 가능한 것에 라벨을 붙이고 넘어가는 것**이 가장 흔한 실패다.

5. **법령·판례는 답변할 때마다 국가법령정보센터(law.go.kr) 원문으로 확인한다.** 이 문서의 법령 설명은 강사 메모이며, 원문을 확인하기 전까지 `[검증필요]`로 다룬다. 판례는 번호를 기억으로 쓰지 않는다 — 원문에서 찾은 것만 쓴다.
6. **원화 금액은 원 단위 풀 콤마로 쓴다.** 예: 240,000,000원. 표·라벨·그림에서도 큰 단위 한글 축약을 쓰지 않는다. 등기부·실거래가 원자료가 원이 아닌 단위(예: 1,000원 단위·10,000원 단위)면 원으로 환산하고 환산 사실을 적는다.
   - **비율을 쓸 때는 금액을 함께 적는다.** 낙찰가율·전세가율·LTV·수익률이 제목·요약·표 머리에 단독으로 나오면 읽는 사람이 크기를 가늠하지 못한다. `낙찰가율 71% (2,398,737,840원)` 형식으로 괄호에 환산 금액을 붙인다.
7. **단일 단서로 단정하지 않는다.** 서류끼리 어긋나면 어긋난다고 적고, 확인 방법을 함께 적는다.
8. **모든 답변의 끝에 아래 문구를 그대로 붙인다.**

> AI 분석은 검토 출발점입니다. 실제 입찰 전 등기부·매각물건명세서 원문과 전문가 확인이 필요합니다.

## 1. 입력 서류 인식

### 파일명 동의어

같은 문서가 오타·표기 차이로 다른 이름으로 올라올 수 있다. 아래는 모두 같은 문서로 본다.

| 문서 | 동의어 (부분 포함이면 매칭) |
|---|---|
| 법원 문건접수내역 | `문건접수`, `물건접수`, `법원문건`, `법원물건`, `송달내역` |

목록에 없는 새 변형을 만나면 분석에는 쓰되, 사용자에게 「파일명 변형 발견 — 동의어 추가 필요」라고 알려 준다.
문건접수내역이 파일명 오타로 빠지면 2절 선행 분석 전체가 빠진다. 그래서 파일명에 관대하게 대응한다.

### 임차인 서류는 원본까지 본다

현황조사서만으로 임차인을 판정하지 않는다. 보증금·확정일자·배당요구 여부·배당요구액은 **권리신고 및 배당요구 신청서 원본**에 정확히 적혀 있다.
스캔 PDF라 글자가 추출되지 않으면 페이지를 이미지로 보고 읽는다. 현황조사서의 「미상」을 그대로 둔 채 배당을 계산하지 않는다.

## 2. 0단계 — 문건접수·송달내역 선행 분석 (필수)

문건접수내역은 채무자·소유자의 저항 강도, 매각 지연·변경·취하 가능성, 경쟁 입찰자 존재를 드러내는 유일한 자료다. 다른 분석보다 먼저 본다.

- 있으면 → 가장 먼저, 꼼꼼히 분석한다.
- 없으면 → 분석은 계속하되 「문건접수내역 미확보 — 지연·취하·경쟁 신호 파악 제한」을 결과 맨 앞에 적는다.

### 해석 5원칙

1. 단일 단서로 결론을 단정하지 않는다.
2. 2~3가지 정황이 같은 방향을 가리킬 때만 그렇게 해석한다.
3. 먼저 **날짜순으로 정렬해 흐름(내러티브)을 재구성**한 뒤 해석한다. 소송위임장 → 보정서 → 당사자표시정정신청 → 경정결정 발송처럼 하나의 흐름으로 잇는다.
4. 확신이 낮으면 「가설 + 근거 + 확인 방법」 형식으로 쓴다. (예: 「상속 개시로 추정되나, 등기부 재발급으로 확인 가능」)
5. 사용자가 고칠 수 있도록 판단 근거를 적는다.

### 익명화 문자열

법원 문서는 「OOOO OOOOO OOO OOO」처럼 가려진다. 글자 수만 보고 법인명·기관명으로 단정하지 않는다. 긴 문자열은 「법무법인 OOO 담당변호사 OOO」 패턴일 가능성을 먼저 점검하고, 복수 가설을 열어 둔다.

### 체크리스트 — 4개 분류 20항목

| 분류 | 확인 항목 |
|---|---|
| 채무자·소유자 동향 | 소송위임장 제출·시점 / 의견서·이의신청·진술서 / 재평가·재감정 신청 / 매각불허가 신청·매각허가결정 취소 신청 / 즉시항고·재항고 이력 |
| 신청채권자 동향 | 보정명령·보정서 횟수 / 당사자표시정정신청·경정결정 발송 / 채권양도·승계집행문 정황 / 송달장소·송달영수인 신고 변경 / 소송대리인 선임 |
| 이해관계인 구성 | 근저당권자(순위·설정일·채권최고액) / 압류권자(국세·지방세·과태료 구분) / 교부청구권자(국민건강보험·국세·지방세 등) / 조세 법정기일 vs 근저당 설정일 / 임차인·점유자 현황 |
| 절차 진행 | 개시결정 송달 완료 여부(채무자·소유자 각각) / 매각기일·매각결정기일 통지 / 기일 변경·연기·취소 이력 / 경정·보정 후속 처리 / 최근 3개월 신규 문건 동향 |

### 산출

1. **시간순 타임라인 표** — 날짜 / 접수자 / 문건 내용 / 해석 (전환점은 굵게)
2. **채무자 저항 지수 (0~10점)**

| 점수 | 수준 | 기준 |
|---|---|---|
| 0~2 | 무대응 | 제출 서류 없음 |
| 3~5 | 일반 대응 | 보정서·의견서 수준 |
| 6~8 | 적극 방어 | 변호사 선임 + 재평가 신청 등 |
| 9~10 | 강력 저항 | 항고·소송 병행 |

3. **매각 지연 위험** — 예상 지연(개월), 근거가 된 신청·항고
4. **입찰자 관점 시사점 3~5줄** — 기일 변경·취하 가능성, 낙찰 후 매각불허가·항고로 잔금 일정이 밀릴 가능성, 명도 난이도 신호

> 저항 지수 6점 이상 또는 3개월 이상 지연 예상이면: 입찰보증금이 묶이는 기간, 잔금 대출 일정, 명도 기간을 보수적으로 잡으라고 종합 의견에 적는다.

당사자 표시가 바뀐 흔적이 있으면 **17절(당사자 변경)**을 함께 수행한다.

## 4. 서울 정비사업 인접 체크 (서울 물건 필수, 3절 직후)

물건이 서울이면 다른 분석 전에 정비사업(재개발·재건축 등) 구역 안인지, 가까운지를 먼저 본다.

### 조회 순서

1. 03단원 창고에 정비사업 테이블을 넣어 두었다면 그것을 먼저 조회한다.

| 구분 | 내용 |

| 순위 | 접수일 | 갑/을구 | 권리 종류 | 권리자(요약) | 금액 | 판정 |

## 7. 임차인 — 대항력·우선변제권·배당요구

| 요건 | 기준 | 효과 |
|---|---|---|
| 대항력 | 주택: 전입신고 + 점유 / 상가: 사업자등록 + 점유. 요건 구비 **다음 날 0시** 발생 | 말소기준보다 빠르면 낙찰자에게 대항 → 미배당 보증금 인수 |
| 우선변제권 | 대항요건 + 확정일자 | 확정일자 순위로 배당 |
| 최우선변제권 | 소액임차인 + 대항요건(경매개시결정 등기 전) + 배당요구 | 근저당보다 앞서 일정액 배당 (8절) |
| 배당요구 | 배당요구 종기까지 신청 | 안 하면 배당 0원. 대항력 임차인이면 전액 인수 |

- 전입일이 말소기준과 **같은 날**이면: 대항력은 다음 날 0시에 생기므로 같은 날 접수된 근저당보다 늦다. `[검증필요 — 원문 확인]`
- 주민등록상 세대주 전입만 있고 점유 사실이 불분명하면(가족 명의 전입, 소유자 가족 등) **허위 임차인 가능성**을 검토한다 → 13절 교차검증.
- 선순위 임차인이 배당요구를 했더라도 배당액이 보증금에 못 미치면 **그 차액은 낙찰자 인수**다. 예상 배당표(10절)로 반드시 계산한다.

### 7-1. 대항력 임차인 vs 선순위 조세 — 압류 등기일이 아니라 법정기일로 비교한다 (2026-10-02 신설 · 대표 지적·승인)

정본은 `auction-property-card` **STEP 4-C**. 여기서는 NPL 매입·유입 판단에 필요한 핵심만 둔다.

- **법리** (그 답변에서 korean-law MCP로 직접 조회 후 [확정]): 국세기본법 §35①3 — 법정기일 **전에** 대항요건+확정일자를 갖춘 임차보증금만 국세에 우선 / §35② — 법정기일 = 신고일(신고분)·납부고지서 발송일(고지분) / 국세징수법 §10·§31① — 압류는 독촉 기한 경과 **후** / 대법원 98다26002 — 임차인 기준일 T = 대항요건 다음날과 확정일자 중 늦은 날 / 대법원 97다11195 — 대항력 임차인의 미배분 잔액은 매수인 인수. 지방세도 같은 구조 — 지방세기본법 §71①3 가·나목(법정기일 = 신고일·납세고지서 발송일), 그 재산에 부과된 재산세등은 §71⑤·⑥로 별도 (조문 확인 2026-10-02, MST 290139 — 사용 시 재조회 후 [확정]).
- **판정**: ① 임차인 기준일 T **이후** 등기·접수된 조세 압류·교부청구는 간격과 관계없이 **법정기일 확인 전까지 임차인보다 선순위로 가정** ② 압류·교부청구일 − T **≤ 6개월이면 「고위험」** ③ 6개월 초과도 「안전」 판정 금지(압류는 법정기일보다 수년 뒤일 수 있다) ④ 금액·법정기일 미확인 조세는 **X [정보부족]** — 0원으로 채우지 않는다.
- **배당표·엑셀**: 「선순위 조세 X」 행을 임차인 앞에 둔다. 대항력 임차인이 있으면 X만큼 임차인 배당이 줄고 그 부족분이 낙찰자 인수가 되므로 **예상 낙찰가(C14)가 X만큼 눌린다** — 매입가 산정에 반영한다. 민감도 장에 **X = 0 / 인수 시작점 / 손익분기 X / 100,000,000원 / 200,000,000원 / 300,000,000원** 행을 넣는다.

## 8. 소액임차인 최우선변제 — 기준일은 담보물권 설정일 (필수 선행)

임차인이 하나라도 있으면 배당표·인수 금액을 계산하기 **전에** 이 절차를 먼저 밟는다. 상세 절차는 「최우선변제판정 스킬」을 호출한다.

> **판정 기준 시점 = 등기부 을구 최선순위 담보물권(근저당권 등) 설정일**
> 임차인 계약일·전입일·확정일자·경매개시일·오늘 날짜가 아니다. 현행 시행령 한도를 그대로 쓰면 틀린다.

근거: 주택임대차보호법 시행령은 개정할 때마다 「개정 전에 담보물권을 취득한 자에 대해서는 종전 규정에 따른다」는 취지의 부칙을 둔다. 상가건물 임대차보호법 시행령도 같은 구조다. `[검증필요 — 부칙 원문 확인]`

### 필수 절차

1. 을구에서 최선순위 근저당 **최초 설정일**을 확정한다. 채권최고액이 부기등기로 늘었어도 주등기 설정일이 기준이다. 을구에 담보물권이 없으면 「최우선변제판정 스킬」의 대체 기준을 따른다.
2. 그 날짜에 적용되는 시행령(주택/상가, 지역 구분)을 찾는다. 경계일 앞뒤는 하루 단위로 확인한다.
3. 금액을 판단에 쓰면 국가법령정보센터에서 시행령 원문(연혁 포함)을 직접 확인하고 조회일을 적는다. 확인 전에는 `[검증필요]`.
4. **개별 최우선변제액 = MIN(시행령 상한, 그 임차인의 실제 보증금).** 상한을 그대로 배당하지 않는다.
5. 배당요구 종기까지 배당요구하지 않은 임차인은 **0원**.
6. 총액이 주택가액(대지 포함, = 매각대금 − 집행비용)의 1/2을 넘는지 본다. 근린주택은 건축물대장 면적으로 주거·근생을 나눈 뒤 각각 1/2 한도를 본다.
7. 상가 환산보증금 = 보증금 + (월차임 × 100). 부가세는 빼고 계산한다.

|---|---|---|---|

## 9. 당해세 판정 (갑구 압류가 있으면 필수 선행)

당해세는 **그 부동산 자체에 부과된 세금**(재산세 등)으로, 배당에서 근저당보다 앞선다. 입찰자에게는 「대항력 있는 임차인이 배당을 덜 받아 → 낙찰자 인수액이 늘어나는」 경로로 영향을 준다. 어느 세목이 당해세인지는 국세기본법·지방세기본법 원문으로 확인한다. `[검증필요]`

> 주택 임차보증금과 당해세의 배당 순서에 관한 특례가 최근 개정으로 생겼다. 확정일자가 법정기일보다 빠른 주택 임차인의 배당에 영향을 줄 수 있으므로, 해당되면 원문을 확인하고 두 경우를 모두 계산한다. `[검증필요]`

### 어디서 찾나

| 구분 | 내용 | 당해세 판정 |
|---|---|---|
| 갑구 | 소유권, **압류**, 가압류, 경매개시결정 | 여기서 압류를 찾는다 |
| 을구 | 근저당, 전세권, 지상권 | 대상 아님 |

교부청구서·배당요구서가 문건접수내역에 있으면 그 세목·금액이 우선이다.

### 판정 방법

1. 압류권리자의 관할이 **물건 소재지의 과세관청과 일치**하는지 본다.

| 소재지 | 압류권리자 | 판정 |
|---|---|---|
| ○○구 ○○동 | ○○구청장 (같은 구) | 당해세 후보 |
| ○○면 ○○리 | ○○군수·○○면장 (같은 곳) | 당해세 후보 |
| ○○구 ○○동 | 다른 구의 구청장 | 당해세 아님 (다른 부동산·다른 세목) |
| ○○구 ○○동 | 광역자치단체장 | 세목 확인 전까지 일반 조세로 보되 교부청구서로 확인 |
| 어디든 | ○○세무서장 | 국세. 종합부동산세처럼 그 부동산에 부과된 세목이면 당해세. 세목 확인 필요 |

2. 세목을 확인하지 못했으면, **입찰자에게 보수적인 쪽(당해세로 보고 먼저 공제)**으로 배당을 계산하고 `[검증필요]`를 붙인다. 그래야 인수 금액을 적게 잡는 실수를 막는다.
3. 등기부 압류란에 권리자 옆·아래로 붙은 숫자는 **체납액을 천원 단위로 적은 것**으로 읽는다. 예: `1127` → 1,127,000원, `31120` → 31,120,000원. 다만 교부청구서 금액이 있으면 그것이 우선이고, 둘이 다르면 차이를 적는다. 이 숫자를 등록번호로 보고 사용자에게 금액을 되묻지 않는다.

### 출력 (배당표 전 필수)

```
[당해세 판정표]
```

| 등기 순번 | 압류권리자 | 관할 | 소재지 | 일치 | 표기 숫자 | 원 환산 | 세목 확인 | 판정 |
|---|---|---|---|---|---|---|---|---|
| 갑구 4 | ○○구청장 | ○○구 | ○○구 | 일치 | 3112 | 3,112,000원 | 교부청구서 없음 | 당해세 후보 `[검증필요]` |

압류가 없으면 「당해세 판정 대상 압류 없음」이라고 적는다.

### 표기 규칙 — 「소멸」로만 두지 않는다

- 권리 순위표·권리 사다리 그림: 당해세 압류는 회색 「소멸」이 아니라 **「당해세 · 0순위 배당」 배지(주황)와 금액**으로 표시한다. 소액임차인 최우선변제도 같은 방식(「최우선변제」 배지).
- 예상 배당표: 최우선변제 행 바로 다음(집행비용·최우선변제 다음, 최선순위 근저당 앞)에 별도 행.
- 배당 흐름(폭포) 그림: 당해세를 별도 주황 행으로 공제.
- **3자 일치 검산: 권리 사다리 배지 금액 = 배당표 당해세 행 = 배당 폭포 당해세 행.** 하나라도 다르면 원자료를 다시 본다. 계산에는 들어갔는데 그림·표에 「소멸」로 남아 있으면 반영되지 않은 것으로 취급한다.

1. **03단원 창고** `C:\AI\경매창고.duckdb`의 `실거래_*` 테이블 (예: 실거래_아파트_매매, 실거래_연립다세대_매매, 실거래_단독다가구_매매, 실거래_오피스텔_매매, 실거래_상업업무_매매 및 각 전월세). 적재일이 오래됐으면(예: 14일 이상) 최신분을 도구로 보완한다.
2. 창고에 없거나 범위 밖이면 **국토부 실거래가 조회 도구** 또는 국토교통부 실거래가 공개시스템.
3. 출처 표기: 「국토교통부 실거래가 (창고 적재 YYYY-MM-DD)」 또는 「국토교통부 실거래가 (조회 도구, 조회일 YYYY-MM-DD)」.

테이블·열 이름은 사용자가 창고를 만든 방식에 따라 다르다. 먼저 테이블 목록과 열 이름을 확인하고 쿼리를 쓴다.

> **출처 게이트** — 시세 표에 창고 적재일 또는 조회일이 없으면 「조회하지 않음」으로 본다. 앞 단계에서 만든 표를 이어받아 쓸 때도 마찬가지다. 창고에 표본이 쌓여 있는데 사례 2~3건으로 판단하는 사고가 여기서 난다.

### 표본 확장 사다리 — 한 단계만 보고 멈추지 않는다

같은 법정동에서 한 번 조회해 0건이면 「데이터 없음」, 3건이면 그대로 쓰는 것이 흔한 실패다. 표본을 넓히면 단가가 크게 바뀌는 일이 실제로 있다.

```
0단계  유형을 먼저 고정한다 (아파트는 단지·전용면적 / 단독과 다가구 구분 / 상업업무는 건축물 주용도)
       ★ 단독과 다가구는 대지 ㎡당 단가가 몇 배씩 다를 수 있다
         (강사 표본: 한 읍 지역에서 다가구가 단독의 약 3.8배 [추정]).
         섞으면 다가구 가치가 단독에 묻혀 과소평가된다.

1단계  같은 법정동(읍·면이면 리까지) + 같은 유형 + 최근 12개월
       → 10건 이상이면 채택
2단계  10건 미만이면 같은 시군구 + 같은 유형 + 건축년도 ±7년
       → 10건 이상이면 채택
3단계  그래도 10건 미만이면 같은 시군구 + 같은 유형 전체
       → 채택하되 [추정] + 「오래된 거래 포함」 표시, 12절 R-ONE 추세 병기
4단계  5건 미만이면 「표본 부족」이라고 쓴다.
       AI 추정시세·민간 시세로 채우지 않는다.
```

- **각 단계의 표본 수 · p25 · 중앙값 · p75를 전부 표로 낸다.** 어느 단계를 채택했는지 밝힌다. 분위를 함께 내야 감정가가 분포의 어디쯤인지 보인다.
- 아파트·오피스텔은 동일 단지·동일 전용면적이 원칙이다. 조건이 안 맞으면 유사 단지로 대체하지 말고 한계를 적는다.
- 단독·다가구·근린은 **대지 ㎡당 단가 중앙값**을 함께 낸다(감정가 검증용).
- 직거래·해제 거래·이례적 고액(재개발 지분 등)은 걸러 내고, 거른 건수를 적는다.

### 추정 감정가 — 감정가를 그대로 분모로 쓰지 않는다

법원 감정가는 **감정 시점과 평가 방식**에 따라 실거래 분포와 크게 벌어질 수 있다. 감정가를 낙찰가율의 분모로 그냥 쓰면 「감정가 대비 71%」 같은 비율이 통째로 흔들리고, 수익률 판단이 뒤집힌다.
**매 건 추정 감정가를 따로 만들어 법원 감정가와 나란히 놓는다.**

```
토지분 = 대지면적 × 실거래 대지 ㎡단가   (p25 / 중앙 / p75 세 벌)
건물분 = 연면적 × 건물 ㎡단가 × 잔가율
추정 감정가 = 토지분 + 건물분
```

| 입력 | 어디서 | 라벨 |
|---|---|---|
| 대지 ㎡단가 | 위 사다리에서 **채택한 단계**의 p25·중앙·p75 | `[확정]` |
| 건물 ㎡단가 | 사용자 입력. 강사 참고치를 쓰면 근거와 함께 | `[추정]` |
| 잔가율 | 준공년도·구조로 산정. 근거를 적는다 | `[추정]` |

**출력 표 (시세 절에 반드시 싣는다)**

| 구분 | 산식 | 하단(p25) | 중앙 | 상단(p75) |
|---|---|---|---|---|
| 토지분 | 대지면적 × 대지 ㎡단가 | | | |
| 건물분 | 연면적 × 건물 ㎡단가 × 잔가율 | | | |
| **추정 감정가** | 토지분 + 건물분 | | | |
| 법원 감정가 | 감정평가서 | | | |
| **감정가 ÷ 추정 감정가** | | | **__%** | |

- **법원 감정가가 추정 중앙의 90% 미만이면 빨간색으로 표시**하고, 「감정가가 실거래 분포보다 높다 — 낙찰가율이 실제보다 낮아 보인다」를 20절에 올린다.
- 낙찰가·수익률 민감도 표에는 **「법원 감정가 기준」과 「추정 중앙 기준」 두 행을 모두** 넣는다. 한쪽만 쓰면 같은 물건의 수익률이 몇 배로 달라 보인다.
- 감정평가서가 없는 예정물건은 추정 감정가만으로 진행하되, 실거래 대지단가와 교차검증했음을 적는다.
- 추정 감정가는 `[추정]`이다. 이것으로 감정평가서를 대체한다고 쓰지 않는다.

**공동주택 공시가격 교차검증 (2026-10-05)**: 아파트·연립·다세대는 「주택공시가격 ÷ 공시가격 현실화율」 행을 추정 감정가 표에 더한다(2026년 공동주택 69% — 정책브리핑 `[검증필요 — 쓸 때 재조회]`). 기준값은 실거래 기반으로 유지하고, 10% 이상 차이 나면 「확인해야 할 것」과 민감도 시나리오에 올린다. 오피스텔에는 쓰지 않는다.

### 읍·면 지역 주의

법정동 코드 10자리는 리(里)를 00으로 잘라 **읍·면 전체가 한 덩어리**가 되는 경우가 있다. 읍·면 물건은 법정동 코드가 아니라 **시군구 주소 문자열로 리까지 직접 거른다.** 시 지역의 ○○동은 문제없다.

### 쿼리 예시 (열 이름은 내 창고에 맞게 바꾼다)

```sql
-- 1단계: 같은 리 + 같은 유형 + 최근 12개월
SELECT 계약년월, 계약일, 주택유형, 건축년도, 연면적, 대지면적, 거래금액,
       ROUND(거래금액 / 대지면적) AS 대지단가, 거래유형
FROM 실거래_단독다가구_매매
WHERE 시군구 = '경기도 ○○시 ○○읍 ○○리' AND 주택유형 = '다가구'
  AND 대지면적 > 10
ORDER BY 계약년월 DESC, 계약일 DESC;

-- 2단계: 시군구 + 유형 + 건축년도 ±7년 분위
SELECT count(*) AS 표본,
       quantile_cont(거래금액 / 대지면적, 0.25) AS p25,
       median(거래금액 / 대지면적)              AS 중앙,
       quantile_cont(거래금액 / 대지면적, 0.75) AS p75
FROM 실거래_단독다가구_매매
WHERE 시군구 LIKE '경기도 ○○시%' AND 주택유형 = '다가구' AND 대지면적 > 10
  AND TRY_CAST(건축년도 AS INT) BETWEEN <준공년-7> AND <준공년+7>;
```

> 실거래 원자료의 거래금액이 10,000원 단위로 저장돼 있으면 원으로 환산(× 10,000)한 뒤 표에 쓴다.

### 낙찰가 예측으로 넘기는 법

> **낙찰가율은 04단원 지침 「2026-10-05 강사 DB 계수표」(저감률 × 회차 × 용도군)를 쓴다.** 기준 시나리오 회차는 그 표의 「누적 매각 확률」이 50%를 처음 넘는 회차(30%·20% 저감 모두 2회 유찰). 내 낙찰 기록이 같은 조건 30건 이상이면 다시 세어 나란히 적고 3%p 이상 다르면 내 실측을 쓴다.


```
[낙찰가 예측 근거]
채택 단계 : _단계 (표본 __건, 기간 ____.__ ~ ____.__)
실거래 p25 / 중앙 / p75 : ___________원 / ___________원 / ___________원
추정 감정가 중앙 : ___________원   |  법원 감정가 : ___________원 (추정 대비 __%)
예측 낙찰가 범위 : ___________원 ~ ___________원 [추정]
```

- 실거래 분포에서 낙찰가를 옮겨 올 때 쓰는 계수(낙찰가율 등)는 **`[추정]`**으로 표시하고, 계수의 **표본 수·지역·기간**을 함께 적는다. **이 값을 그대로 입찰가로 쓰지 말 것.** 입찰가 범위는 「입찰가산정 스킬」에서 사용자가 정한다.
- 감정가·AI 추정시세·민간 시세로 낙찰가를 예측하지 않는다.
- AI 추정시세는 「사용 안 함」이라고 적어서라도 산출물에 숫자를 싣지 않는다. 큰 숫자가 보이면 읽는 사람이 그 숫자를 기억한다.

## 12. R-ONE 추세 보조 (표본 부족 지역 전용)

**11절 사다리가 3단계 또는 4단계에서 멈췄을 때만** 한국부동산원 부동산통계(R-ONE, www.reb.or.kr/r-one)로 그 지역 시장의 **방향**을 본다. 1~2단계에서 10건 이상 채택됐으면 쓰지 않는다.

| 용도 | 통계 (월간, 매매가격지수 등) |
|---|---|
| 단독·다가구 | 매매가격지수 — 단독주택 |
| 연립·다세대 | 매매가격지수 — 연립/다세대 |
| 아파트 | 매매가격지수 — 아파트 |
| 오피스텔 | 오피스텔 매매가격지수 |
| 토지 | 지역별 지가변동률 |
| 상가·근생 | 상업용부동산 임대동향 — 지역별 임대가격지수(분기, 매매가가 아니라 임대가격 방향) |

통계표 ID는 개편 때 바뀌므로 매번 검색해서 찾는다.

- 출력: 지역 · 통계표 · 최신 기준월 · 최신값 · 전월 대비 · 12개월 전 대비를 한 줄 표로.
- **R-ONE 수치로 시세·낙찰가를 만들거나 보정하지 않는다.** 과거 실거래를 지수로 현재 시점 환산하는 것도 하지 않는다. 쓰는 곳은 두 가지뿐:
  1. 3단계처럼 오래된 거래가 섞인 표본을 채택할 때, 그 사이 시장이 오른 쪽인지 내린 쪽인지를 근거로 병기
  2. 4단계 「표본 부족」인데 12개월 전 대비가 하락이면 종합 정리에 「표본 부족 + 하락 지역」 위험으로 올림
- 출처: 「한국부동산원 R-ONE (통계표·항목, 기준월, 조회일)」. 조회한 값은 `[확정]`, 해석은 `[추정]`.
- R-ONE 방향과 실거래 방향이 반대면 실거래를 따르고 불일치를 한 줄 적는다.

## 13. 전월세 실거래가 — 임차권 교차검증과 임대 가정

매매 실거래가가 낙찰가 예측의 기초라면, 전월세 실거래가는 **임차인 보증금이 진짜인지, 소액임차인에 해당하는지, 낙찰 후 임대가 되는지**의 기초다.

### 필수 조회 케이스 (하나라도 해당하면 생략 불가)

| 케이스 | 목적 |
|---|---|
| 임차인이 있는 물건 | 보증금 적정성 → 허위·과다 임차 판정 |
| 대항력 있는 임차인 | 시장 보증금 대비 인수 부담 판단 |
| 소액임차인 판정 필요 | 그 지역 보증금 분포 확인 |
| **낙찰 후 임대 계획이 있는 물건** | **임대수입 가정의 근거 (아래 「임대 가정」 절)** |
| 주거용 전세가율 판정 | 깡통전세 여부, 재매각·대출 여건 |

조회 순서는 11절과 같다(창고 → 조회 도구). 상업용 전월세는 국토부 실거래 공개 범위가 제한적이므로 한계로 적는다.

### 원칙

- 대상: 동일 단지 + 동일 전용면적(아파트·오피스텔). 조건 미달이면 추정·보간·유사 단지 대체 금지 → 「데이터 없음」.
- 기간: 최근 6개월 기준, 부족하면 11절 사다리처럼 넓히되 넓힌 사실을 적는다.
- **거래 유형 분리 필수**: 전세(월세 0) / 보증부월세(보증금>0, 월세>0) / 순수월세(보증금≈0). 섞어서 평균 내지 않는다.
- **신규·갱신 구분**: 신규 계약이 시세 판단의 주 근거. 갱신 계약은 인상률 상한 때문에 시세와 괴리될 수 있어 참고만.
- 해제 거래 제외.

### 출력 예시 (금액은 원 단위)

**전세**

| 계약일 | 전용면적(m²) | 층 | 보증금 | 신규/갱신 |
|---|---|---|---|---|
| 2026-03-10 | 84.97 | 14층 | 550,000,000원 | 신규 |

**보증부월세**

| 계약일 | 전용면적(m²) | 층 | 보증금 | 월세 | 신규/갱신 |
|---|---|---|---|---|---|
| 2026-02-20 | 84.97 | 6층 | 100,000,000원 | 1,800,000원 | 신규 |

통계 요약: 유형별 건수·평균·최고·최저, 전세가율 = 평균 전세 보증금 ÷ 매매 평균가 × 100, 시장 임대수익률 = (월세 × 12) ÷ (매매가 − 보증금) × 100.

### 임대 가정은 실거래 중앙값으로 잡는다 (낙찰 후 임대 계획이 있으면 필수)

「이 정도는 받겠지」로 월세를 잡으면 수익률이 통째로 틀어진다. **사례 두세 건을 평균 내는 것도 위험하다** — 그 사례가 분포의 위쪽이면 임대수입이 과대평가되고, 대출 상환 여력이 있는 것처럼 보인다.

```
환산 월세      = 월세 + (보증금 × 전환율 ÷ 12)      전환율은 사용자 입력
환산 월세 m²단가 = 환산 월세 ÷ 전용면적
```

- **면적대·연식별로 나눠 중앙값(median)을 쓴다.** 평균도, 최고도 아니다.
- 대상 물건의 호실별 면적에 그 m²단가를 곱해 예상 임대수입을 낸다.
- **임대수입을 쓴 표·슬라이드에는 근거가 된 월세 실거래 표와 출처(창고 적재일 또는 조회일)를 함께 싣는다.** 표가 없으면 그 수익률은 근거 없는 숫자다.
- 실거래가 없으면 「데이터 없음」으로 두고 임대수익 계산을 생략한다. 감으로 채우지 않는다.

| 계약일 | 전용면적(m²) | 층 | 보증금 | 월세 | 환산 월세 | m²단가 | 신규/갱신 |
|---|---|---|---|---|---|---|---|

### 연계 규칙

1. **체크리스트 1~4번과 교차검증** — 임차인 신고 보증금 vs 동일 단지·동일 면적 신규 전세 평균.
   - 신고 보증금이 신규 평균의 **120% 초과**면 「허위·과다 보증금 의심」 `[추정]` → 전입세대열람·현황조사서·임대차계약서 원본 확인을 확인 목록에 올린다. (120%는 강사 기준 `[추정]`)
   - 소유자 가족·친척 명의 임차, 경매개시 직전 전입·증액도 의심 신호다.
2. **소액임차인 판정** — 8절 기준일의 한도와 실거래 보증금 분포를 함께 본다. 시장 보증금이 한도 근처면 소액 여부가 배당을 크게 바꾼다.
3. **임대수익 가치** (상가·오피스텔·다가구) — 수익환원 가치 = 연 순임대수입 ÷ 환원율. 순임대수입은 위 중앙값 기준으로 낸다. 환원율은 사용자 입력 또는 근거와 함께 `[추정]`. 거래사례 기반 가치와 비교해 낮은 쪽을 보수적 기준으로 삼는다.
4. **전세가율과 낙찰 후 여건** (주거용) `[추정 — 강사 기준]`

| 전세가율 | 판정 | 입찰자 관점 |
|---|---|---|
| 70% 미만 | 안전 | 일반 |
| 70~80% | 주의 | 재매각 시 매수 수요 약화 가능 |
| 80~90% | 위험 | 재매각·임대 지연 가능, 보유 기간 보수적으로 |
| 90% 이상 | 고위험 | 깡통전세 지역, 한계 고지 필수 |

### 표본 충실도 (전월세)

| 신규 거래 건수 | 처리 |
|---|---|
| 5건 이상 | 신규 중앙값으로 시세 판단 |
| 3~4건 | 신규 중앙값 + 갱신 참고, 한계 고지 |
| 1~2건 | 갱신 포함 전체, 판단 신중 |
| 갱신만 있음 | 「갱신 인상률 상한으로 시세 왜곡 가능」 한계 고지 |
| 0건 | 「데이터 없음」 — 소액·대항력·임대수익 판단에 한계 고지 |

### 금지

- 조회 없이 「이 지역 전세는 보통 ~」 식 추정
- 전세·보증부월세·순수월세 혼합 평균
- 갱신 거래만으로 시세 단정
- **사례 두세 건의 평균으로 임대 가정 잡기**
- 금지 소스(KB시세·호갱노노·아실·네이버 호가) 인용
- 허위·과다 의심을 발견하고도 한계 고지 생략

## 14. 근린생활시설 1종/2종 판정 (상가·근생 물건)

구분상가·꼬마빌딩·주상복합 상가부·근생 현황 주택은 **건축물대장상 1종/2종 구분**이 임대 가능 업종과 재매각 가치에 직접 영향을 준다. 아파트·다가구·다세대·토지는 적용하지 않는다.

### 절차

1. **건축물대장 확인** — 표제부 주용도, 층별 용도, 전유부(구분상가는 호실 용도).
2. **1종/2종 식별** — 「제1종근린생활시설」 / 「제2종근린생활시설」 / 종 미표기 / 복합(층·호실별로 분리 판정).
3. **종 미표기면 세부 업종으로 판정** `[검증필요 — 건축법 시행령 별표 원문으로 면적 기준 확인]`

| 세부 업종 | 분류 |
|---|---|
| 소매점(일정 면적 미만), 휴게음식점·제과점(일정 면적 미만), 이용원·미용원·목욕장·세탁소, 의원·치과·한의원, 소규모 체육도장 | 1종 |
| 일반 사무소·부동산중개사무소(일정 면적 미만), 일반음식점, 학원·교습소(일정 면적 미만), 제조업소·수리점, 노래연습장, 고시원, 안마시술소 | 2종 |
| 유흥주점, 숙박, 병원급 의료시설, 일정 면적 이상 사무소(업무시설) | 근생 아님 |

   - 사무소·사무실·오피스·중개사무소는 같은 용도로 취급한다. 면적 기준을 넘으면 업무시설이다. 구분상가는 **호실 전유면적**으로 본다.

4. **2종 전환 가능성** (1종만 가능한 물건)

| 확인 항목 | 위치 | 기준 |
|---|---|---|
| 부설주차장 | 건축물대장 | 2종 전환 시 법정 주차대수 충족 가능한지 |
| 정화조 용량 | 건축물대장 | 일반음식점 등 오수발생량 대비 |
| 교육환경보호구역 | 토지이용계획확인원 | 학교 인근 제한 업종 |
| 용도지역 | 토지이용계획확인원 | 아래 표 |
| 업종 제한 특약 | 관리규약·분양계약 | 동일 건물 업종 독점 |

| 용도지역 | 1종 | 2종 |
|---|---|---|
| 제1종전용주거 | 제한 | 제한 |
| 제2종전용주거 · 제1종일반주거 | 가능 | 일부 제한 |
| 제2종·제3종일반주거 | 가능 | 대부분 가능 |
| 준주거 · 상업 · 준공업 | 가능 | 가능 |

(용도지역별 허용 여부는 국토계획법 시행령·지자체 조례로 원문 확인 `[검증필요]`)

### 입지별 할인율 — 낙찰 후 임대·재매각 가치 참고 `[추정 — 강사 기준]`

| 입지 | 1종만 가능할 때 가치 할인 참고 |
|---|---|
| 역세권·유흥상권 | 15~20% |
| 대학가·학원가 | 10~15% |
| 일반 상업지 | 10~15% |
| 오피스 밀집지 | 10~15% (주된 수요인 사무소가 2종이라 수요 자체가 막힘) |
| 아파트 단지 내 상가 | 0~5% |
| 주거지 이면도로 | 0~5% |

조정 요소(±): 현 임차인이 2종 업종으로 불법 영업 중(+5%, 시정명령·이행강제금) / 1종 고단가 업종 장기 임차(−5%) / 주차 법정 대비 120% 이상(−3%) / 80% 미만(+3%) / 교육환경보호구역 저촉(+5%) / 주변에 2종 가능 대체 물건 다수(+3%).

- 이 할인율은 **실거래 기반 가치에 대한 참고 조정**이다. 입찰가에 몇 %를 반영할지는 사용자가 정한다. 기계적으로 적용하지 않는다.

### 출력

```
[근생 1종/2종 판정]
건축물대장 용도 / 세부 업종 / 현재 임차 업종 / 용도지역 / 주차 / 정화조 / 교육환경보호구역 / 업종제한 특약
→ 현재 분류 : ___  |  2종 전환 가능성 : 가능 / 불가 / 검증필요
→ 입지 : ___  |  참고 할인율 : __% [추정]  |  조정 요소 : ___
```

대장만으로 판정이 모호하면: 「최종 판정은 관할 구청 건축과 확인 필요, 2종 전환은 추가 인허가가 필요할 수 있음, 교육환경보호구역은 교육지원청 확인 필요」를 적는다.

금지: 대장 확인 없이 「2종 가능」 가정 / 민간 사이트 용도 표기 인용 / 현재 임차 업종이 2종이라고 건물 용도를 2종으로 역추정(불법 영업일 수 있음) / 추상적 표현(「임차수요 많음」)으로 판정 생략.

## 15. 역세권 실측

역명만 적고 거리를 생략하지 않는다. 좌표(지오코딩)를 구해 가장 가까운 역까지 **직선거리와 도보경로 거리**를 잰다(카카오맵·브이월드 등 지도 도구). 등급: 500m 이내 초역세권 / 1,000m 이내 역세권 / 1,500m 이내 준역세권 `[추정 — 강사 기준]`. 창고에 철도역 좌표 테이블이 있으면 그것으로 먼저 잰다.

**「인근에 지하철 있음 — 거리 미측정 `[정보부족]`」으로 넘어가지 않는다.** 지오코딩 1번 + 도보경로 3번이면 끝나는 일이므로 `[정보부족]` 게이트(0절 원칙 4)를 통과하지 못한다.

## 17. 당사자 표시 변경 체크

문건접수·송달내역에서 소유자·채무자 표시가 중간에 바뀌었으면 **한 가지 원인으로 단정하지 않는다.** 여러 원인이 겹칠 수 있다.

### 용어부터 구분

| 용어 | 의미 | 실질 변동 |
|---|---|---|
| 경정결정 | 서류상 오기·누락 정정 | 없음 |
| 당사자표시정정 | 표시 오류 정정 | 없음 |
| 승계집행문 부여 | 상속·합병 등 실질 승계 | **있음** |
| 당사자변경 | 당사자 실질 교체 | **있음** |
| 소유권이전등기 | 소유자 실제 교체 | **있음** |

같은 날 「경정결정정본 발송」이 있으면 우선 단순 정정으로 본다. 등기촉탁·이전등기 문건, 승계집행문 문건 중 2개 이상이 없으면 「실질 변동 없음」을 기본으로 둔다.
소송위임장 제출 뒤 송달처가 바뀌었으면 「대리인(변호사) 송달」 가능성을 먼저 본다.

### 4가지 유형 (단독 또는 병행)

| 유형 | 표시 패턴 | 신호 | 입찰자 관점 위험 |
|---|---|---|---|
| A 상속 | 「망 홍OO의 상속인 OOO 외 N인」 | 송달간주 반복, 송달영수인 신고, 당사자표시정정신청, 경정결정 | 상속인 전원 송달·상속포기로 지연, 명도 상대가 여럿 |

## 19. 낙찰 후 자금과 세금

### 19-1. 대출 가능액부터 판정한다 — 80%를 기본값으로 두지 않는다

「낙찰가의 80%를 대출받는다」는 가정은 규제지역·차주 유형에 따라 **0원**이 될 수 있다.
**수익률을 계산하기 전에 대출 가능 여부부터 판정한다.** 순서를 바꾸면 자기자본이 실제의 몇 분의 일로 잡혀 수익률이 통째로 뒤집힌다.

| 차주 · 물건 | 판정 | 근거 |
|---|---|---|
| 법인 + 규제지역 주택 | **0원** | 은행업감독규정 〈별표 6〉 — 규제지역 주택 구입 목적 기업자금대출 신규 취급 제한 `[검증필요 — 별표 원문 확인]` |
| 개인 + 규제지역 + 주택 보유 세대 | 축소 또는 0원 | 감독규정·정부 대책에 따라 다름 `[검증필요 — 원문 확인]` |
| 비규제지역 또는 비주택(상가·토지 등) | 시장 조건으로 가정 | 금리는 16절 ECOS 참고치, 실제 한도는 금융기관 상담 |

- **규제지역(조정대상지역·투기과열지구) 지정 여부는 매번 최신 고시로 확인한다.** 수시로 바뀐다. `[검증필요]`
- 감독규정·대책의 구체적 수치(LTV %, 한도 구간, 전입 의무 기간)는 **원문을 확인하기 전까지 적지 않는다.** 언론 보도만 본 상태면 `[검증필요]`로 두고 숫자를 비운다.
- **대출이 0원이면 DSCR(상환능력 비율)을 쓰지 않는다.** 「해당 없음」으로 적고, 무차입 기준 현금수익률(연 순현금 ÷ 총투입)만 낸다. 0원인데 DSCR을 계산하면 분모가 없어 의미 없는 숫자가 나온다.
- 자금 시나리오는 **하나로 고정**한다. 보수·중립·공격 세 벌을 나란히 두면 어느 것이 기준인지 흐려진다. 민감도가 필요하면 금리·공실률 한 변수만 흔든다.

```
[자금 요약]
총투입        : ___________원   (10절 정의와 같은 값)
대출 판정      : 가능 ___________원 (LTV __%, ___________원) / 불가 0원 — 근거: ___
자기자본       : ___________원
연 순현금      : ___________원   (13절 임대 가정 기준, 임대 계획이 없으면 「해당 없음」)
현금수익률     : __.__% (___________원)
DSCR          : ____ / 대출 0원이면 「해당 없음」
```

### 19-2. 세금 — 수치를 이 문서에서 가져오지 않는다

세율·한도·공제액은 해마다 바뀐다. **이 문서에 수치를 적지 않는다.** 답변할 때마다 국가법령정보센터 원문(지방세법·지방세특례제한법·종합부동산세법·소득세법·법인세법)을 확인하고, 확인한 값만 `[확정]`으로 쓴다. 계산 자체는 세금 계산 스킬이나 위택스·홈택스 모의계산으로 한다.

| 세목 | 경매 취득에서 볼 점 |
|---|---|
| 취득세 | 경매 낙찰도 유상 취득. 과세표준은 낙찰가(취득가). 주택 수·조정대상지역·개인/법인에 따라 세율이 크게 달라짐. **주택과 근생이 섞인 건물은 시가표준액 비율로 안분**해 주택 부분에만 주택 세율 `[검증필요 — 시행령 원문]`. 지방교육세·농어촌특별세 포함 |
| 재산세 | 매년 6월 1일 소유자에게 과세. 낙찰 잔금일이 6월 1일 전이면 그해부터. 공시가격 기준이며 **낙찰가와 무관**. 주택·근생 혼합은 면적 비율로 안분(취득세와 기준이 다름) `[검증필요]` |
| 종합부동산세 | 6월 1일 기준 보유 주택·토지 공시가격 합산. 개인과 법인의 공제·세율 차이가 큼. 조정대상지역 지정 여부는 최신 고시로 확인 |
| 양도소득세·법인세 | 보유 기간·주택 수에 따라 달라짐. **출구 시점을 사용자가 정했을 때만 계산**, 아니면 「미산출 — 출구 시점 지정 필요」 |

- 공시가격은 부동산 공시가격 알리미(realtyprice.kr) 또는 공시가격 조회 도구로 조회한다. 조회하지 못했을 때만 감정가 비율로 가정하고, 가정했다고 적는다.
- 경매 취득 건물분 부가가치세, 체납 관리비(공용부분) 승계 여부도 확인 목록에 올린다. `[검증필요]`
